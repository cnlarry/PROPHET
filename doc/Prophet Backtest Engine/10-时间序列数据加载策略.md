# Prophet 回测引擎数据加载策略优化方案

## 问题描述

回测引擎需要支持使用`FEARGREED()`和`FUNDINGRATE()`时间序列函数的策略，但并非所有策略都使用这些函数。

**核心矛盾**：
- 客户端（C#/Python）无法预先知道策略是否使用这些函数
- 如果总是加载这些数据，对不需要的策略造成不必要的等待
- 如果不加载，使用这些函数的策略会失败

## 方案对比

### 方案1：客户端预解析DSL ❌

**实现方式**：
```csharp
// 客户端预解析DSL代码
bool usesFearGreed = dslCode.Contains("FEARGREED()");
bool usesFundingRate = dslCode.Contains("FUNDINGRATE()");

if (usesFearGreed) {
    await LoadFearGreedDataAsync();
}
if (usesFundingRate) {
    await LoadFundingRateDataAsync();
}
```

**优点**：
- 实现简单
- 不需要修改引擎

**缺点**：
- ❌ 字符串匹配不可靠（注释、字符串字面量等）
- ❌ 客户端需要理解DSL语法
- ❌ 违反单一职责原则
- ❌ 维护成本高（DSL变化需要同步客户端）

**结论**：不推荐

---

### 方案2：引擎提供数据需求查询接口 ⭐⭐

**实现方式**：

C++ API新增函数：
```cpp
// 查询引擎需要哪些时间序列数据
PROPHET_API int Prophet_GetRequiredTimeSeries(
    void* engine,
    bool* needs_feargreed,
    bool* needs_fundingrate
);
```

客户端调用：
```csharp
var engine = ProphetCoreEngine.Prophet_CreateEngine(dslCode, paramsJson);

// 查询数据需求
bool needsFearGreed = false;
bool needsFundingRate = false;
ProphetCoreEngine.Prophet_GetRequiredTimeSeries(
    engine, ref needsFearGreed, ref needsFundingRate
);

// 按需加载
if (needsFearGreed) {
    await LoadFearGreedDataAsync();
}
if (needsFundingRate) {
    await LoadFundingRateDataAsync();
}
```

**优点**：
- ✅ 引擎负责DSL解析，客户端只需查询结果
- ✅ 精确判断，不会误判
- ✅ 符合单一职责原则
- ✅ 易于扩展（新增时间序列函数）

**缺点**：
- ⚠️ 需要修改C++引擎
- ⚠️ 需要在DSL解析时记录函数依赖
- ⚠️ 中等开发工作量

**实现要点**：
1. 引擎在解析DSL时，记录使用的函数
2. 提供C API查询接口
3. 客户端根据查询结果按需加载

**结论**：推荐作为长期方案

---

### 方案3：延迟加载/回调机制 ⭐

**实现方式**：

引擎在需要数据时回调客户端：
```cpp
// 引擎提供回调接口
typedef void (*TimeSeriesDataCallback)(
    const char* data_type,  // "FEARGREED" or "FUNDINGRATE"
    void* user_data
);

PROPHET_API void Prophet_SetTimeSeriesCallback(
    void* engine,
    TimeSeriesDataCallback callback,
    void* user_data
);
```

客户端实现：
```csharp
void OnTimeSeriesDataNeeded(string dataType, IntPtr userData) {
    if (dataType == "FEARGREED") {
        LoadFearGreedDataAsync().GetAwaiter().GetResult();
    }
}

ProphetCoreEngine.Prophet_SetTimeSeriesCallback(
    engine, OnTimeSeriesDataNeeded, IntPtr.Zero
);
```

**优点**：
- ✅ 最灵活，按需加载
- ✅ 数据可以动态更新

**缺点**：
- ❌ 实现复杂（回调、线程同步）
- ❌ C++/C#互操作复杂
- ❌ 异步处理困难
- ❌ 高开发和维护成本

**结论**：不推荐（过度设计）

### 方案4：总是加载，快速失败（当前方案）⭐⭐⭐

**实现方式**：

```csharp
public class TimeSeriesApiClient
{
    public TimeSeriesApiClient(HttpClient httpClient, string baseUrl)
    {
        _httpClient = httpClient;
        _httpClient.Timeout = TimeSpan.FromSeconds(5); // 快速超时
        _baseUrl = baseUrl;
    }
}

private async Task LoadTimeSeriesDataAsync()
{
    try
    {
        // 并行加载，减少等待时间
        var fearGreedTask = _timeSeriesClient.GetFearGreedDataAsync(365);
        var fundingRateTask = _timeSeriesClient.GetFundingRateDataAsync(_config.Symbol, 720);
        
        await Task.WhenAll(fearGreedTask, fundingRateTask);
        
        // 注入数据...
    }
    catch (Exception ex)
    {
        // 静默失败，继续回测
        Console.WriteLine($"⚠️ 时间序列数据加载失败: {ex.Message}");
    }
}
```

**优点**：
- ✅ 实现简单，无需修改引擎
- ✅ 对使用这些函数的策略100%支持
- ✅ 快速失败（5秒超时）
- ✅ 并行加载优化性能
- ✅ 静默失败不影响回测

**缺点**：
- ⚠️ 对不需要数据的策略有5-10秒延迟
- ⚠️ 需要Prophet.API运行（或快速失败）

**性能分析**：
- **API可用**：2个请求并行，总时间 ~500ms
- **API不可用**：2个请求超时，总时间 ~5秒

**适用场景**：
- 开发和测试阶段（Prophet.API通常在运行）
- 大部分策略使用时间序列函数
- 用户可以接受5秒的启动延迟

**结论**：推荐作为短期方案

// 并行加载优化
private async Task LoadTimeSeriesDataAsync()
{
    Console.WriteLine("📊 开始加载时间序列数据（并行）...");

            }

    }));
    
    await Task.WhenAll(tasks);

### 长期（v2.0）：方案2 - 数据需求查询

**实施步骤**：

#### 1. C++引擎修改

在`prophet::core::Engine`中记录函数依赖：

```cpp
class Engine {
private:
    bool uses_feargreed_ = false;
    bool uses_fundingrate_ = false;
    
public:
    Engine(const std::string& dsl_code, const ParamsMap& params) {
        // 解析DSL时，检测函数使用
        ParseDSL(dsl_code);
        AnalyzeFunctionDependencies();
    }
    
    void AnalyzeFunctionDependencies() {
        // 遍历AST，检查是否使用了FEARGREED()或FUNDINGRATE()
        for (const auto& node : ast_nodes_) {
            if (node->type == NodeType::FUNCTION_CALL) {
                if (node->name == "FEARGREED") {
                    uses_feargreed_ = true;
                }
                if (node->name == "FUNDINGRATE") {
                    uses_fundingrate_ = true;
                }
            }
        }
    }
    
    bool UsesFearGreed() const { return uses_feargreed_; }
    bool UsesFundingRate() const { return uses_fundingrate_; }
};
```

#### 2. C API新增接口

```cpp
PROPHET_API int Prophet_GetRequiredTimeSeries(
    void* engine,
    bool* needs_feargreed,
    bool* needs_fundingrate
) {
    if (!engine || !needs_feargreed || !needs_fundingrate) {
        return -1;
    }
    
    auto* eng = static_cast<prophet::core::Engine*>(engine);
    *needs_feargreed = eng->UsesFearGreed();
    *needs_fundingrate = eng->UsesFundingRate();
    
    return 0;
}
```

#### 3. C#客户端调用

```csharp
public void Initialize(string dslCode, BacktestConfig config)
{
    // 1. 创建引擎
    _engineHandle = ProphetCoreEngine.Prophet_CreateEngine(dslCode, paramsJson);
    
    // 2. 查询数据需求
    bool needsFearGreed = false;
    bool needsFundingRate = false;
    ProphetCoreEngine.Prophet_GetRequiredTimeSeries(
        _engineHandle, ref needsFearGreed, ref needsFundingRate
    );
    
    // 3. 按需加载（异步转同步）
    LoadTimeSeriesDataAsync(needsFearGreed, needsFundingRate)
        .GetAwaiter().GetResult();
}

private async Task LoadTimeSeriesDataAsync(bool loadFearGreed, bool loadFundingRate)
{
    var tasks = new List<Task>();
    
    if (loadFearGreed) {
        Console.WriteLine("📊 策略需要FEARGREED数据，开始加载...");
        tasks.Add(LoadAndInjectFearGreedAsync());
    }
    
    if (loadFundingRate) {
        Console.WriteLine("📊 策略需要FUNDINGRATE数据，开始加载...");
        tasks.Add(LoadAndInjectFundingRateAsync());
    }
    
    if (tasks.Count == 0) {
        Console.WriteLine("✅ 策略不需要时间序列数据，跳过加载");
        return;
    }
    
    await Task.WhenAll(tasks);
}
```

#### 4. Python客户端同步

```python
# 创建引擎
engine = Core.Engine(dsl_code, params)

# 查询数据需求
needs_feargreed, needs_fundingrate = engine.get_required_timeseries()

if needs_feargreed:

    print("📊 策略需要FUNDINGRATE数据，开始加载...")
    engine.set_funding_rate_series(timestamps, values)
```

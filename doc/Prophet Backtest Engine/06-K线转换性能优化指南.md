# Prophet 回测引擎 - K线转换性能优化指南

- **文档名称**: K线转换性能优化指南
- **版本**: 1.0
- **创建日期**: 2025-11-19
- **目标**: 将K线转换性能提升20-100倍

## 🎯 背景

Prophet 量化交易平台的核心引擎（Prophet.Core，C++实现）接收**1分钟（1m）K线数据**，然后根据策略需求转换成其他时间框架（5m, 15m, 1h, 4h, 1d等）。

### 当前性能瓶颈

在回测场景下，需要频繁转换大量K线数据，当前实现存在以下问题：

1. **重复计算**：每次策略评估都重新转换K线数据，没有缓存机制
2. **串行处理**：K线转换是单线程逐根处理，未利用多核CPU
3. **标量计算**：未使用SIMD指令进行向量化加速

### 性能影响示例

**测试场景**：回测1年数据，策略同时使用5m、15m、1h三个时间框架

| 优化前 | 优化后（预期）| 提升倍数 |
|-------|--------------|---------|
| 300秒 | 3-15秒       | 20-100倍 |

## 🚀 优化方案

### 1️⃣ **LRU缓存机制**

#### 设计原理

使用LRU（Least Recently Used）缓存策略，避免重复转换相同的K线数据。

#### 缓存键设计

```cpp
struct CacheKey {
    std::string symbol;          // 交易对（如 BTCUSDT）
    std::string source_interval; // 源时间框架（固定为1m）
    std::string target_interval; // 目标时间框架（如5m, 15m）
    int64_t start_time;          // 开始时间戳
    int64_t end_time;            // 结束时间戳
    
    // 哈希函数
    size_t hash() const {
        return std::hash<std::string>()(symbol + source_interval + target_interval) 
             ^ (start_time << 1) ^ (end_time << 2);
    }
};
```

#### 缓存结构

```cpp
class KlineCache {
private:
    struct CacheValue {
        std::vector<Candlestick> candles;
        std::chrono::steady_clock::time_point last_access;
    };
    
    std::unordered_map<CacheKey, CacheValue> _cache;
    std::list<CacheKey> _lru_list;  // LRU链表
    std::mutex _mutex;              // 线程安全
    size_t _max_size = 100;         // 最大缓存条数
    
public:
    // 获取缓存（命中则返回，未命中返回nullopt）
    std::optional<std::vector<Candlestick>> get(const CacheKey& key);
    
    // 写入缓存
    void put(const CacheKey& key, const std::vector<Candlestick>& value);
    
    // 清空缓存
    void clear();
    
    // 获取缓存命中率
    double hit_rate() const;
};
```

#### 增量更新优化

当新的1m K线数据到达时，只需追加转换，不需要重算全部：

```cpp
// 示例：从1m转换到5m
// 缓存中已有：2024-01-01 00:00 ~ 2024-01-01 23:55 (288根5m K线)
// 新数据：    2024-01-02 00:00 ~ 2024-01-02 00:04 (5根1m K线)
// 优化：只转换新增的5根1m -> 1根5m，追加到缓存

std::vector<Candlestick> convert_with_cache(
    const std::vector<Candlestick>& new_1m_candles,
    const std::string& target_interval)
{
    // 1. 检查缓存
    auto cached = cache.get(key);
    if (cached.has_value()) {
        // 2. 只转换新增部分
        auto new_candles = convert_incremental(new_1m_candles, target_interval);
        cached->insert(cached->end(), new_candles.begin(), new_candles.end());
        return *cached;
    }
    
    // 3. 缓存未命中，全量转换
    auto result = convert_full(new_1m_candles, target_interval);
    cache.put(key, result);
    return result;
}
```

### 2️⃣ **SIMD向量化加速**

#### 目标操作

K线转换的核心计算：

```cpp
// 从N根1m K线 -> 1根5m K线
Candlestick convert_5m(const std::vector<Candlestick>& minute_candles) {
    Candlestick result;
    result.open = minute_candles[0].open;           // 第一根的open
    result.high = max(minute_candles.high);         // 批量max ✅ 可向量化
    result.low = min(minute_candles.low);           // 批量min ✅ 可向量化
    result.close = minute_candles.back().close;     // 最后一根的close
    result.volume = sum(minute_candles.volume);     // 批量sum ✅ 可向量化
    return result;
}
```

#### AVX2向量化实现

使用AVX2指令集，一次处理8个double：

```cpp
#include <immintrin.h>

// 向量化求max（处理8个double）
double vectorized_max(const double* data, size_t count) {
    __m256d max_vec = _mm256_set1_pd(-INFINITY);
    
    // 主循环：8个一组处理
    size_t i = 0;
    for (; i + 8 <= count; i += 8) {
        __m256d vals = _mm256_loadu_pd(&data[i]);
        max_vec = _mm256_max_pd(max_vec, vals);
    }
    
    // 水平归约（8个 -> 1个）
    double max_vals[4];
    _mm256_storeu_pd(max_vals, max_vec);
    double result = std::max({max_vals[0], max_vals[1], max_vals[2], max_vals[3]});
    
    // 处理剩余元素（标量）
    for (; i < count; ++i) {
        result = std::max(result, data[i]);
    }
    
    return result;
}

// 完整的向量化转换
Candlestick convert_5m_vectorized(const std::vector<Candlestick>& candles) {
    const size_t N = candles.size();
    
    // 提取high和low数组
    std::vector<double> highs(N), lows(N), volumes(N);
    for (size_t i = 0; i < N; ++i) {
        highs[i] = candles[i].high;
        lows[i] = candles[i].low;
        volumes[i] = candles[i].volume;
    }
    
    Candlestick result;
    result.open = candles[0].open;
    result.high = vectorized_max(highs.data(), N);      // ✅ 向量化
    result.low = vectorized_min(lows.data(), N);        // ✅ 向量化
    result.close = candles.back().close;
    result.volume = vectorized_sum(volumes.data(), N);  // ✅ 向量化
    
    return result;
}
```

#### 编译器自动向量化

如果不想手写SIMD，可以使用编译器自动向量化：

```cpp
// 编译选项：-O3 -march=native -ffast-math
double simple_max(const double* data, size_t count) {
    double result = -INFINITY;
    #pragma omp simd reduction(max:result)  // OpenMP SIMD指令
    for (size_t i = 0; i < count; ++i) {
        result = std::max(result, data[i]);
    }
    return result;
}
```

### 3️⃣ **多线程并行转换**

#### 场景

策略同时需要多个时间框架（如5m、15m、1h）时，并行转换：

```cpp
#include <thread>
#include <future>

std::map<std::string, std::vector<Candlestick>> convert_multiple_timeframes(
    const std::vector<Candlestick>& minute_candles,
    const std::vector<std::string>& target_intervals)
{
    std::map<std::string, std::vector<Candlestick>> results;
    std::vector<std::future<std::pair<std::string, std::vector<Candlestick>>>> futures;
    
    // 为每个时间框架启动一个异步任务
    for (const auto& interval : target_intervals) {
        futures.push_back(std::async(std::launch::async, [&, interval]() {
            auto candles = convert_timeframe(minute_candles, interval);
            return std::make_pair(interval, candles);
        }));
    }
    
    // 等待所有任务完成
    for (auto& future : futures) {
        auto [interval, candles] = future.get();
        results[interval] = candles;
    }
    
    return results;
}
```

#### 线程池优化

避免频繁创建销毁线程：

```cpp
class ThreadPool {
private:
    std::vector<std::thread> workers;
    std::queue<std::function<void()>> tasks;
    std::mutex queue_mutex;
    std::condition_variable condition;
    bool stop = false;
    
public:
    ThreadPool(size_t threads = std::thread::hardware_concurrency()) {
        for (size_t i = 0; i < threads; ++i) {
            workers.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    {
                        std::unique_lock<std::mutex> lock(this->queue_mutex);
                        this->condition.wait(lock, [this] { 
                            return this->stop || !this->tasks.empty(); 
                        });
                        if (this->stop && this->tasks.empty())
                            return;
                        task = std::move(this->tasks.front());
                        this->tasks.pop();
                    }
                    task();
                }
            });
        }
    }
    
    template<class F>
    auto enqueue(F&& f) -> std::future<decltype(f())> {
        using return_type = decltype(f());
        auto task = std::make_shared<std::packaged_task<return_type()>>(std::forward<F>(f));
        std::future<return_type> res = task->get_future();
        {
            std::unique_lock<std::mutex> lock(queue_mutex);
            tasks.emplace([task](){ (*task)(); });
        }
        condition.notify_one();
        return res;
    }
    
    ~ThreadPool() {
        {
            std::unique_lock<std::mutex> lock(queue_mutex);
            stop = true;
        }
        condition.notify_all();
        for (std::thread &worker : workers)
            worker.join();
    }
};

// 使用线程池
ThreadPool pool(4);  // 4个工作线程
auto future1 = pool.enqueue([&]{ return convert_timeframe(candles, "5m"); });
auto future2 = pool.enqueue([&]{ return convert_timeframe(candles, "15m"); });
auto future3 = pool.enqueue([&]{ return convert_timeframe(candles, "1h"); });
```

#### Task 2.4: 实现回测引擎核心

    - [ ] **进度更新（含剩余时间估算）**
    - [ ] 结果生成（内存操作）
    - [ ] **回测结束后统一落库**（批量写入）
  - [ ] `EstimateRemainingTime()` - 剩余时间估算算法
  - [ ] `CollectAllSignals()` - 收集所有信号事件
- [ ] 集成测试：端到端回测流程
- [ ] 性能测试：验证批量落库性能提升

**文件**:
```csharp
// Prophet.Client/Backtest/Engine/BacktestEngine.cs
```

**关键点**:
- ✅ 回测过程中不访问数据库，仅内存操作
- ✅ 进度更新包含剩余时间估算
- ✅ 收集所有信号（含未成交原因）

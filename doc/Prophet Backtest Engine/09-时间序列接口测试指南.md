# Prophet.API 时间序列接口测试指南

## 概述

本文档提供Prophet.API时间序列数据接口的测试步骤和示例。

## 已实现的接口

### 1. 恐惧与贪婪指数接口

**接口地址**: `GET /api/timeseries/feargreed`

**查询参数**:
- `days` (int, 可选): 加载天数，默认365天，最多3650天

**请求示例**:
```bash
# 获取默认365天的数据
curl -X GET "http://localhost:5299/api/timeseries/feargreed" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# 获取最近90天的数据
curl -X GET "http://localhost:5299/api/timeseries/feargreed?days=90" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

**返回示例**:
```json
[
  {
    "date": "2025-11-20T00:00:00",
    "value": 45,
    "classification": "Fear"
  },
  {
    "date": "2025-11-19T00:00:00",
    "value": 42,
    "classification": "Fear"
  }
]
```

### 2. 资金费率接口

**接口地址**: `GET /api/timeseries/fundingrate`

**查询参数**:
- `symbol` (string, 必填): 交易对，如 "ETHUSDT"
- `count` (int, 可选): 加载条数，默认720条，最多10000条

**请求示例**:
```bash
# 获取ETHUSDT的默认720条数据
curl -X GET "http://localhost:5299/api/timeseries/fundingrate?symbol=ETHUSDT" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"

# 获取BTCUSDT的最近100条数据
curl -X GET "http://localhost:5299/api/timeseries/fundingrate?symbol=BTCUSDT&count=100" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN"
```

**返回示例**:
```json
[
  {
    "symbol": "ETHUSDT",
    "calc_time": 1732121943000,
    "calc_time_str": "2025-11-20T14:32:23",
    "funding_interval_hours": 8,
    "last_funding_rate": 0.0001234567
  },
  {
    "symbol": "ETHUSDT",
    "calc_time": 1732089943000,
    "calc_time_str": "2025-11-20T05:32:23",
    "funding_interval_hours": 8,
    "last_funding_rate": 0.0001123456
  }
]
```

## 端到端测试流程

### 步骤1: 启动Prophet.API

```bash
cd Prophet.API
dotnet run
```

### 步骤2: 获取JWT Token

使用认证接口登录获取Token：

```bash
curl -X POST "http://localhost:5299/api/auth/login" \
  -H "Content-Type: application/json" \
  -d '{
    "username": "your_username",
    "password": "your_password"
  }'
```

响应中会包含JWT Token。

### 步骤3: 测试恐惧与贪婪指数接口

```bash
export JWT_TOKEN="your_jwt_token_here"

curl -X GET "http://localhost:5299/api/timeseries/feargreed?days=30" \
  -H "Authorization: Bearer $JWT_TOKEN" \
  | jq .
```

### 步骤4: 测试资金费率接口

```bash
curl -X GET "http://localhost:5299/api/timeseries/fundingrate?symbol=ETHUSDT&count=100" \
  -H "Authorization: Bearer $JWT_TOKEN" \
  | jq .
```

### 步骤5: 测试客户端集成

1. 启动Prophet.Client客户端
2. 登录并进入回测模块
3. 选择一个使用FEARGREED或FUNDINGRATE的策略
4. 点击"开始回测"
5. 观察终端日志，应该看到：
   ```
   📊 开始加载时间序列数据...
   📥 从API加载恐惧与贪婪指数数据（最近365天）...
   ✅ 已加载 365 条恐惧与贪婪指数数据
   ✅ 已注入 365 条恐惧与贪婪指数数据
   ```

## 数据库准备

### 检查数据表是否存在

```sql
-- 检查feargreed表
SELECT COUNT(*) FROM feargreed;

-- 检查fundingrate表
SELECT COUNT(*) FROM fundingrate;

-- 查看最近的恐惧与贪婪指数
SELECT * FROM feargreed ORDER BY `date` DESC LIMIT 10;

-- 查看某个交易对的最近资金费率
SELECT * FROM fundingrate 
WHERE symbol = 'ETHUSDT' 
ORDER BY calc_time DESC 
LIMIT 10;
```

### 如果表不存在，创建表

使用提供的SQL脚本创建表：

```bash
# 创建feargreed表
mysql -u root -p prophet < "SQL Scripts/feargreed.sql"

# 创建fundingrate表
mysql -u root -p prophet < "SQL Scripts/fundingrate.sql"
```

## 常见问题

### Q1: 返回空数组

**原因**: 数据库中没有数据

**解决**: 确保已经填充了历史数据到`feargreed`和`fundingrate`表

### Q2: 401 Unauthorized

**原因**: JWT Token无效或过期

**解决**: 重新登录获取新的Token

### Q3: 500 Internal Server Error

**原因**: 数据库连接失败或表不存在

**解决**: 
1. 检查`appsettings.json`中的数据库连接字符串
2. 确保数据库表已创建
3. 查看Prophet.API终端日志中的错误详情

## 架构实现

### 分层结构

```
TimeSeriesController (API层)
    ↓
TimeSeriesService (业务逻辑层)
    ↓
TimeSeriesRepository (数据访问层)
    ↓
MySQL Database (feargreed, fundingrate表)
```

### 依赖注入

在`Program.cs`中已注册：

```csharp
builder.Services.AddScoped<ITimeSeriesRepository, TimeSeriesRepository>();
builder.Services.AddScoped<ITimeSeriesService, TimeSeriesService>();
```

### 认证授权

- 接口需要JWT认证（`[Authorize]`特性）
- 健康检查接口允许匿名访问（`[AllowAnonymous]`）

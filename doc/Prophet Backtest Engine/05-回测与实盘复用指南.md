## 🎯 设计原则

### 核心原则：依赖抽象，而非实现

```
策略逻辑 → 抽象接口 → 具体实现
                ↓
        ┌──────┴──────┐
        │             │
    回测实现      实盘实现
```

**关键点**:
1. 策略逻辑只依赖接口
2. 回测和实盘都实现相同接口
3. 通过依赖注入切换实现

### 1. StrategyRunner（策略执行器）

**复用率**: 100%

```csharp
public class StrategyRunner
{
    // ✅ 回测和实盘完全相同
    public Signal Evaluate(List<Candlestick> candles, Strategy strategy)
    {
        // 1. 调用Prophet.Core计算指标
        var indicators = ProphetCore.CalculateIndicators(candles, strategy.Indicators);
        
        // 2. 评估DSL规则
        var signal = ProphetCore.EvaluateDSL(candles, indicators, strategy.Rules);
        
        // 3. 计算止盈止损
        signal.TakeProfit = CalculateTakeProfit(signal, strategy);
        signal.StopLoss = CalculateStopLoss(signal, strategy);
        
        return signal;
    }
}
```

**为什么100%复用**:
- 策略逻辑不关心数据来源
- 只关心"当前K线数据 + 历史数据窗口"
- 回测和实盘的数据格式完全相同

### 2. RiskManager（风险管理）

**复用率**: 100%

```csharp
public class RiskManager
{
    // ✅ 回测和实盘完全相同
    public decimal CalculateTakeProfit(Signal signal, Strategy strategy)
    {
        // 基于ATR或固定百分比
        var atr = signal.Indicators["ATR"];
        return signal.EntryPrice + atr * strategy.TakeProfitMultiplier;
    }
    
    public decimal CalculateStopLoss(Signal signal, Strategy strategy)
    {
        var atr = signal.Indicators["ATR"];
        return signal.EntryPrice - atr * strategy.StopLossMultiplier;
    }
    
    public decimal CalculatePositionSize(
        decimal equity, 
        decimal riskPercentage, 
        decimal stopLossDistance)
    {
        // 固定风险百分比
        var riskAmount = equity * riskPercentage;
        return riskAmount / stopLossDistance;
    }
}
```

### 3. PerformanceAnalyzer（绩效分析）

**复用率**: 90%

```csharp
public class PerformanceAnalyzer : IPerformanceAnalyzer
{
    // ✅ 核心算法100%相同
    public void Update(Candlestick candle, decimal currentEquity)
    {
        // 记录权益曲线
        _equityCurve.Add(new EquityPoint
        {
            Time = candle.Time,
            Equity = currentEquity
        });
        
        // 更新峰值
        if (currentEquity > _peakEquity)
        {
            _peakEquity = currentEquity;
        }
        
        // 计算回撤
        var drawdown = (_peakEquity - currentEquity) / _peakEquity;
        if (drawdown > MaxDrawdown)
        {
            MaxDrawdown = drawdown;
        }
    }
    
    // ✅ 统计算法完全相同
    public BacktestResult GenerateReport()
    {
        return new BacktestResult
        {
            TotalReturn = CalculateTotalReturn(),
            MaxDrawdown = MaxDrawdown,
            SharpeRatio = CalculateSharpeRatio(),
            WinRate = CalculateWinRate()
        };
    }
}
```

**差异点**:
- 回测：存储到本地SQLite
- 实盘：存储到云端MySQL或实时监控

### 2. IOrderManager（订单管理）

#### 接口定义（100%相同）

```csharp
public interface IOrderManager
{
    void Initialize(decimal initialCapital);
    Order? ProcessSignal(Signal signal, Candlestick candle);
    decimal CurrentEquity { get; }
    event EventHandler<OrderFilledEventArgs> OrderFilled;
}
```

#### 回测实现

```csharp
public class SimulatedOrderManager : IOrderManager
{
    public Order? ProcessSignal(Signal signal, Candlestick candle)
    {
        // 模拟滑点
        var executionPrice = ApplySlippage(candle.Close, signal.Action);
        
        // 立即成交
        var order = new Order
        {
            Status = OrderStatus.Filled,
            OpenPrice = executionPrice,
            OpenTime = candle.Time
        };
        
        // 触发事件
        OrderFilled?.Invoke(this, new OrderFilledEventArgs { Order = order });
        
        return order;
    }
}
```

#### 实盘实现

```csharp
public class ExchangeOrderManager : IOrderManager
{
    public Order? ProcessSignal(Signal signal, Candlestick candle)
    {
        // 创建订单
        var order = new Order
        {
            Status = OrderStatus.Pending,
            OpenPrice = candle.Close  // 预期价格
        };
        
        // 异步提交到交易所
        _ = Task.Run(async () =>
        {
            var result = await _exchange.PlaceOrderAsync(order);
            order.Status = OrderStatus.Filled;
            order.OpenPrice = result.FilledPrice;
            order.OpenTime = result.FilledTime;
            
            // 触发事件
            OrderFilled?.Invoke(this, new OrderFilledEventArgs { Order = order });
        });
        
        return order;
    }
}
```

## 🎨 统一的执行引擎

### ExecutionEngine（统一接口）

```csharp
public abstract class ExecutionEngine
{
    protected readonly IDataFeed _dataFeed;
    protected readonly IOrderManager _orderManager;
    protected readonly IPerformanceAnalyzer _performanceAnalyzer;
    protected readonly StrategyRunner _strategyRunner;  // ✅ 共享
    
    // ✅ 核心逻辑相同
    protected virtual void ProcessCandle(
        Candlestick candle, 
        List<Candlestick> history,
        Strategy strategy)
    {
        // 1. 调用策略
        var signal = _strategyRunner.Evaluate(history, strategy);
        
        // 2. 处理订单
        if (signal.Action != SignalAction.None)
        {
            var order = _orderManager.ProcessSignal(signal, candle);
        }
        
        // 3. 更新绩效
        _performanceAnalyzer.Update(candle, _orderManager.CurrentEquity);
    }
}
```

### 回测引擎

```csharp
public class BacktestEngine : ExecutionEngine
{
    public async Task<BacktestResult> RunAsync(Strategy strategy, BacktestConfig config)
    {
        // 预加载数据
        var candles = await _dataFeed.LoadCandlesAsync(...);
        
        // 循环遍历（回测特有）
        for (int i = 0; i < candles.Count; i++)
        {
            var history = candles.Take(i + 1).ToList();
            ProcessCandle(candles[i], history, strategy);  // ✅ 复用核心逻辑
        }
        
        return _performanceAnalyzer.GenerateReport();
    }
}
```

### 实盘引擎

```csharp
public class LiveEngine : ExecutionEngine
{
    public async Task RunAsync(Strategy strategy)
    {
        // 加载初始历史数据
        var history = await _dataFeed.LoadCandlesAsync(...);
        
        // 流式处理（实盘特有）
        await foreach (var candle in _dataFeed.StreamCandlesAsync())
        {
            history.Add(candle);
            ProcessCandle(candle, history, strategy);  // ✅ 复用核心逻辑
        }
    }
}
```

## 🎯 设计目标

### 核心目标

1. **本地化回测**: 完全在客户端运行，无需服务器依赖
2. **可视化体验**: 买卖信号直接标注在K线图上
3. **高性能**: 支持100+次参数优化回测
4. **代码复用**: 回测与实盘共享核心逻辑（90%+复用率）
5. **易于扩展**: 模块化设计，支持插件化

### 非功能性需求

- **性能**: 单次回测 < 3秒（1年1分钟数据）
- **并发**: 支持4线程并行回测
- **内存**: 单次回测 < 500MB
- **稳定性**: 99.9% 成功率

## 🔧 核心模块设计

### 1. BacktestEngine (回测引擎核心)

**职责**: 协调整个回测流程

**接口设计**:

```csharp
public interface IBacktestEngine
{
    // 运行回测
    Task<BacktestResult> RunAsync(
        Strategy strategy,
        BacktestConfig config,
        CancellationToken cancellationToken
    );
    
    // 批量回测（参数优化）
    Task<List<BacktestResult>> RunBatchAsync(
        Strategy strategy,
        List<BacktestConfig> configs,
        ParallelOptions options
    );
    
    // 事件
    event EventHandler<BacktestProgressEventArgs> ProgressChanged;
    event EventHandler<SignalGeneratedEventArgs> SignalGenerated;
    event EventHandler<OrderExecutedEventArgs> OrderExecuted;
}
```

**实现类**:

```csharp
public class BacktestEngine : IBacktestEngine
{
    private readonly IDataFeed _dataFeed;
    private readonly IOrderManager _orderManager;
    private readonly IPerformanceAnalyzer _performanceAnalyzer;
    private readonly StrategyRunner _strategyRunner;
    
    public BacktestEngine(
        IDataFeed dataFeed,
        IOrderManager orderManager,
        IPerformanceAnalyzer performanceAnalyzer)
    {
        _dataFeed = dataFeed;
        _orderManager = orderManager;
        _performanceAnalyzer = performanceAnalyzer;
        _strategyRunner = new StrategyRunner();
    }
    
    public async Task<BacktestResult> RunAsync(
        Strategy strategy,
        BacktestConfig config,
        CancellationToken cancellationToken)
    {
        // 1. 预加载数据
        var candles = await _dataFeed.LoadCandlesAsync(
            config.StartDate, 
            config.EndDate
        );
        
        // 2. 初始化
        _orderManager.Initialize(config.InitialCapital);
        _performanceAnalyzer.Initialize(config);
        
        // 3. 逐根K线回测
        for (int i = 0; i < candles.Count; i++)
        {
            if (cancellationToken.IsCancellationRequested)
                break;
            
            var candle = candles[i];
            
            // 3.1 获取当前时刻的历史数据窗口
            var windowData = candles.Take(i + 1).ToList();
            
            // 3.2 调用策略引擎（Prophet.Core）
            var signal = _strategyRunner.Evaluate(windowData, strategy);
            
            // 3.3 处理信号
            if (signal.Action != SignalAction.None)
            {
                // 触发信号事件（UI绘制）
                SignalGenerated?.Invoke(this, new SignalGeneratedEventArgs
                {
                    Signal = signal,
                    Candle = candle,
                    CandleIndex = i
                });
                
                // 执行订单
                var order = _orderManager.ProcessSignal(signal, candle);
                if (order != null)
                {
                    OrderExecuted?.Invoke(this, new OrderExecutedEventArgs
                    {
                        Order = order
                    });
                }
            }
            
            // 3.4 更新绩效统计
            _performanceAnalyzer.Update(candle, _orderManager.CurrentEquity);
            
            // 3.5 更新进度
            ProgressChanged?.Invoke(this, new BacktestProgressEventArgs
            {
                Current = i + 1,
                Total = candles.Count,
                Percentage = (i + 1) * 100.0 / candles.Count,
                CurrentTime = candle.Time
            });
        }
        
        // 4. 生成报告
        return _performanceAnalyzer.GenerateReport();
    }
}
```

```csharp
public class HistoricalDataFeed : IDataFeed

    private readonly IDataRepository _repository;

    public IAsyncEnumerable<Candlestick> StreamCandlesAsync(
```

**实盘实现**:

```csharp
public class RealTimeDataFeed : IDataFeed
{
    private readonly IWebSocketClient _wsClient;
    
    public Task<List<Candlestick>> LoadCandlesAsync(
        DateTime startDate, 
        DateTime endDate)
    {
        throw new NotSupportedException("实盘模式不支持历史加载");
    }
    
    public async IAsyncEnumerable<Candlestick> StreamCandlesAsync(
        [EnumeratorCancellation] CancellationToken cancellationToken)
    {
        await foreach (var candle in _wsClient.SubscribeCandlesAsync(cancellationToken))
        {
            yield return candle;
        }
    }
}
```

### 3. IOrderManager (订单管理接口 - 可复用)

**职责**: 处理买卖信号，管理仓位

**接口设计**:

```csharp
public interface IOrderManager
{
    // 初始化
    void Initialize(decimal initialCapital);
    
    // 处理信号
    Order? ProcessSignal(Signal signal, Candlestick candle);
    
    // 当前状态
    decimal CurrentEquity { get; }
    decimal CurrentPosition { get; }
    List<Order> OpenOrders { get; }
    List<Order> ClosedOrders { get; }
    
    // 订单事件
    event EventHandler<OrderFilledEventArgs> OrderFilled;
}
```

**回测实现**:

```csharp
public class SimulatedOrderManager : IOrderManager
{
    public Order? ProcessSignal(Signal signal, Candlestick candle)
    {
        // 模拟订单成交
        var executionPrice = ApplySlippage(candle.Close, signal.Action);
        var order = CreateOrder(signal, candle, executionPrice);
        
        // 立即成交
        order.Status = OrderStatus.Filled;
        order.FilledTime = candle.Time;
        
        return order;
    }
    
    private decimal ApplySlippage(decimal price, SignalAction action)
    {
        // 模拟滑点 0.05%
        var slippage = price * 0.0005m;
        return action == SignalAction.Buy 
            ? price + slippage 
            : price - slippage;
    }
}
```

**实盘实现**:

```csharp
public class ExchangeOrderManager : IOrderManager
{
    private readonly IExchangeClient _exchangeClient;
    
    public Order? ProcessSignal(Signal signal, Candlestick candle)
    {
        // 真实下单到交易所
        var order = CreateOrder(signal, candle, candle.Close);
        
        // 异步等待成交
        _ = Task.Run(async () =>
        {
            var result = await _exchangeClient.PlaceOrderAsync(order);
            order.Status = result.Status;
            order.FilledPrice = result.FilledPrice;
            order.FilledTime = result.FilledTime;
            
            OrderFilled?.Invoke(this, new OrderFilledEventArgs { Order = order });
        });
        
        return order;
    }
}
```

### 4. IPerformanceAnalyzer (绩效分析接口 - 可复用)

**职责**: 计算回测统计指标

**接口设计**:

```csharp
public interface IPerformanceAnalyzer
{
    void Initialize(BacktestConfig config);
    
    void Update(Candlestick candle, decimal currentEquity);
    
    BacktestResult GenerateReport();
    
    // 实时指标
    decimal CurrentReturn { get; }
    decimal CurrentDrawdown { get; }
    decimal MaxDrawdown { get; }
}
```

**通用实现** (回测和实盘都可用):

```csharp
public class PerformanceAnalyzer : IPerformanceAnalyzer
{
    private decimal _initialCapital;
    private decimal _peakEquity;
    private List<EquityPoint> _equityCurve = new();
    
    public void Update(Candlestick candle, decimal currentEquity)
    {
        // 记录权益曲线
        _equityCurve.Add(new EquityPoint
        {
            Time = candle.Time,
            Equity = currentEquity
        });
        
        // 更新峰值
        if (currentEquity > _peakEquity)
        {
            _peakEquity = currentEquity;
        }
        
        // 计算当前回撤
        var drawdown = (_peakEquity - currentEquity) / _peakEquity;
        if (drawdown > MaxDrawdown)
        {
            MaxDrawdown = drawdown;
        }
    }
    
    public BacktestResult GenerateReport()
    {
        var finalEquity = _equityCurve.LastOrDefault()?.Equity ?? _initialCapital;
        
        return new BacktestResult
        {
            InitialCapital = _initialCapital,
            FinalEquity = finalEquity,
            TotalReturn = (finalEquity - _initialCapital) / _initialCapital,
            MaxDrawdown = MaxDrawdown,
            SharpeRatio = CalculateSharpeRatio(),
            WinRate = CalculateWinRate(),
            EquityCurve = _equityCurve
        };
    }
}
```

## 🎨 UI集成设计

### K线图信号标注

```csharp
// 在CandlestickChart中添加信号标注
public class CandlestickChart : UserControl
{
    private List<SignalMarker> _signals = new();
    
    public void AddSignal(SignalAction action, int candleIndex, decimal price)
    {
        _signals.Add(new SignalMarker
        {
            Action = action,
            CandleIndex = candleIndex,
            Price = price,
            Icon = action == SignalAction.Buy ? "📈" : "📉"
        });
        
        DrawChart(); // 重新绘制
    }
    
    private void DrawSignals()
    {
        foreach (var signal in _signals)
        {
            if (!IsInVisibleRange(signal.CandleIndex))
                continue;
            
            var (x, y) = GetCanvasPosition(signal.CandleIndex, signal.Price);
            
            // 绘制箭头
            if (signal.Action == SignalAction.Buy)
            {
                DrawUpArrow(x, y, Colors.Green);
            }
            else
            {
                DrawDownArrow(x, y, Colors.Red);
            }
            
            // 鼠标悬停显示详情
            AddTooltip(x, y, $"{signal.Action} @ {signal.Price:N2}");
        }
    }
}
```

```csharp
// 批量写入（每1000条）
public class BacktestDataWriter
{
    private const int BATCH_SIZE = 1000;
    private List<Order> _orderBuffer = new();
    
    public void AddOrder(Order order)
    {
        _orderBuffer.Add(order);
        
        if (_orderBuffer.Count >= BATCH_SIZE)
        {
            FlushOrders();
        }
    }
    
    private void FlushOrders()
    {
        _db.BulkInsert(_orderBuffer);
        _orderBuffer.Clear();
    }
```

## 1. 概述

本文档提供了从旧版本 Prophet DSL 迁移到最新版本的指导，帮助用户顺利升级策略。

## 2. 从旧版本迁移

### 2.1 v3.1.x 到 v3.2.x

主要变更：
- 引入信号函数系统
- 函数语法优化

### 2.2 v3.2.x 到 v3.3.x

主要变更：
- 指标系统重构
- 变量系统增强

## 3. 语法变更

### 3.1 指标引用语法

**旧语法：**
```javascript
MA(5m, 20).value
MACD(5m, 12, 26, 9).histogram
```

**新语法：**
```javascript
$(5m).MA(20).value
$(5m).MACD(12, 26, 9).histogram
```

### 3.2 信号函数语法

**旧语法（已废弃）：**
```javascript
// ⚠️ 注意：这是旧版本语法，已不再支持
IF condition1 AND condition2 THEN BUY
```

**新语法：**
```javascript
ALL {
    condition1,
    condition2
} = BUY
```

## 4. 功能替换

### 4.1 函数组替换

以下函数组已被移除，请使用对应的指标系统：

| 旧函数组 | 新指标 |
|---------|--------|
| MA | MA |
| MACD | MACD |
| RSI | RSI |
| BOLL | BOLL |

### 4.2 数据访问优化

使用新的 KLINE 函数替代旧的数据访问方式：

**旧方式：**
```javascript
CLOSE(5m)
HIGH(5m, 1)
```

**新方式：**
```javascript
KLINE(5m).close()
KLINE(5m).high(-1)
```

## 5. 最佳实践

### 5.1 逐步迁移

建议逐步迁移策略，先迁移简单的部分，再处理复杂的逻辑。

### 5.2 测试验证

迁移完成后，务必进行充分的测试验证，确保策略行为一致。

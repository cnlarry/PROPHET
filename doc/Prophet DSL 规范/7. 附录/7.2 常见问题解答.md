## 1. 语法问题

### 1.1 变量声明报错

**问题：** 变量声明时提示语法错误。

**解决方案：** 确保变量名以 @ 符号开头，并且在正确的作用域内声明。

```javascript
// 正确写法
@price = KLINE(5m).close();

// 错误写法
price = KLINE(5m).close();  // 缺少 @ 前缀
```

### 1.2 信号函数语法错误

**问题：** 信号函数使用时报错。

**解决方案：** 检查信号函数的语法格式，确保条件表达式正确。

```javascript
// 正确写法
ALL {
    $(5m).RSI().value > 70;
    $(5m).MACD().histogram > 0;
} = SELL;

// 错误写法
ALL {  // 缺少条件表达式
} = SELL;
```

## 2. 指标使用

### 2.1 指标不返回数据

**问题：** 指标函数返回 NaN 或无数据。

**解决方案：** 
1. 检查指标参数配置
2. 确认时间周期设置正确
3. 验证数据源完整性

### 2.2 指标引用语法

**问题：** 指标引用语法不熟悉。

**解决方案：** 使用标准语法格式：

```javascript
$(TIMEFRAME).INDICATOR(PARAMS).FIELD(offset)
```

例如：
```javascript
$(5m).RSI(14).value
$(1h).MACD(12,26,9).histogram(-1)
```

## 3. 性能优化

### 3.1 策略执行缓慢

**问题：** 策略执行速度慢。

**解决方案：**
1. 使用变量缓存重复计算的结果
2. 减少历史数据访问深度
3. 优化条件判断顺序

### 3.2 内存占用过高

**问题：** 策略运行时内存占用高。

**解决方案：**
1. 避免声明不必要的变量
2. 及时释放临时变量
3. 简化复杂表达式

## 4. 调试技巧

### 4.1 如何输出调试信息

**解决方案：** 使用 PRINT 函数输出变量值：

```javascript
@price = KLINE(5m).close();
PRINT("当前价格:", @price);
```

### 4.2 条件不触发

**解决方案：**
1. 分步验证每个条件
2. 输出中间变量值
3. 检查逻辑运算符优先级

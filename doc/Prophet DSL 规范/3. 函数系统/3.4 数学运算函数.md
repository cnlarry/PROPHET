## 概述

数学函数提供基本的数学运算能力，所有函数遵循标准数学定义。这些函数：

- ✅ **不需要** `timeframe` 参数
- ✅ 使用标准函数调用语法：`FUNCTION(param1, param2, ...)`
- ✅ 可以与其他DSL函数组合使用
- ✅ 支持嵌套调用

**函数特点：**
- 纯数学运算，不涉及K线数据
- 遵循标准数学定义
- 支持参数验证和错误处理
- 性能优化，计算高效

## 基础运算函数

### ABS - 绝对值

**语法：** `ABS(x)`

**说明：** 返回数值的绝对值。

**参数：**
- `x`: 任意实数

**返回值：** 非负实数

**示例：**
```javascript
ABS(-5.5)               // 返回 5.5
ABS(10.3)               // 返回 10.3
ABS(0)                  // 返回 0

// 与指标结合使用
ABS($(5m).MACD().macd)    // MACD值的绝对值
ABS($(5m).MACD().histogram) // 柱状图的绝对值

// 计算价差的绝对值
price_diff = KLINE(5m).close(0) - KLINE(5m).open(0)
abs_diff = ABS(price_diff)
```

**应用场景：**
- 计算价差幅度（不考虑方向）
- 指标偏离度计算
- 距离测量
- 误差计算

---

### ROUND - 四舍五入

**语法：** `ROUND(value, precision)`

**参数：**
- `value`: 要处理的数值
- `precision`: 保留的小数位数（整数）

**返回值：** 四舍五入后的数值

**示例：**
```javascript
ROUND(3.14159, 2)          // 返回 3.14
ROUND(3.14159, 0)          // 返回 3
ROUND(3.14159, 4)          // 返回 3.1416

ROUND($(5m).RSI().value, 0)  // RSI值四舍五入到整数
ROUND(KLINE(5m).close(0), 2) // 价格保留2位小数

// 百分比格式化
pct = CHANGE(5m).close(10).pct
ROUND(pct, 2)              // 返回如 2.35%
```

**应用场景：**
- 数值显示格式化
- 价格精度处理
- 百分比展示
- 减少浮点误差

---

### CEIL - 向上取整

**语法：** `CEIL(x)`

**说明：** 返回大于或等于给定数值的最小整数。

**参数：**
- `x`: 任意实数

**返回值：** 整数

**示例：**
```javascript
CEIL(3.14)     // 返回 4
CEIL(3.0)      // 返回 3
CEIL(-2.5)     // 返回 -2
CEIL(-2.0)     // 返回 -2

// 动态周期计算（向上取整）
PERIOD = HT(5m).DCPERIOD
period_int = CEIL(PERIOD)  // 确保周期为整数

// 止损价格向上取整
stop_price = KLINE(5m).close(0) * 0.98
CEIL(stop_price)
```

**应用场景：**
- 周期参数取整
- 数量向上取整
- 价格档位调整

---

### FLOOR - 向下取整

**语法：** `FLOOR(x)`

**说明：** 返回小于或等于给定数值的最大整数。

**参数：**
- `x`: 任意实数

**返回值：** 整数

**示例：**
```javascript
FLOOR(3.14)    // 返回 3
FLOOR(3.9)     // 返回 3
FLOOR(-2.5)    // 返回 -3
FLOOR(-2.0)    // 返回 -2

// 动态周期计算（向下取整）
PERIOD = HT(5m).DCPERIOD
period_int = FLOOR(PERIOD)

// 止盈价格向下取整
target_price = KLINE(5m).close(0) * 1.05
FLOOR(target_price)
```

**应用场景：**
- 周期参数取整
- 数量向下取整
- 保守估算

---

### SQRT - 平方根

**语法：** `SQRT(x)`

**说明：** 返回数值的平方根。

**参数：**
- `x`: 非负实数（x ≥ 0）

**返回值：** 非负实数

**⚠️ 注意：** 如果 x < 0，将抛出异常

**示例：**
```javascript
SQRT(16)                 // 返回 4
SQRT(2)                  // 返回 1.414...
SQRT(0)                  // 返回 0

// 标准差计算
SQRT(VARIANCE(5m).close(20))

// ATR平方根
SQRT($(5m).ATR().value)

// 波动率计算
variance = VARIANCE(5m).close(20)
std = SQRT(variance)
```

**应用场景：**
- 标准差计算
- 距离计算（欧几里得距离）
- 波动率归一化
- 数学模型构建

**安全使用：**
```javascript
// ❌ 错误：可能对负数开方
SQRT(KLINE(5m).close(0) - KLINE(5m).high(0))

// ✅ 正确：确保非负（使用自定义函数）
calcSafeSqrt(diff: Double): Double {
  if (diff > 0) {
    return SQRT(diff);
  }
  return 0.0;
}

@result: Double = calcSafeSqrt(KLINE(5m).high(0) - KLINE(5m).close(0));
```

---

### POW - 幂运算

**语法：** `POW(base, exponent)`

**说明：** 返回底数的指数次幂。

**参数：**
- `base`: 底数
- `exponent`: 指数

**返回值：** base^exponent

**示例：**
```javascript
POW(2, 3)                // 返回 8 (2³)
POW(10, 2)               // 返回 100
POW(2, 0)                // 返回 1
POW(4, 0.5)              // 返回 2 (平方根)
POW(4, -1)               // 返回 0.25 (倒数)

// 收盘价的平方
POW(KLINE(5m).close(0), 2)

// 方差计算
std = STD(5m).close(20)
variance = POW(std, 2)

// 指数加权
weight = POW(0.9, 5)     // 0.9的5次方
```

**应用场景：**
- 平方/立方计算
- 指数加权
- 方差计算
- 复利计算
- 数学模型

## 三角函数

### 基本三角函数

**⚠️ 重要：** 所有三角函数使用**弧度制**，不是角度制！

#### SIN - 正弦

**语法：** `SIN(angle)`

**参数：** `angle` - 弧度值

**返回值：** [-1, 1]

**示例：**
```javascript
SIN(0)                   // 返回 0
SIN(3.14159 / 2)         // 返回 1 (π/2)
SIN(3.14159)             // 返回 0 (π)

// 角度转弧度：degrees * π / 180
degrees = 90
radians = degrees * 3.14159 / 180
SIN(radians)             // 返回 1
```

---

#### COS - 余弦

**语法：** `COS(angle)`

**参数：** `angle` - 弧度值

**返回值：** [-1, 1]

**示例：**
```javascript
COS(0)                   // 返回 1
COS(3.14159 / 2)         // 返回 0 (π/2)
COS(3.14159)             // 返回 -1 (π)
```

---

#### TAN - 正切

**语法：** `TAN(angle)`

**参数：** `angle` - 弧度值

**返回值：** 实数（在 ±π/2 处不连续）

**示例：**
```javascript
TAN(0)                   // 返回 0
TAN(3.14159 / 4)         // 返回 1 (π/4, 即45度)
```

---

### 反三角函数

#### ASIN - 反正弦

**语法：** `ASIN(value)`

**参数：** `value` - 必须在 [-1, 1] 范围内

**返回值：** 弧度，范围 [-π/2, π/2]

**⚠️ 注意：** 如果 value 不在 [-1, 1]，将抛出异常

**示例：**
```javascript
ASIN(0)                  // 返回 0
ASIN(1)                  // 返回 π/2
ASIN(0.5)                // 返回 π/6 (30度)

// 角度计算
radians = ASIN(0.5)
degrees = radians * 180 / 3.14159  // 约30度
```

---

#### ACOS - 反余弦

**语法：** `ACOS(value)`

**参数：** `value` - 必须在 [-1, 1] 范围内

**返回值：** 弧度，范围 [0, π]

**⚠️ 注意：** 如果 value 不在 [-1, 1]，将抛出异常

**示例：**
```javascript
ACOS(0)                  // 返回 π/2
ACOS(1)                  // 返回 0
ACOS(-1)                 // 返回 π
```

---

#### ATAN - 反正切

**语法：** `ATAN(value)`

**参数：** `value` - 任意实数

**返回值：** 弧度，范围 (-π/2, π/2)

**示例：**
```javascript
ATAN(0)                  // 返回 0
ATAN(1)                  // 返回 π/4 (45度)
ATAN(-1)                 // 返回 -π/4

// 斜率转角度
slope = SLOPE(5m).close(20)
angle = ATAN(slope) * 180 / 3.14159
```

## 双曲函数

双曲函数在某些数学模型和信号处理中使用。

### SINH - 双曲正弦

**语法：** `SINH(x)`

**定义：** `SINH(x) = (e^x - e^(-x)) / 2`

**示例：**
```javascript
SINH(0)                  // 返回 0
SINH(1)                  // 返回 1.175...
```

---

### COSH - 双曲余弦

**语法：** `COSH(x)`

**定义：** `COSH(x) = (e^x + e^(-x)) / 2`

**示例：**
```javascript
COSH(0)                  // 返回 1
COSH(1)                  // 返回 1.543...
```

---

### TANH - 双曲正切

**语法：** `TANH(x)`

**定义：** `TANH(x) = SINH(x) / COSH(x)`

**返回值：** (-1, 1)

**示例：**
```javascript
TANH(0)                  // 返回 0
TANH(1)                  // 返回 0.762...
TANH(-1)                 // 返回 -0.762...

// 激活函数（神经网络风格）
normalized = TANH(x)     // 将x压缩到(-1,1)
```

**应用场景：**
- 数值归一化（类似Sigmoid）
- 机器学习激活函数
- 平滑函数

## 指数和对数函数

### EXP - 自然指数

**语法：** `EXP(x)`

**说明：** 返回 e^x，其中 e ≈ 2.71828

**示例：**
```javascript
EXP(0)                   // 返回 1
EXP(1)                   // 返回 2.71828...
EXP(2)                   // 返回 7.389...

// 指数增长模型
base_value = 100
growth_rate = 0.05
periods = 10
future_value = base_value * EXP(growth_rate * periods)

// 指数衰减
decay_factor = EXP(-0.1)
```

**应用场景：**
- 指数增长/衰减模型
- 正态分布计算
- 指数移动平均权重
- 复利计算

---

### LN - 自然对数

**语法：** `LN(x)`

**说明：** 返回 x 的自然对数（以 e 为底）

**参数：** x 必须大于 0

**⚠️ 注意：** 如果 x ≤ 0，将抛出异常

**示例：**
```javascript
LN(1)                    // 返回 0
LN(2.71828)              // 返回 1
LN(10)                   // 返回 2.303...

// 对数收益率
current_price = KLINE(5m).close(0)
previous_price = KLINE(5m).close(10)
log_return = LN(current_price / previous_price)

// 增长率计算
growth = LN(price_now / price_before)
```

**应用场景：**
- 对数收益率计算
- 增长率分析
- 幂律分布
- 信息熵计算

---

### LOG10 - 常用对数

**语法：** `LOG10(x)`

**说明：** 返回 x 的常用对数（以 10 为底）

**参数：** x 必须大于 0

**⚠️ 注意：** 如果 x ≤ 0，将抛出异常

**示例：**
```javascript
LOG10(1)                 // 返回 0
LOG10(10)                // 返回 1
LOG10(100)               // 返回 2
LOG10(1000)              // 返回 3

// 数量级判断
magnitude = FLOOR(LOG10(price))

// 对数坐标转换
log_price = LOG10(KLINE(5m).close(0))
```

**应用场景：**
- 数量级判断
- 对数刻度绘图
- 科学计数法
- 范围压缩

**对数换底公式：**
```javascript
// log_a(x) = ln(x) / ln(a)
// log_2(8) = ?
LN(8) / LN(2)            // 返回 3
```

## 使用示例

### 示例1：标准化价格变化

```javascript
// 计算标准化的价格变化（Z-score）
PERIOD = 20
current_close = KLINE(5m).close(0)
avg_close = AVERAGE(5m).close(PERIOD)
std_close = STD(5m).close(PERIOD)

// Z-score计算
z_score = (current_close - avg_close) / std_close

// 判断价格是否异常（使用自定义函数）
checkOutlier(z_score: Double): Boolean {
  if (ABS(z_score) > 2) {
    // 价格偏离超过2个标准差
    return true;
  }
  return false;
}
```

## 最佳实践

### 1. 参数验证

始终验证参数范围，避免异常：

```javascript
// ❌ 不安全
result = SQRT(value)
log_val = LN(price)

// ✅ 安全（使用自定义函数）
calcSafeSqrt(value: Double): Double {
  if (value >= 0) {
    return SQRT(value);
  } else {
    return 0;
  }
}

calcSafeLog(price: Double): Double {
  if (price > 0) {
    return LN(price);
  }
  return 0.0;
}
```

---

### 2. 浮点精度

注意浮点数精度问题：

```javascript
// ❌ 不推荐：直接相等比较
ALL{
  SQRT(4) == 2;
} = BUY;

// ✅ 推荐：使用容差
ALL{
  ABS(SQRT(4) - 2) < 0.0001;
} = BUY;

// ✅ 推荐：四舍五入后比较
ALL{
  ROUND(SQRT(4), 5) == 2;
} = BUY;
```

---

### 3. 性能优化

避免重复计算：

```javascript
// ❌ 低效：重复计算
// 使用自定义函数避免重复计算
checkStdRange(variance: Double, threshold: Double, max_val: Double): Boolean {
  @std: Double = SQRT(variance);
  if (@std > threshold AND @std < max_val) {
    return true;
  }
  return false;
}

// ✅ 高效：缓存结果
@std: Double = SQRT(variance);
checkStdRange2(@std: Double, threshold: Double, max_val: Double): Boolean {
  if (@std > threshold AND @std < max_val) {
    return true;
  }
  return false;
}
```

---

### 4. 三角函数角度转换

统一使用弧度制，需要时进行转换：

```javascript
// 常量定义
PI = 3.14159265359

// 角度转弧度
degrees_to_radians = degrees * PI / 180

// 弧度转角度
radians_to_degrees = radians * 180 / PI

// 使用示例
angle_deg = 45
angle_rad = angle_deg * PI / 180
sin_value = SIN(angle_rad)
```

---

### 5. 数值稳定性

对于可能产生极大/极小值的计算，使用对数技巧：

```javascript
// ❌ 可能溢出
result = POW(x, 100) * POW(y, 100)

// ✅ 使用对数避免溢出
log_result = 100 * LN(x) + 100 * LN(y)
result = EXP(log_result)
```

---

### 6. 合理使用取整

根据业务需求选择合适的取整方式：

```javascript
// 保守策略（向不利方向取整）
stop_loss = FLOOR(price * 0.95)    // 止损向下取整
take_profit = CEIL(price * 1.05)   // 止盈向上取整

// 激进策略（向有利方向取整）
stop_loss = CEIL(price * 0.95)     // 止损向上取整
take_profit = FLOOR(price * 1.05)  // 止盈向下取整

// 平衡策略（四舍五入）
target = ROUND(price * 1.05, 2)
```

---

### 7. 避免无效运算

```javascript
// 检查除数（使用自定义函数）
safeDivide(numerator: Double, denominator: Double): Double {
  if (denominator != 0) {
    return numerator / denominator;
  }
  return 0.0;
}

// 检查对数参数
safeLog(value: Double): Double {
  if (value > 0) {
    return LN(value);
  }
  return 0.0;
}

// 检查平方根参数
safeSqrt(value: Double): Double {
  if (value >= 0) {
    return SQRT(value);
  }
  return 0.0;
}

// 检查反三角函数参数（使用自定义函数）
safeAsin(value: Double): Double {
  if (ABS(value) <= 1) {
    return ASIN(value);
  }
  return 0.0;
}
```

## 注意事项

### 1. 参数范围限制

| 函数 | 参数限制 | 违反时行为 |
|------|---------|----------|
| SQRT | x ≥ 0 | 抛出异常 |
| LN, LOG10 | x > 0 | 抛出异常 |
| ASIN, ACOS | -1 ≤ x ≤ 1 | 抛出异常 |
| POW, EXP | 结果不溢出 | 抛出异常 |

---

### 2. 精度问题

- 浮点数运算存在精度误差
- 避免直接比较浮点数是否相等
- 使用 `ROUND()` 或容差比较

```javascript
// 理论上相等，但浮点误差可能导致不相等
std = STD(5m).close(20)
variance = VARIANCE(5m).close(20)

// 使用容差判断（使用自定义函数）
checkVarianceEquality(std: Double, variance: Double): Boolean {
  if (ABS(POW(std, 2) - variance) < 0.0001) {
    // 认为相等
    return true;
  }
  return false;
}
```

---

### 3. 三角函数单位

- 所有三角函数使用**弧度制**
- 1 弧度 ≈ 57.3 度
- π 弧度 = 180 度

**常用转换：**
```javascript
PI = 3.14159265359

// 角度 → 弧度
radians = degrees * PI / 180

// 弧度 → 角度
degrees = radians * 180 / PI
```

---

### 4. 数值溢出

- `EXP()` 对大数值可能溢出
- `POW()` 的结果可能溢出
- 使用对数技巧避免溢出

```javascript
// 可能溢出
EXP(1000)        // 溢出
POW(10, 100)     // 溢出

// 安全范围
EXP(x)    // x 通常应在 [-20, 20] 范围
POW(a, b) // 结果应在系统浮点数范围内
```

---

### 5. 特殊值处理

- `LN(0)` 和 `LOG10(0)` 是未定义的（负无穷）
- `1/0` 除零错误
- `SQRT(-1)` 无实数解

**建议：** 始终在调用前验证参数有效性。

---

### 6. 性能考虑

计算复杂度排序（从快到慢）：

1. **最快：** 加减法、`ABS()`、`ROUND()`
2. **快：** `CEIL()`、`FLOOR()`、乘除法
3. **中等：** `SQRT()`、`POW(x, 2)`
4. **慢：** `EXP()`、`LN()`、`POW(x, y)`
5. **最慢：** 三角函数、双曲函数

**优化建议：**
- 缓存重复计算的结果
- 优先使用简单运算
- 避免在循环中使用复杂函数

---

### 7. 数学常量

DSL 不直接提供数学常量，但可以近似：

```javascript
// 常用常量定义
PI = 3.14159265359
E = 2.71828182846

// 验证
EXP(1)           // ≈ 2.71828 (自然常数 e)
ACOS(-1)         // ≈ 3.14159 (圆周率 π)
```

---

### 8. 数值范围

大多数数学函数返回值范围：

| 函数 | 返回值范围 |
|------|-----------|
| SIN, COS | [-1, 1] |
| TAN | (-∞, +∞) |
| ASIN, ACOS | 弧度 |
| ATAN | (-π/2, π/2) |
| TANH | (-1, 1) |
| LN, LOG10 | (-∞, +∞) |
| EXP | (0, +∞) |
| SQRT | [0, +∞) |

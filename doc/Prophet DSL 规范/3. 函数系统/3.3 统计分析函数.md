## 概述

统计分析函数用于对时间序列数据进行统计计算，提取数据特征，识别趋势和异常点。

**函数特点：**
- ✅ 需要 `timeframe` 参数
- ✅ 支持历史数据访问（通过 offset）
- ✅ 返回数值结果
- ✅ 可用于条件判断和变量赋值

## 极值函数

### HIGHEST - 最高值

获取指定周期内的最高值。

#### 语法
```javascript
HIGHEST(timeframe).field(period)
```

#### 参数
- `timeframe`: 时间周期（如 "5m", "1h"）
- `field`: 数据字段（如 "close", "high", "volume"）
- `PERIOD`: 回溯周期数（范围：1~100）

#### 返回值
指定周期内的最高值。

#### 示例
```javascript
// 获取过去20根K线的最高收盘价
highest_close = HIGHEST(5m).close(20)

// 获取过去50根K线的最高成交量
highest_volume = HIGHEST(5m).volume(50)
```

---

获取指定周期内的最低值。

#### 语法
```javascript
LOWEST(timeframe).field(period)
```

#### 参数
- `timeframe`: 时间周期
- `field`: 数据字段
- `PERIOD`: 回溯周期数（范围：1~100）

#### 返回值
指定周期内的最低值。

#### 示例
```javascript
// 获取过去20根K线的最低收盘价
lowest_close = LOWEST(5m).close(20)

// 获取过去50根K线的最低成交量
lowest_volume = LOWEST(5m).volume(50)
```

```javascript
MEDIAN(timeframe).field(period)
```

- `field`: 数据字段
- `PERIOD`: 回溯周期数（范围：1~100）

## 变化率函数

### CHANGE - 变化量计算

计算当前值与N个周期前的变化量，支持绝对值和百分比两种形式。

#### 语法
```javascript
CHANGE(timeframe).field(period).value  // 绝对变化量（默认）
CHANGE(timeframe).field(period).pct   // 百分比变化率
CHANGE(timeframe).field(period)       // 默认返回绝对变化量
```

#### 参数
- `timeframe`: 时间周期
- `field`: 数据字段（open, high, low, close, volume）
- `PERIOD`: 回溯周期数

#### 返回字段
- `.value`: 绝对变化量（当前值 - 历史值）
- `.pct`: 百分比变化率（(当前值 - 历史值) / 历史值 × 100）

#### 示例

**1. 绝对变化量（.value）**
```javascript
// 计算5周期价格变化（绝对值）
price_change = CHANGE(5m).close(5).value

// 简写形式（默认返回 value）
price_change = CHANGE(5m).close(5)

// 判断价格变化方向
ALL{
  CHANGE(5m).close(5).value > 0;
} = BUY;
ALL{
  CHANGE(5m).close(5).value < 0;
} = SELL;
```

**2. 百分比变化率（.pct）**
```javascript
// 计算5周期价格变化率（百分比）
price_change_pct = CHANGE(5m).close(5).pct

// 判断显著变化
ALL{
  ABS(CHANGE(5m).close(5).pct) > 5;
} = BUY;
```

**3. 同时使用两种形式**
```javascript
// 获取绝对变化和百分比变化
abs_change = CHANGE(5m).close(10).value
pct_change = CHANGE(5m).close(10).pct

// 综合判断：绝对值大且百分比也大
ALL{
  CHANGE(5m).close(10).value > 5;
  CHANGE(5m).close(10).pct > 2;
} = BUY;
```

**注意事项：**
- 当历史值为0时，百分比计算会返回0（避免除零错误）
- `.pct` 返回的值已经乘以100，直接是百分比（如 2.5 表示 2.5%）
- 不指定子字段时，默认返回 `.value`（绝对变化量）

## 排名函数

### RANK - 排名计算

计算当前值在最近N个周期内的排名，支持绝对排名和百分位排名两种形式。

#### 语法
```javascript
RANK(timeframe).field(period).value  // 绝对排名（默认）
RANK(timeframe).field(period).pct    // 百分位排名
RANK(timeframe).field(period)        // 默认返回绝对排名
```

#### 参数
- `timeframe`: 时间周期
- `field`: 数据字段（open, high, low, close, volume）
- `PERIOD`: 回溯周期数

#### 返回字段
- `.value`: 绝对排名（整数，1 到 PERIOD）
- `.pct`: 百分位排名（浮点数，0.0 到 1.0）

#### 示例

**1. 绝对排名（.value）**
```javascript
// 当前收盘价在最近20根K线中的排名
rank_close_20 = RANK(5m).close(20).value

// 简写形式（默认返回 value）
rank_close_20 = RANK(5m).close(20)

// 如果排名很高，说明价格处于高位
ALL{
  RANK(5m).close(20).value > 18;
} = SELL;     // 第18名以上
ALL{
  RANK(5m).close(20).value < 3;
} = BUY;      // 第3名以下
```

**2. 百分位排名（.pct）**
```javascript
// 当前价格的百分位位置（0-1之间）
pct_rank = RANK(5m).close(20).pct

// 判断价格区间
ALL{
  RANK(5m).close(20).pct > 0.8;
} = SELL;     // 上20%
ALL{
  RANK(5m).close(20).pct < 0.2;
} = BUY;      // 下20%
ALL{
  RANK(5m).close(20).pct >= 0.4;
  RANK(5m).close(20).pct <= 0.6;
} = HOLD;     // 中间20%
```

**3. 同时使用两种形式**
```javascript
// 获取绝对排名和百分位排名
abs_rank = RANK(5m).close(50).value
pct_rank = RANK(5m).close(50).pct

// 综合判断：排名高且百分位也高
ALL{
  RANK(5m).close(50).value > 45;
  RANK(5m).close(50).pct > 0.9;
} = SELL;
```

**注意事项：**
- 绝对排名从1开始，1表示最低值，PERIOD表示最高值
- 百分位排名范围是0.0到1.0，0.0表示最低，1.0表示最高
- 不指定子字段时，默认返回 `.value`（绝对排名）

## 趋势函数

### SLOPE - 线性回归斜率

计算指定周期内数据的线性回归斜率。

#### 语法
```javascript
SLOPE(timeframe).field(period)
```

#### 参数
- `timeframe`: 时间周期
- `field`: 数据字段
- `PERIOD`: 回溯周期数（范围：1~100）

#### 返回值
线性回归斜率。

#### 示例
```javascript
// 计算20周期价格趋势斜率
price_slope = SLOPE(5m).close(20)

// 判断趋势方向
ALL{
  SLOPE(5m).close(20) > 0;
} = BUY;
ALL{
  SLOPE(5m).close(20) < 0;
} = SELL;
```

## 交叉检测函数

### CROSS - 交叉检测

检测两个序列是否发生交叉。

#### 语法
```javascript
CROSS(timeframe).field1(field2).direction
```

#### 参数
- `timeframe`: 时间周期
- `field1`: 第一个序列
- `field2`: 第二个序列
- `direction`: 交叉方向（above/below）

#### 返回值
布尔值，表示是否发生交叉。

#### 示例
```javascript
// 检测价格上穿均线
ALL{
  CROSS(5m).close($(5m).MA(20).value).above = true;
} = BUY;

// 检测均线死叉
ALL{
  CROSS(5m).close($(5m).MA(50).value).below = true;
} = SELL;
```

## 波动率函数

### VOLA - 波动率分析

计算价格或其他字段的波动率。

#### 语法
```javascript
VOLA(timeframe).field(period).value  // 绝对波动率（标准差）
VOLA(timeframe).field(period).pct    // 百分比波动率（变异系数）
```

#### 参数
- `timeframe`: 时间周期
- `field`: 数据字段
- `PERIOD`: 回溯周期

#### 返回值
- `.value`: 绝对波动率
- `.pct`: 百分比波动率

#### 示例
```javascript
// 计算20期收盘价标准差
volatility = VOLA(5m).close(20).value

// 计算变异系数
cv = VOLA(5m).close(20).pct
```

---

### ATR - 平均真实波幅

计算平均真实波幅。

#### 语法
```javascript
ATR(timeframe).PERIOD
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 回溯周期

#### 返回值
平均真实波幅。

#### 示例
```javascript
// 计算14周期ATR
atr_14 = ATR(5m).14

// 动态止损
entry_price = GET_POSITION_ENTRY_PRICE()
stop_loss = entry_price - 2 * atr_14
```

## 使用示例

### 示例1：布林带策略

```javascript
// 计算布林带
ma_20 = AVERAGE(5m).close(20)
std_20 = STD(5m).close(20)
upper_band = ma_20 + 2 * std_20
lower_band = ma_20 - 2 * std_20

// 布林带策略
current_close = KLINE(5m).close()
ALL{
  KLINE(5m).close(0) > $(5m).BOLL().upper;
  $(5m).RSI().value > 70;
} = SELL;
ALL{
  KLINE(5m).close(0) < $(5m).BOLL().lower;
  $(5m).RSI().value < 30;
} = BUY;
```

---

### 示例2：趋势跟踪策略

```javascript
// 计算多周期趋势
slope_20 = SLOPE(5m).close(20)
slope_50 = SLOPE(5m).close(50)

// 多时间框架确认
ALL{
  SLOPE(5m).close(20) > 0;
  SLOPE(5m).close(50) > 0;
} = BUY;
ALL{
  SLOPE(5m).close(20) < 0;
  SLOPE(5m).close(50) < 0;
} = SELL;
```

---

### 示例3：波动率调整策略

```javascript
// 波动率分析
current_atr = ATR(5m).14
avg_atr = AVERAGE(5m).ATR(14).value(50)

// 波动率扩张检测
ALL{
  ATR(5m).close(14).value > AVERAGE(5m).ATR(14).value(50) * 1.5;
} = BUY;
```

---

### 示例4：统计套利策略

```javascript
// 计算价格偏离度
current_price = KLINE(5m).close()
mean_price = AVERAGE(5m).close(100)
std_price = STD(5m).close(100)
z_score = (current_price - mean_price) / std_price

// 均值回归策略
ALL{
  ZSCORE(5m).close(20) < -2;
} = BUY;
ALL{
  ZSCORE(5m).close(20) > 2;
} = SELL;
```

## 最佳实践

### 1. 合理选择周期

```javascript
// 短周期：敏感但噪音多
short_ma = AVERAGE(5m).close(10)

// 长周期：稳定但滞后
long_ma = AVERAGE(5m).close(50)

// 多周期组合
ALL{
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
} = BUY;
```

---

### 2. 异常值处理

```javascript
// 使用中位数替代均值减少异常值影响
median_price = MEDIAN(5m).close(20)
mean_price = AVERAGE(5m).close(20)

// 检测异常值
ALL{
  ABS(MEDIAN(5m).close(20) - AVERAGE(5m).close(20)) > STD(5m).close(20);
} = HOLD;
```

---

### 3. 标准化比较

```javascript
// 不同品种的波动率比较
vol_btc = VOLA(5m).close(20).pct
vol_eth = VOLA(5m).close(20).pct

// 选择波动率较高的品种
ALL{
  VOLA(5m).close(20).pct > VOLA(5m).close(20).pct;
} = BUY;
```

---

### 4. 动态参数调整

```javascript
// 根据波动率调整参数（使用自定义函数）
calcLookbackPeriod(atr: Double): Integer {
  if (atr > 10) {
    return 10;
  } else {
    return 20;
  }
}

@period: Integer = calcLookbackPeriod(ATR(5m).close(14).value);

// 动态计算指标
dynamic_sma = AVERAGE(5m).close(period)
```

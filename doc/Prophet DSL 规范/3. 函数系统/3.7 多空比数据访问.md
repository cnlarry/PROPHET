## 概述

多空比数据反映了市场中多头和空头力量的对比关系，是判断市场情绪和趋势的重要指标。Prophet DSL 提供了完善的多空比数据访问功能，支持多种分析方法。

**核心特点：**
- ✅ 实时访问多空比数据
- ✅ 支持多种比率计算（多空比、多头比例、空头比例、净多头比例、多头主导率）
- ✅ 提供趋势判断功能
- ✅ 支持极端值检测
- ✅ 历史数据回溯（最多100个数据点）

**数据来源：** 币安合约交易所 API（全球持仓人数多空比）

**更新频率：** 每5分钟更新一次

## CURRENT().longshort - 多空比数据访问

`CURRENT().longshort` 是访问多空比数据的统一入口，提供了丰富的子方法来获取不同维度的多空比数据。

### 语法总览

```dsl
CURRENT().longshort.ratio(offset)          // 多空比率（long/short）
CURRENT().longshort.long(offset)           // 多头比例（0~1）
CURRENT().longshort.short(offset)          // 空头比例（0~1）
CURRENT().longshort.net(offset)            // 净多头比例（-1~1）
CURRENT().longshort.dominance(offset)      // 多头主导率（0~100）
CURRENT().longshort.trend(period)          // 趋势判断（RISING/FALLING/STABLE）
CURRENT().longshort.extreme(threshold)     // 极端检测（true/false）
```

---

### 基础访问方法

#### ratio(offset) - 多空比率

**语法：** `CURRENT().longshort.ratio([offset])`

**说明：** 获取多空比率（多头/空头），反映市场多空力量的绝对对比。

**参数：**
- `offset`: 偏移次数（整数，范围：[-100, 0]）
  - `0`: 当前最新值（默认）
  - `-1`: 上一个数据点
  - `-5`: 5个数据点之前

**返回值：** 浮点数
- `> 1.0`: 多头占优（如 1.5 表示多头是空头的1.5倍）
- `= 1.0`: 多空平衡
- `< 1.0`: 空头占优（如 0.8 表示多头是空头的0.8倍）

**计算公式：** `ratio = long_ratio / short_ratio`

**示例：**
```dsl
// 获取当前多空比
current_ratio = CURRENT().longshort.ratio(0)
current_ratio_short = CURRENT().longshort.ratio()  // 省略参数，默认为0

// 获取5个数据点之前的多空比
prev_ratio = CURRENT().longshort.ratio(-5)

// 多空比过高，做空信号
ALL{
    CURRENT().longshort.ratio(0) > 1.5,      // 多空比大于1.5
    $(1h).RSI().value > 70,                  // RSI超买
    $(5m).MACD().trend = BEARISH
} = SELL;

// 多空比对比（判断趋势）
ALL{
    CURRENT().longshort.ratio(0) > CURRENT().longshort.ratio(-5),  // 多空比上升
    CURRENT().longshort.ratio(0) > 1.2,
    $(5m).MACD().signal = BUY
} = BUY;
```

**应用场景：**
- 判断市场多空力量对比
- 识别市场情绪偏向
- 检测多头或空头过度集中
- 构建反向指标

#### long(offset) - 多头比例

**语法：** `CURRENT().longshort.long([offset])`

**说明：** 获取多头比例（多头人数/总人数），反映持仓者中多头的占比。

**参数：**
- `offset`: 偏移次数（整数，范围：[-100, 0]）

**返回值：** 浮点数（0~1）
- 接近 `1.0`: 几乎所有人都做多
- 接近 `0.5`: 多空平衡
- 接近 `0.0`: 几乎所有人都做空

**计算公式：** `long_ratio = long_accounts / (long_accounts + short_accounts)`

**示例：**
```dsl
// 获取当前多头比例
long_pct = CURRENT().longshort.long(0)

// 多头过度集中
ALL{
    CURRENT().longshort.long(0) > 0.65,      // 多头比例超过65%
    $(1h).RSI().value > 70,
    $(5m).MACD().trend = BEARISH
} = SELL;  // 可能反转

// 多头极度萎缩（逆向机会）
ALL{
    CURRENT().longshort.long(0) < 0.35,      // 多头比例低于35%
    $(1h).RSI().value < 30,
    $(5m).MACD().signal = BUY
} = BUY;  // 恐慌性抛售后的机会
```

**应用场景：**
- 识别市场情绪极端
- 判断多头力量强弱
- 构建反向交易策略
- 评估市场参与者信心

#### short(offset) - 空头比例

**语法：** `CURRENT().longshort.short([offset])`

**说明：** 获取空头比例（空头人数/总人数），反映持仓者中空头的占比。

**参数：**
- `offset`: 偏移次数（整数，范围：[-100, 0]）

**返回值：** 浮点数（0~1）
- 接近 `1.0`: 几乎所有人都做空
- 接近 `0.5`: 多空平衡
- 接近 `0.0`: 几乎所有人都做多

**计算公式：** `short_ratio = short_accounts / (long_accounts + short_accounts)`

**注意：** `long(offset) + short(offset) = 1.0`

**示例：**
```dsl
// 获取当前空头比例
short_pct = CURRENT().longshort.short(0)

// 空头过度集中
ALL{
    CURRENT().longshort.short(0) > 0.65,     // 空头比例超过65%
    $(1h).RSI().value < 30,
    $(5m).MACD().trend = BULLISH
} = BUY;  // 可能反转

// 验证关系
ALL{
    CURRENT().longshort.long(0) + CURRENT().longshort.short(0) = 1.0
} = CHECK_PASSED;  // 应该始终为真
```

**应用场景：**
- 识别空头力量强弱
- 判断市场看空情绪
- 检测做空过度
- 构建多头反转策略

#### net(offset) - 净多头比例

**语法：** `CURRENT().longshort.net([offset])`

**说明：** 获取净多头比例，反映多空力量的相对强弱（标准化到-1~1范围）。

**参数：**
- `offset`: 偏移次数（整数，范围：[-100, 0]）

**返回值：** 浮点数（-1~1）
- `> 0`: 多头占优（如 0.3 表示净多头30%）
- `= 0`: 多空平衡
- `< 0`: 空头占优（如 -0.3 表示净空头30%）

**计算公式：** `net = (long_ratio - short_ratio) / (long_ratio + short_ratio)`

**示例：**
```dsl
// 获取当前净多头比例
net_long = CURRENT().longshort.net(0)

// 净多头强势
ALL{
    CURRENT().longshort.net(0) > 0.3,        // 净多头比例超过30%
    $(5m).MACD().crossover_type = GOLDEN_CROSS
} = BUY;

// 净多头减弱（可能见顶）
ALL{
    CURRENT().longshort.net(0) < CURRENT().longshort.net(-5),  // 净多头比例下降
    CURRENT().longshort.net(0) > 0.2,        // 但仍然是多头市场
    $(1h).RSI().value > 70
} = SELL;  // 提前离场

// 极端空头（逆向机会）
ALL{
    CURRENT().longshort.net(0) < -0.3,       // 净空头超过30%
    $(1h).MACD().trend = BULLISH
} = BUY;  // 恐慌性做空
```

**应用场景：**
- 判断市场偏向程度
- 识别情绪极端
- 追踪多空力量变化
- 构建均衡策略

---

#### dominance(offset) - 多头主导率

**语法：** `CURRENT().longshort.dominance([offset])`

**说明：** 获取多头主导率（多头比例的百分比形式），直观反映多头的主导程度。

**参数：**
- `offset`: 偏移次数（整数，范围：[-100, 0]）

**返回值：** 浮点数（0~100）
- `> 50`: 多头主导
- `= 50`: 多空平衡
- `< 50`: 空头主导

**计算公式：** `dominance = long_ratio / (long_ratio + short_ratio) * 100`

**注意：** `dominance(offset) = long(offset) * 100`

**示例：**
```dsl
// 获取当前多头主导率
dominance = CURRENT().longshort.dominance(0)

// 多头强势主导
ALL{
    CURRENT().longshort.dominance(0) > 70,   // 多头主导率超过70%
    CURRENT().longshort.long(0) > 0.6,       // 多头比例超过60%
    $(1h).MACD().signal = BUY
} = BUY;

// 多头主导减弱
ALL{
    CURRENT().longshort.dominance(0) < 55,   // 多头主导率低于55%
    CURRENT().longshort.dominance(-5) > 60,  // 5个数据点前超过60%
    $(5m).RSI().value > 65
} = SELL;  // 多头力量衰退

// 空头主导（逆向机会）
ALL{
    CURRENT().longshort.dominance(0) < 35,   // 空头主导（多头主导率低于35%）
    $(1h).RSI().value < 30
} = BUY;  // 极端空头情绪
```

**应用场景：**
- 直观判断主导方
- 评估市场信心
- 识别情绪转折
- 设置交易过滤条件

### 统计分析方法

#### trend(period) - 趋势判断

**语法：** `CURRENT().longshort.trend([period])`

**说明：** 判断多空比的趋势方向，使用线性回归分析最近N个数据点。

**参数：**
- `period`: 判断趋势的周期（整数，范围：[2, 100]，默认7）

**返回值：** 字符串枚举
- `"RISING"`: 上升趋势（多空比增加，多头力量增强）
- `"FALLING"`: 下降趋势（多空比减少，空头力量增强）
- `"STABLE"`: 稳定/横盘（多空比无明显变化）

**判断逻辑：**
- 对最近N个数据点进行线性回归
- 斜率 > 阈值 → `RISING`
- 斜率 < -阈值 → `FALLING`
- 其他情况 → `STABLE`

**示例：**
```dsl
// 7个数据点的趋势（默认）
trend_7 = CURRENT().longshort.trend(7)
trend_7_explicit = CURRENT().longshort.trend()

// 20个数据点的趋势（更平滑）
trend_20 = CURRENT().longshort.trend(20)

// 多空比上升趋势
ALL{
    CURRENT().longshort.trend(7) = RISING,   // 短期上升
    CURRENT().longshort.ratio(0) > 1.2,
    $(5m).MACD().signal = BUY
} = BUY;  // 多头力量增强

// 多空比下降趋势（空头增强）
ALL{
    CURRENT().longshort.trend(7) = FALLING,  // 短期下降
    CURRENT().longshort.ratio(0) < 0.9,
    $(5m).MACD().trend = BEARISH
} = SELL;  // 空头力量增强

// 多周期趋势确认
ALL{
    CURRENT().longshort.trend(7) = RISING,   // 短期上升
    CURRENT().longshort.trend(20) = RISING,  // 长期上升
    $(1h).MACD().trend = BULLISH
} = STRONG_BUY;  // 趋势一致性强
```

**应用场景：**
- 判断多空力量变化方向
- 识别趋势转折点
- 多周期趋势确认
- 构建趋势跟随策略

#### extreme(threshold) - 极端检测

**语法：** `CURRENT().longshort.extreme([threshold])`

**说明：** 检测多空比是否处于极端状态，用于识别市场情绪过热或过冷。

**参数：**
- `threshold`: 极端阈值（浮点数，范围：[0.1, 10.0]，默认2.0）

**返回值：** 布尔值
- `true`: 多空比处于极端状态
- `false`: 多空比处于正常范围

**判断逻辑：**
- `ratio > threshold` OR `ratio < (1 / threshold)` → `true`（极端）
- 否则 → `false`（正常）

**示例：**
```dsl
// 使用默认阈值2.0检测
is_extreme = CURRENT().longshort.extreme(2.0)
is_extreme_default = CURRENT().longshort.extreme()

// 使用更严格的阈值1.5
is_very_extreme = CURRENT().longshort.extreme(1.5)

// 极端多空比（反向信号）
ALL{
    CURRENT().longshort.extreme(2.0) = true, // 多空比极端（>2.0或<0.5）
    $(1h).RSI().value > 75
} = SELL;  // 多头过热或空头过热

// 极端多头（做空机会）
ALL{
    CURRENT().longshort.extreme(2.0) = true,
    CURRENT().longshort.ratio(0) > 2.0,      // 确认是多头极端
    $(1h).MACD().trend = BEARISH
} = SELL;

// 极端空头（做多机会）
ALL{
    CURRENT().longshort.extreme(2.0) = true,
    CURRENT().longshort.ratio(0) < 0.5,      // 确认是空头极端
    $(1h).MACD().trend = BULLISH
} = BUY;

// 从极端恢复
ALL{
    CURRENT().longshort.extreme(2.0) = false,    // 不再极端
    CURRENT().longshort.extreme(-5, 2.0) = true, // 5个数据点前是极端
    $(5m).MACD().signal = BUY
} = BUY;  // 情绪恢复正常
```

**应用场景：**
- 识别市场情绪极端
- 构建反向交易策略
- 设置风险警告
- 过滤交易时机

## 数据来源与更新频率

### 数据来源

**API端点：** 币安合约交易所 `/futures/data/globalLongShortAccountRatio`

**数据类型：** 全球持仓人数多空比（Global Long/Short Account Ratio）

**数据说明：**
- 统计所有币安合约用户的持仓方向
- 按人数计算多空比（不是按持仓量）
- 反映市场参与者的整体情绪

### 更新频率

**更新间隔：** 每5分钟更新一次

**数据延迟：** 通常1-2分钟

**历史数据：** 最多可回溯100个数据点（约8.3小时）

### 数据注入方式

#### C# 客户端

```csharp
// 方式1：自动加载（推荐）
var generator = new DslStrategySignalGenerator();
generator.SetTimeSeriesData(
    fearGreedData,
    fundingRateData,
    longShortRatioData  // 自动注入
);

// 方式2：手动注入
var timestamps = longShortData.Select(d => 
    new DateTimeOffset(d.UpdateTime).ToUnixTimeSeconds()).ToArray();
var longRatios = longShortData.Select(d => (double)d.LongPositionRatio).ToArray();
var shortRatios = longRatios.Select(lr => 1.0 - lr).ToArray();
var ratios = longShortData.Select(d => (double)d.LongShortRatio).ToArray();

ProphetCoreEngine.Prophet_SetLongShortRatioSeries(
    engineHandle, timestamps, longRatios, shortRatios, ratios, data.Count);
```

#### Python 客户端

```python
# 方式1：自动加载（推荐）
runner = StrategyRunner(
    strategy_json="my_strategy.json",
    symbol="BTCUSDT",
    db=database_connection,
    auto_load_longshort=True,     # 自动加载
    longshort_count=100            # 加载100个数据点
)

# 方式2：手动加载

# 方式3：手动设置

    {
        "timestamp": 1700000000,  # Unix时间戳（秒）
        "long_ratio": 0.55,       # 多头比例
        "short_ratio": 0.45,      # 空头比例
        "ratio": 1.22             # 多空比
    },
    # ...
]
runner.SetLongShortRatio(longshort_data)
```

## 使用示例

### 示例1：多空比反向策略

```dsl
// 多空比过高，做空信号
ALL{
    CURRENT().longshort.ratio(0) > 1.5,      // 多空比大于1.5
    CURRENT().longshort.long(0) > 0.6,       // 多头比例超过60%
    $(1h).RSI().value > 70,                  // RSI超买
    $(5m).MACD().trend = BEARISH
} = SELL;  // 多头过热

// 多空比过低，做多信号
ALL{
    CURRENT().longshort.ratio(0) < 0.7,      // 多空比小于0.7
    CURRENT().longshort.short(0) > 0.55,     // 空头比例超过55%
    $(1h).RSI().value < 30,                  // RSI超卖
    $(5m).MACD().trend = BULLISH
} = BUY;  // 空头过热
```

```dsl
} = SELL;  // 多头过热 + 高资金费率
```

### 1. 结合多个多空比指标

```dsl
ALL{
```

### 2. 注意多空比的滞后性

**理解：**
- 多空比反映的是当前持仓状态，不是交易意图

- 需要结合价格行为和技术指标

**建议：**

```dsl
    $(5m).RSI().value > 70
```

**❌ 避免做法：**

```dsl
// 只看绝对值
```

**✅ 推荐做法：**

```dsl
// 使用相对阈值和范围
ALL{
```

**建议阈值参考：**

- `dominance`: 45-55 正常，60+ 多头主导，40- 空头主导
- `net`: -0.1~0.1 正常，0.3+ 多头强势，-0.3- 空头强势

## 注意事项

### ⚠️ 数据可用性

1. **历史数据限制**
   - 最多可回溯100个数据点（约8.3小时）
   - 回测时确保数据覆盖回测周期
   - 数据缺失时函数会抛出异常

2. **更新频率**
   - 每5分钟更新一次
   - 实时交易中可能有1-2分钟延迟
   - 回测中使用历史数据，不存在延迟

3. **数据注入**
   - 必须通过 `Prophet_SetLongShortRatioSeries()` 注入数据
   - 客户端需要实现数据采集和注入逻辑
   - 未注入数据时访问会抛出异常

---

### ⚠️ 解读注意事项

1. **多空比不等于价格走势**
   - 多空比反映的是持仓状态，不是价格方向
   - 高多空比可能伴随价格下跌（多头被迫平仓）
   - 低多空比可能伴随价格上涨（空头被迫平仓）

2. **极端多空比的双刃剑**
   - 极端多空比既可能是趋势延续，也可能是反转信号
   - 需要结合价格行为和技术指标判断
   - 建议在技术面确认后再交易

3. **滞后性**
   - 多空比是持仓状态的快照，有一定滞后性
   - 市场情绪可能已经改变，但多空比还未反映
   - 建议结合快速反应的技术指标

---

### ⚠️ 性能考虑

```dsl
// ✅ 合理使用，避免过度计算
long_ratio = CURRENT().longshort.ratio(0)
long_pct = CURRENT().longshort.long(0)

ALL{
    long_ratio > 1.5,
    long_pct > 0.6,
    $(5m).MACD().signal = BUY
} = BUY;

// ❌ 避免重复计算相同值
ALL{
    CURRENT().longshort.ratio(0) > 1.5,      // 重复调用
    CURRENT().longshort.ratio(0) < 2.0,      // 重复调用
    CURRENT().longshort.long(0) > 0.6
} = BUY;
```

---

### ⚠️ 异常处理

```dsl
// 确保数据已注入

// "CURRENT.longshort: No long short ratio data available. Please set long short ratio series."
```

## 总结

Prophet DSL 的多空比数据访问功能为策略提供了强大的市场情绪分析能力：

**核心优势：**
- ✅ 多维度数据访问（比率、比例、净值、主导率）
- ✅ 趋势判断和极端检测
- ✅ 历史数据回溯（100个数据点）
- ✅ 与其他时间序列函数完美集成
- ✅ 支持多周期分析

**方法选择：**
1. **ratio()** - 绝对多空比率（最直观）
2. **long() / short()** - 多头/空头比例（0~1）
3. **net()** - 净多头比例（标准化，-1~1）
4. **dominance()** - 多头主导率（百分比形式，0~100）
5. **trend()** - 趋势方向（RISING/FALLING/STABLE）
6. **extreme()** - 极端检测（true/false）

**使用原则：**
1. 结合多个多空比指标综合判断
2. 注意多空比的滞后性，结合技术指标
3. 使用趋势而非绝对值
4. 设置合理的阈值
5. 多周期确认
6. 结合其他时间序列数据（恐惧指数、资金费率）
7. 注意数据可用性和异常处理

**典型应用场景：**
- 反向交易策略（极端多空比反转）
- 趋势跟随策略（多空比趋势）
- 市场情绪过滤（避免极端情绪交易）
- 多维度确认（结合恐惧指数、资金费率）

## 1. 函数体系概述

### 1.1 函数层级

Prophet DSL 的函数系统分为两个层级：

| 层级 | 函数类型 | 用途 | 返回值 |
|------|---------|------|-------|
| **一级** | 信号函数 | 决定条件之间的逻辑关系 | 信号类型（BUY/SELL/HOLD） |
| **辅助** | 数学/逻辑/数据函数 | 数值计算、逻辑运算、数据访问 | 数值或布尔值 |

> **注意**：信号函数已移至独立文档 [Prophet DSL 信号函数.md](Prophet%20DSL信号函数.md)

### 1.2 完整函数列表


**数学函数：**
- 基础：`ABS()`, `MAX()`, `MIN()`, `SQRT()`, `POW()`, `ROUND()`
- 三角：`SIN()`, `COS()`, `TAN()`, `ASIN()`, `ACOS()`, `ATAN()`
- 双曲：`SINH()`, `COSH()`, `TANH()`
- 指数对数：`EXP()`, `LN()`, `LOG10()`
- 取整：`CEIL()`, `FLOOR()`

**数据函数（Data Functions）：**
- `KLINE(tf).field(offset)` - 访问K线数据（当前和历史）
- `HIGHEST(tf).field(n)` - n期最高值
- `LOWEST(tf).field(n)` - n期最低值
- `AVERAGE(tf).field(n)` - n期平均值
- `STD(tf).field(n)` - n期标准差（波动率）
- `CHANGE(tf).field(n).value` - n期绝对变化量
- `CHANGE(tf).field(n).pct` - n期相对变化率（百分比）
- `SUM(tf).field(n)` - n期累加和
- `PRICE(tf).method(offset)` - 价格计算函数（AVG/MED/TYP/WCL）
- `SLOPE(tf).field(n)` - n期线性回归斜率
- `RANK(tf).field(n).value` - 当前值在n期中的绝对排名
- `RANK(tf).field(n).pct` - 当前值的百分位排名（0-1）
- `MEDIAN(tf).field(n)` - n期中位数
- `VARIANCE(tf).field(n)` - n期方差
- `PATTERN(tf).pattern_name(penetration)` - K线形态识别
- `HT(tf).method` - 希尔伯特变换（DCPERIOD/DCPHASE/TRENDLINE/TRENDMODE/PHASOR/SINE）
- `POWER(tf).BOP(offset)` - 力量平衡指标

> **注意**：MA、OSC、VOLUME、TREND、MOMENTUM、STAT、DMI、BAND 等函数组已移除，请使用对应的指标系统代替。

## 4. 数据访问函数

数据访问函数是Prophet DSL的基础，用于获取和计算K线数据的各种信息。

### KLINE - K线数据访问

获取指定时间周期的K线数据的各个字段。

**语法：**
```javascript
KLINE(timeframe).field([offset])
```

**参数：**

| 参数 | 类型 | 说明 | 必需 | 默认值 |
|------|------|------|------|--------|
| `timeframe` | 字符串 | 时间周期 | 是 | - |
| `field` | 字符串 | 数据字段 | 是 | - |
| `offset` | 整数 | 时间偏移 | 否 | `0` |

**支持的时间周期：**

| 周期 | 说明 | 示例 |
|------|------|------|
| `1m` | 1分钟 | `KLINE(1m)` |
| `5m` | 5分钟 | `KLINE(5m)` |
| `15m` | 15分钟 | `KLINE(15m)` |
| `30m` | 30分钟 | `KLINE(30m)` |
| `1h` | 1小时 | `KLINE(1h)` |
| `4h` | 4小时 | `KLINE(4h)` |
| `1d` | 1天 | `KLINE(1d)` |
| `1w` | 1周 | `KLINE(1w)` |

**支持的数据字段：**

| 字段 | 说明 | 数据类型 |
|------|------|---------|
| `open` | 开盘价 | double |
| `high` | 最高价 | double |
| `low` | 最低价 | double |
| `close` | 收盘价 | double |
| `volume` | 成交量 | double |

**偏移参数说明：**
- `offset = 0`: 当前K线（最新）
- `offset = -1`: 上一根K线
- `offset = -2`: 上上根K线
- 范围：`[-100, 0]`，最小可回溯100根K线

**返回值：**
返回指定字段的数值。

**示例：**
```javascript
// 获取当前5分钟K线的收盘价（简写形式，推荐）
current_close = KLINE(5m).close()

// 获取上一根5分钟K线的开盘价
previous_open = KLINE(5m).open(-1)

// 获取当前1小时K线的最高价（简写形式）
hourly_high = KLINE(1h).high()

// 获取当前成交量（简写形式）
current_volume = KLINE(5m).volume()

// 完整形式（等价，但不推荐）
current_close_full = KLINE(5m).close(0)
```

**跨周期访问：**
```javascript
// 同时访问不同时间周期（简写形式）
m5_close = KLINE(5m).close()    // 5分钟收盘价
m15_close = KLINE(15m).close()  // 15分钟收盘价
h1_close = KLINE(1h).close()    // 1小时收盘价

// 跨周期比较
ALL{
  KLINE(5m).close(0) > KLINE(15m).close(0);
  KLINE(15m).close(0) > KLINE(1h).close(0);
} = BUY;
```

**实战应用场景：**

**场景1：突破检测**
```javascript
// 检测价格突破前期高点
current_high = KLINE(5m).high()
previous_high_1 = KLINE(5m).high(-1)
previous_high_2 = KLINE(5m).high(-2)

// 当前高点超过前两根K线
ALL{
  KLINE(5m).high(0) > KLINE(5m).high(-1);
  KLINE(5m).high(0) > KLINE(5m).high(-2);
} = BUY;
```

**场景2：跳空缺口**
```javascript
// 检测向上跳空
current_low = KLINE(5m).low()
previous_high = KLINE(5m).high(-1)

// 跳空缺口大于0.5%
ALL{
  (KLINE(5m).low(0) - KLINE(5m).high(-1)) / KLINE(5m).high(-1) > 0.005;
} = BUY;
```

**场景3：成交量突增**
```javascript
// 检测成交量放大
current_vol = KLINE(5m).volume()
avg_vol = (KLINE(5m).volume(-1) + KLINE(5m).volume(-2) + KLINE(5m).volume(-3)) / 3

// 成交量放大2倍以上
ALL{
  KLINE(5m).volume(0) > (KLINE(5m).volume(-1) + KLINE(5m).volume(-2) + KLINE(5m).volume(-3)) / 3 * 2;
} = BUY;
```

### PRICE - 综合价格计算

提供多种价格计算方法，用于生成综合价格指标。

**语法：**
```javascript
PRICE(timeframe).type([offset])  // 带括号形式
PRICE(timeframe).type            // 不带括号形式（语法糖）
```

**参数：**

| 参数 | 类型 | 说明 | 必需 | 默认值 |
|------|------|------|------|--------|
| `timeframe` | 字符串 | 时间周期 | 是 | - |
| `type` | 字符串 | 价格类型 | 是 | - |
| `offset` | 整数 | 时间偏移 | 否 | `0` |

**支持的价格类型：**

#### AVG - 平均价

**公式：** `AVG = (open + high + low + close) / 4`

**说明：** 四个价格的简单平均，反映K线的整体价格水平。

**适用场景：**
- 价格中枢判断
- 波动率计算
- 多周期价格比较

**示例：**
```javascript
// 简写形式（推荐）
avg_price = PRICE(5m).AVG()
avg_price_alt = PRICE(5m).AVG  // 不带括号也可以

ALL{
  KLINE(5m).close(0) > PRICE(5m).AVG();
} = BUY;  // 价格在平均价上方
```

#### MED - 中位数价

**公式：** `MED = (high + low) / 2`

**说明：** 最高价和最低价的中点，表示K线的中心位置。

**适用场景：**
- 支撑阻力位判断
- 价格均衡分析
- 趋势中枢识别

**示例：**
```javascript
// 简写形式（推荐）
median_price = PRICE(5m).MED()

ALL{
  KLINE(5m).close(0) > PRICE(5m).MED();
  KLINE(5m).open(0) < PRICE(5m).MED();
} = BUY;
```

#### TYP - 典型价

**公式：** `TYP = (high + low + close) / 3`

**说明：** 最高、最低和收盘价的平均，更强调收盘价的重要性。

**适用场景：**
- 资金流向分析
- 价格趋势判断
- 与成交量结合使用

**示例：**
```javascript
// 简写形式（推荐）
typical_price = PRICE(5m).TYP()
typical_price_prev = PRICE(5m).TYP(-1)

// 典型价上升趋势
ALL{typical_price > typical_price_prev;} = BUY;
```

#### WCL - 加权收盘价

**公式：** `WCL = (high + low + 2 * close) / 4`

**说明：** 强调收盘价的价格指标，收盘价权重为其他价格的两倍。

**适用场景：**
- 收盘价趋势强化
- 日内交易决策
- 价格动量分析

**示例：**
```javascript
// 简写形式（推荐）
weighted_close = PRICE(5m).WCL()
ALL{weighted_close > PRICE(5m).WCL(-1);} = BUY;  // 加权价上升
```

#### MID - 中点价

**公式：** `MID = (high + low) / 2`

**说明：** 与MED相同，提供另一个名称选择。

**价格类型对比：**

| 类型 | 公式 | 特点 | 适用场景 |
|------|------|------|---------|
| AVG | (O+H+L+C)/4 | 全面均衡 | 整体价格水平 |
| MED | (H+L)/2 | 中心位置 | 支撑阻力 |
| TYP | (H+L+C)/3 | 重视收盘 | 资金流向 |
| WCL | (H+L+2*C)/4 | 强调收盘 | 收盘趋势 |
| MID | (H+L)/2 | 中心位置 | 同MED |

**综合示例：**
```javascript
// 多周期价格对比（简写形式）
typ_5m = PRICE(5m).TYP()
typ_15m = PRICE(15m).TYP()
typ_1h = PRICE(1h).TYP()

// 多周期共振
ALL{
  PRICE(5m).TYP() > PRICE(15m).TYP();
  PRICE(15m).TYP() > PRICE(1h).TYP();
} = BUY;
```

## 5. 统计分析函数

统计函数用于分析时间序列数据的统计特征，帮助识别趋势、波动和异常。

### 5.1 通用语法

所有统计函数遵循统一的调用格式：

```javascript
FUNCTION(timeframe).field(period)
```

| 参数 | 说明 | 示例 |
|------|------|------|
| `timeframe` | 时间周期 | `5m`, `15m`, `1h` |
| `field` | 数据字段 | `close`, `high`, `low`, `volume` |
| `PERIOD` | 统计周期（K线数量） | `20`, `50`, `100` |

---

### 5.2 极值函数

#### HIGHEST - 最高值

**语法：**
```javascript
HIGHEST(timeframe).field(period)
```

**说明：** 返回指定周期内的最大值。

**示例：**
```javascript
// 最近20根5分钟K线的最高价
high_20 = HIGHEST(5m).high(20)

// 最近50根K线收盘价的最高点
close_high_50 = HIGHEST(5m).close(50)

// 最近10根K线的最大成交量
vol_high_10 = HIGHEST(5m).volume(10)
```

**应用场景：**
- 阻力位识别
- 突破检测
- 动态止盈设置
- 波动范围计算

---

#### LOWEST - 最低值

**语法：**
```javascript
LOWEST(timeframe).field(period)
```

**说明：** 返回指定周期内的最小值。

**示例：**
```javascript
// 最近20根K线的最低价
low_20 = LOWEST(5m).low(20)

// 最近30根K线收盘价的最低点
close_low_30 = LOWEST(5m).close(30)
```

**应用场景：**
- 支撑位识别
- 回调检测
- 动态止损设置
- 价格区间定义

---

### 5.3 集中趋势函数

#### AVERAGE - 平均值

**语法：**
```javascript
AVERAGE(timeframe).field(period)
```

**说明：** 计算指定周期内的算术平均值（简单移动平均）。

**计算公式：**
```javascript
AVERAGE = (x₁ + x₂ + ... + xₙ) / n
```

**示例：**
```javascript
// 最近20根K线收盘价的平均值
avg_close_20 = AVERAGE(5m).close(20)

// 最近10根K线的平均成交量
avg_vol_10 = AVERAGE(5m).volume(10)
```

**应用场景：**
- 价格中枢判断
- 趋势方向识别
- 均值回归策略
- 过滤价格噪音

---

#### SUM - 累加和

**语法：**
```javascript
SUM(timeframe).field(period)
```

**说明：** 计算指定周期内所有值的总和。

**计算公式：**
```
SUM = x₁ + x₂ + ... + xₙ
```

**示例：**
```javascript
// 最近20根K线的总成交量
total_vol_20 = SUM(5m).volume(20)

// 计算平均价格（手动方式）
sum_close = SUM(5m).close(20)
avg_close = sum_close / 20
```

**应用场景：**
- 累计成交量分析
- 资金流向估算
- 自定义统计计算

---

#### MEDIAN - 中位数

**语法：**
```javascript
MEDIAN(timeframe).field(period)
```

**说明：** 返回指定周期内的中位数（排序后的中间值）。

**计算方法：**
1. 将数据从小到大排序
2. 如果数量为奇数：返回中间位置的值
3. 如果数量为偶数：返回中间两个值的平均

**示例：**
```javascript
// 最近20根K线收盘价的中位数
median_close_20 = MEDIAN(5m).close(20)

// 与平均值对比（使用自定义函数）
checkDataSkew(avg: Double, med: Double): Boolean {
  if (avg > med * 1.05) {
    // 数据右偏（有较大异常值）
    return true;
  }
  return false;
}
```

**应用场景：**
- 抗异常值统计
- 价格分布分析
- 识别偏态分布
- 稳健的中心估计

**优势：**
- 对异常值不敏感
- 更能代表"典型"价格
- 适合有极端波动的市场

---

### 5.4 离散度函数

#### STD - 标准差

**语法：**
```javascript
STD(timeframe).field(period)
```

**说明：** 计算指定周期内的标准差，衡量数据的离散程度。

**计算公式：**
```
STD = √[Σ(xᵢ - μ)² / n]
其中 μ 为平均值
```

**示例：**
```javascript
// 最近20根K线收盘价的标准差
std_close_20 = STD(5m).close(20)

// 波动率计算
volatility = std_close_20 / AVERAGE(5m).close(20)

// 高波动判断
ALL{
  STD(5m).close(20) > AVERAGE(5m).close(20) * 0.02;
} = HOLD;
```

**应用场景：**
- 波动率计算
- 风险评估
- 布林带自定义
- 异常检测

**解读：**
- 标准差越大，数据波动越剧烈
- 标准差越小，数据越稳定
- 通常与均值结合使用

---

#### VARIANCE - 方差

**语法：**
```javascript
VARIANCE(timeframe).field(period)
```

**说明：** 计算指定周期内的方差（标准差的平方）。

**计算公式：**
```
VARIANCE = Σ(xᵢ - μ)² / n
其中 μ 为平均值
```

**关系：**
```
VARIANCE = STD²
STD = √VARIANCE
```

**示例：**
```javascript
// 最近20根K线的方差
var_close_20 = VARIANCE(5m).close(20)

// 从方差计算标准差
std_close_20 = SQRT(var_close_20)
```

**应用场景：**
- 理论统计计算
- 协方差计算基础
- 数学模型构建

---

### 5.5 变化率函数

#### CHANGE - 变化量计算

**语法：**
```javascript
CHANGE(timeframe).field(period).value  // 绝对变化量
CHANGE(timeframe).field(period).pct    // 百分比变化率
CHANGE(timeframe).field(period)        // 默认：绝对变化量
```

**说明：** 计算当前值与N个周期前的值的变化量，支持绝对值和百分比两种形式。

**返回字段：**

| 字段 | 说明 | 计算公式 |
|------|------|----------|
| `value` | 绝对变化量（默认） | `current - previous` |
| `pct` | 百分比变化率 | `(current - previous) / previous × 100` |

**示例：**

**1. 绝对变化量（.value）**
```javascript
// 最近5根K线的价格变化（绝对值）
change_5 = CHANGE(5m).close(5).value

// 简写形式（默认返回 value）
change_5 = CHANGE(5m).close(5)

// 判断上涨还是下跌
ALL{
  CHANGE(5m).close(5).value > 0;
} = BUY;
ALL{
  CHANGE(5m).close(5).value < 0;
} = SELL;
```

**2. 百分比变化率（.pct）**
```javascript
// 最近10根K线的涨跌幅（百分比）
pct_change_10 = CHANGE(5m).close(10).pct

// 判断涨跌幅度
ALL{
  CHANGE(5m).close(10).pct > 2;
} = BUY;      // 涨幅超过2%
ALL{
  CHANGE(5m).close(10).pct < -2;
} = SELL;     // 跌幅超过2%
```

**3. 同时使用两种形式**
```javascript
// 获取绝对变化和百分比变化
abs_change = CHANGE(5m).close(10).value
pct_change = CHANGE(5m).close(10).pct

// 综合判断：绝对值大且百分比也大
ALL{
  CHANGE(5m).close(10).value > 5;
  CHANGE(5m).close(10).pct > 2;
} = BUY;
```

**应用场景：**

**绝对变化量（value）：**
- 动量计算
- 趋势判断
- 价格变化幅度分析
- 绝对涨跌统计

**百分比变化率（pct）：**
- 收益率计算
- 涨跌幅统计
- 相对动量分析
- 百分比止盈止损
- 跨品种对比（归一化）

**注意事项：**
1. **基准值为0：** 当 previous 接近0时，百分比计算会返回0（避免除零错误）
2. **百分比单位：** `.pct` 返回的值已经乘以100，直接是百分比（如 2.5 表示 2.5%）
3. **默认字段：** 不指定子字段时，默认返回 `.value`（绝对变化量）

### 5.6 排名函数

#### RANK - 排名计算

**语法：**
```javascript
RANK(timeframe).field(period).value  // 绝对排名
RANK(timeframe).field(period).pct    // 百分位排名
RANK(timeframe).field(period)        // 默认：绝对排名
```

**说明：** 计算当前值在最近N个周期内的排名，支持绝对排名和百分位排名两种形式。

**返回字段：**

| 字段 | 说明 | 返回值 | 计算公式 |
|------|------|--------|----------|
| `value` | 绝对排名（默认） | 整数（1 到 PERIOD） | 小于当前值的个数 + 1 |
| `pct` | 百分位排名 | 浮点数（0.0 到 1.0） | `(rank - 1) / (PERIOD - 1)` |

**示例：**

**1. 绝对排名（.value）**
```javascript
// 当前收盘价在最近20根K线中的排名
rank_close_20 = RANK(5m).close(20).value

// 简写形式（默认返回 value）
rank_close_20 = RANK(5m).close(20)

// 如果排名很高，说明价格处于高位
ALL{
  RANK(5m).close(20).value > 18;
} = SELL;     // 第18名以上
ALL{
  RANK(5m).close(20).value < 3;
} = BUY;        // 第3名以下
```

**2. 百分位排名（.pct）**
```javascript
// 当前价格的百分位位置（0-1之间）
pct_rank = RANK(5m).close(20).pct

// 判断价格区间
ALL{
  RANK(5m).close(20).pct > 0.8;
} = SELL;        // 上20%
ALL{
  RANK(5m).close(20).pct < 0.2;
} = BUY;         // 下20%
ALL{
  RANK(5m).close(20).pct >= 0.4;
  RANK(5m).close(20).pct <= 0.6;
} = HOLD; // 中间20%
```

**3. 同时使用两种形式**
```javascript
// 获取绝对排名和百分位排名
abs_rank = RANK(5m).close(20).value
pct_rank = RANK(5m).close(20).pct

// 综合判断
// abs_rank = 18 (第18名), pct_rank = 0.89 (前89%)
ALL{
  RANK(5m).close(20).value > 15;
  RANK(5m).close(20).pct > 0.75;
} = SELL;
```

**应用场景：**

**绝对排名（value）：**
- 相对位置判断
- 超买超卖识别（如：排名 > 18 或 < 3）
- 价格强度评估
- 简单阈值策略

**百分位排名（pct）：**
- 标准化的位置判断
- 跨周期比较（归一化到[0,1]）
- 分位数回归策略
- 相对强度评估
- 便于跨品种比较

**注意事项：**
1. **排名规则：** 从小到大排名，1表示最小值，period表示最大值
2. **百分位范围：** `.pct` 返回0.0到1.0之间的值（0=最小，1=最大）
3. **默认字段：** 不指定子字段时，默认返回 `.value`（绝对排名）
4. **边界情况：** 当 PERIOD=1 时，百分位固定为 0.5

### 5.7 趋势函数

#### SLOPE - 线性回归斜率

**语法：**
```javascript
SLOPE(timeframe).field(period)
```

**说明：** 计算指定周期内数据的线性回归斜率，反映趋势方向和强度。

**计算方法：** 使用最小二乘法拟合直线 y = mx + b，返回斜率 m。

**计算公式：**
```
SLOPE = [n·Σ(xy) - Σx·Σy] / [n·Σ(x²) - (Σx)²]
```

**返回值：**
- 正值表示上升趋势
- 负值表示下降趋势
- 绝对值越大，趋势越强

**示例：**
```javascript
// 最近20根K线收盘价的趋势斜率
slope_20 = SLOPE(5m).close(20)

// 判断趋势方向
ALL{
  SLOPE(5m).close(20) > 0;
} = BUY;         // 上升趋势
ALL{
  SLOPE(5m).close(20) < 0;
} = SELL;       // 下降趋势

// 判断趋势强度
ALL{
  SLOPE(5m).close(20) > 0.5;
} = BUY;
ALL{
  SLOPE(5m).close(20) < -0.5;
} = SELL;
ALL{
  ABS(SLOPE(5m).close(20)) < 0.1;
} = HOLD; // 横盘
```

**应用场景：**
- 趋势方向识别
- 趋势强度量化
- 趋势一致性判断
- 趋势转折预测

**注意：**
- 斜率的绝对大小取决于价格水平
- 可以用标准化斜率进行跨品种比较
- 短周期斜率更敏感，长周期更平滑

### 5.8 标准化函数

#### ZSCORE - 标准化得分

**语法：**
```javascript
ZSCORE(timeframe).field(period)
```

**说明：** 计算当前值相对于历史均值的标准化得分，用于判断当前值相对于历史水平的位置。

**计算公式：**
```javascript
ZSCORE = (current - mean) / std_dev
```

**返回值：**
- Z = 0：等于均值
- Z > 0：高于均值
- Z < 0：低于均值
- |Z| > 2：显著偏离均值（通常认为是异常）
- |Z| > 3：极端异常

**示例：**
```javascript
// 计算价格的标准化得分
zscore = ZSCORE(5m).close(50)

// 超卖判断（低于均值2个标准差）
ALL{
  ZSCORE(5m).close(50) < -2;
} = BUY;

// 超买判断（高于均值2个标准差）
ALL{
  ZSCORE(5m).close(50) > 2;
} = SELL;

// 极端超卖
ALL{
  ZSCORE(5m).close(50) < -3;
} = BUY;
```

**应用场景：**

**1. 均值回归策略**
```javascript
zscore = ZSCORE(5m).close(50)

ALL {
    zscore < -2,                    // 严重超卖
    CHANGE(5m).close(1).pct > -1,  // 跌势放缓
    $(5m).RSI().value < 30            // RSI确认
} = BUY

// 止盈：回归到超买
ALL{
  ZSCORE(5m).close(50) > 2;
} = SELL;
```

**2. 异常值检测**
```javascript
// 价格异常偏离
zscore = ZSCORE(5m).close(100)

ALL{
  ABS(ZSCORE(5m).close(100)) > 3;
} = HOLD;  // 极端异常
```

**3. 跨品种比较**
```javascript
// 标准化后可以比较不同价格水平的资产
btc_z = ZSCORE(5m).close(50)
eth_z = ZSCORE(5m).close(50)

// 相对强弱判断
ALL{
  ZSCORE(5m).close(50) > ZSCORE(5m).close(50) + 1;
} = BUY;
```

**4. 波段交易**
```javascript
zscore = ZSCORE(5m).close(20)

// 在合理区间内操作
ALL {
    zscore > -0.5,
    zscore < 0.5,
    SLOPE(5m).close(10) > 0
} = RANGING_MARKET
```

**优势：**
- 归一化：消除价格水平差异
- 直观：标准化得分易于理解和设置阈值
- 统计意义：基于正态分布的统计学原理
- 通用性：适用于任何数值序列

**注意事项：**
1. **数据要求：** 需要足够的历史数据（建议至少20期）
2. **标准差为0：** 当所有值相同时，返回0
3. **分布假设：** 假设数据近似正态分布，实际市场可能有偏
4. **阈值选择：** -2/+2 是常用阈值，可根据实际情况调整

### 5.9 百分位函数

#### PERCENTILE - 百分位数

**语法：**
```javascript
PERCENTILE(timeframe).field(period, quantile)
```

**说明：** 计算指定百分位数的值，返回有多少百分比的数据小于等于该值。

**参数：**

| 参数 | 类型 | 说明 | 范围 |
|------|------|------|------|
| `timeframe` | 字符串 | 时间周期 | 标准周期 |
| `field` | 字符串 | 数据字段 | open/high/low/close/volume |
| `PERIOD` | 整数 | 统计周期 | > 0 |
| `quantile` | 浮点数 | 百分位数 | 0.0 - 1.0 |

**常用百分位：**
- `0.05`: 5%分位数（只有5%的值小于此值）
- `0.25`: 25%分位数（第一四分位数，Q1）
- `0.50`: 50%分位数（中位数）
- `0.75`: 75%分位数（第三四分位数，Q3）
- `0.95`: 95%分位数（只有5%的值大于此值）

**示例：**
```javascript
// 获取95%和5%分位数
p95 = PERCENTILE(5m).high(100, 0.95)
p05 = PERCENTILE(5m).low(100, 0.05)

// 计算波动范围
range = p95 - p05

// 中位数（等同于 MEDIAN）
median = PERCENTILE(5m).close(50, 0.5)
```

**应用场景：**

**1. 动态止损止盈**
```javascript
// 基于历史分位数设置止损
p05 = PERCENTILE(5m).low(100, 0.05)
p95 = PERCENTILE(5m).high(100, 0.95)

stop_loss = p05 * 0.98   // 5%分位数下方2%
take_profit = p95 * 1.02  // 95%分位数上方2%

ALL{
  KLINE(5m).close(0) < PERCENTILE(5m).close(50, 0.05) * 0.98;
} = SELL;
ALL{
  KLINE(5m).close(0) > PERCENTILE(5m).close(50, 0.95) * 1.02;
} = SELL;
```

**2. 风险管理（VaR计算）**
```javascript
// Value at Risk: 5%最坏情况
var_5 = PERCENTILE(5m).close(100, 0.05)
current = KLINE(5m).close()

// 当前价格相对VaR的距离
risk_distance = (current - var_5) / current * 100

ALL{
  (KLINE(5m).close(0) - PERCENTILE(5m).close(100, 0.05)) / KLINE(5m).close(0) * 100 < 2;
} = HOLD;
```

**3. 分位数回归策略**
```javascript
p75 = PERCENTILE(5m).close(50, 0.75)
p25 = PERCENTILE(5m).close(50, 0.25)
current = KLINE(5m).close()

// 在下四分位附近买入
ALL{
  KLINE(5m).close(0) < PERCENTILE(5m).close(50, 0.25) * 1.02;
} = BUY;

// 在上四分位附近卖出
ALL{
  KLINE(5m).close(0) > PERCENTILE(5m).close(50, 0.75) * 0.98;
} = SELL;
ALL{
  KLINE(5m).close(0) > PERCENTILE(5m).close(50, 0.75) * 0.98;
} = SELL;
```

**4. 波动率通道**
```javascript
// 基于百分位数构建通道
median = PERCENTILE(5m).close(100, 0.5)
p90 = PERCENTILE(5m).close(100, 0.9)
p10 = PERCENTILE(5m).close(100, 0.1)

upper_band = median + (p90 - median) * 1.5
lower_band = median - (median - p10) * 1.5

// 突破上轨
ALL{
  KLINE(5m).close(0) > $(5m).BOLL().upper;
} = BUY;
```

**优势：**
- 灵活性：可以指定任意百分位
- 鲁棒性：对异常值不敏感
- 实用性：直接用于止损止盈计算
- 直观性：百分位概念易于理解

**注意事项：**
1. **数据要求：** 至少需要 PERIOD 个数据点
2. **计算方法：** 使用线性插值，结果更平滑
3. **quantile 范围：** 必须在 [0.0, 1.0] 之间
4. **与 MEDIAN 的关系：** `PERCENTILE(5m).close(n, 0.5)` 等同于 `MEDIAN(5m).close(n)`

### 5.10 交叉检测函数

#### CROSS - 交叉检测

**语法：**
```javascript
CROSS(timeframe).field(threshold).above  // 向上穿越
CROSS(timeframe).field(threshold).below  // 向下穿越
CROSS(timeframe).field(threshold).any    // 任意穿越
```

**说明：** 检测数值是否穿越阈值，用于识别金叉、死叉、突破等关键信号。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `timeframe` | 字符串 | 时间周期 |
| `field` | 字符串 | 数据字段 |
| `threshold` | 数值 | 阈值（可以是常量或变量） |

**返回字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `above` | 布尔 | 向上穿越（前一期 ≤ 阈值 && 当前期 > 阈值） |
| `below` | 布尔 | 向下穿越（前一期 ≥ 阈值 && 当前期 < 阈值） |
| `any` | 布尔 | 任意穿越（above 或 below） |

**示例：**

**1. 价格穿越固定值**
```javascript
// 价格向上穿越100
ALL{
  CROSS(5m).close(100).above = true;
} = BUY;

// 价格向下穿越100
ALL{
  CROSS(5m).close(100).below = true;
} = SELL;

// 价格穿越100（任意方向）
ALL{
  CROSS(5m).close(100).any = true;
} = HOLD;
```

**2. 价格穿越均线（金叉/死叉）**
```javascript
// 计算均线
ma20 = $(5m).MA(20).value
ma50 = $(5m).MA(50).value

// 价格金叉MA20
ALL{
  CROSS(5m).close($(5m).MA(20).value).above = true;
} = BUY;

// 价格死叉MA20
ALL{
  CROSS(5m).close($(5m).MA(20).value).below = true;
} = SELL;

// MA20金叉MA50
ALL{
  $(5m).MA(20).value > $(5m).MA(50).value;
  $(5m).MA(20).value(1) <= $(5m).MA(50).value(1);
} = BUY;
```

**3. 指标穿越阈值**
```javascript
// RSI上穿50
ALL{
  CROSS(5m).close(50).above = true;
  $(5m).RSI().value > 50;
} = BUY;

// MACD穿越0轴
ALL{
  CROSS(5m).close(0).above = true;
} = BUY;
```

**应用场景：**

**场景1：经典金叉策略**
```javascript
ma20 = $(5m).MA(20).value

ALL {
    CROSS(5m).close(ma20).above,            // 价格金叉MA20
    $(5m).MACD().histogram > 0,                // MACD确认
    KLINE(5m).volume() > AVERAGE(5m).volume(20)  // 放量
} = BUY
```

**场景2：多重确认突破**
```javascript
high_20 = HIGHEST(5m).high(20)

ALL {
    CROSS(5m).close(high_20).above,         // 突破前高
    $(5m).RSI().value > 50,                    // RSI强势
    ZSCORE(5m).close(50) > 0                 // 价格在均值上方
} = BREAKOUT_BUY
```

**场景3：反转信号**
```javascript
// 超买后回落穿越70
rsi = $(5m).RSI().value

ALL{
  CROSS(5m).close(70).below = true;
  $(5m).RSI().value < 70;
} = SELL;

// 超卖后反弹穿越30
ALL{
  CROSS(5m).close(30).above = true;
  $(5m).RSI().value > 30;
} = BUY;
```

**场景4：动态阈值突破**
```javascript
// 布林带突破
boll_upper = $(5m).BOLL(20, 2.0).upper
boll_lower = $(5m).BOLL(20, 2.0).lower

// 突破上轨
ALL{
  CROSS(5m).close($(5m).BOLL(20, 2.0).upper).above = true;
} = BUY;

// 跌破下轨
ALL{
  CROSS(5m).close($(5m).BOLL(20, 2.0).lower).below = true;
} = SELL;
```

**优势：**
- 精确性：准确识别穿越时刻
- 灵活性：支持固定阈值和动态阈值
- 直观性：金叉死叉概念清晰
- 实用性：最常用的信号触发机制

**注意事项：**
1. **需要至少2个数据点：** 需要比较当前期和前一期
2. **穿越定义：** 严格的穿越（不包括等于边界的情况）
3. **假信号：** 在震荡市场可能产生频繁假信号
4. **滞后性：** 穿越信号是事后确认，有一定滞后

**与其他函数配合：**
```javascript
// CROSS + CONSECUTIVE
ALL {
    CROSS(5m).close(ma20).above,       // 金叉触发
    CONSECUTIVE(5m).close(3).rising()  // 连续上涨确认
} = CONFIRMED_BREAKOUT

// CROSS + ZSCORE
ALL {
    CROSS(5m).close(100).above,        // 突破100
    ZSCORE(5m).close(50) > -1          // 不是异常低位（避免假突破）
} = VALID_BREAKOUT

// CROSS + CHANGE
ALL {
    CROSS(5m).close(ma20).above,       // 金叉
    CHANGE(5m).close(1).pct > 0.5      // 有足够的动量
} = MOMENTUM_CROSS
```

### 5.11 波动率函数

#### VOLA - 波动率分析

**语法：**
```javascript
VOLA(timeframe).field(period).value  // 绝对波动率（标准差）
VOLA(timeframe).field(period).pct    // 百分比波动率（变异系数）
VOLA(timeframe).field(period)        // 默认返回 .value
```

**说明：** 计算价格或其他字段的波动率，用于识别市场波动状态。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `timeframe` | 字符串 | 时间周期（如 "5m", "1h"） |
| `field` | 字符串 | 数据字段（open/high/low/close/volume） |
| `PERIOD` | 整数 | 回溯周期 |

**返回字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | 数值 | 绝对波动率（标准差）= √[Σ(x - mean)² / n] |
| `pct` | 数值 | 百分比波动率（变异系数）= (std_dev / mean) * 100 |

**计算方法：**
1. **绝对波动率 (value)**：计算指定周期的标准差
2. **百分比波动率 (pct)**：变异系数 (Coefficient of Variation)，归一化的波动率

**示例：**

**1. 基础用法**
```javascript
// 计算20期收盘价标准差
vol_20 = VOLA(5m).close(20).value

// 计算20期变异系数
vol_pct = VOLA(5m).close(20).pct

// 默认返回绝对波动率
vol_default = VOLA(5m).close(20)
```

**2. 低波动率待突破**
```javascript
// 波动率处于低位（20期波动率小于50期波动率的70%）
vol_20 = VOLA(5m).close(20).value
vol_50 = VOLA(5m).close(50).value

ALL{
  VOLA(5m).close(20).value < VOLA(5m).close(50).value * 0.7;
} = HOLD;
```

**3. 波动率突破策略**
```javascript
// 波动率突然放大（当前波动率 > 历史均值的1.5倍）
vol_current = VOLA(5m).close(10).value
vol_avg = AVERAGE(5m).close(50)

ALL{
  VOLA(5m).close(10).value > AVERAGE(5m).close(50) * 1.5;
} = BUY;
```

**4. 跨品种波动率比较**
```javascript
// 使用百分比波动率进行跨品种比较
vol_pct_btc = VOLA(5m).close(20).pct
vol_pct_eth = VOLA(5m).close(20).pct

// 选择波动率较大的品种（更适合短线交易）
ALL{
  VOLA(5m).close(20).pct > VOLA(5m).close(20).pct;
} = BUY;
```

**5. 波动率收缩后扩张**
```javascript
// 波动率从低位开始扩张
vol_5 = VOLA(5m).close(5).value
vol_20 = VOLA(5m).close(20).value

ALL {
    vol_5 > vol_20,                          // 短期波动率超过长期

    KLINE(5m).volume() > AVERAGE(5m).volume(20)  // 成交量放大
} = VOLATILITY_EXPANSION
```

**应用场景：**

```javascript
ALL {

```

**场景4：波动率突破确认**


**优势：**
- **市场状态识别**：区分震荡市和趋势市
- **风险度量**：量化价格波动幅度
- **跨品种比较**：使用 .pct 进行归一化比较
- **策略优化**：根据波动率调整止损距离

**注意事项：**
1. **波动率聚集**：高波动率后往往继续高波动
2. **波动率均值回归**：极端波动率倾向于回归均值
3. **周期选择**：短周期对市场变化更敏感
4. **数据质量**：需要足够的数据点（建议至少 PERIOD * 2）

#### ATR - 平均真实波幅

**语法：**
```javascript
ATR(timeframe).close(PERIOD).value  // 绝对ATR
ATR(timeframe).close(PERIOD).pct    // 百分比ATR
ATR(timeframe).close(PERIOD)        // 默认返回 .value
```

**说明：** 计算平均真实波动幅度（Average True Range），考虑跳空缺口的波动率指标。

**参数：**

| 参数 | 类型 | 说明 |
|------|------|------|
| `timeframe` | 字符串 | 时间周期（如 "5m", "1h"） |
| `field` | 字符串 | 固定使用 "close"（ATR内部使用high/low/close） |
| `PERIOD` | 整数 | 回溯周期 |

**返回字段：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `value` | 数值 | 绝对ATR（平均真实波幅） |
| `pct` | 数值 | 百分比ATR = (ATR / current_price) * 100 |

**计算方法：**
1. **True Range (TR)**：max(high-low, abs(high-prev_close), abs(low-prev_close))
2. **ATR**：TR 的 N 期简单移动平均
3. **百分比ATR**：(ATR / 当前价格) * 100

**示例：**

**1. 基础用法**
```javascript
// 计算14期ATR
atr_14 = ATR(5m).close(14).value

// 计算ATR占价格的百分比
atr_pct = ATR(5m).close(14).pct

// 默认返回绝对ATR
atr_default = ATR(5m).close(14)
```

**2. 动态止损**
```javascript
// 基于ATR的动态止损（1.5倍ATR）
entry_price = KLINE(5m).close()
atr = ATR(5m).close(14).value

stop_loss = entry_price - 1.5 * atr

ALL{
  KLINE(5m).close(0) < KLINE(5m).close(0) - 1.5 * ATR(5m).close(14).value;
} = SELL;
```

**3. ATR通道**
```javascript
// ATR通道（类似布林带）
sma_20 = $(5m).MA(20).value
atr = ATR(5m).close(14).value

upper_channel = sma_20 + 2 * atr
lower_channel = sma_20 - 2 * atr

// 突破上轨
ALL{
  CROSS(5m).close($(5m).MA(20).value + 2 * ATR(5m).close(14).value).above = true;
} = BUY;

// 跌破下轨
ALL{
  CROSS(5m).close($(5m).MA(20).value - 2 * ATR(5m).close(14).value).below = true;
} = SELL;
```

**4. ATR过滤器**
```javascript
// 只在ATR适中的环境交易（避免过高过低）
atr_pct = ATR(5m).close(14).pct

ALL {
    atr_pct > 0.5,                      // ATR不能太小（避免无波动）
    atr_pct < 3.0,                      // ATR不能太大（避免高风险）
    CROSS(5m).close(ma20).above         // 交易信号
} = FILTERED_ENTRY
```

**5. ATR倍数止盈止损**
```javascript
// 专业的风险管理系统
entry = KLINE(5m).close()
atr = ATR(5m).close(14).value

stop_loss = entry - 2 * atr      // 2倍ATR止损
take_profit = entry + 4 * atr    // 4倍ATR止盈（风险收益比2:1）

ALL{
  KLINE(5m).close(0) < KLINE(5m).close(0) - 2 * ATR(5m).close(14).value;
} = SELL;
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(0) + 4 * ATR(5m).close(14).value;
} = SELL;
```

**应用场景：**

**场景1：仓位管理（基于ATR）**
```javascript
// 根据ATR动态调整仓位大小

  if (atr_pct < 1.0) {
    return "LARGE";
  } else if (atr_pct < 2.0) {
    return "MEDIUM";
  } else {
    return "SMALL";
  }
}
```

**场景2：ATR突破策略**
```javascript
// ATR扩张突破（Volatility Breakout）
atr_10 = ATR(5m).close(10).value
atr_50 = ATR(5m).close(50).value

ALL {
    atr_10 > atr_50 * 1.5,              // ATR扩张

    KLINE(5m).volume() > AVERAGE(5m).volume(20) * 1.5  // 放量确认

```

**场景3：波动率收缩突破（Squeeze）**
```javascript

    KLINE(5m).volume() < AVERAGE(5m).volume(20)  // 缩量
} = SQUEEZE_SETUP

  CONSECUTIVE(5m).close(3).narrowing();
  KLINE(5m).volume(0) < AVERAGE(5m).volume(20);
  ATR(5m).close(14).value > LOWEST(5m).close(50) * 1.3;
} = BUY;
```

**场景4：趋势强度确认**
```javascript

    $(5m).MA(20).value > $(5m).MA(50).value,  // 趋势向上
    atr > atr_avg * 1.2,                 // 波动率扩张
    CHANGE(5m).close(1).pct > 0          // 价格上涨
} = STRONG_UPTREND
```

**场景5：跨周期ATR分析**
```javascript
// 多周期ATR确认
atr_5m = ATR(5m).close(14).pct
atr_15m = ATR(15m).close(14).pct
atr_1h = ATR(1h).close(14).pct

// 多周期ATR同时扩张（强趋势）
ALL {
    atr_5m > 1.5,
    atr_15m > 1.5,
    atr_1h > 1.5,
    CROSS(5m).close(ma20).above
} = MULTI_TIMEFRAME_BREAKOUT
```

**优势：**
- **考虑跳空**：比标准差更全面（包含开盘跳空）
- **风险管理**：专业的止损止盈距离计算
- **仓位优化**：根据波动率动态调整仓位
- **趋势识别**：ATR扩张通常伴随强趋势

**注意事项：**
1. **ATR不是方向性指标**：只衡量波动幅度，不预测方向
2. **周期选择**：14期是经典参数，可根据品种调整
3. **百分比更具可比性**：跨品种比较建议使用 .pct
4. **极端行情**：黑天鹅事件可能导致ATR失效

**与其他函数配合：**
```javascript

atr_zscore = ZSCORE(5m).close(50)

  ZSCORE(5m).close(50) > 2;
} = HOLD;

  ZSCORE(5m).close(50) < -2;
} = HOLD;

  ATR(5m).close(14).value > PERCENTILE(5m).close(100, 0.95);
} = HOLD;

vola = VOLA(5m).close(14).value

// 两个波动率指标都扩张

  VOLA(5m).close(14).value > AVERAGE(5m).close(50) * 1.5;
} = BUY;

// ATR + CROSS（波动率突破）
atr = ATR(5m).close(14).value
atr_threshold = AVERAGE(5m).close(50)

ALL{
  CROSS(5m).close(AVERAGE(5m).close(50)).above = true;
} = BUY;
```

**VOLA vs ATR 对比：**

| 特性 | VOLA | ATR |
|------|------|-----|
| **计算方法** | 标准差 | 真实波幅平均 |
| **跳空处理** | 不考虑 | 考虑跳空缺口 |
| **适用场景** | 一般波动率分析 | 专业风险管理 |
| **字段要求** | 任意字段 | 需要 high/low/close |
| **归一化** | .pct（变异系数） | .pct（占价格百分比） |
| **推荐用途** | 波动率比较、过滤 | 止损止盈、仓位管理 |

## 6. 高级分析函数

高级分析函数基于先进的数学理论和市场微观结构分析，用于捕捉价格的深层特征。

### HT - 希尔伯特变换

希尔伯特变换（Hilbert Transform）是一种信号处理技术，用于分析时间序列的周期性、相位和趋势成分。

**语法：**
```javascript
HT(timeframe).type.subfield
```

**参数：**

| 参数 | 类型 | 说明 | 必需 |
|------|------|------|------|
| `timeframe` | 字符串 | 时间周期 | 是 |
| `type` | 字符串 | HT类型 | 是 |
| `subfield` | 字符串 | 子字段 | 视类型而定 |

#### 支持的类型

**1. DCPERIOD - 主导周期**

**说明：** 识别价格序列的主导周期（Dominant Cycle PERIOD）。

**返回值：** 周期长度（K线数量），范围通常在10-40之间

**用途：**
- 动态调整指标周期
- 识别市场节奏变化
- 周期性策略优化

**示例：**
```javascript
// 获取当前主导周期
dominant_period = HT(5m).DCPERIOD

// 动态调整移动平均周期（使用自定义函数）
calcMaPeriod(dominant_period: Double): Integer {
  if (dominant_period > 20) {
    return 30;
  } else {
    return 20;
  }
}

@ma_period: Integer = calcMaPeriod(HT(5m).DCPERIOD);
```

---

**2. DCPHASE - 主导周期相位**

**说明：** 返回当前价格在主导周期中的相位角度。

**返回值：** 相位角度（度数），范围：0° - 360°
- 0°/360°：周期底部
- 180°：周期顶部

**用途：**
- 周期性买卖时机选择
- 识别周期转折点
- 波段操作入场点

**示例：**
```javascript
// 获取当前相位
phase = HT(5m).DCPHASE

// 在周期底部附近买入
ANY{
  HT(5m).phase < 30;
  HT(5m).phase > 330;
} = BUY;

// 在周期顶部附近卖出
ALL{
  HT(5m).phase > 150;
  HT(5m).phase < 210;
} = SELL;
```

---

**3. PHASOR - 相位矢量**

**语法：**
```javascript
HT(timeframe).PHASOR.inphase
HT(timeframe).PHASOR.quadrature
```

**说明：** 返回希尔伯特变换的相位分量。

**子字段：**
- `inphase`: 同相分量（I）
- `quadrature`: 正交分量（Q）

**关系：**
```
幅度 = √(I² + Q²)
相位 = arctan(Q / I)
```

**示例：**
```javascript
// 获取相位矢量分量
in_phase = HT(5m).PHASOR.inphase
quadrature = HT(5m).PHASOR.quadrature

// 计算幅度
amplitude = SQRT(POW(in_phase, 2) + POW(quadrature, 2))
```

---

**4. SINE - 主导周期正弦**

**语法：**
```javascript
HT(timeframe).SINE.sine
HT(timeframe).SINE.leadsine
```

**说明：** 生成与主导周期同步的正弦波。

**子字段：**
- `sine`: 主正弦波
- `leadsine`: 领先正弦波（相位提前）

**返回值：** 范围：-1 到 +1

**用途：**
- 周期性信号参考
- 趋势转折预测
- 周期交叉策略

**示例：**
```javascript
// 获取正弦波信号
sine = HT(5m).SINE.sine
lead_sine = HT(5m).SINE.leadsine

// 正弦波交叉
ALL{
  HT(5m).SINE.sine > HT(5m).SINE.leadsine;
} = BUY;
```

---

**5. TRENDMODE - 趋势模式**

**说明：** 判断当前市场是否处于趋势模式。

**返回值：**
- 0：震荡模式（Cycle Mode）
- 1：趋势模式（Trend Mode）

**用途：**
- 策略模式切换
- 指标参数自适应
- 风险管理调整

**示例：**
```javascript
// 获取趋势模式
trend_mode = HT(5m).TRENDMODE

// 根据模式选择策略（趋势模式）
ALL{
  HT(5m).trendmode == 1;
  $(5m).MACD().histogram > 0;
} = BUY;

// 震荡模式：使用均值回归策略
ALL{
  HT(5m).trendmode != 1;
  $(5m).RSI().value < 30;
} = BUY;
```

---

**6. TRENDLINE - 趋势线**

**说明：** 提取价格序列的趋势成分（去除周期波动后的趋势）。

**返回值：** 平滑的趋势线值

**用途：**
- 识别主趋势方向
- 过滤周期性噪音
- 趋势强度评估

**示例：**
```javascript
// 获取趋势线
trendline = HT(5m).TRENDLINE
current_price = KLINE(5m).close()

// 价格相对趋势线的位置
deviation = (current_price - trendline) / trendline * 100

// 偏离过大时回归
ALL{
  (KLINE(5m).close(0) - HT(5m).TRENDLINE) / HT(5m).TRENDLINE * 100 > 2;
} = SELL;  // 价格过高，可能回归
ALL{
  (KLINE(5m).close(0) - HT(5m).TRENDLINE) / HT(5m).TRENDLINE * 100 < -2;
} = BUY;  // 价格过低，可能反弹
```

### POWER - 力量平衡指标

`POWER`函数用于分析市场买卖力量的平衡关系。

**语法：**
```javascript
POWER(timeframe).type([offset])
```

**参数：**

| 参数 | 类型 | 说明 | 必需 | 默认值 |
|------|------|------|------|--------|
| `timeframe` | 字符串 | 时间周期 | 是 | - |
| `type` | 字符串 | 力量类型 | 是 | - |
| `offset` | 整数 | 时间偏移 | 否 | `0` |

#### BOP - Balance of Power (力量平衡)

**说明：** 衡量K线内买方和卖方力量的平衡关系。

**计算公式：**
```
BOP = (Close - Open) / (High - Low)
```

**返回值：** 范围：-1 到 +1
- +1：强势收盘（收盘 = 最高价且开盘 = 最低价）
- -1：弱势收盘（收盘 = 最低价且开盘 = 最高价）
- 0：平衡状态

**解读：**
- `BOP > 0`：买方力量占优（收盘价 > 开盘价）
- `BOP < 0`：卖方力量占优（收盘价 < 开盘价）
- `|BOP|` 越大：力量越悬殊
- `|BOP|` 越小：力量越均衡

**应用场景：**

1. **力量方向判断**
```
// 简写形式（推荐）
bop = POWER(5m).BOP()

ALL{
  POWER(5m).BOP() > 0.5;
} = BUY;
ALL{
  POWER(5m).BOP() < -0.5;
} = SELL;
```

2. **K线质量评估**
- 高BOP值的K线更可靠
- 低BOP值表示犹豫不决

3. **背离识别**
```javascript
// 价格新高但BOP降低：顶背离
close_current = KLINE(5m).close()
close_5ago = KLINE(5m).close(5)
bop_current = POWER(5m).BOP()
bop_5ago = POWER(5m).BOP(-5)

ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  POWER(5m).BOP() < POWER(5m).BOP(-5);
} = SELL;
```

4. **趋势确认**
- 上升趋势中BOP持续为正
- 下降趋势中BOP持续为负

**示例：**
```javascript
// 突破 + 力量确认
high_20 = HIGHEST(5m).high(20)
current_close = KLINE(5m).close()
bop = POWER(5m).BOP()

// 突破伴随强势买盘
ALL{
  KLINE(5m).close(0) > HIGHEST(5m).high(20);
  POWER(5m).BOP() > 0.6;
} = BUY;
```

## 7. K线形态函数

K线形态函数用于识别各种经典K线形态，帮助交易者捕捉市场反转和持续信号。

**语法：**
```javascript
PATTERN(timeframe).pattern_name([penetration])
```

**参数：**

| 参数 | 类型 | 说明 | 必需 | 默认值 |
|------|------|------|------|--------|
| `timeframe` | 字符串 | 时间周期 | 是 | - |
| `pattern_name` | 字符串 | 形态名称 | 是 | - |
| `penetration` | 浮点数 | 穿透率（0.0-1.0） | 否 | `0.3` |

**返回值：**
- `true`：识别到该形态
- `false`：未识别到该形态

**支持的形态：**
- `ENGULFING`：吞没形态
- `HAMMER`：锤子线
- `DOJI`：十字星
- `SHOOTING_STAR`：流星线
- `MORNING_STAR`：晨星
- `EVENING_STAR`：黄昏之星
- 更多形态请参考TA-Lib文档

**示例：**
```javascript
// 使用默认穿透率（推荐）
PATTERN(1h).ENGULFING()    // 使用默认0.3
PATTERN(5m).DOJI()          // 使用默认0.3

// 自定义穿透率（需要更严格或宽松的条件时）
PATTERN(1h).ENGULFING(0.5)  // 更严格
PATTERN(5m).DOJI(0.2)       // 更宽松

// 完整形式（等价，但默认值时不推荐）
PATTERN(1h).ENGULFING(0.3)  // 等价于 PATTERN(1h).ENGULFING()
```

```javascript
// 反转形态和持续形态

// ========== 看涨反转形态 + 趋势确认 ==========
ANY {
    // 锤子线（看涨反转）
    PATTERN(5m).HAMMER() == true AND $(5m).RSI().oversold = true AND KLINE(5m).close(0) > KLINE(5m).open(0) AND KLINE(5m).close(0) < $(5m).BOLL().lower;

    PATTERN(5m).ENGULFING() == BULLISH AND $(5m).RSI().value < 40 AND KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5;

    PATTERN(5m).MORNINGSTAR() == true AND $(5m).MACD().histogram > 0 AND KLINE(5m).close(0) > $(5m).EMA().value;
    
    // 三白兵
    PATTERN(5m).THREE_WHITE_SOLDIERS() == true AND $(5m).ADX().value > 20 AND CONSECUTIVE(5m).close(3).rising() >= 3;
    
    // 上升三法
    PATTERN(5m).RISING_THREE_METHODS() == true AND $(5m).MACD().trend == BULLISH;
} = BUY;

// ========== 看跌反转形态出场 ==========
ANY {
    // 射击之星
    PATTERN(5m).SHOOTING_STAR() == true;
    
    // 黄昏之星
    PATTERN(5m).EVENINGSTAR() == true;

    PATTERN(5m).ENGULFING() == BEARISH;
    
    // 乌云盖顶
    PATTERN(5m).DARK_CLOUD_COVER() == true;
    
    // 三只乌鸦
    PATTERN(5m).THREE_BLACK_CROWS() == true;
} = SELL;

// ========== 看跌反转形态 + 趋势确认 ==========
ANY {

    PATTERN(5m).INVERTED_HAMMER() == true AND $(5m).RSI().overbought = true AND KLINE(5m).close(0) < KLINE(5m).open(0) AND KLINE(5m).close(0) > $(5m).BOLL().upper;
    
    // 看跌吞没形态
    PATTERN(5m).ENGULFING() == BEARISH AND $(5m).RSI().value > 60 AND KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5;
    
    // 黄昏之星形态
    PATTERN(5m).EVENINGSTAR() == true AND $(5m).MACD().histogram < 0 AND KLINE(5m).close(0) < $(5m).EMA().value;
    
    // 三只乌鸦
    PATTERN(5m).THREE_BLACK_CROWS() == true AND $(5m).ADX().value > 20 AND CONSECUTIVE(5m).close(3).falling() >= 3;

    PATTERN(5m).FALLING_THREE_METHODS() == true AND $(5m).MACD().trend == BEARISH;

    PATTERN(5m).PIERCING() == true;
    
    // 三白兵
    PATTERN(5m).THREE_WHITE_SOLDIERS() == true;
} = BUY;
```

**穿透率说明：**
- 穿透率用于控制形态识别的严格程度
- 取值范围：0.0（最宽松）到1.0（最严格）
- 建议值：0.3（默认），适合大多数市场情况
- 高波动市场：可适当降低穿透率（如0.2）
- 低波动市场：可适当提高穿透率（如0.5）

**注意事项：**
1. **形态确认**：单一K线形态可靠性有限，建议结合其他指标确认
2. **时间周期**：不同时间周期的形态可靠性不同，长期周期更可靠
3. **成交量配合**：重要形态需成交量放大确认
4. **市场环境**：形态在趋势反转时更有效，震荡市场中可靠性降低
5. **反向确认**：关注形态形成后的后续K线确认

**最佳实践：**
- 结合RSI、MACD等指标确认形态
- 关注形态形成时的成交量变化
- 优先使用长期周期的形态信号
- 形态信号与趋势方向一致时可靠性更高

## 8. 序列条件函数

序列条件函数用于检查连续周期的条件满足情况。

### CONSECUTIVE / CONSEC - 连续条件检测

检查某字段是否连续N个周期满足特定条件。

**语法：**
```javascript
CONSECUTIVE(timeframe).field(period).condition(params...)
CONSEC(timeframe).field(period).condition(params...)  // 简写形式
```

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| `timeframe` | 时间周期 | `5m`, `1h`, `1d` |
| `field` | K线字段 | `close`, `open`, `high`, `low`, `volume` |
| `PERIOD` | 连续周期数（范围：1~100） | `3`, `5`, `20` |
| `condition` | 判断条件 | `rising()`, `above(100)` |
| `params` | 条件参数 | 阈值、区间等 |

**支持的条件类型：**

#### 1. 趋势类条件（无参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `rising()` | 连续上涨（严格大于） | `CONSEC(5m).close(3).rising()` |
| `falling()` | 连续下跌（严格小于） | `CONSEC(5m).close(3).falling()` |
| `increasing()` | 连续增加（允许相等） | `CONSEC(5m).volume(5).increasing()` |
| `decreasing()` | 连续减少（允许相等） | `CONSEC(5m).close(5).decreasing()` |

#### 2. 阈值类条件（单参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `above(value)` | 连续高于阈值 | `CONSEC(5m).close(20).above(100)` |
| `below(value)` | 连续低于阈值 | `CONSEC(5m).close(10).below(50)` |

#### 3. 区间类条件（双参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `between(min, max)` | 连续在区间内 | `CONSEC(5m).close(5).between(100, 200)` |

#### 4. 穿越类条件（单参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `crosses_above(value)` | 从下方穿越 | `CONSEC(5m).close(3).crosses_above(100)` |
| `crosses_below(value)` | 从上方穿越 | `CONSEC(5m).close(3).crosses_below(100)` |

**穿越判断逻辑：**
- `crosses_above(100)`：前N-1个周期都低于100，最新周期高于100
- `crosses_below(100)`：前N-1个周期都高于100，最新周期低于100

**返回值：**
- `true`：最近N个周期连续满足条件
- `false`：不满足

**示例：**
```javascript
// close连续3期上涨
CONSEC(5m).close(3).rising()

// volume连续5期增加
CONSEC(5m).volume(5).increasing()

// close连续20期高于100
CONSEC(5m).close(20).above(100)

// close连续10期在100-200区间
CONSEC(5m).close(10).between(100, 200)
```

**综合策略示例：**
```javascript
// 多重确认突破策略
ALL {
    // 1. 价格突破MA20
    KLINE(5m).close() > $(5m).MA(20).value,
    
    // 2. 连续3期上涨确认趋势
    CONSEC(5m).close(3).rising(),
    
    // 3. 成交量连续放大
    CONSEC(5m).volume(3).increasing(),
    
    // 4. 价格在安全区间
    CONSEC(5m).close(5).between(100, 500),
    
    // 5. RSI未超买
    $(5m).RSI().value < 70
} = BUY
```

### COUNT - 条件计数

统计最近N个周期中满足特定条件的次数。

**⚠️ 重要说明：COUNT的双重用法**

COUNT在Prophet DSL中有**两种完全不同的用法**：

1. **信号函数**：`COUNT(n){...}` - 在规则顶层使用，详见[信号函数文档](./Prophet%20DSL%20信号函数.md)
2. **数据函数**：`COUNT(timeframe).field(period).condition(...)` - 在表达式中使用（本节）

两种用法可以**完美共存**，解析器会根据语法自动区分。

---

#### 基础语法

```javascript
COUNT(timeframe).field(period).condition(params...)
```

**参数：**

| 参数 | 说明 | 示例 |
|------|------|------|
| `timeframe` | 时间周期 | `5m`, `1h`, `1d` |
| `field` | K线字段 | `close`, `open`, `high`, `low`, `volume` |
| `PERIOD` | 统计期数（范围：1~100） | `20`, `50`, `100` |
| `condition` | 判断条件 | `rising()`, `above(100)` |
| `params` | 条件参数 | 阈值、区间等 |

**返回值：** 返回整数（0 到 PERIOD 之间），表示满足条件的期数。

---

#### 支持的9种条件

##### 1. 趋势条件（无参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `rising()` | 每期上涨（相对前一期） | `COUNT(5m).close(20).rising()` |
| `falling()` | 每期下跌（相对前一期） | `COUNT(5m).close(20).falling()` |
| `increasing()` | 每期增加（可相等） | `COUNT(5m).volume(20).increasing()` |
| `decreasing()` | 每期减少（可相等） | `COUNT(5m).close(20).decreasing()` |

**判断逻辑：** 每期独立判断（不是连续判断）

```javascript
// 示例：COUNT(5m).close(20).rising()
// 统计过去20期中有多少期满足 close[i] > close[i-1]
```

##### 2. 阈值条件（单参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `above(value)` | 每期高于阈值 | `COUNT(5m).close(20).above(100)` |
| `below(value)` | 每期低于阈值 | `COUNT(5m).close(20).below(50)` |

```javascript
// 过去20期中有多少期close>100
COUNT(5m).close(20).above(100)

// 过去50期中有多少期volume<1000
COUNT(5m).volume(50).below(1000)
```

##### 3. 区间条件（双参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `between(min, max)` | 每期在区间内 | `COUNT(5m).close(20).between(90, 110)` |

```javascript
// 过去20期中有多少期close在[90, 110]区间
COUNT(5m).close(20).between(90, 110)
```

##### 4. 穿越条件（单参数）

| 条件 | 说明 | 示例 |
|------|------|------|
| `crosses_above(value)` | 每期向上穿越 | `COUNT(5m).close(20).crosses_above(100)` |
| `crosses_below(value)` | 每期向下穿越 | `COUNT(5m).close(20).crosses_below(100)` |

**穿越判断逻辑：**
- `crosses_above(100)`：前一期 < 100 且 当前期 > 100
- `crosses_below(100)`：前一期 > 100 且 当前期 < 100

```javascript
// 过去20期中有多少次向上穿越100
COUNT(5m).close(20).crosses_above(100)
```

---

#### 使用示例

**示例1：趋势强度确认**

```javascript
// 需求：过去20期中至少有15期上涨才是强趋势
ALL{
    COUNT(5m).close(20).rising() >= 15;
    KLINE(5m).close() > AVERAGE(5m).close(20);
} = BUY;
```

**示例2：高位整理突破**

```javascript
// 需求：长期在高位盘整后突破
ALL{
    // 过去100期中至少80期在100以上（高位盘整）
    COUNT(5m).close(100).above(100) >= 80;
    
    // 开始突破
    CONSEC(5m).close(3).rising();
    
    // 成交量放大（简写形式）
    KLINE(5m).volume() > AVERAGE(5m).volume(20) * 1.5;
} = BUY;
```

**示例3：成交量活跃度**

```javascript
// 需求：统计过去20期中有多少期成交量放大
ALL{
    COUNT(5m).volume(20).increasing() >= 12;  // 60%的时间在放量
    KLINE(5m).close() > HIGHEST(5m).high(20);
} = BUY;
```

**示例4：两种COUNT混合使用**

```javascript
// COUNT信号函数 + COUNT数据函数
COUNT(2){
    // 条件1：过去20期中至少有15期上涨（数据函数）
    COUNT(5m).close(20).rising() >= 15;
    
    // 条件2：当前价格高于均价
    KLINE(5m).close() > AVERAGE(5m).close(20);
    
    // 条件3：连续3期上涨
    CONSEC(5m).close(3).rising();
} = BUY;  // 正好满足2个条件才触发（信号函数）
```

---

#### COUNT vs CONSECUTIVE

| 特性 | COUNT | CONSECUTIVE |
|------|-------|-------------|
| 判断方式 | 每期独立判断 | 连续判断 |
| 返回值 | 整数（计数） | 布尔值 |
| 适用场景 | 统计特征、趋势强度 | 连续性确认 |

**对比示例：**

```javascript
// COUNT：统计过去20期中有多少期上涨（每期独立判断）
COUNT(5m).close(20).rising()  
// 可能返回：15（表示20期中有15期上涨，不一定连续）

// CONSECUTIVE：判断最近3期是否连续上涨
CONSEC(5m).close(3).rising()
// 返回：true或false（必须是连续3期都上涨）
```

**使用建议：**
- 需要**统计特征**时用 COUNT
- 需要**连续确认**时用 CONSECUTIVE
- 两者可以组合使用

---

#### 注意事项

**1. 数据不足处理**

```javascript
// 如果K线数据少于PERIOD，返回0（不抛出异常）
COUNT(5m).close(100).rising()  // 只有50根K线 → 返回0
```

**2. 第一期无法判断趋势**

```javascript
// rising/falling/increasing/decreasing需要比较前一期
// 所以最多只能统计PERIOD-1期

COUNT(5m).close(20).rising()  
// 实际上只能判断19期（第1期没有前一期比较）
```

**3. 字段验证**

```javascript
// 只支持5种字段
COUNT(5m).close(20).rising()   // ✅ 支持
COUNT(5m).open(20).falling()   // ✅ 支持
COUNT(5m).high(20).above(100)  // ✅ 支持
COUNT(5m).low(20).below(50)    // ✅ 支持
COUNT(5m).volume(20).increasing() // ✅ 支持

COUNT(5m).price(20).rising()   // ❌ 不支持（price不是有效字段）
```

**4. 参数数量验证**

```javascript
// 不同条件需要的参数数量不同
COUNT(5m).close(20).rising()        // ✅ 无参数
COUNT(5m).close(20).above(100)      // ✅ 1个参数
COUNT(5m).close(20).between(90, 110) // ✅ 2个参数

COUNT(5m).close(20).rising(100)     // ❌ 错误：rising不接受参数
COUNT(5m).close(20).above()         // ❌ 错误：above需要1个参数
COUNT(5m).close(20).between(100)    // ❌ 错误：between需要2个参数
```

## 9. Smart Money Concepts (SMC) 函数

Smart Money Concepts（智能资金概念）是一套现代价格行为分析方法，以下函数实现了SMC中的核心概念。

### FVG - Fair Value Gap（公平价值缺口）

FVG是价格快速移动时形成的"价格空白区域"，在Smart Money Concepts（SMC）交易策略中被广泛使用。

**语法：**
```javascript
FVG(timeframe).operation([parameters]).subfield
```

**核心概念：**
- **看涨FVG**：K线1的high < K线3的low（向上的价格空隙）
- **看跌FVG**：K线1的low > K线3的high（向下的价格空隙）
- **回补**：价格重新进入FVG区域的过程

---

#### 1. FVG 形态检测

检测当前是否形成FVG。

**语法：**
```javascript
FVG(timeframe).bullish      // 看涨FVG（简写，推荐）
FVG(timeframe).bearish      // 看跌FVG（简写，推荐）
FVG(timeframe).any          // 任意类型FVG
```

**返回值：** 布尔值（true/false）

**示例：**
```javascript
// 基础检测
ALL{
  FVG(5m).bullish = true;
} = BUY;             // 看涨FVG形成时买入

// 结合其他条件
ALL {
    FVG(5m).bullish,
    $(5m).RSI().value > 50,
    KLINE(5m).volume() > AVERAGE(5m).volume(20)
} = BUY

// 多周期共振
ALL {
    FVG(15m).bullish,
    FVG(5m).bullish,
    $(5m).MACD().histogram > 0
} = BUY
```

---

#### 2. FVG 区域信息

获取最近未回补FVG的区域边界。

**语法：**
```javascript
FVG(timeframe).top          // 上边界（简写，推荐）
FVG(timeframe).bottom       // 下边界（简写，推荐）
FVG(timeframe).mid          // 中间价（简写，推荐）
FVG(timeframe).size         // FVG大小

// 带lookback参数
FVG(timeframe).top(0)       // 最近的FVG上边界（默认）
FVG(timeframe).top(1)       // 前1个FVG上边界
FVG(timeframe).bottom(2)    // 前2个FVG下边界
```

**返回值：** 数值（价格）

**示例：**
```javascript
// 价格回踩FVG中点策略
fvg_mid = FVG(5m).mid
current_price = KLINE(5m).close()

ALL {
    FVG(5m).bullish,
    current_price > fvg_mid * 0.998,
    current_price < fvg_mid * 1.002,
    $(5m).MACD().histogram > 0
} = BUY

// 止损设置在FVG下方
stop_loss = FVG(5m).bottom * 0.995
ALL{
  KLINE(5m).close(0) < FVG(5m).bottom * 0.995;
} = SELL;

// FVG大小过滤（只交易足够大的FVG）
ALL{
  FVG(5m).size > ATR(5m).close(14).value * 1.5;
} = BUY;
```

---

#### 3. FVG 回补状态

获取FVG的回补信息。

**语法：**
```javascript
FVG(timeframe).filled.pct        // 回补百分比（0-100）
FVG(timeframe).filled.isfull     // 是否完全回补（布尔）
FVG(timeframe).filled.ispartial  // 是否部分回补（布尔）

// 带lookback参数
FVG(timeframe).filled(0).pct     // 最近FVG的回补百分比
FVG(timeframe).filled(1).isfull  // 前1个FVG是否完全回补
```

**返回值：**
- `.pct`：数值（0-100）
- `.isfull`、`.ispartial`：布尔值

**示例：**
```javascript
// 只在FVG回补少于30%时入场
filled_pct = FVG(5m).filled.pct

ALL {
    FVG(5m).bullish,
    filled_pct < 30,
    filled_pct > 0,
    CONSEC(5m).close(2).rising()
} = BUY

// FVG完全回补时止盈
ALL{
  FVG(5m).filled.isfull = true;
} = SELL;

// 部分回补监控
ALL{
  FVG(5m).filled.ispartial = true;
  CONSEC(5m).close(2).rising();
} = HOLD;
```

---

#### 4. FVG 剩余区域

获取未回补部分的区域。

**语法：**
```javascript
FVG(timeframe).remaining.top     // 剩余区域上边界
FVG(timeframe).remaining.bottom  // 剩余区域下边界
FVG(timeframe).remaining.mid     // 剩余区域中点
FVG(timeframe).remaining.size    // 剩余区域大小
```

**返回值：** 数值

**示例：**
```javascript
// 根据剩余FVG大小决策
remaining_size = FVG(5m).remaining.size
atr = ATR(5m).close(14).value

// 剩余空间足够大时入场
ALL{
  FVG(5m).remaining.size > ATR(5m).close(14).value * 2;
} = BUY;

// 剩余空间太小时避免入场
ALL{
  FVG(5m).remaining.size < ATR(5m).close(14).value * 0.5;
} = HOLD;

// 在剩余区域中点附近入场
remaining_mid = FVG(5m).remaining.mid
current_price = KLINE(5m).close()

ALL {
    current_price > remaining_mid * 0.99,
    current_price < remaining_mid * 1.01,
    FVG(5m).filled.pct < 70
} = ENTRY_AT_REMAINING_MID
```

---

#### 5. FVG 统计功能

统计指定周期内的FVG数量。

**语法：**
```javascript
FVG(timeframe).count(PERIOD)           // 总FVG数量
FVG(timeframe).count(PERIOD).bullish   // 看涨FVG数量
FVG(timeframe).count(PERIOD).bearish   // 看跌FVG数量
FVG(timeframe).count(PERIOD).unfilled  // 未回补FVG数量
```

**返回值：** 整数

**示例：**
```javascript
// FVG密集区突破策略
fvg_count = FVG(5m).count(50)
unfilled_count = FVG(5m).count(50).unfilled

ALL {
    fvg_count > 5,
    unfilled_count > 3,
    FVG(5m).bullish,
    KLINE(5m).close() > HIGHEST(5m).high(20)
} = BUY

// FVG稀缺性判断
bullish_count = FVG(5m).count(100).bullish
bearish_count = FVG(5m).count(100).bearish

// 看涨FVG远多于看跌FVG（强势市场）
ALL{
  FVG(5m).count(100).bullish > FVG(5m).count(100).bearish * 2;
} = BUY;
```

---

#### 完整策略示例

**示例1：FVG回踩入场策略**

```javascript
// 入场条件：看涨FVG形成且回补少于30%，价格在FVG中点上方，RSI适中
ALL {
    FVG(5m).bullish,
    FVG(5m).filled.pct < 30,
    KLINE(5m).close() > FVG(5m).mid,
    $(5m).RSI().value > 50,
    $(5m).RSI().value < 70
} = BUY

// 出场条件：FVG完全回补或价格跌破FVG下边界
ANY {
    FVG(5m).filled.isfull,
    KLINE(5m).close() < FVG(5m).bottom
} = SELL
```

**示例2：多重FVG确认策略**

```javascript
// 多周期FVG共振，FVG大小超过ATR，连续3根K线上涨
ALL {
    FVG(15m).bullish,
    FVG(5m).bullish,
    FVG(5m).filled.pct < 20,
    FVG(5m).size > ATR(5m).close(14).value,
    CONSEC(5m).close(3).rising()
} = BUY
```

**示例3：FVG配合力量指标策略**

```javascript
// FVG有剩余空间，价格在剩余区中点上方，买方力量强劲
ALL {
    FVG(5m).bullish,
    FVG(5m).remaining.size > 0,
    KLINE(5m).close() > FVG(5m).remaining.mid,
    POWER(5m).BOP() > 0.5,
    CROSS(5m).close($(5m).MA(20).value).above
} = BUY
```

---

#### 应用场景总结

| 场景 | 使用方法 | 说明 |
|------|---------|------|
| **形态确认** | `FVG(5m).bullish` | 检测FVG是否刚形成 |
| **回踩入场** | `FVG(5m).mid` | 价格回踩FVG中点附近入场 |
| **回补监控** | `FVG(5m).filled.pct` | 监控FVG回补程度 |
| **空间评估** | `FVG(5m).remaining.size` | 评估剩余空间是否足够 |
| **密集区分析** | `FVG(5m).count(50)` | 识别FVG密集区 |
| **多周期共振** | `FVG(15m).bullish && FVG(5m).bullish` | 多时间框架确认 |
| **止损设置** | `FVG(5m).bottom * 0.995` | 在FVG下方设置止损 |

---

#### 注意事项

1. **数据要求**：需要至少3根K线来检测FVG
2. **FVG类型**：看涨FVG和看跌FVG的回补方向相反
3. **过滤噪音**：可使用 `FVG.size > ATR` 过滤太小的FVG
4. **未回补列表**：只返回未完全回补的FVG
5. **性能优化**：统计功能会遍历历史数据，建议合理设置period

### PREMIUM - 溢价/折价区分析

**功能说明：**
分析当前价格在某个范围内的位置，判断是否处于溢价区（高价区）、折价区（低价区）或均衡区。

**语法：**
```javascript
// 区域判断（返回布尔值）
PREMIUM(timeframe).premium(PERIOD)    // 是否在溢价区（价格偏高）
PREMIUM(timeframe).discount(PERIOD)   // 是否在折价区（价格偏低）
PREMIUM(timeframe).equilibrium(PERIOD) // 是否在均衡区

// 区域数值（返回数值）
PREMIUM(timeframe).zone(PERIOD)       // 区域类型：1=溢价，0=均衡，-1=折价
PREMIUM(timeframe).pct(PERIOD)        // 在范围内的百分比位置（0-100）
PREMIUM(timeframe).level(PERIOD)      // 均衡价格水平（50%位置）
PREMIUM(timeframe).strength(PERIOD)   // 区域强度（0-100）
PREMIUM(timeframe).high(PERIOD)       // 范围高点
PREMIUM(timeframe).low(PERIOD)        // 范围低点
```

**参数：**
- `PERIOD`：回看周期（范围：1~100），默认100

**返回值：**
- 区域判断：布尔值（true/false）
- 区域数值：数值

**使用示例：**
```javascript
// 在折价区买入
ALL {
    PREMIUM(5m).discount(100),
    $(5m).RSI().value < 40
} = BUY

// 在溢价区卖出
ALL {
    PREMIUM(15m).premium(100),
    PREMIUM(15m).strength(100) > 70,
    $(15m).RSI().value > 60
} = SELL

// 价格接近均衡线
ALL{
  ABS(KLINE(5m).close(0) - PREMIUM(5m).level(100)) / PREMIUM(5m).level(100) < 0.01;
} = HOLD;
```

### ORDERBLOCK - 订单块检测

**功能说明：**
检测Order Block（订单块），这是SMC中代表机构订单聚集的区域，通常是趋势反转前的最后一个相反方向K线。

**语法：**
```javascript
// 形态检测（返回布尔值）
ORDERBLOCK(timeframe).bullish      // 是否存在看涨订单块
ORDERBLOCK(timeframe).bearish      // 是否存在看跌订单块
ORDERBLOCK(timeframe).any          // 是否存在任何订单块

// 区域信息（返回数值，可选.bullish/.bearish筛选）
ORDERBLOCK(timeframe).top(lookback)       // 订单块上边界
ORDERBLOCK(timeframe).bottom(lookback)    // 订单块下边界
ORDERBLOCK(timeframe).mid(lookback)       // 订单块中间价
ORDERBLOCK(timeframe).strength(lookback)  // 订单块强度（0-100）

// 状态信息
ORDERBLOCK(timeframe).tested(lookback)    // 是否被测试过
ORDERBLOCK(timeframe).testcount(lookback) // 测试次数
ORDERBLOCK(timeframe).broken(lookback)    // 是否被突破
ORDERBLOCK(timeframe).distance(lookback)  // 当前价格距离订单块的百分比距离

// 统计功能
ORDERBLOCK(timeframe).count(PERIOD)       // 统计数量
```

**参数：**
- `lookback`：回看索引，0表示最近的订单块，默认0
- `PERIOD`：统计周期

**返回值：**
- 形态检测：布尔值
- 区域信息和状态：数值

**使用示例：**
```javascript
// 价格回到看涨订单块时买入
ALL {
    ORDERBLOCK(5m).bullish,
    KLINE(5m).close() > ORDERBLOCK(5m).bottom(0),
    KLINE(5m).close() < ORDERBLOCK(5m).mid(0),
    !ORDERBLOCK(5m).broken(0)
} = BUY

// 订单块被测试但未突破
ALL {
    ORDERBLOCK(15m).bearish,
    ORDERBLOCK(15m).tested(0),
    ORDERBLOCK(15m).testcount(0) >= 2,
    !ORDERBLOCK(15m).broken(0),
    KLINE(15m).close() < ORDERBLOCK(15m).mid(0)
} = SELL
```

### SWING - 摆动高低点检测

**功能说明：**
检测价格的摆动高点和摆动低点，这是识别市场结构的基础。

**语法：**
```javascript
// 存在性检测（返回布尔值）
SWING(timeframe).high(left_bars, right_bars)   // 是否存在摆动高点
SWING(timeframe).low(left_bars, right_bars)    // 是否存在摆动低点

// 价格信息（返回数值，可选.high/.low筛选）
SWING(timeframe).price(left_bars, right_bars, lookback)     // 摆动点价格
SWING(timeframe).strength(left_bars, right_bars, lookback)  // 摆动点强度
SWING(timeframe).distance(left_bars, right_bars)            // 距离最近摆动点的百分比

// 状态信息
SWING(timeframe).broken(left_bars, right_bars, lookback)    // 摆动点是否被突破

// 统计功能
SWING(timeframe).count(left_bars, right_bars, PERIOD)       // 统计摆动点数量
```

**参数：**
- `left_bars`：左侧K线数量，默认5
- `right_bars`：右侧K线数量，默认5
- `lookback`：回看索引，默认0
- `PERIOD`：统计周期，默认100

**返回值：**
- 存在性检测：布尔值
- 其他：数值

**使用示例：**
```javascript
// 摆动低点被突破
ALL {
    SWING(5m).low(5, 5),
    SWING(5m).broken.low(5, 5, 0),
    KLINE(5m).close() < SWING(5m).price.low(5, 5, 0)
} = TREND_CHANGE

// 价格接近摆动高点
ALL {
    SWING(15m).high(5, 5),
    ABS(SWING(15m).distance.high(5, 5)) < 1.0,
    $(15m).RSI().value > 65
} = RESISTANCE_NEAR
```

```javascript
// 形态检测（返回布尔值）
CHOCH(timeframe).bullish(swing_left, swing_right)  // 是否发生看涨CHoCH

// 趋势信息
CHOCH(timeframe).trend(swing_left, swing_right)  // 当前趋势：1=上升，-1=下降，0=未知

CHOCH(timeframe).count(swing_left, swing_right, PERIOD)    // 统计CHoCH数量
```

- 形态检测：布尔值
- 其他：数值

**使用示例：**
```javascript
// CHoCH后趋势反转
ALL {
    CHOCH(15m).bullish(5, 5),
    CHOCH(15m).trend(5, 5) == 1,
    KLINE(15m).close() > CHOCH(15m).price(5, 5, 0),

    $(15m).RSI().value < 60
} = BUY

// 趋势明确
ALL{
  CHOCH(5m).trend(5, 5) == 1;
  BOS(5m).bullish(5, 5) = true;
} = BUY;
```

### LIQUIDITY - 流动性区域检测

**功能说明：**
检测流动性区域（等高点、等低点），这些区域代表止损订单聚集的位置。

**语法：**
```javascript
// 存在性检测（返回布尔值）
LIQUIDITY(timeframe).buyside(price_tolerance)   // 是否存在买方流动性（等高点）
LIQUIDITY(timeframe).sellside(price_tolerance)  // 是否存在卖方流动性（等低点）

// 价格信息（返回数值，可选.buyside/.sellside筛选）
LIQUIDITY(timeframe).price(price_tolerance, lookback)     // 流动性价格水平
LIQUIDITY(timeframe).strength(price_tolerance, lookback)  // 流动性强度（触及次数）

// 状态信息
LIQUIDITY(timeframe).swept(price_tolerance, lookback)     // 是否被扫荡
LIQUIDITY(timeframe).distance(price_tolerance)            // 当前价格距离流动性的百分比

// 统计功能
LIQUIDITY(timeframe).count(price_tolerance, PERIOD)       // 统计流动性区域数量
```

**参数：**
- `price_tolerance`：价格容差百分比，用于判断等高/等低，默认0.5%
- `lookback`：回看索引，默认0
- `PERIOD`：统计周期，默认100

**返回值：**
- 存在性检测：布尔值
- 其他：数值

**使用示例：**
```javascript
// 流动性被扫荡后反向交易
ALL {
    LIQUIDITY(5m).buyside(0.5),
    LIQUIDITY(5m).swept.buyside(0.5, 0),
    KLINE(5m).close() < LIQUIDITY(5m).price.buyside(0.5, 0)
} = SELL

// 接近流动性区域
ALL {
    LIQUIDITY(15m).sellside(0.5),
    ABS(LIQUIDITY(15m).distance.sellside(0.5)) < 2.0,
    !LIQUIDITY(15m).swept.sellside(0.5, 0)
} = SUPPORT_NEAR
```

### BREAKER - 突破块检测

**功能说明：**
检测Breaker Block（突破块），即被突破的Order Block，极性反转后成为强力的支撑/阻力。

**语法：**
```javascript
// 形态检测（返回布尔值）
BREAKER(timeframe).bullish      // 是否存在看涨突破块
BREAKER(timeframe).bearish      // 是否存在看跌突破块

// 区域信息（返回数值，可选.bullish/.bearish筛选）
BREAKER(timeframe).top(lookback)       // 突破块上边界
BREAKER(timeframe).bottom(lookback)    // 突破块下边界
BREAKER(timeframe).mid(lookback)       // 突破块中间价
BREAKER(timeframe).strength(lookback)  // 突破块强度

// 状态信息
BREAKER(timeframe).tested(lookback)    // 是否被测试过
BREAKER(timeframe).testcount(lookback) // 测试次数
BREAKER(timeframe).broken(lookback)    // 是否失效

// 统计功能
BREAKER(timeframe).count(PERIOD)       // 统计突破块数量
```

**参数：**
- `lookback`：回看索引，默认0
- `PERIOD`：统计周期，默认100

**返回值：**
- 形态检测：布尔值
- 其他：数值

**使用示例：**
```javascript
// 价格回到看涨突破块时买入
ALL {
    BREAKER(5m).bullish,
    KLINE(5m).close() > BREAKER(5m).bottom(0),
    KLINE(5m).close() < BREAKER(5m).top(0),
    !BREAKER(5m).broken(0),
    BREAKER(5m).testcount(0) < 3
} = BUY

// 突破块作为强支撑
ALL {
    BREAKER(15m).bullish,
    BREAKER(15m).tested(0),
    KLINE(15m).close() > BREAKER(15m).mid(0),
    $(15m).RSI().value > 45
} = SUPPORT_CONFIRMED
```

## 最佳实践

### 1. 周期选择原则

**短周期 (5-20根K线)**
- 优点：反应灵敏，适合捕捉快速变化
- 缺点：噪音较多，容易产生假信号
- 适用：日内交易、快速进出场

**中周期 (20-50根K线)**
- 优点：平衡灵敏度和稳定性
- 缺点：延迟适中
- 适用：短期波段、趋势跟踪

**长周期 (50-200根K线)**
- 优点：信号稳定，过滤噪音
- 缺点：反应迟钝，可能错过机会
- 适用：中长期趋势、主趋势判断

### 2. 多周期组合

```javascript
// 趋势确认：使用多个周期
short_avg = AVERAGE(5m).close(10)
mid_avg = AVERAGE(5m).close(20)
long_avg = AVERAGE(5m).close(50)

// 金叉排列
ALL{
  AVERAGE(5m).close(10) > AVERAGE(5m).close(20);
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
} = BUY;
```

### 3. 标准化处理

```javascript
// 标准化变化率，便于跨周期比较
change_raw = CHANGE(5m).close(10)
std_dev = STD(5m).close(10)
change_normalized = change_raw / std_dev

// 标准化斜率
slope_raw = SLOPE(5m).close(20)
price_level = AVERAGE(5m).close(20)
slope_normalized = slope_raw / price_level
```

### 4. 异常值处理

```javascript
// 使用中位数代替平均值，抗异常值
avg = AVERAGE(5m).close(20)     // 受极端值影响
median = MEDIAN(5m).close(20)   // 更稳健

// 使用中位数判断数据偏态（使用自定义函数）
checkDataSkew(avg: Double, median: Double): Boolean {
  if (avg > median * 1.05) {
    // 数据右偏，有较大的正异常值
    return true;
  }
  return false;
}
```

### 5. 性能优化

```javascript
// ❌ 不推荐：重复计算
ALL{
  AVERAGE(5m).close(20) > KLINE(5m).close(0);
} = HOLD;

// ✅ 推荐：缓存结果
@avg_20: Double = AVERAGE(5m).close(20);
@current: Double = KLINE(5m).close(0);

ALL{
  @avg_20 > @current;
} = HOLD;
```

### 6. 参数范围检查

```javascript
// 检查HT返回值的合理性（使用自定义函数）
calcStrategyPeriod(PERIOD: Double): Integer {
  if (PERIOD > 0 AND PERIOD < 100) {
    // 合理的周期值
    return ROUND(PERIOD, 0);
  } else {
    // 使用默认值
    return 20;
  }
}

@strategy_period: Integer = calcStrategyPeriod(HT(5m).DCPERIOD);
```

### 7. 数学函数使用注意

**参数范围限制：**

| 函数 | 参数限制 | 违反时行为 |
|------|---------|----------|
| SQRT | x ≥ 0 | 抛出异常 |
| LN, LOG10 | x > 0 | 抛出异常 |
| ASIN, ACOS | -1 ≤ x ≤ 1 | 抛出异常 |
| POW, EXP | 结果不溢出 | 抛出异常 |

**安全使用：**
```javascript
// ❌ 错误：可能对负数开方
SQRT(KLINE(5m).close() - KLINE(5m).high())

// ✅ 正确：确保非负（使用自定义函数）
calcSafeSqrt(): Double {
  if (KLINE(5m).close(0) > KLINE(5m).high(0)) {
    return SQRT(KLINE(5m).close(0) - KLINE(5m).high(0));
  }
  return 0.0;
}
```

### 8. HT使用建议

**数据要求：**
- HT需要足够的历史数据（建议至少50根K线）
- 数据量不足会影响周期识别准确性

**周期选择：**
- 日内交易：使用5m或15m
- 波段交易：使用1h或4h
- 长期趋势：使用1d

### 9. BOP使用建议

**阈值设置：**
```javascript
STRONG_BULL_THRESHOLD = 0.6
WEAK_BULL_THRESHOLD = 0.3
NEUTRAL_THRESHOLD = 0.1
WEAK_BEAR_THRESHOLD = -0.3
STRONG_BEAR_THRESHOLD = -0.6
```

**避免单独使用：**
```javascript
// ❌ 不推荐：仅依赖BOP

  POWER(5m).BOP() > 0.6;
} = BUY;

// ✅ 推荐：结合其他指标

  POWER(5m).BOP() > 0.6;
  $(5m).RSI().value > 50;
  $(5m).MACD().histogram > 0;
} = BUY;
```

**平滑处理：**
```javascript
// 单根K线BOP可能波动大，使用平均值
bop_avg = (POWER(5m).BOP() + POWER(5m).BOP(-1) + POWER(5m).BOP(-2)) / 3
ALL{
  POWER(5m).BOP() > 0.5;
} = BUY;
```

## 注意事项

### 1. 时间周期格式

支持的时间周期：
- 分钟：1m, 5m, 15m, 30m
- 小时：1h, 4h, 6h, 12h
- 天：1d, 3d
- 周：1w
- 月：1M

### 2. 数据充足性

- 确保有足够的历史数据计算指标
- 指标周期越大，需要的数据越多
- 数据不足时函数可能返回NaN或0
- 统计函数需要至少2个数据点才能计算标准差和方差

### 3. 性能优化

- 相同计算会自动缓存，避免重复计算
- 避免使用过大的周期（如period > 500）
- 复杂计算（如SLOPE、HT）比简单计算（如AVERAGE）慢
- 尽量减少不必要的高周期指标调用

### 4. 精度问题

- 浮点数比较时注意精度
- 使用ROUND函数处理小数
- 避免直接比较浮点数是否相等

```javascript
// ❌ 不推荐
ALL{
  SQRT(4) == 2;
} = BUY;

// ✅ 推荐：使用容差
ALL{
  ABS(SQRT(4) - 2) < 0.0001;
} = BUY;
```

### 5. 边界条件

- 所有统计函数需要足够的历史数据
- 如果请求的周期数超过可用数据，自动调整为可用数据量
- HT函数对数据量敏感，建议至少50根K线

### 6. 数值精度

```javascript
// 注意浮点数精度问题
std = STD(5m).close(100)
variance = VARIANCE(5m).close(100)

// 理论上 std² = variance，但可能有微小误差
if (ABS(POW(std, 2) - variance) < 0.0001) {  // 使用容差
  // 验证计算精度
}
    ...
```

### 7. 时间对齐

- 所有统计都基于K线序列
- 确保不同函数使用相同的时间周期
- 注意K线更新时刻的数据一致性

### 8. 数据同步

- 不同时间周期的K线更新时间不同
- 高频周期（1m）更新更快
- 低频周期（1h, 1d）更新较慢
- 在周期切换时刻要特别注意

### 9. HT限制

- **数据依赖**：需要足够的历史数据
- **计算延迟**：HT计算复杂，有一定延迟
- **周期稳定性**：市场周期可能快速变化
- **参数敏感性**：短周期数据可能不稳定

### 10. BOP限制

- **十字星问题**：当High=Low时，BOP无定义
- **跳空缺口**：开盘直接涨停或跌停，BOP=±1
- **单K线局限**：只反映单根K线，需结合趋势

### 11. 三角函数注意

三角函数使用**弧度**而非角度：

```javascript
// 角度转弧度
degrees = 90
radians = degrees * 3.14159 / 180
result = SIN(radians)

// 弧度转角度
angle_deg = ATAN(1) * 180 / 3.14159  // 45度
```

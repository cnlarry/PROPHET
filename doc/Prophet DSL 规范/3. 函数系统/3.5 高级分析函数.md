## 概述

高级分析函数提供了超越基础统计分析的复杂市场分析能力，包括周期检测、趋势识别、力量平衡和形态识别等功能。

**函数特点：**
- ✅ 需要 `timeframe` 参数
- ✅ 基于复杂的数学模型
- ✅ 提供深度市场洞察
- ✅ 可用于条件判断和变量赋值

## HT - 希尔伯特变换

希尔伯特变换是一组用于分析时间序列周期性和趋势的强大工具。

### DCPERIOD - 周期检测

检测价格序列的主要周期长度。

#### 语法
```javascript
HT(timeframe).DCPERIOD
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
主要周期长度（单位：K线根数）。

#### 示例
```javascript
// 检测市场主要周期
main_cycle = HT(5m).DCPERIOD

// 根据周期调整策略参数
period = main_cycle * 2
moving_average = AVERAGE(5m).close(period)
```

---

### DCPHASE - 相位分析

分析价格序列的相位状态。

#### 语法
```javascript
HT(timeframe).DCPHASE
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
相位值（弧度）。

#### 示例
```javascript
// 获取当前相位
current_phase = HT(5m).DCPHASE

// 相位转换检测
ALL{
  HT(5m).DCPHASE - HT(5m).DCPHASE(1) > 3.14159;
} = HOLD;
```

---

### TRENDLINE - 趋势线

提取价格序列的趋势成分。

#### 语法
```javascript
HT(timeframe).TRENDLINE
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
趋势线值。

#### 示例
```javascript
// 获取趋势线
trend_line = HT(5m).TRENDLINE
current_price = KLINE(5m).close()

// 价格相对于趋势线的位置
ALL{
  (KLINE(5m).close(0) - HT(5m).TRENDLINE) / HT(5m).TRENDLINE * 100 > 2;
} = SELL;
ALL{
  (KLINE(5m).close(0) - HT(5m).TRENDLINE) / HT(5m).TRENDLINE * 100 < -2;
} = BUY;
```

---

### TRENDMODE - 趋势模式

识别当前市场是处于趋势模式还是周期模式。

#### 语法
```javascript
HT(timeframe).TRENDMODE
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
- `1`: 趋势模式
- `0`: 周期模式

#### 示例
```javascript
// 获取趋势模式
trend_mode = HT(5m).TRENDMODE

// 根据模式选择策略
// 趋势跟踪策略
ALL{
  HT(5m).trendmode == 1;
  SLOPE(5m).close(20) > 0;
} = BUY;

// 均值回归策略
ALL{
  HT(5m).trendmode != 1;
  $(5m).RSI().value < 30;
} = BUY;
```

### PHASOR - 相量分析

进行相量分析，提供正弦和余弦成分。

#### 语法
```javascript
HT(timeframe).PHASOR.inphase    // 同相成分
HT(timeframe).PHASOR.quadrature // 正交成分
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
- `.inphase`: 同相成分
- `.quadrature`: 正交成分

#### 示例
```javascript
// 获取相量成分
inphase = HT(5m).PHASOR.inphase
quadrature = HT(5m).PHASOR.quadrature

// 计算幅度和相位
amplitude = SQRT(POW(inphase, 2) + POW(quadrature, 2))
phase = ATAN(quadrature / inphase)
```

---

### SINE - 正弦分析

提取正弦和领先正弦成分。

#### 语法
```javascript
HT(timeframe).SINE.sine      // 正弦成分
HT(timeframe).SINE.leadsine  // 领先正弦成分
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
- `.sine`: 正弦成分
- `.leadsine`: 领先正弦成分

#### 示例
```javascript
// 获取正弦成分
sine_wave = HT(5m).SINE.sine
leading_sine = HT(5m).SINE.leadsine

// 领先指标信号
ALL{
  HT(5m).SINE.leadsine > HT(5m).SINE.sine;
  HT(5m).SINE.sine < 0;
} = BUY;
ALL{
  HT(5m).SINE.leadsine < HT(5m).SINE.sine;
  HT(5m).SINE.sine > 0;
} = SELL;
```

## POWER - 力量平衡指标

分析市场买卖力量的平衡关系。

### BOP - 力量平衡

衡量K线内买方和卖方力量的平衡关系。

#### 语法
```javascript
POWER(timeframe).BOP([offset])
```

#### 参数
- `timeframe`: 时间周期
- `offset`: 时间偏移（可选，默认为0）

#### 返回值
力量平衡值（范围：-1 到 +1）。
- `+1`: 强势收盘（买方力量占优）
- `-1`: 弱势收盘（卖方力量占优）
- `0`: 平衡状态

#### 示例
```javascript
// 获取力量平衡值
bop = POWER(5m).BOP()

// 力量方向判断
ALL{
  POWER(5m).BOP() > 0.5;
} = BUY;
ALL{
  POWER(5m).BOP() < -0.5;
} = SELL;

// 背离识别
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  POWER(5m).BOP() < POWER(5m).BOP(5);
} = SELL;
```

## PATTERN - K线形态识别

识别各种经典K线形态。

### 基础形态

#### 语法
```javascript
PATTERN(timeframe).pattern_name([penetration])
```

#### 参数
- `timeframe`: 时间周期
- `pattern_name`: 形态名称
- `penetration`: 穿透率（0.0-1.0，可选）

#### 返回值
布尔值，表示是否识别到该形态。

#### 支持的形态

##### 看涨形态
- `HAMMER` - 锤子线
- `INVERTED_HAMMER` - 倒锤子线
- `ENGULFING_BULLISH` - 看涨吞没
- `MORNING_STAR` - 晨星
- `PIERCING` - 刺透形态

##### 看跌形态
- `HANGING_MAN` - 上吊线
- `SHOOTING_STAR` - 射击之星
- `ENGULFING_BEARISH` - 看跌吞没
- `EVENING_STAR` - 黄昏之星
- `DARK_CLOUD_COVER` - 乌云盖顶

#### 示例
```javascript
// 识别锤子线
ALL{
  PATTERN(5m).HAMMER() = true;
} = BUY;

// 识别看跌吞没
ALL{
  PATTERN(5m).ENGULFING_BEARISH() = true;
} = SELL;

// 自定义穿透率
ALL{
  PATTERN(5m).MORNING_STAR(0.5) = true;
} = BUY;
```

---

### 复杂形态

#### 三兵形态
- `THREE_WHITE_SOLDIERS` - 三白兵
- `THREE_BLACK_CROWS` - 三只乌鸦
- `THREE_INSIDE_UP` - 三内升
- `THREE_OUTSIDE_UP` - 三外升

#### 组合形态
- `RISING_THREE_METHODS` - 上升三法
- `FALLING_THREE_METHODS` - 下降三法
- `MAT_HOLD` - 铺垫形态

#### 示例
```javascript
// 三白兵确认强势
ALL{
  PATTERN(5m).THREE_WHITE_SOLDIERS() = true;
  $(5m).RSI().value > 50;
} = BUY;

// 黄昏之星结合RSI
ALL{
  PATTERN(5m).EVENING_STAR() = true;
  $(5m).RSI().value > 70;
} = SELL;
```

## 使用示例

### 示例1：多维度趋势分析

```javascript
// 希尔伯特趋势分析
trend_mode = HT(5m).TRENDMODE
trend_line = HT(5m).TRENDLINE

// 移动平均趋势
ma_20 = AVERAGE(5m).close(20)
ma_50 = AVERAGE(5m).close(50)

// 综合趋势判断
ALL{
  HT(5m).TRENDMODE == 1;
  $(5m).MA(20).value > $(5m).MA(50).value;
  KLINE(5m).close(0) > HT(5m).TRENDLINE;
} = BUY;
```

---

### 示例2：形态+指标确认策略

```javascript
// K线形态识别
bullish_engulfing = PATTERN(5m).ENGULFING_BULLISH()
morning_star = PATTERN(5m).MORNING_STAR()

// 技术指标确认
rsi = $(5m).RSI().value
macd_histogram = $(5m).MACD().histogram

// 综合买入信号
ALL{
  ANY{
    PATTERN(5m).ENGULFING() == BULLISH;
    PATTERN(5m).MORNINGSTAR() == true;
  };
  $(5m).RSI().value < 60;
  $(5m).MACD().histogram > 0;
} = BUY;
```

---

### 示例3：力量平衡交易策略

```javascript
// 力量平衡分析
bop = POWER(5m).BOP()
bop_ma = AVERAGE(5m).POWER.BOP(14)

// 力量转换信号
ALL{
  POWER(5m).BOP() > AVERAGE(5m).POWER.BOP(14);
  POWER(5m).BOP() > 0;
} = BUY;
ALL{
  POWER(5m).BOP() < AVERAGE(5m).POWER.BOP(14);
  POWER(5m).BOP() < 0;
} = SELL;
```

---

### 示例4：周期自适应策略

```javascript
// 周期检测
main_cycle = HT(5m).DCPERIOD
cycle_phase = HT(5m).DCPHASE

// 自适应参数（使用自定义函数）
calcLookback(main_cycle: Double): Integer {
  if (main_cycle > 20) {
    // 长周期市场
    return 50;
  } else {
    // 短周期市场
    return 20;
  }
}

@lookback: Integer = calcLookback(HT(5m).DCPERIOD);

// 计算指标
adaptive_ma = AVERAGE(5m).close(lookback)
```

## 最佳实践

### 1. 多指标确认

```javascript
// 不要单独依赖单一指标
ht_trend = HT(5m).TRENDMODE
ma_trend = AVERAGE(5m).close(20) > AVERAGE(5m).close(50)
price_trend = KLINE(5m).close() > KLINE(5m).open()

// 多重确认
ALL{
  HT(5m).TRENDMODE == 1;
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
  KLINE(5m).close(0) > KLINE(5m).open(0);
} = BUY;
```

---

### 2. 形态结合成交量

```javascript
// K线形态
bullish_pattern = PATTERN(5m).ENGULFING_BULLISH()

// 成交量确认
current_volume = KLINE(5m).volume()
average_volume = AVERAGE(5m).volume(20)

// 有效形态
ALL{
  PATTERN(5m).ENGULFING_BULLISH() = true;
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5;
} = BUY;
```

---

### 3. 动态参数调整

```javascript
// 根据市场状态调整参数
trend_mode = HT(5m).TRENDMODE

// 根据市场状态调整参数（使用自定义函数）
calcIndicatorPeriod(trend_mode: Integer): Integer {
  if (trend_mode == 1) {
    // 趋势市场：使用长周期指标
    return 50;
  } else {
    // 震荡市场：使用短周期指标
    return 14;
  }
}

@indicator_period: Integer = calcIndicatorPeriod(HT(5m).TRENDMODE);

rsi = $(5m).RSI(indicator_period).value
```

---

### 4. 风险管理结合

```javascript
// 高级分析信号
advanced_signal = HT(5m).TRENDMODE == 1 AND PATTERN(5m).MORNING_STAR()

// 风险控制
atr = ATR(5m).14
position_size = ACCOUNT.EQUITY() / (atr * 2)  // ATR止损下的仓位计算

ALL{
  HT(5m).TRENDMODE == 1;
  PATTERN(5m).MORNING_STAR() = true;
} = BUY;
```

## 概述

Prophet DSL提供时间序列函数，用于访问除OHCLV之外的序列数据，包括当前市场状态访问。

### 函数类型对比

| 特性 | 数据函数 | 时间序列函数 |
|------|---------|------------|
| **语法** | `FUNC(timeframe).method()` | `FUNC().method()` 或 `FUNC().field` |
| **时间框架** | 必需（如 `5m`, `1h`） | 不需要 |
| **数据来源** | K线数据 | 外部数据源（历史序列）或当前市场状态 |
| **数据维度** | 历史序列 | 历史序列或当前快照 |
| **示例** | `HIGHEST(5m).high(20)` | `FEARGREED().value(-7)`, `CURRENT().price` |
| **典型函数** | `HIGHEST`, `LOWEST`, `REF` | `CURRENT`, `FEARGREED`, `FUNDINGRATE` |

### 时间序列函数

**用途：** 访问具有自身时间维度的历史数据序列，或当前市场状态快照

**函数特点：**
- ✅ **不需要** `timeframe` 参数
- ✅ 数据自带时间维度（日期、时间戳等）
- ✅ 支持多种语法形式：
  - 标准方法调用：`FUNCTION().method(params)`（如 `FEARGREED().value(-7)`）
  - 字段访问：`FUNCTION().field`（如 `CURRENT().price`）
- ✅ 支持历史回溯和统计分析
- ✅ 可以与其他DSL函数组合使用

**适用数据类型：**
- 当前市场状态（价格、时间）
- 市场情绪指标（恐惧与贪婪指数）
- 资金费率历史数据
- 多空比数据
- 链上数据指标
- 社交媒体情绪分析
- 宏观经济数据

**现有函数：**
- `CURRENT()` - 当前市场状态访问
- `FEARGREED()` - 恐惧与贪婪指数
- `FUNDINGRATE()` - 资金费率

## CURRENT - 市场状态访问

**语法：** `CURRENT().field`

**说明：** 时间序列函数的一种，用于访问当前市场状态的各类数据，包括价格、时间、资金费率、恐惧与贪婪指数和多空比数据的最新值。

**核心特点：**
- 统一入口访问当前市场状态
- 简化的字段访问语法，直接获取最新值
- 支持嵌套子函数组（如 `CURRENT().longshort.ratio(offset)`）
- 基于 `get_signal(current_price, current_time)` 传入的参数
- 实时数据通过 `set_funding_rate_series()`、`set_fear_greed_series()` 和 `set_long_short_ratio_series()` 设置

---

### 价格字段

#### price - 当前价格

**语法：** `CURRENT().price`

**返回值：** 浮点数（当前价格）

**数据来源：** `get_signal(current_price, current_time)` 的 `current_price` 参数

**示例：**
```dsl
// 价格突破判断
ALL{
    CURRENT().price > 50000,
    $(5m).MACD().trend = BULLISH
} = BUY;

// 价格区间判断
ALL{
    CURRENT().price BETWEEN(48000, 52000),
    $(1h).RSI().value < 50
} = BUY;

// 与移动平均线比较
ALL{
    CURRENT().price > $(1h).EMA(20).value,
    $(5m).MACD().signal = BUY
} = BUY;
```

---

### 时间字段

#### timestamp - 当前时间戳

**语法：** `CURRENT().timestamp`

**返回值：** 整数（Unix时间戳，毫秒）

**数据来源：** `get_signal(current_price, current_time)` 的 `current_time` 参数

**示例：**
```dsl
// 通常不直接使用，而是使用time相关字段
current_ts = CURRENT().timestamp
```

---

#### Time - 当前时间（带时区）

**语法：** 
- `CURRENT().Time` - UTC时间（默认）
- `CURRENT().Time()` - UTC时间（推荐写法）
- `CURRENT().Time(timezone)` - 指定时区时间

**参数：**
- `timezone`: 时区偏移（整数，-12 到 12）
  - `0`: UTC时间（默认）
  - `8`: UTC+8（北京时间）
  - `-5`: UTC-5（美东时间）

**子字段：**
- `week` - 星期几（0-6，0=星期日）
- `month` - 月份（1-12）
- `day` - 日期（1-31）
- `hour` - 小时（0-23）
- `minute` - 分钟（0-59）
- `second` - 秒（0-59）

**示例：**
```dsl
// 基础时间访问
utc_hour = CURRENT().Time.hour           // UTC时间的小时
beijing_hour = CURRENT().Time(8).hour    // 北京时间的小时

// 星期几判断（周末不交易）
ALL{
    CURRENT().Time.week != 0,            // 不是星期日
    CURRENT().Time.week != 6,            // 不是星期六
    $(5m).MACD().signal = BUY
} = BUY;

// 交易时段控制
ALL{
    CURRENT().Time(8).hour BETWEEN(9, 17),  // 北京时间9:00-17:00
    $(5m).RSI().value < 30
} = BUY;

// 月初策略
ALL{
    CURRENT().Time.day <= 5,             // 每月前5天
    FEARGREED().value(0) < 30,
    $(1h).MACD().trend = BULLISH
} = BUY;

// 整点时刻
ALL{
    CURRENT().Time.minute = 0,           // 整点
    $(5m).BOLL().percent_b < 0.2
} = BUY;
```

**时区示例：**
```dsl
// 假设 get_signal() 传入的时间为 2025-12-07 13:48:55 UTC

CURRENT().Time.hour           // 返回 13（UTC时间）
CURRENT().Time().hour         // 返回 13（UTC时间，推荐写法）
CURRENT().Time(0).hour        // 返回 13（UTC时间）
CURRENT().Time(8).hour        // 返回 21（北京时间 21:48:55）
CURRENT().Time(-5).hour       // 返回 8（美东时间 08:48:55）

CURRENT().Time(8).week        // 返回 0（北京时间是星期日）
CURRENT().Time.day            // 返回 7（UTC时间是7号）
CURRENT().Time(8).day         // 返回 7（北京时间仍是7号）
```

### 资金费率字段

#### fundingrate - 当前资金费率

**语法：** `CURRENT().fundingrate`

**返回值：** 浮点数（通常在 -0.01 到 0.01 之间）

**数据来源：** `engine.set_funding_rate_series()` 设置的最新数据

**说明：** 
- 正值：多头支付空头（市场看多）
- 负值：空头支付多头（市场看空）
- 相当于 `FUNDINGRATE().value(0)` 的简化版

**示例：**
```dsl
// 资金费率过高，做空信号
ALL{
    CURRENT().fundingrate > 0.001,       // 资金费率较高
    $(5m).RSI().value > 70,
    $(1h).MACD().trend = BEARISH
} = SELL;

// 资金费率为负，做多有利
ALL{
    CURRENT().fundingrate < 0,           // 空头支付多头
    $(1h).MACD().signal = BUY
} = BUY;

// 极端资金费率警告
ALL{
    CURRENT().fundingrate > 0.002,       // 极高资金费率
    CURRENT().price > $(1h).BOLL().upper
} = SELL;  // 多头过热
```

### 恐惧与贪婪指数字段

#### feargreed - 恐惧与贪婪指数

**语法：** 
- `CURRENT().feargreed.value` - 当天指数值（0-100）
- `CURRENT().feargreed.classification` - 当天分类标签

**参数（可选）：**
- `offset`: 偏移天数（0 到 -100）
  - `0`: 今天（默认）
  - `-1`: 昨天
  - `-7`: 7天前

**返回值：**
- `value`: 整数（0-100）
- `classification`: 字符串枚举
  - `"Extreme Fear"` - 极度恐慌（0-24）
  - `"Fear"` - 恐慌（25-44）
  - `"Neutral"` - 中性（45-55）
  - `"Greed"` - 贪婪（56-75）
  - `"Extreme Greed"` - 极度贪婪（76-100）

**数据来源：** `engine.set_fear_greed_series()` 设置的数据

**说明：** 相当于 `FEARGREED().value(0)` 和 `FEARGREED().classification(0)` 的简化版

**示例：**
```dsl
// 使用数值判断
ALL{
    CURRENT().feargreed.value < 25,      // 极度恐慌
    $(1h).RSI().value < 35,
    $(5m).MACD().signal = BUY
} = BUY;

// 使用分类判断（更直观）
ALL{
    CURRENT().feargreed.classification = "Extreme Fear",
    $(5m).MACD().crossover_type = GOLDEN_CROSS
} = BUY;

// 带偏移量访问
ALL{
    CURRENT().feargreed(-1).value > CURRENT().feargreed.value,  // 比昨天更恐慌
    CURRENT().feargreed.value < 30
} = BUY;

// 情绪过滤
ALL{
    CURRENT().feargreed.classification != "Extreme Fear",
    CURRENT().feargreed.classification != "Extreme Greed",
    $(5m).MACD().trend = BULLISH
} = BUY;  // 避免极端情绪
```

### 多空比字段

#### longshort - 多空比数据

**语法：** 
- `CURRENT().longshort.ratio(offset)` - 多空比率
- `CURRENT().longshort.long(offset)` - 多头比例
- `CURRENT().longshort.short(offset)` - 空头比例
- `CURRENT().longshort.net(offset)` - 净多头比例
- `CURRENT().longshort.dominance(offset)` - 多头主导率
- `CURRENT().longshort.trend(period)` - 趋势判断
- `CURRENT().longshort.extreme(threshold)` - 极端检测

**参数：**
- `offset`: 偏移次数（0 到 -100，仅用于 ratio, long, short, net, dominance）
  - `0`: 当前（默认）
  - `-1`: 上一次
  - `-5`: 5次前
- `period`: 趋势判断周期（2 到 100，仅用于 trend）
- `threshold`: 极端阈值（0.1 到 10.0，仅用于 extreme）

**返回值：**
- `ratio`: 浮点数（多空比率，long/short）
- `long`: 浮点数（多头比例，0~1）
- `short`: 浮点数（空头比例，0~1）
- `net`: 浮点数（净多头比例，(long-short)/(long+short)）
- `dominance`: 浮点数（多头主导率，long/(long+short)*100）
- `trend`: 字符串枚举（RISING/FALLING/STABLE）
- `extreme`: 布尔值（true=极端，false=正常）

**数据来源：** `engine.set_long_short_ratio_series()` 设置的数据

**说明：** 多空比数据反映市场多空力量对比，可用于判断市场情绪和趋势

**示例：**
```dsl
// 多空比过高，做空信号
ALL{
    CURRENT().longshort.ratio(0) > 1.5,      // 多空比大于1.5
    $(1h).RSI().value > 70,
    $(5m).MACD().trend = BEARISH
} = SELL;

// 多头主导，做多信号
ALL{
    CURRENT().longshort.dominance(0) > 70,   // 多头主导率超过70%
    CURRENT().longshort.long(0) > 0.6,       // 多头比例超过60%
    $(1h).MACD().signal = BUY
} = BUY;

// 多空比趋势上升
ALL{
    CURRENT().longshort.trend(7) = RISING,   // 7个数据点趋势上升
    CURRENT().longshort.ratio(0) > 1.2,
    $(5m).MACD().signal = BUY
} = BUY;

// 极端多空比检测
ALL{
    CURRENT().longshort.extreme(2.0) = true, // 多空比极端（>2.0或<0.5）
    $(1h).RSI().value > 75
} = SELL;  // 多头过热，做空

// 净多头比例判断
ALL{
    CURRENT().longshort.net(0) > 0.3,        // 净多头比例超过30%
    $(5m).MACD().crossover_type = GOLDEN_CROSS
} = BUY;
```

### CURRENT函数的特点与使用建议

**功能特点：**

| 功能 | CURRENT | 其他时间序列函数 | 说明 |
|------|---------|------------|------|
| 当前价格 | `CURRENT().price` | N/A | 简洁获取当前价格 |
| 当前时间 | `CURRENT().Time.hour` | N/A | 便捷访问当前时间信息 |
| 当前资金费率 | `CURRENT().fundingrate` | `FUNDINGRATE().value(0)` | 等价，CURRENT更简洁 |
| 昨天资金费率 | N/A | `FUNDINGRATE().value(-1)` | 只有其他时间序列函数支持历史数据 |
| 资金费率平均 | N/A | `FUNDINGRATE().avg(24)` | 只有其他时间序列函数支持统计分析 |
| 当前恐惧指数 | `CURRENT().feargreed.value` | `FEARGREED().value(0)` | 等价，CURRENT更简洁 |
| 7天前恐惧指数 | N/A | `FEARGREED().value(-7)` | 只有其他时间序列函数支持历史数据 |
| 恐惧指数趋势 | N/A | `FEARGREED().trend(7)` | 只有其他时间序列函数支持趋势分析 |

**使用建议：**
- ✅ 只需要最新值 → 使用 `CURRENT()`（更简洁）
- ✅ 需要历史数据或统计分析 → 使用其他时间序列函数（`FEARGREED()`, `FUNDINGRATE()`）

**使用示例：**
```dsl
// 方式1：使用CURRENT获取当前值（简洁）
ALL{
    CURRENT().feargreed.value < 25,
    CURRENT().fundingrate < 0,
    $(5m).MACD().signal = BUY
} = BUY;

// 方式2：使用其他时间序列函数（功能更丰富）
ALL{
    FEARGREED().value(0) < 25,
    FEARGREED().trend(7) = FALLING,      // 趋势分析
    FUNDINGRATE().avg(24) < 0,           // 统计分析
    $(5m).MACD().signal = BUY
} = BUY;

// 方式3：混合使用（推荐）
ALL{
    CURRENT().feargreed.value < 25,      // 简洁获取当前值
    FEARGREED().change(7) < -15,         // 使用时间序列的统计功能
    CURRENT().fundingrate < 0,           // 简洁获取当前值
    $(5m).MACD().signal = BUY
} = BUY;
```

## FEARGREED - 恐惧与贪婪指数

**语法：** `FEARGREED().method(params)`

**说明：** Alternative.me 加密货币恐惧与贪婪指数，用于衡量市场整体情绪。

**数据范围：** 0-100
- **0-24**: 极度恐慌 (Extreme Fear)
- **25-44**: 恐慌 (Fear)
- **45-55**: 中性 (Neutral)
- **56-75**: 贪婪 (Greed)
- **76-100**: 极度贪婪 (Extreme Greed)

**数据来源：** Alternative.me API + `feargreed` 数据表

**更新频率：** 每日更新（UTC时间）

---

### 基础访问方法

#### value() - 获取指定日期的指数值

**语法：** `FEARGREED().value([offset])`

**参数：**
- `offset`: 偏移天数（整数，0-365）
  - `0`: 今天（默认）
  - `1`: 昨天
  - `7`: 7天前
  - 以此类推...

**返回值：** 整数 (0-100)

**示例：**
```dsl
// 获取今天的恐惧与贪婪指数
today_fg = FEARGREED().value(0)
today_fg_short = FEARGREED().value()  // 省略参数，默认为0

// 获取昨天的指数
yesterday_fg = FEARGREED().value(-1)

// 获取7天前的指数
week_ago_fg = FEARGREED().value(-7)

// 在交易规则中使用
ALL{
    FEARGREED().value(0) < 25,      // 当前极度恐慌
    $(5m).RSI().value < 35          // RSI超卖
} = BUY;

// 对比不同时期的指数
ALL{
    FEARGREED().value(0) > FEARGREED().value(-7);  // 比7天前更高
    $(1h).MACD().trend = BULLISH;
} = BUY;
```

**应用场景：**
- 判断当前市场情绪
- 识别极端情绪区域
- 对比不同时期的情绪变化
- 作为入场/出场的过滤条件

---

#### classification() - 获取情绪分类标签

**语法：** `FEARGREED().classification([offset])`

**参数：**
- `offset`: 偏移天数（整数，范围：[-100, 0]）
  - `0`: 今天（默认）
  - `-1`: 昨天
  - `-7`: 7天前
  - 最小可回溯100天

**返回值：** 字符串（以下之一）
- `"Extreme Fear"`: 极度恐慌 (0-24)
- `"Fear"`: 恐慌 (25-44)
- `"Neutral"`: 中性 (45-55)
- `"Greed"`: 贪婪 (56-75)
- `"Extreme Greed"`: 极度贪婪 (76-100)

**示例：**
```dsl
// 获取当前的分类标签
current_class = FEARGREED().classification(0)
current_class_short = FEARGREED().classification()  // 省略参数，默认为0

// 判断是否极度恐慌
ALL{
    FEARGREED().classification(0) = "Extreme Fear",
    $(5m).RSI().value < 30
} = BUY;

// 判断情绪级别变化
ALL{
    FEARGREED().classification(-1) = "Extreme Fear";  // 昨天极度恐慌
    FEARGREED().classification(0) = "Fear";          // 今天恐慌（有所缓解）
    $(1h).MACD().signal = BUY;
} = BUY;  // 恐慌开始缓解

// 避免极端情绪交易
ALL{
    FEARGREED().classification(0) != "Extreme Fear",
    FEARGREED().classification(0) != "Extreme Greed",
    $(5m).MACD().crossover_type = GOLDEN_CROSS
} = BUY;  // 只在非极端情绪下交易
```

**应用场景：**
- 直观判断市场情绪级别
- 检测情绪级别的变化
- 过滤极端情绪时期
- 策略可读性更好

**value() vs classification()：**
```dsl
// 使用数值（更灵活）
FEARGREED().value(0) < 25          // 可以设置精确阈值

// 使用分类（更直观）
FEARGREED().classification(0) = "Extreme Fear"  // 语义更清晰
```

### 统计分析方法

#### change() - 计算变化量

**语法：** `FEARGREED().change([PERIOD])`

**参数：**
- `PERIOD`: 计算变化的周期（天数，1~100，默认7）

**返回值：** 整数（可正可负）
- 正值：指数上升
- 负值：指数下降

**计算公式：** `当前值 - N天前的值`

**示例：**
```dsl
// 7天变化量
change_7d = FEARGREED().change(7)   // 默认7天
change_7d_explicit = FEARGREED().change()

// 30天变化量
change_30d = FEARGREED().change(30)

// 判断下降趋势
ALL{
    FEARGREED().change(7) < -10,    // 7天下降超过10点
    FEARGREED().change(30) < -20,   // 30天下降超过20点
    $(5m).MACD().signal = BUY
} = BUY;  // 在恐慌加剧时逆势买入

// 判断快速恶化
ALL{
    FEARGREED().change(1) < -5,     // 单日下降超过5点
    FEARGREED().value(0) < 30       // 且已经处于恐慌区
} = HOLD;  // 持币观望
```

**应用场景：**
- 识别情绪快速变化
- 判断市场转折点
- 构建反向指标
- 动量策略参考

---

#### avg() - 计算平均值

**语法：** `FEARGREED().avg([PERIOD])`

**参数：**
- `PERIOD`: 计算平均值的周期（天数，1~100，默认7）

**返回值：** 浮点数 (0-100)

**说明：** 计算最近N天的平均恐惧与贪婪指数，用于平滑短期波动。

**示例：**
```dsl
// 7天平均值
avg_7d = FEARGREED().avg(7)    // 默认7天
avg_7d_explicit = FEARGREED().avg()

// 30天平均值
avg_30d = FEARGREED().avg(30)

// 均值回归策略
ALL{
    FEARGREED().value(0) < FEARGREED().avg(30) - 10,  // 低于30天均值10点以上
    FEARGREED().trend(7) = FALLING,                   // 且处于下降趋势
    $(1h).RSI().value < 40
} = BUY;  // 均值回归买入

// 对比短期和长期均值
ALL{
    FEARGREED().avg(7) < FEARGREED().avg(30),   // 短期均值低于长期
```

#### trend() - 判断趋势方向

```dsl
    $(1h).MACD().trend = BULLISH           // 但技术面转好
} = BUY;  // 逆势买入

// 多周期趋势确认
ALL{
    FEARGREED().trend(7) = RISING,         // 短期上升

// 趋势反转信号
ALL{

    FEARGREED().trend(7) = RISING,         // 短期开始上升
    FEARGREED().value(0) > FEARGREED().avg(30)  // 突破长期均值
} = BUY;  // 趋势可能反转
```

- 判断情绪趋势方向
- 识别趋势反转

- 构建趋势跟随策略

## FUNDINGRATE - 资金费率

**语法：** `FUNDINGRATE().method(params)`

**说明：** 期货合约资金费率历史数据，用于判断多空力量对比。

**数据范围：** 通常在 -0.01 到 0.01 之间
- **正值**：多头支付空头（市场看多）
- **负值**：空头支付多头（市场看空）

### value() - 获取资金费率

  - `-8`: 约1天前（3次/天）
  - 最小可回溯100次

**返回值：** 浮点数（通常在 -0.01 到 0.01 之间）

**示例：**

## 注意事项

### ⚠️ 数据可用性

1. **历史数据限制**
   - 恐惧与贪婪指数：通常保存最近1-2年数据
   - 回测时确保数据覆盖回测周期
   - 数据缺失时函数返回默认值或跳过

2. **更新频率**
   - FEARGREED：每日更新，通常在UTC 00:00后
   - 实时交易中，今日数据可能延迟更新
   - 回测中使用历史数据，不存在延迟

---

### ⚠️ 时区问题

```dsl
// 恐惧与贪婪指数使用UTC日期
// offset=0 指的是UTC当天
// 如果你在UTC+8时区，当地凌晨可能还是昨天的数据

// 建议：在策略中明确说明时区
// 或使用较大的offset来避免边界问题
FEARGREED().value(1)  // 使用昨天的数据，更保险
```

---

### ⚠️ 避免过拟合

```dsl
// ❌ 过度优化的阈值
ALL{
    FEARGREED().value(0) = 23,              // 太精确
    FEARGREED().change(7) = -12,
    $(5m).RSI().value = 32
} = BUY;

// ✅ 使用范围更合理
ALL{
    FEARGREED().value(0) < 25,              // 使用范围
    FEARGREED().change(7) < -10,
    $(5m).RSI().value < 35
} = BUY;
```

---

### ⚠️ 情绪指标的滞后性

**理解：**
- 情绪指标基于多个因素综合计算
- 可能滞后于市场实际变化
- 不应作为唯一的交易信号

**建议：**
```dsl
// 结合快速反应的技术指标
ALL{
    FEARGREED().value(0) < 30,              // 情绪确认
    $(5m).MACD().signal = BUY,              // 技术面先行
    $(5m).RSI().value < 35
} = BUY;
```

---

### ⚠️ 极端值的处理

```dsl
// 在极端情绪时，市场可能非理性
// 建议等待情绪稳定后再交易

// ❌ 在极端值立即交易

    FEARGREED().trend(7) = STABLE,          // 趋势稳定
    $(5m).MACD().signal = BUY
} = BUY;  // 等待恐慌稳定后入场
```

## 总结

Prophet DSL的时间序列函数为策略提供了强大的非K线数据访问能力：

**核心优势：**
- ✅ 不依赖时间框架，数据自带时间维度
- ✅ 提供丰富的统计分析方法
- ✅ 简洁访问当前市场状态
- ✅ 与技术指标完美结合
- ✅ 支持多维度市场分析

**函数选择：**
1. **CURRENT()** - 便捷访问当前市场状态
   - 当前价格：`CURRENT().price`
   - 当前时间：`CURRENT().Time.hour`
   - 最新资金费率：`CURRENT().fundingrate`
   - 最新恐惧指数：`CURRENT().feargreed.value`

2. **FEARGREED()** - 恐惧与贪婪指数分析
   - 历史数据访问：`FEARGREED().value(7)`
   - 趋势判断：`FEARGREED().trend(30)`
   - 统计分析：`FEARGREED().avg(24)`

3. **FUNDINGRATE()** - 资金费率分析
   - 历史数据访问：`FUNDINGRATE().value(8)`
   - 平均资金费率：`FUNDINGRATE().avg(24)`
   - 趋势判断：`FUNDINGRATE().trend(24)`

**使用原则：**
1. 优先使用CURRENT()获取当前值（更简洁）
2. 需要历史数据或统计分析时使用时间序列函数
3. 作为过滤器，不作为主要信号
4. 结合技术分析，多维度确认
5. 使用统计方法降噪
6. 避免过拟合和过度优化
7. 注意数据可用性和时区问题

**数据注入方式：**

**Python端：**

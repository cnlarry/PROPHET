## 1. 概述

本文档详细介绍 Prophet DSL 中的注释系统，帮助开发者编写清晰、易维护的策略代码。

## 2. 注释语法

Prophet DSL 支持多种注释语法，包括单行注释、多行注释和文档注释。

## 3. 单行注释

使用 `//` 开始单行注释，注释内容从 `//` 开始到行尾结束。

```javascript
// 这是一个单行注释
@price = KLINE(5m).close();  // 获取当前收盘价

// 计算移动平均线
@ma_value = $(5m).MA(20).value;  // 20周期简单移动平均
```

## 4. 多行注释

使用 `/* */` 包围多行注释内容。

```javascript
/*
这是一个多行注释
可以跨越多行
用于详细说明复杂的逻辑
*/

/*
策略说明：
- 使用RSI指标判断超买超卖
- 结合MACD确认趋势
- 设置止损止盈点位
*/
ALL {
    $(5m).RSI().value > 30;
    $(5m).RSI().value < 70;
    $(5m).MACD().histogram > 0;
} = BUY;
```

## 5. 文档注释

使用 `/** */` 格式编写文档注释，通常用于描述函数、变量或策略的整体说明。

```javascript
/**
 * 策略名称：均值回归策略
 * 适用市场：震荡市场
 * 时间周期：5分钟
 * 作者：Prophet Team
 * 版本：1.0
 */

/**
 * 计算动态止损价位
 * @param price 当前价格
 * @param atr ATR指标值
 * @return 止损价位
 */
calculate_stop_loss(price, atr): Double {
    return price - (atr * 2.0);
}
```

## 6. 最佳实践

### 6.1 注释位置

- 在复杂逻辑前添加注释说明
- 在变量声明旁添加用途说明
- 在函数定义前添加功能说明

### 6.2 注释内容

- 解释"为什么"而不仅仅是"是什么"
- 说明业务逻辑和策略思路
- 标注重要的参数和阈值选择原因

### 6.3 注释维护

- 及时更新过时的注释
- 保持注释与代码的一致性
- 避免冗余和无意义的注释

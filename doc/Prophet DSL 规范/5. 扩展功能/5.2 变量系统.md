## 1. 变量概述

### 1.1 什么是变量？

变量是存储数据的容器，可以在策略中重复使用，避免重复计算。

### 1.2 变量前缀

Prophet DSL 中，所有用户变量都以 `@` 符号开头：

```javascript
@price      // ✅ 正确
price       // ❌ 错误：缺少 @ 前缀
```

### 1.3 变量类型

| 变量类型 | 声明位置 | 作用域 | 使用场景 |
|---------|---------|--------|---------|
| **全局变量** | DSL顶层 | 整个策略 | 跨规则共享数据 |
| **局部变量** | 函数内部 | 当前函数 | 函数内部计算 |
| **块级变量** | if/else块内 | 当前代码块 | 临时计算 |

## 2. 全局变量

### 2.1 定义

全局变量在 DSL 顶层声明，可以在整个策略中使用（所有函数和信号规则）。

### 2.2 声明语法

#### 方式 1: 声明并初始化
```javascript
@variable_name: Type = expression;
```

**示例**:
```javascript
@price: Double = KLINE(5m).close(0);
@FAST_PERIOD: Integer = 12;
@use_stop_loss: Boolean = true;
```

#### 方式 2: 先声明，后赋值
```javascript
// 声明
@variable_name: Type;

// 赋值（稍后）
@variable_name = expression;
```

**示例**:
```javascript
// 声明
@temp: Double;
@threshold: Double;

// 赋值
@temp = KLINE(5m).close(0);
@threshold = @temp * 1.02;
```

#### 方式 3: 自动类型推断
```javascript
@variable_name = expression;  // 根据 expression 推断类型
```

**示例**:
```javascript
@price = KLINE(5m).close(0);      // 推断为 Double
@count = 10;                       // 推断为 Integer
@flag = true;                      // 推断为 Boolean
```

### 2.3 初始化时机

**全局变量在每次信号生成时重新初始化**：

```javascript
@price: Double = KLINE(5m).close(0);  // 每次 GetSignal() 都会重新计算

// 时刻 1: GetSignal() → @price = 3000.0
// 时刻 2: GetSignal() → @price = 3050.0（价格变化）
```

### 2.4 全局变量使用

#### 在信号规则中使用
```javascript
@price: Double = KLINE(5m).close(0);
@threshold: Double = 3000.0;

ALL{
    @price > @threshold;          // ✅ 使用全局变量
    $(5m).RSI().value < 70;
} = BUY;
```

#### 在自定义函数中使用
```javascript
@global_price: Double = 3000.0;

calcDouble(): Double {
    return @global_price * 2;     // ✅ 访问全局变量
}

ALL{
    calcDouble() > 5000;
} = BUY;
```

#### 禁止在信号体内声明或赋值
```javascript
ALL{
    @price: Double = 3000;        // ❌ 禁止：信号体内不能声明变量
    @price = 3100;                // ❌ 禁止：信号体内不能赋值
} = BUY;
```

**原因**：信号体内只能包含条件表达式，不能有副作用。

### 2.5 全局变量示例

#### 示例 1: 参数化配置
```javascript
// 全局参数
@FAST_PERIOD: Integer = 12;
@SLOW_PERIOD: Integer = 26;
@rsi_oversold: Double = 30.0;

// 使用参数
ALL{
    $(5m).EMA(@FAST_PERIOD).value > $(5m).EMA(@SLOW_PERIOD).value;
    $(5m).RSI().value < @rsi_oversold;
} = BUY;
```

#### 示例 2: 避免重复计算
```javascript
// 计算一次，多处使用
@current_price: Double = KLINE(5m).close(0);
@ema_fast: Double = $(5m).EMA(12).value;
@ema_slow: Double = $(5m).EMA(26).value;

ALL{
    @current_price > @ema_fast;
    @ema_fast > @ema_slow;
    @current_price > 3000;
} = BUY;

MIN(2){
    @current_price < @ema_slow;
    $(5m).RSI().value > 70;
} = SELL;
```

#### 示例 3: 动态阈值
```javascript
@price: Double = KLINE(5m).close(0);
@atr: Double = $(5m).ATR(14).value;

// 动态止损：价格 - 2倍ATR
@stop_loss: Double = @price - (@atr * 2.0);

// 动态止盈：价格 + 3倍ATR
@take_profit: Double = @price + (@atr * 3.0);

ALL{
    @price > @stop_loss;
    @price < @take_profit;
} = HOLD;
```

## 3. 局部变量

### 3.1 定义

局部变量在函数内部声明，仅在当前函数及其子作用域中可见。

### 3.2 声明语法

与全局变量相同，但必须在函数内部：

```javascript
funcName(): ReturnType {
    @local_var: Type = expression;  // 局部变量
    return @local_var;
}
```

### 3.3 局部变量示例

#### 示例 1: 函数内部计算
```javascript
calcTrendScore(): Double {
    // 局部变量（仅函数内可见）
    @ema_fast: Double = $(5m).EMA(12).value;
    @ema_slow: Double = $(5m).EMA(26).value;
    @adx: Double = $(5m).ADX(14).value;
    
    @score: Double = 0.0;
    
    if (@ema_fast > @ema_slow) {
        @score += 50.0;
    }
    
    if (@adx > 25) {
        @score += 50.0;
    }
    
    return @score;
}

ALL{
    calcTrendScore() > 75;
    // @score > 50;  // ❌ 错误：@score 不可见（局部变量）
} = BUY;
```

#### 示例 2: 访问全局变量
```javascript
// 全局变量
@global_price: Double = 3000.0;

calcAdjustedPrice(): Double {
    // 局部变量
    @multiplier: Double = 1.05;
    
    // 可以访问全局变量
    return @global_price * @multiplier;
}
```

## 4. 变量作用域

### 4.1 作用域层次

```
策略（全局作用域）
├── 全局变量 (@global_var)
├── 自定义函数 1
│   ├── 参数作用域 (param1, param2)
│   └── 函数体作用域
│       ├── 局部变量 (@local_var1, @local_var2)
│       └── if/else 块作用域
│           └── 块内变量 (@block_var)
├── 自定义函数 2
│   └── ...
├── 信号规则 1 (ALL{...})
│   └── 可以使用全局变量
└── 信号规则 2 (MIN{...})
    └── 可以使用全局变量
```

### 4.2 作用域示例

#### 示例 1: 全局变量可见性
```javascript
// 全局变量
@global_var: Double = 100.0;

calcFunc1(): Double {
    return @global_var * 2;  // ✅ 可以访问
}

calcFunc2(): Double {
    return @global_var * 3;  // ✅ 可以访问
}

ALL{
    @global_var > 50;        // ✅ 可以访问
} = BUY;
```

#### 示例 2: 局部变量不可见
```javascript
calcFunc(): Double {
    @local_var: Double = 50.0;  // 局部变量
    return @local_var;
}

ALL{
    calcFunc() > 40;     // ✅ 调用函数OK
    @local_var > 30;     // ❌ 错误：@local_var 不可见
} = BUY;
```

#### 示例 3: 块级作用域
```javascript
calcScore(rsi: Double): Double {
    @outer_var: Double = 100.0;  // 整个函数可见
    
    if (rsi < 30) {
        @inner_var: Double = 50.0;  // ✅ 仅在 if 块内可见
        @outer_var = @outer_var + @inner_var;  // ✅ 可访问外层变量
    }
    
    // @inner_var = 60.0;  // ❌ 错误：@inner_var 不可见
    
    return @outer_var;
}
```

### 4.3 变量遮蔽（Shadowing）

内层作用域可以声明与外层同名的变量，会遮蔽外层变量：

```javascript
@price: Double = 3000;  // 全局变量

calcPrice(): Double {
    @price: Double = 3500;  // 局部变量（遮蔽全局变量）
    return @price;  // 返回 3500（使用局部变量）
}

ALL{
    @price < 3100;        // 使用全局变量 3000 ✅
    calcPrice() > 3400;   // 函数返回 3500 ✅
} = BUY;
```

**注意**：虽然允许遮蔽，但为了代码清晰，建议避免同名变量。

## 5. 变量使用规则

### 5.1 使用前必须声明

```javascript
// ❌ 错误：未声明就使用
ALL{
    @undefined_var > 100;
} = BUY;
```

**错误信息**:
```
ParserException: Variable '@undefined_var' not declared
  Line: 2, Column: 5
```

### 5.2 使用前必须赋值

#### 编译时检查
```javascript
@temp: Double;  // 只声明，未赋值

ALL{
    @temp > 100;  // ❌ 编译错误
} = BUY;

@temp = 200;  // 赋值在规则之后
```

**错误信息**:
```
ParserException: Variable '@temp' used before assignment
  Line: 3, Column: 5
  Variable '@temp' declared at line 1, column 1
  Note: Variables must be assigned before use
```

#### 运行时检查
即使通过编译，运行时仍会检查：

```
Signal{
    type: HOLD,
    reason: "Variable '@temp' used before assignment at line 3"
}
```

### 5.3 类型一致性

```javascript
// ✅ 正确
@price: Double = 3000.0;
@price = 3100.0;  // OK：类型一致

// ❌ 错误：类型不匹配
@count: Integer = 10;
@count = 3.14;  // 错误：Double 赋值给 Integer
```

### 5.4 命名规则

**用户变量命名规范**：
- ✅ 全小写 + 下划线
- ✅ 示例：`@my_var`, `@price`, `@rsi_value`

```javascript
// ✅ 正确命名
@price: Double = 3000;
@FAST_PERIOD: Integer = 12;
@is_bullish: Boolean = true;

// ❌ 错误命名（不符合规范）
@Price: Double = 3000;        // 大写字母
@fastPeriod: Integer = 12;    // 驼峰命名
@IsBullish: Boolean = true;   // 大写开头
```

**环境变量（已废弃）**：
- 旧版本支持全大写环境变量（如 `@CURRENT_PRICE`）
- **现在已废弃**，请使用数据函数代替：`KLINE(5m).close(0)`

## 6. 最佳实践

### 6.1 使用有意义的变量名

```javascript
// ❌ 不推荐：名称不清晰
@x: Double = KLINE(5m).close(0);
@y: Double = $(5m).EMA(12).value;
@z: Double = @x - @y;

// ✅ 推荐：名称清晰
@current_price: Double = KLINE(5m).close(0);
@ema_fast: Double = $(5m).EMA(12).value;
@price_diff: Double = @current_price - @ema_fast;
```

### 6.2 显式类型声明

```javascript
// ❌ 不推荐：依赖类型推断
@price = KLINE(5m).close(0);
@PERIOD = 14;

// ✅ 推荐：显式声明类型
@price: Double = KLINE(5m).close(0);
@PERIOD: Integer = 14;
```

### 6.3 避免过度使用全局变量

```javascript
// ❌ 不推荐：太多全局变量
@v1: Double = ...;
@v2: Double = ...;
@v3: Double = ...;
// ... 20个全局变量

// ✅ 推荐：封装在函数中
calcMarketState(): Double {
    @v1: Double = ...;
    @v2: Double = ...;
    @v3: Double = ...;
    // 局部变量，函数外不可见
    return result;
}
```

### 6.4 变量初始化要完整

```javascript
// ❌ 不推荐：分支中可能未赋值
@score: Double;

if (@condition) {
    @score = 100.0;
}
// else 分支未赋值

return @score;  // ❌ 可能未赋值

// ✅ 推荐：所有分支都赋值
@score: Double = 0.0;  // 默认值

if (@condition) {
    @score = 100.0;
}

return @score;  // ✅ 一定已赋值
```

### 6.5 避免变量遮蔽

```javascript
// ❌ 不推荐：变量遮蔽，容易混淆
@price: Double = 3000;

calcPrice(): Double {
    @price: Double = 3500;  // 遮蔽全局变量
    return @price;
}

// ✅ 推荐：使用不同名称
@global_price: Double = 3000;

calcLocalPrice(): Double {
    @local_price: Double = 3500;
    return @local_price;
}
```

## 7. 常见错误

### 错误 1: 变量未声明

```javascript
// ❌ 错误
ALL{
    @price > 3000;  // @price 未声明
} = BUY;
```

**修复**:
```javascript
// ✅ 正确
@price: Double = KLINE(5m).close(0);

ALL{
    @price > 3000;
} = BUY;
```

### 错误 2: 变量未赋值就使用

```javascript
// ❌ 错误
@temp: Double;

ALL{
    @temp > 100;  // @temp 未赋值
} = BUY;
```

**修复**:
```javascript
// ✅ 正确
@temp: Double = KLINE(5m).close(0);

ALL{
    @temp > 100;
} = BUY;
```

### 错误 3: 在信号体内赋值

```javascript
// ❌ 错误
ALL{
    @price = 3000;  // 信号体内不能赋值
} = BUY;
```

**修复**:
```javascript
// ✅ 正确：在顶层赋值
@price: Double = 3000;

ALL{
    @price > 2900;
} = BUY;
```

### 错误 4: 类型不匹配

```javascript
// ❌ 错误
@count: Integer = 3.14;  // Double 赋值给 Integer
```

**修复**:
```javascript
// ✅ 正确：类型匹配
@count: Integer = 3;
// 或
@value: Double = 3.14;
```

### 错误 5: 访问不可见变量

```javascript
// ❌ 错误
calcFunc(): Double {
    @local_var: Double = 100;
    return @local_var;
}

ALL{
    @local_var > 50;  // 局部变量不可见
} = BUY;
```

**修复**:
```javascript
// ✅ 正确：使用函数返回值
calcFunc(): Double {
    @local_var: Double = 100;
    return @local_var;
}

ALL{
    calcFunc() > 50;  // 使用函数返回值
} = BUY;
```

## 8. 快速参考

### 8.1 变量声明语法

| 语法 | 示例 | 说明 |
|------|------|------|
| 声明+初始化 | `@var: Type = expr;` | 推荐 |
| 先声明 | `@var: Type;` | 需后续赋值 |
| 后赋值 | `@var = expr;` | 必须已声明 |
| 类型推断 | `@var = expr;` | 可以，但不推荐 |

### 8.2 变量使用位置

| 位置 | 声明 | 赋值 | 使用 |
|------|------|------|------|
| DSL顶层 | ✅ | ✅ | ✅ |
| 信号规则体内 | ❌ | ❌ | ✅ |
| 自定义函数内 | ✅ | ✅ | ✅ |

### 8.3 变量作用域

| 变量类型 | 声明位置 | 可见范围 |
|---------|---------|---------|
| 全局变量 | DSL顶层 | 整个策略 |
| 局部变量 | 函数内 | 当前函数 |
| 块级变量 | if/else块 | 当前块 |

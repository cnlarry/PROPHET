## 1. 概述

### 1.1 什么是自定义函数？

自定义函数允许您将复杂的交易逻辑封装为可复用的函数，使策略代码更清晰、更易维护。

### 1.2 设计原则

- ✅ **全局定义，任意调用**：函数在结构顶层定义，可在任何地方调用
- ✅ **纯函数**：无副作用，不修改全局状态
- ✅ **类型安全**：混合类型系统（推断 + 显式声明）
- ✅ **简洁表达**：支持 if-else 和三元表达式
- ✅ **块级作用域**：变量作用域仅限定义的代码块

### 1.3 设计目标

| 目标 | 说明 |
|------|------|
| **简化复杂逻辑** | 将复杂的条件判断封装为可复用函数 |
| **提高可读性** | 通过函数名清晰表达业务逻辑 |
| **避免重复** | 多个规则可共享相同的计算逻辑 |
| **类型安全** | 编译时类型检查，避免运行时错误 |

## 2. 基础语法

### 2.1 函数定义格式

#### **无类型声明（自动推断）**
```javascript
functionName(param1, param2) {
  // 函数体
  return result;
}
```

#### **带类型声明（推荐）**
```javascript
functionName(param1: Type1, param2: Type2): ReturnType {
  // 函数体
  return result;
}
```

### 2.2 函数调用

```javascript
// 在信号函数中调用
ALL{
  myFunction(arg1, arg2) > threshold;
} = BUY;

// 在其他自定义函数中调用
anotherFunction(x: Double): Double {
  @result: Double = myFunction(x, 10);
  return @result;
}
```

### 2.3 返回值
每个函数必须有返回值，支持 **early return**（提前返回）：
```javascript
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    return 100.0;  // ✅ 提前返回
  }
  
  if (rsi > 70) {
    return -100.0;  // ✅ 提前返回
  }
  
  return 0.0;  // 默认返回
}
```

**规则**:
- 每个函数必须至少有一个 `return` 语句
- 编译器检查所有代码路径是否都有返回值

### 2.4 注释

与现有 DSL 一致：

```javascript
// 单行注释

/*
 * 多行注释
 */
```

## 3. 变量使用

### 3.1 变量类型

Prophet DSL 支持两种变量：
1. **全局变量**：在策略顶层声明，可在自定义函数和信号规则中使用
2. **局部变量**：在函数内部声明，仅在函数内可见
> **重要变更** (v4.1): 环境变量概念已废弃，所有 `@` 前缀的变量都是用户变量

### 3.2 全局变量

#### 3.2.1 声明和初始化

```javascript
// 声明并初始化
@price: Double = KLINE(5m).close(0);
@trend_score: Integer = 0;
@is_bullish: Boolean = false;

// 只声明不初始化
@temp_value: Double;

// 自动类型推断
@auto_var = 100.0;  // 推断为 Double
```

#### 3.2.2 赋值
```javascript
// 简单赋值
@price = KLINE(5m).close(0);

// 复合赋值
@score += 10;
@score -= 5;
@score *= 2;
@score /= 3;
```

#### 3.2.3 在函数中使用

```javascript
// 全局变量
@current_price: Double = KLINE(5m).close(0);

// 自定义函数可以访问全局变量
isBullishTrend(): Boolean {
  @ema_fast: Double = $(5m).EMA(12).value;
  @ema_slow: Double = $(5m).EMA(26).value;
  
  return @current_price > @ema_fast AND @ema_fast > @ema_slow;
}

// 在信号规则中使用
ALL{
  isBullishTrend();
  @current_price > $(5m).MACD().signal;
} = BUY;
```

### 3.3 局部变量
局部变量仅在函数内可见：
```javascript
calcScore(rsi: Double): Double {
  @outer: Double = 100.0;  // 整个函数可见
  
  if (rsi < 30) {
    @inner: Double = 50.0;  // 仅在 if 块内可见
    @outer = @outer + @inner;  // ✅ 可访问外层变量
  }
  
  // ❌ 错误：@inner 在此处不可见
  // return @inner;
  
  return @outer;  // ✅ 正确
}
```

### 3.4 变量作用域规则
| 变量类型 | 声明位置 | 作用域 | 可在何处使用 |
|---------|---------|--------|-------------|
| **全局变量** | 策略顶层 | 整个策略 | 自定义函数、信号规则 |
| **局部变量** | 函数内部 | 函数内部 | 仅当前函数及其子块 |

**优先级**: 局部变量 > 全局变量（同名时局部变量优先）

### 3.5 变量命名规则

| 类型 | 格式 | 示例 | 说明 |
|------|------|------|------|
| **用户变量** | 全小写 + 下划线 | `@my_score`, `@rsi_value` | ✅ 推荐 |
| **混合大小写** | 任意 | `@MyVar`, `@myVar` | ⚠️ 不推荐 |

### 3.6 变量必须先赋值

```javascript
// ❌ 错误：使用未赋值的变量
@score: Double;  // 只声明，未赋值
ALL{
  @score > 50;  // ❌ 运行时错误：变量未赋值
} = BUY;

// ✅ 正确：先赋值再使用
@score: Double = calcScore($(5m).RSI().value);

ALL{
  @score > 50;  // ✅ 正确
} = BUY;
```

### 3.7 执行顺序

顶层语句按编写顺序执行：

```javascript
// 1. 声明全局变量
@price: Double = KLINE(5m).close(0);

// 2. 定义自定义函数
calcTrend(): Boolean {
  return @price > $(5m).EMA(12).value;
}

// 3. 更新全局变量
@trend_confirmed: Boolean = calcTrend();

// 4. 规则1（先评估）
ALL{
  @trend_confirmed;
  $(5m).RSI().value < 30;
} = BUY;

// 5. 规则2（后评估，但由于规则1触发，不会执行）
MIN(2){
  @price > @ma_slow;
  $(5m).MACD().trend = BULLISH;
} = SELL;
```

**短路评估**: 一旦某个规则触发信号（BUY/SELL），后续规则不再评估

## 4. 类型系统

### 4.1 基础类型

| 类型 | 说明 | 字面量示例 | C++ 类型 |
|------|------|-----------|---------|
| `Integer` | 整数 | `10`, `-5`, `0` | `int` |
| `Double` | 浮点数 | `10.5`, `3.14`, `1e-4` | `double` |
| `Boolean` | 布尔值 | `true`, `false` | `bool` |
| `String` | 字符串 | `"5m"`, `"BTCUSDT"` | `std::string` |
| `Enum` | 枚举值 | `BULLISH`, `GOLDEN_CROSS` | `std::string` |

### 4.2 类型推断

```javascript
@int_val = 10;           // 推断为 Integer
@double_val = 10.5;      // 推断为 Double
@bool_val = true;        // 推断为 Boolean
@str_val = "5m";         // 推断为 String
@enum_val = BULLISH;     // 推断为 Enum
```

### 4.3 类型转换

#### **隐式转换（自动）**
```javascript
@int_val: Integer = 10;
@double_val: Double = @int_val;  // ✅ Integer → Double
```

#### **显式转换（使用数学函数）**
```javascript
@double_val: Double = 10.7;

@int1: Integer = ROUND(@double_val);  // 11（四舍五入）
@int2: Integer = FLOOR(@double_val);  // 10（向下取整）
@int3: Integer = CEIL(@double_val);   // 11（向上取整）
```

### 4.4 复合赋值运算符

```javascript
@score: Double = 0.0;

// 传统写法
@score = @score + 10;
@score = @score - 5;
@score = @score * 2;
@score = @score / 2;

// 复合赋值（简化）
@score += 10;
@score -= 5;
@score *= 2;
@score /= 2;
```

## 5. 流程控制

### 5.1 if-else 语句

```javascript
// 单分支
if (condition) {
  statements;
}

// 双分支
if (condition) {
  statements1;
} else {
  statements2;
}

// 多分支
if (condition1) {
  statements1;
} else if (condition2) {
  statements2;
} else {
  statements3;
}
```

**示例**:
```javascript
calcRsiLevel(rsi: Double): String {
  if (rsi < 30) {
    return "OVERSOLD";
  } else if (rsi > 70) {
    return "OVERBOUGHT";
  } else {
    return "NEUTRAL";
  }
}
```

### 5.2 三元表达式
简化 if-else 的写法：

```javascript
// 语法
@result = condition ? value_if_true : value_if_false;

// 示例
calcScore(rsi: Double): Double {
  return rsi < 30 ? 100.0 : 0.0;
}

// 嵌套三元表达式
calcScore(rsi: Double): Double {
  return rsi < 30 ? 100.0 : (rsi > 70 ? -100.0 : 0.0);
}
```

### 5.3 提前返回（Early Return）
可以在函数中间提前返回：

```javascript
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    return 100.0;  // ✅ 提前返回
  }
  
  if (rsi > 70) {
    return -100.0;  // ✅ 提前返回
  }
  
  return 0.0;  // 默认返回
}
```

## 6. 作用域规则
### 6.1 全局作用域
**全局变量**在策略顶层声明，可在整个策略中使用：

```javascript
// 全局变量（顶层声明）
@current_price: Double = KLINE(5m).close(0);
@trend_confirmed: Boolean = false;

// 自定义函数可以访问全局变量
isBullishTrend(): Boolean {
  @ema_fast: Double = $(5m).EMA(12).value;
  return @current_price > @ema_fast;
}

// 在信号规则中使用全局变量
ALL{
  isBullishTrend();
  @trend_confirmed;
} = BUY;
```

**全局变量规则**:
- ✅ 可在自定义函数中读取
- ✅ 可在信号规则中读取
- ❌ 不能在信号规则内声明或赋值
- ❌ 不能在自定义函数内修改（纯函数设计）

### 6.2 块级作用域
**局部变量**仅在函数内可见：

```javascript
calcScore(rsi: Double): Double {
  @outer_var: Double = 100.0;  // 整个函数可见
  
  if (rsi < 30) {
    @inner_var: Double = 50.0;  // ✅ 仅在 if 块内可见
    @outer_var = @outer_var + @inner_var;  // ✅ 可访问外层变量
  }
  
  // ❌ 编译错误：@inner_var 在此处不可见
  // return @inner_var;
  
  return @outer_var;  // ✅ 正确
}
```

**作用域优先级**: 局部变量 > 全局变量（同名时局部变量优先）

### 6.3 变量使用规则

**禁止使用未赋值的变量**:

```javascript
// ❌ 编译错误：可能未赋值
calcScore(condition: Boolean): Double {
  @score: Double;  // 声明但未赋值
  
  if (condition) {
    @score = 100.0;
  }
  // else 分支未赋值
  
  return @score;  // ❌ 编译错误：@score 可能未赋值
}

// ✅ 正确：所有路径都赋值
calcScore(condition: Boolean): Double {
  @score: Double;
  
  if (condition) {
    @score = 100.0;
  } else {
    @score = 0.0;
  }
  
  return @score;  // ✅ 编译通过
}
```

### 6.4 函数调用规则

**可以调用的内容**:
- ✅ 其他自定义函数
- ✅ 系统内置函数（如 `ABS`, `MAX`, `ROUND` 等）
- ✅ 数据函数（如 `KLINE`, `HIGHEST`, `AVERAGE` 等）
- ✅ 指标引用（如 `$(5m).RSI().value`）
- ✅ 全局变量（如 `@current_price`）
- ✅ 局部变量（如 `@my_score`）

```javascript
// 全局变量
@global_threshold: Double = 50.0;

// 自定义函数调用自定义函数
isOversold(rsi: Double): Boolean {
  return rsi < @global_threshold;  // ✅ 访问全局变量
}

shouldBuy(rsi: Double, macd: Double): Boolean {
  @oversold: Boolean = isOversold(rsi);  // ✅ 调用其他自定义函数
  @bullish: Boolean = macd > 0;
  
  return @oversold AND @bullish;
}
```

### 6.5 短路评估

信号规则按顺序评估，**一旦触发立即返回**，不再评估后续规则：

```javascript
// 规则1：如果触发，立即返回BUY信号
ALL{
  $(5m).RSI().value < 30;
  $(5m).MACD().trend = BULLISH;
} = BUY;

// 规则2：只有在规则1未触发时才会评估
MIN(2){
  $(5m).EMA(12).value > $(5m).EMA(26).value;
  $(5m).ADX().value > 25;
} = SELL;
```

**执行流程**:
1. 按源代码顺序执行全局变量声明/赋值
2. 按顺序评估信号规则
3. 第一个触发的规则立即返回信号
4. 后续规则不再评估（性能优化）
5. 如果没有规则触发，返回 `HOLD` 信号

## 7. 最佳实践
### 7.1 函数命名

✅ **推荐**:
```javascript
// 动词开头，清晰表达功能
calcScore(rsi: Double): Double { ... }
isOversold(rsi: Double): Boolean { ... }
shouldBuy(rsi: Double): Boolean { ... }
checkCondition(price: Double): Boolean { ... }
```

❌ **不推荐**:
```javascript
// 名称不清晰
func1(x: Double): Double { ... }
myFunction(a: Double): Double { ... }
test(b: Double): Boolean { ... }
```

### 7.2 参数命名

✅ **推荐**:
```javascript
// 参数名清晰表达含义
calcScore(rsi_value: Double, macd_histogram: Double): Double { ... }
```

❌ **不推荐**:
```javascript
// 参数名过于简略
calcScore(r: Double, m: Double): Double { ... }
calcScore(x: Double, y: Double): Double { ... }
```

### 7.3 函数长度

✅ **推荐**:
```javascript
// 函数保持简洁，单一职责
isOversold(rsi: Double): Boolean {
  return rsi < 30;
}

isBullish(macd: Double): Boolean {
  return macd > 0;
}

// 组合使用
shouldBuy(rsi: Double, macd: Double): Boolean {
  return isOversold(rsi) AND isBullish(macd);
}
```

❌ **不推荐**:
```javascript
// 函数过长，逻辑复杂
calcEverything(rsi: Double, macd: Double, ...): Double {
  // 100+ 行代码
  // ...
}
```

### 7.4 类型声明

✅ **推荐**:
```javascript
// 显式声明类型，提高可读性
calcScore(rsi: Double, threshold: Double): Double {
  @result: Double = 0.0;
  if (rsi < threshold) {
    @result = 100.0;
  }
  return @result;
}
```

❌ **不推荐**:
```javascript
// 完全依赖类型推断，可读性差
calcScore(rsi, threshold) {
  @result = 0.0;
  if (rsi < threshold) {
    @result = 100.0;
  }
  return @result;
}
```

### 7.5 提前返回

✅ **推荐**:
```javascript
// 使用提前返回，减少嵌套
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    return 100.0;
  }
  
  if (rsi > 70) {
    return -100.0;
  }
  
  return 0.0;
}
```

❌ **不推荐**:
```javascript
// 嵌套过深
calcScore(rsi: Double): Double {
  @score: Double = 0.0;
  
  if (rsi < 30) {
    @score = 100.0;
  } else {
    if (rsi > 70) {
      @score = -100.0;
    } else {
      @score = 0.0;
    }
  }
  
  return @score;
}
```

## 8. 常见错误

### 8.1 类型不匹配
❌ **错误**:
```javascript
calcScore(rsi: Double): Integer {
  return 100.0;  // ❌ 返回 Double，但声明为 Integer
}
```

✅ **正确**:
```javascript
calcScore(rsi: Double): Integer {
  return 100;  // ✅ 返回 Integer
}
```

### 8.2 变量未赋值
❌ **错误**:
```javascript
calcScore(condition: Boolean): Double {
  @score: Double;
  
  if (condition) {
    @score = 100.0;
  }
  
  return @score;  // ❌ else 分支未赋值
}
```

✅ **正确**:
```javascript
calcScore(condition: Boolean): Double {
  @score: Double = 0.0;  // ✅ 默认值
  
  if (condition) {
    @score = 100.0;
  }
  
  return @score;
}
```

### 8.3 缺失返回值
❌ **错误**:
```javascript
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    return 100.0;
  }
  // ❌ 没有默认返回值
}
```

✅ **正确**:
```javascript
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    return 100.0;
  }
  
  return 0.0;  // ✅ 默认返回值
}
```

### 8.4 变量作用域错误
❌ **错误**:
```javascript
calcScore(rsi: Double): Double {
  if (rsi < 30) {
    @inner: Double = 100.0;
  }
  
  return @inner;  // ❌ @inner 超出作用域
}
```

✅ **正确**:
```javascript
calcScore(rsi: Double): Double {
  @result: Double = 0.0;  // ✅ 在函数作用域声明
  
  if (rsi < 30) {
    @result = 100.0;
  }
  
  return @result;
}
```

### 8.5 函数未定义
❌ **错误**:
```javascript
calcScore(rsi: Double): Double {
  return unknownFunc(rsi);  // ❌ 函数未定义
}
```

✅ **正确**:
```javascript
// 先定义被调用的函数
helper(rsi: Double): Double {
  return rsi * 2;
}

// 再调用
calcScore(rsi: Double): Double {
  return helper(rsi);  // ✅ 函数已定义
}
```

// 市场状态评分函数

### 9.6 示例6：止盈止损计算函数
自定义函数非常适合封装复杂的止盈止损计算逻辑，使策略代码更清晰：

```javascript
// 计算止盈价格（基于ATR和风险回报比）
calcTakeProfit(price: Double, atr: Double, reward_ratio: Double): Double {
  return price + atr * reward_ratio;
}

// 计算止损价格（基于ATR和风险水平）
calcStopLoss(price: Double, atr: Double, risk_level: Double): Double {
  return price - atr * risk_level;
}

// 根据趋势强度动态调整止盈止损
calcDynamicTP(price: Double, atr: Double, adx: Double): Double {
  // 强趋势（ADX > 40）：更激进止盈
  if (adx > 40) {
    return price + atr * 3.0;
  }
  // 中等趋势（ADX 20-40）：标准止盈
  else if (adx > 20) {
    return price + atr * 2.0;
  }
  // 弱趋势（ADX < 20）：保守止盈
  else {
    return price + atr * 1.5;
  }
}

calcDynamicSL(price: Double, atr: Double, adx: Double): Double {
  // 强趋势：紧密止损
  if (adx > 40) {
    return price - atr * 1.0;
  }
  // 中等趋势：标准止损
  else if (adx > 20) {
    return price - atr * 1.5;
  }
  // 弱趋势：宽松止损
  else {
    return price - atr * 2.0;
  }
}

// 使用自定义函数计算止盈止损
@current_price: Double = KLINE(5m).close();
@atr: Double = $(5m).ATR().value;
@adx: Double = $(5m).ADX().value;

ALL{
  $(5m).MACD().trend = BULLISH;
  $(5m).RSI().value < 70;
} = BUY(
  calcDynamicTP(@current_price, @atr, @adx),  // 动态止盈
  calcDynamicSL(@current_price, @atr, @adx)   // 动态止损
);
```

**优势**:
- ✅ **逻辑清晰**：止盈止损计算逻辑封装在函数中，策略代码更简洁
- ✅ **易于维护**：修改止盈止损逻辑只需修改函数定义
- ✅ **可复用**：多个信号可以共享相同的止盈止损计算函数
- ✅ **灵活配置**：可以根据不同条件调用不同的计算函数

## 10. FAQ

### Q1: 自定义函数可以在哪里定义？
**A**: 自定义函数必须在策略的**结构顶层**定义，与信号函数（如 `ALL`, `ANY` 等）平级。
```javascript
// ✅ 正确：顶层定义
calcScore(rsi: Double): Double { ... }

ALL{...} = BUY;

calcHelper(x: Double): Double { ... }

MIN(2){...} = SELL;

// ❌ 错误：不能在信号函数内部定义
ALL{
  calcScore(rsi: Double): Double { ... }  // ❌ 错误
} = BUY;
```

### Q2: 自定义函数可以递归调用吗？

**A**: **阶段1（MVP）不支持递归**。递归调用会导致编译错误。
```javascript
// ❌ 暂不支持
factorial(n: Integer): Integer {
  if (n <= 1) {
    return 1;
  }
  return n * factorial(n - 1);  // ❌ 递归调用
}
```

### Q3: 自定义函数可以访问指标和环境变量吗？

**A**: **可以**。自定义函数可以访问：
- ✅ 指标引用（如 `$(5m).RSI().value`）
- ✅ 环境变量（如 `@CURRENT_PRICE`）
- ✅ 数据函数（如 `KLINE(5m).close(0)`）
- ✅ 系统函数（如 `ABS`, `MAX`, `ROUND` 等）
- ✅ 其他自定义函数

```javascript
calcMarketScore(timeframe: String): Integer {
  @rsi: Double = $(timeframe).RSI().value;  // ✅ 指标引用
  @price: Double = @CURRENT_PRICE;         // ✅ 环境变量
  @close: Double = KLINE(timeframe).close(0);  // ✅ 数据函数
  @abs_diff: Double = ABS(@price - @close);    // ✅ 系统函数
  
  return @rsi < 30 ? 100 : 0;
}
```

### Q4: 是否支持默认参数？
**A**: **不支持**。所有参数必须显式传递。
```javascript
// ❌ 不支持
calcScore(rsi: Double, threshold: Double = 30.0): Double { ... }

// ✅ 必须显式传递所有参数
calcScore($(5m).RSI().value, 30.0)
```

### Q5: 变量命名有什么限制？

**A**: 
- ✅ 用户变量：`@` + 全小写 + 下划线（`@my_var`, `@rsi_value`）
- ✅ 环境变量：`@` + 全大写 + 下划线（`@CURRENT_PRICE`）
- ❌ 禁止：混合大小写（`@MyVar`, `@myVar`）

### Q6: 是否支持数组和循环？

**A**: **不支持**。阶段1和阶段2都不支持数组和循环。
```javascript
// ❌ 不支持
for (@i: Integer = 0; @i < 10; @i++) { ... }
while (condition) { ... }
@arr: Array = [1, 2, 3];
```

### Q7: 如何调试自定义函数？

**A**: 阶段1可以通过以下方式调试：
1. 在函数中添加注释，说明逻辑
2. 将复杂函数拆分为多个简单函数
3. 在策略测试中观察函数返回值
阶段2会增加更强大的调试功能。

### Q8: 自定义函数的性能如何？
**A**: 自定义函数在编译时会进行优化：
- ✅ 类型推断和检查在编译时完成
- ✅ 常量折叠优化
- ✅ 函数内联优化（阶段2）

## 11. 附录

### 11.1 语法 EBNF

```ebnf
(* 函数定义 *)
function_definition = identifier, "(", [parameter_list], ")", [":", type], "{", statement_list, "}" ;

(* 参数列表 *)
parameter_list = parameter, { ",", parameter } ;
parameter = identifier, [":", type] ;

(* 语句 *)
statement = variable_declaration
          | assignment_statement
          | if_statement
          | return_statement
          | expression_statement ;

(* 变量声明 *)
variable_declaration = "@", identifier, [":", type], "=", expression, ";" ;

(* 赋值语句 *)
assignment_statement = "@", identifier, assignment_operator, expression, ";" ;
assignment_operator = "=" | "+=" | "-=" | "*=" | "/=" ;

(* if-else 语句 *)
if_statement = "if", "(", expression, ")", "{", statement_list, "}", 
               [ "else", ( if_statement | "{", statement_list, "}" ) ] ;

(* return 语句 *)
return_statement = "return", expression, ";" ;

(* 三元表达式 *)
ternary_expression = logical_or_expression, ["?", expression, ":", expression] ;
```

### 11.2 关键字列表
| 关键字 | 说明 |
|-------|------|
| `if` | 条件判断 |
| `else` | 条件分支 |
| `return` | 函数返回 |
| `true` | 布尔真值 |
| `false` | 布尔假值 |

### 11.3 保留前缀

| 前缀 | 用途 | 示例 |
|------|------|------|
| `@` | 变量和环境变量 | `@my_var`, `@CURRENT_PRICE` |
| `$` | 指标引用 | `$(5m).RSI().value` |
| `#` | 参数引用（已废弃） | - |

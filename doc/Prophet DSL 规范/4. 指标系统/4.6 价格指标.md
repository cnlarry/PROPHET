## 概述

价格指标用于分析价格行为、识别关键价位和支持阻力区域，帮助交易者做出更好的交易决策。

**指标特点：**
- ✅ 识别关键价格水平
- ✅ 分析价格结构
- ✅ 确定支撑阻力
- ✅ 预测价格走势

---

## 价格通道

价格通道通过绘制价格的上下边界来识别价格波动范围。

### 唐奇安通道

唐奇安通道基于一定周期内的最高价和最低价构建通道。

#### 语法
```javascript
$(timeframe).DONCHIAN([PERIOD]).upper
$(timeframe).DONCHIAN([PERIOD]).middle
$(timeframe).DONCHIAN([PERIOD]).lower
$(timeframe).DONCHIAN([PERIOD]).width
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

#### 返回值
- `.upper`: 上轨（周期内最高价）
- `.middle`: 中轨（上下轨平均值）
- `.lower`: 下轨（周期内最低价）
- `.width`: 通道宽度

#### 示例
```javascript
// 计算唐奇安通道
upper_channel = $(5m).DONCHIAN(20).upper
middle_channel = $(5m).DONCHIAN(20).middle
lower_channel = $(5m).DONCHIAN(20).lower
channel_width = $(5m).DONCHIAN(20).width

// 价格位置判断
ALL{
  KLINE(5m).close(0) > $(5m).DONCHIAN(20).upper;
} = SELL;
ALL{
  KLINE(5m).close(0) < $(5m).DONCHIAN(20).lower;
} = BUY;
ALL{
  KLINE(5m).close(0) > $(5m).DONCHIAN(20).lower;
  KLINE(5m).close(0) < $(5m).DONCHIAN(20).upper;
} = HOLD;

// 通道突破
previous_upper = $(5m).DONCHIAN(20).upper(1)
ALL{current_price > upper_channel; KLINE(5m).close(-1) <= previous_upper;} = CHANNEL_BREAKOUT_UP;

previous_lower = $(5m).DONCHIAN(20).lower(-1);
ALL{current_price < lower_channel; KLINE(5m).close(-1) >= previous_lower;} = CHANNEL_BREAKOUT_DOWN;

// 通道宽度分析
ALL{
  $(5m).DONCHIAN(20).width > AVERAGE(5m).DONCHIAN.width(50) * 1.5;
} = HOLD;
ALL{
  $(5m).DONCHIAN(20).width < AVERAGE(5m).DONCHIAN.width(50) * 0.5;
} = HOLD;
```

### Keltner通道

Keltner通道使用EMA和ATR构建通道，更适合趋势跟踪。

#### 语法
```javascript
$(timeframe).KELTNER([PERIOD], [multiplier]).upper
$(timeframe).KELTNER([PERIOD], [multiplier]).middle
$(timeframe).KELTNER([PERIOD], [multiplier]).lower
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: EMA周期（可选，默认20）
- `multiplier`: ATR乘数（可选，默认1.5）

#### 返回值
- `.upper`: 上轨
- `.middle`: 中轨（EMA）
- `.lower`: 下轨

#### 示例
```javascript
// 计算Keltner通道
upper_keltner = $(5m).KELTNER(20, 1.5).upper
middle_keltner = $(5m).KELTNER(20, 1.5).middle
lower_keltner = $(5m).KELTNER(20, 1.5).lower

// 价格相对于Keltner通道
ALL{
  KLINE(5m).close(0) > $(5m).KELTNER(20, 1.5).upper;
} = SELL;
ALL{
  KLINE(5m).close(0) < $(5m).KELTNER(20, 1.5).lower;
} = BUY;

// Keltner交易策略
ALL{current_price > upper_keltner; $(5m).KELTNER(20, 1.5).upper(-1) >= KLINE(5m).close(-1);} = KELTNER_BREAKOUT_UP;
ALL{current_price < lower_keltner; $(5m).KELTNER(20, 1.5).lower(-1) <= KLINE(5m).close(-1);} = KELTNER_BREAKOUT_DOWN;
```

## 支撑阻力

支撑阻力指标用于识别关键的价格水平。

### Pivot Points - 轴心点

轴心点基于前一交易日的价格数据计算支撑阻力水平。

#### 语法
```javascript
$(timeframe).PIVOT().pivot
$(timeframe).PIVOT().r1
$(timeframe).PIVOT().r2
$(timeframe).PIVOT().r3
$(timeframe).PIVOT().s1
$(timeframe).PIVOT().s2
$(timeframe).PIVOT().s3
$(timeframe).PIVOT().trend
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
- `.pivot`: 轴心点
- `.r1`: 第一阻力
- `.r2`: 第二阻力
- `.r3`: 第三阻力
- `.s1`: 第一支撑
- `.s2`: 第二支撑
- `.s3`: 第三支撑
- `.trend`: 趋势方向

#### 示例
```javascript
// 计算轴心点
pivot = $(1d).PIVOT().pivot
r1 = $(1d).PIVOT().r1
r2 = $(1d).PIVOT().r2
r3 = $(1d).PIVOT().r3
s1 = $(1d).PIVOT().s1
s2 = $(1d).PIVOT().s2
s3 = $(1d).PIVOT().s3

// 价格接近关键水平
ALL{
  ABS(KLINE(5m).close(0) - $(1d).PIVOT().r1) < KLINE(5m).close(0) * 0.005;
} = HOLD;  // 0.5%范围内
ALL{
  ABS(KLINE(5m).close(0) - $(1d).PIVOT().s1) < KLINE(5m).close(0) * 0.005;
} = HOLD;

// 轴心点趋势
ALL{
  $(1d).PIVOT().trend == BULLISH;
} = BUY;
ALL{
  $(1d).PIVOT().trend == BEARISH;
} = SELL;

// 轴心点交易策略
ALL{
  KLINE(5m).close(0) > $(1d).PIVOT().pivot;
  KLINE(5m).close(0) < $(1d).PIVOT().r1;
} = BUY;
ALL{
  KLINE(5m).close(0) < $(1d).PIVOT().pivot;
  KLINE(5m).close(0) > $(1d).PIVOT().s1;
} = SELL;
```

### ZigZag - 之字转向

之字转向过滤小幅价格波动，突出主要价格转折点。

#### 语法
```javascript
$(timeframe).ZIGZAG([percentage]).value
$(timeframe).ZIGZAG([percentage]).trend
```

#### 参数
- `timeframe`: 时间周期
- `percentage`: 转向百分比（可选，默认5.0）

#### 返回值
- `.value`: ZigZag值
- `.trend`: 趋势方向

#### 示例
```javascript
// 计算ZigZag
zigzag = $(5m).ZIGZAG(5.0).value
zigzag_trend = $(5m).ZIGZAG(5.0).trend

// ZigZag转折点
ALL{
  $(5m).ZIGZAG(5.0).value != $(5m).ZIGZAG(5.0).value(1);
} = HOLD;

// 趋势确认
ALL{
  $(5m).ZIGZAG(5.0).trend == BULLISH;
} = BUY;
ALL{
  $(5m).ZIGZAG(5.0).trend == BEARISH;
} = SELL;

// 支撑阻力识别
// ZigZag的高点和低点可以作为潜在的支撑阻力位
```

## 价格形态

价格形态指标分析特定的价格行为模式。

### VWAP - 成交量加权平均价

VWAP衡量特定时间段内成交量加权的平均价格。

#### 语法
```javascript
$(timeframe).VWAP().value
$(timeframe).VWAP().trend
```

#### 参数
- `timeframe`: 时间周期

#### 返回值
- `.value`: VWAP值
- `.trend`: 相对于VWAP的趋势

#### 示例
```javascript
// 计算VWAP
vwap = $(1d).VWAP().value
current_price = KLINE(5m).close()

// 价格相对于VWAP
ALL{
  KLINE(5m).close(0) > $(1d).VWAP().value;
} = BUY;
ALL{
  KLINE(5m).close(0) < $(1d).VWAP().value;
} = SELL;

// VWAP交易策略
ALL{
  KLINE(5m).close(0) > $(1d).VWAP().value;
  $(1d).VWAP().trend == BULLISH;
} = BUY;
ALL{
  KLINE(5m).close(0) < $(1d).VWAP().value;
  $(1d).VWAP().trend == BEARISH;
} = SELL;

// VWAP偏离度
ALL{
  (KLINE(5m).close(0) - $(1d).VWAP().value) / $(1d).VWAP().value * 100 > 2;
} = SELL;  // 超过2%偏离
ALL{
  (KLINE(5m).close(0) - $(1d).VWAP().value) / $(1d).VWAP().value * 100 < -2;
} = BUY;
```

### TWAP - 时间加权平均价

TWAP衡量特定时间段内时间加权的平均价格。

#### 语法
```javascript
$(timeframe).TWAP([PERIOD]).value
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

#### 返回值
- `.value`: TWAP值

#### 示例
```javascript
// 计算TWAP
twap = $(5m).TWAP(20).value
current_price = KLINE(5m).close()

// 价格相对于TWAP
ALL{
  KLINE(5m).close(0) > $(5m).TWAP(20).value;
} = BUY;
ALL{
  KLINE(5m).close(0) < $(5m).TWAP(20).value;
} = SELL;

// TWAP交易策略
ALL{
  $(5m).TWAP(20).value > $(5m).TWAP(20).value(1);
  KLINE(5m).close(0) > $(5m).TWAP(20).value;
} = BUY;
ALL{
  $(5m).TWAP(20).value < $(5m).TWAP(20).value(1);
  KLINE(5m).close(0) < $(5m).TWAP(20).value;
} = SELL;
```

## 价格震荡指标

价格震荡指标衡量价格相对于特定范围的位置。

### Stochastic - 随机指标

随机指标比较收盘价与指定周期内的价格范围。

#### 语法
```javascript
$(timeframe).STOCH([K_PERIOD], [D_PERIOD]).k
$(timeframe).STOCH([K_PERIOD], [D_PERIOD]).d
$(timeframe).STOCH([K_PERIOD], [D_PERIOD]).trend
```

#### 参数
- `timeframe`: 时间周期
- `K_PERIOD`: %K线周期（可选，默认14）
- `D_PERIOD`: %D线周期（可选，默认3）

#### 返回值
- `.k`: %K值（0-100）
- `.d`: %D值（0-100）
- `.trend`: 趋势方向

#### 示例
```javascript
// 计算随机指标
stoch_k = $(5m).STOCH(14, 3).k
stoch_d = $(5m).STOCH(14, 3).d

// 超买超卖判断
ALL{
  $(5m).STOCH(14, 3).k > 80;
  $(5m).STOCH(14, 3).d > 80;
} = SELL;
ALL{
  $(5m).STOCH(14, 3).k < 20;
  $(5m).STOCH(14, 3).d < 20;
} = BUY;

// 金叉死叉信号
ALL{
  $(5m).STOCH(14, 3).k > $(5m).STOCH(14, 3).d;
  $(5m).STOCH(14, 3).k(1) <= $(5m).STOCH(14, 3).d(1);
} = BUY;
ALL{
  $(5m).STOCH(14, 3).k < $(5m).STOCH(14, 3).d;
  $(5m).STOCH(14, 3).k(1) >= $(5m).STOCH(14, 3).d(1);
} = SELL;

// 随机指标趋势
ALL{
  $(5m).STOCH(14, 3).trend == BULLISH;
} = BUY;
```

### Williams %R - 威廉指标

威廉指标衡量当前收盘价在指定周期内的相对位置。

#### 语法
```javascript
$(timeframe).WILLR([PERIOD]).value
$(timeframe).WILLR([PERIOD]).level
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认14）

#### 返回值
- `.value`: 威廉指标值（0到-100）
- `.level`: 超买超卖级别

#### 示例
```javascript
// 计算威廉指标
willr = $(5m).WILLR(14).value

// 超买超卖判断
ALL{
  $(5m).WILLR(14).value > -20;
} = SELL;
ALL{
  $(5m).WILLR(14).value < -80;
} = BUY;
ALL{
  $(5m).WILLR(14).value >= -80;
  $(5m).WILLR(14).value <= -20;
} = HOLD;

// 威廉指标超买超卖判断
ALL{
  $(5m).WILLR(14).value > -20;
} = SELL;
ALL{
  $(5m).WILLR(14).value < -80;
} = BUY;

// 威廉指标背离
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(10);
  $(5m).WILLR(14).value < $(5m).WILLR(14).value(10);
} = BUY;
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(10);
  $(5m).WILLR(14).value > $(5m).WILLR(14).value(10);
} = SELL;
```

## 使用示例

### 示例1：多价格水平确认

```javascript
// 唐奇安通道突破
donchian_upper = $(5m).DONCHIAN(20).upper
donchian_lower = $(5m).DONCHIAN(20).lower

// 轴心点确认
pivot = $(1d).PIVOT().pivot
r1 = $(1d).PIVOT().r1
s1 = $(1d).PIVOT().s1

// VWAP确认
vwap = $(1d).VWAP().value

current_price = KLINE(5m).close()

// 多重确认突破
ALL{
  KLINE(5m).close(0) > $(5m).DONCHIAN(20).upper;
  KLINE(5m).close(0) > $(1d).PIVOT().r1;
  KLINE(5m).close(0) > $(1d).VWAP().value;
} = BUY;
```

### 示例2：支撑阻力交易策略

```javascript
// 关键支撑阻力位
pivot = $(1d).PIVOT().pivot
r1 = $(1d).PIVOT().r1
s1 = $(1d).PIVOT().s1

// 价格接近支撑
ALL{
  ABS(KLINE(5m).close(0) - $(1d).PIVOT().s1) < KLINE(5m).close(0) * 0.005;
  $(5m).RSI().value < 30;
} = BUY;

// 价格接近阻力
ALL{
  ABS(KLINE(5m).close(0) - $(1d).PIVOT().r1) < KLINE(5m).close(0) * 0.005;
  $(5m).RSI().value > 70;
} = SELL;
```

### 示例3：价格通道交易

```javascript
// Keltner通道策略
upper_keltner = $(5m).KELTNER(20, 1.5).upper
lower_keltner = $(5m).KELTNER(20, 1.5).lower
middle_keltner = $(5m).KELTNER(20, 1.5).middle

current_price = KLINE(5m).close()

// 通道突破策略（回调买入）
ALL{
  KLINE(5m).close(0) > $(5m).KELTNER(20, 1.5).upper;
  KLINE(5m).close(0) < $(5m).KELTNER(20, 1.5).middle + ($(5m).KELTNER(20, 1.5).upper - $(5m).KELTNER(20, 1.5).middle) * 0.5;
} = BUY;

// 通道突破策略（反弹卖出）
ALL{
  KLINE(5m).close(0) < $(5m).KELTNER(20, 1.5).lower;
  KLINE(5m).close(0) > $(5m).KELTNER(20, 1.5).middle - ($(5m).KELTNER(20, 1.5).middle - $(5m).KELTNER(20, 1.5).lower) * 0.5;
} = SELL;
```

## 最佳实践

### 1. 多指标确认

```javascript
// 不要单独依赖单一价格指标
donchian_breakout = KLINE(5m).close() > $(5m).DONCHIAN(20).upper
pivot_confirmation = KLINE(5m).close() > $(1d).PIVOT().pivot
vwap_confirmation = KLINE(5m).close() > $(1d).VWAP().value

// 多重确认更可靠
ALL{
  KLINE(5m).close(0) > $(5m).DONCHIAN(20).upper;
  KLINE(5m).close(0) > $(1d).PIVOT().r1;
  KLINE(5m).close(0) > $(1d).VWAP().value;
} = BUY;
```

---

### 2. 时间框架结合

```javascript
// 长期支撑阻力
long_term_pivot = $(1d).PIVOT().pivot
long_term_r1 = $(1d).PIVOT().r1
long_term_s1 = $(1d).PIVOT().s1

// 短期价格行为
short_term_donchian = $(5m).DONCHIAN(20).upper

// 多时间框架策略
ALL{
  KLINE(5m).close(0) > $(1d).PIVOT().r1;
  KLINE(5m).close(0) < $(5m).DONCHIAN(20).upper;
} = HOLD;
```

---

### 3. 动态支撑阻力

```javascript
// 使用移动平均线作为动态支撑阻力
dynamic_support = AVERAGE(5m).close(20)
dynamic_resistance = AVERAGE(5m).close(50)

// 结合固定支撑阻力
fixed_support = $(1d).PIVOT().s1
fixed_resistance = $(1d).PIVOT().r1

// 综合支撑阻力
combined_support = (dynamic_support + fixed_support) / 2
combined_resistance = (dynamic_resistance + fixed_resistance) / 2
```

---

### 4. 价格行为分析

```javascript
// 识别关键K线模式
// 结合支撑阻力位分析

support_level = $(1d).PIVOT().s1
resistance_level = $(1d).PIVOT().r1

// 锤子线在支撑位
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
  ABS(KLINE(5m).low(0) - $(1d).PIVOT().s1) < $(1d).PIVOT().s1 * 0.005;
  PATTERN(5m).HAMMER() = true;
} = BUY;

// 上吊线在阻力位
ALL{
  KLINE(5m).close(0) < KLINE(5m).open(0);
  ABS(KLINE(5m).high(0) - $(1d).PIVOT().r1) < $(1d).PIVOT().r1 * 0.005;
  PATTERN(5m).HANGING_MAN() = true;
} = SELL;
```

## 概述

波动率指标用于衡量市场价格变动的剧烈程度，帮助交易者评估风险和调整交易策略。

**指标特点：**
- ✅ 衡量价格波动程度
- ✅ 评估市场风险水平
- ✅ 动态调整交易参数
- ✅ 识别高波动和低波动时期

## ATR - 平均真实波幅

ATR衡量市场的平均波动幅度，是最重要的波动率指标之一。

### 语法
```javascript
$(timeframe).ATR([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认14）

### 返回值
- `.value`: ATR值

### 示例
```javascript
// 计算14周期ATR
atr = $(5m).ATR(14).value

// 波动率状态判断
ALL{
  $(5m).ATR(14).value > AVERAGE(5m).ATR.value(50) * 1.5;
} = HOLD;
ALL{
  $(5m).ATR(14).value < AVERAGE(5m).ATR.value(50) * 0.5;
} = HOLD;
ALL{
  $(5m).ATR(14).value >= AVERAGE(5m).ATR.value(50) * 0.5;
  $(5m).ATR(14).value <= AVERAGE(5m).ATR.value(50) * 1.5;
} = HOLD;

// 动态止损（使用自定义函数）
calcStopLoss(entry_price: Double, stop_loss_distance: Double, is_long: Boolean): Double {
  if (is_long) {
    return entry_price - stop_loss_distance;
  } else {
    return entry_price + stop_loss_distance;
  }
}

// 仓位规模调整
account_risk = ACCOUNT.EQUITY() * 0.01  // 账户1%风险
position_size = account_risk / stop_loss_distance
```

## VOLA - 波动率分析

VOLA提供更全面的波动率分析，包括绝对波动率和相对波动率。

### 语法
```javascript
$(timeframe).VOLA([PERIOD]).value     // 绝对波动率（标准差）
$(timeframe).VOLA([PERIOD]).pct       // 百分比波动率（变异系数）
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: 绝对波动率（标准差）
- `.pct`: 百分比波动率（变异系数）

### 示例
```javascript
// 绝对波动率
abs_volatility = $(5m).VOLA(20).value

// 百分比波动率（变异系数）
pct_volatility = $(5m).VOLA(20).pct

// 波动率比较
current_price = KLINE(5m).close()
volatility_ratio = abs_volatility / current_price * 100

ALL{
  VOLA(5m).close(20).value / KLINE(5m).close(0) * 100 > 2;
} = HOLD;
ALL{
  VOLA(5m).close(20).value / KLINE(5m).close(0) * 100 < 1;
} = HOLD;

// 跨品种波动率比较
ALL{
  VOLA(5m).close(20).pct > VOLA(5m).close(20).pct;
} = BUY;
```

## 标准差

标准差衡量价格偏离其平均值的程度。

### 语法
```javascript
$(timeframe).STDDEV([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: 标准差值

### 示例
```javascript
// 计算20周期标准差
std_dev = $(5m).STDDEV(20).value

// 布林带计算
ma_20 = AVERAGE(5m).close(20)
upper_band = ma_20 + 2 * std_dev
lower_band = ma_20 - 2 * std_dev

// 异常波动检测
ALL{
  STD(5m).close(20) > AVERAGE(5m).STDDEV.value(100) * 2;
} = HOLD;
```

## 方差

方差是标准差的平方，衡量数据离散程度。

### 语法
```javascript
$(timeframe).VARIANCE([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: 方差值

### 示例
```javascript
// 计算20周期方差
variance = $(5m).VARIANCE(20).value

// 标准差是方差的平方根
std_dev = SQRT(variance)

// 波动率稳定性
variance_rolling = AVERAGE(5m).VARIANCE.value(50)
variance_std = STD(5m).VARIANCE.value(50)
ALL{
  STD(5m).VARIANCE.value(50) < AVERAGE(5m).VARIANCE.value(50) * 0.1;
} = HOLD;
```

## 波动率比率

波动率比率比较不同周期的波动率，识别波动率趋势。

### 语法
```javascript
$(timeframe).VOL_RATIO([SHORT_PERIOD], [LONG_PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `SHORT_PERIOD`: 短周期（可选，默认10）
- `LONG_PERIOD`: 长周期（可选，默认50）

### 返回值
- `.value`: 波动率比率

### 示例
```javascript
// 计算波动率比率
vol_ratio = $(5m).VOL_RATIO(10, 50).value

// 波动率趋势
ALL{
  $(5m).VOL_RATIO(10, 50).value > 1.2;
} = HOLD;
ALL{
  $(5m).VOL_RATIO(10, 50).value < 0.8;
} = HOLD;
ALL{
  $(5m).VOL_RATIO(10, 50).value >= 0.8;
  $(5m).VOL_RATIO(10, 50).value <= 1.2;
} = HOLD;

// 波动率突破策略
ALL{
  $(5m).VOL_RATIO(10, 50).value > AVERAGE(5m).VOL_RATIO.value(100) * 1.5;
} = BUY;
```

## 使用示例

### 示例1：波动率调整止损

```javascript
// 基于ATR的动态止损
atr = $(5m).ATR(14).value
base_stop = atr * 2

// 考虑市场状态调整（使用自定义函数）
calcVolatilityRegime(atr: Double): String {
  if (atr > AVERAGE(5m).ATR.value(50) * 1.5) {
    return "HIGH";
  } else if (atr < AVERAGE(5m).ATR.value(50) * 0.5) {
    return "LOW";
  } else {
    return "NORMAL";
  }
}

adjusted_stop = SWITCH(volatility_regime) {
    CASE "HIGH": base_stop * 1.5
    CASE "LOW": base_stop * 0.8
    DEFAULT: base_stop
}

SET_STOP_LOSS(adjusted_stop)
```

---

### 示例2：波动率择时策略

```javascript
// 低波动率积累，高波动率释放
current_atr = $(5m).ATR(14).value
historical_atr = AVERAGE(5m).ATR.value(100)

// 波动率压缩
ALL{
  $(5m).ATR(14).value < AVERAGE(5m).ATR.value(100) * 0.5;
} = HOLD;

// 波动率扩张
ALL{
  $(5m).ATR(14).value > AVERAGE(5m).ATR.value(100) * 1.5;
} = BUY;

// 策略应用（使用自定义函数）
checkVolatilityCompression(): Boolean {
  return $(5m).ATR(14).value < AVERAGE(5m).ATR.value(100) * 0.5;
}

checkVolatilityExpansion(): Boolean {
  return $(5m).ATR(14).value > AVERAGE(5m).ATR.value(100) * 1.5;
}

ALL{
  checkVolatilityExpansion();
} = BUY;
```

### 示例3：波动率风险管理

```javascript
// 根据波动率调整仓位规模
atr = $(5m).ATR(14).value
account_equity = ACCOUNT.EQUITY()
risk_per_trade = account_equity * 0.01  // 1%账户风险

// 基础仓位规模
base_position_size = risk_per_trade / (atr * 2)  // 2倍ATR止损

// 波动率调整（使用自定义函数）
calcPositionSize(atr: Double, base_position_size: Double): Double {
  if (atr > AVERAGE(5m).ATR.value(50) * 2) {
    // 极高波动率：减仓
    return base_position_size * 0.5;
  }
  return base_position_size;
}
ELIF atr < AVERAGE(5m).ATR.value(50) * 0.5:
    // 极低波动率：加仓
    position_size = base_position_size * 1.5
ELSE:
    // 正常波动率：标准仓位
    position_size = base_position_size

EXECUTE_TRADE(position_size)
```

## 最佳实践

### 1. 波动率标准化比较

```javascript
// 使用百分比波动率进行跨品种比较
btc_abs_vol = $(5m).VOLA(20).value
btc_price = KLINE(5m).close()
btc_pct_vol = btc_abs_vol / btc_price * 100

eth_abs_vol = $(5m).VOLA(20).value
eth_price = KLINE(5m).close()
eth_pct_vol = eth_abs_vol / eth_price * 100

// 标准化比较更准确
ALL{
  VOLA(5m).close(20).pct > VOLA(5m).close(20).pct;
} = BUY;
```

---

### 2. 波动率均值回归

```javascript
// 波动率倾向于均值回归
current_vol = $(5m).ATR(14).value
average_vol = AVERAGE(5m).ATR.value(100)
vol_std = STD(5m).ATR.value(100)

// 极值波动率往往预示反转
ALL{
  $(5m).ATR(14).value > AVERAGE(5m).ATR.value(100) + 2 * STD(5m).ATR.value(100);
} = HOLD;
ALL{
  $(5m).ATR(14).value < AVERAGE(5m).ATR.value(100) - 2 * STD(5m).ATR.value(100);
} = HOLD;
```

---

### 3. 波动率与趋势结合

```javascript
// 高波动率趋势vs低波动率震荡
atr = $(5m).ATR(14).value
atr_threshold = AVERAGE(5m).ATR.value(100)

trend_strength = $(5m).ADX().value

// 波动率与趋势结合（使用自定义函数）
selectStrategy(atr: Double, atr_threshold: Double, trend_strength: Double): String {
  if (atr > atr_threshold AND trend_strength > 25) {
    // 高波动率趋势市场
    return "TREND_FOLLOWING";
  } else if (atr < atr_threshold AND trend_strength < 20) {
    // 低波动率震荡市场
    return "MEAN_REVERSION";
  } else {
    // 混合市场
    return "ADAPTIVE";
  }
}
```

// 使用历史波动率预测未来波动率
historical_vol = AVERAGE(5m).ATR.value(100)

// 波动率趋势（使用自定义函数）
checkVolatilityTrend(recent_vol: Double, historical_vol: Double): String {

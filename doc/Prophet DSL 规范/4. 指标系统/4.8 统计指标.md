## 1. 概述

本文档详细介绍 Prophet DSL 支持的统计指标，这些指标用于分析价格数据的统计特性。

## 2. 统计指标清单

Prophet DSL 支持以下统计指标：

| 指标名称 | 说明 |
|---------|------|
| KaufmanER | 凯夫纳效率比率 |
| LinearRegSlope | 线性回归斜率 |
| StdDev | 标准差 |

## 3. 指标详解

### 3.1 KaufmanER - 凯夫纳效率比率

**语法**：`$(timeframe).KaufmanER(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：10）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：效率比率值（0-1）
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**说明**：
凯夫纳效率比率衡量价格变动的效率，值越接近1表示趋势越强，值越接近0表示震荡越剧烈。

### 3.2 LinearRegSlope - 线性回归斜率

**语法**：`$(timeframe).LinearRegSlope(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：14）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：线性回归斜率值
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**说明**：
线性回归斜率衡量价格在一段时间内的线性趋势强度和方向。

### 3.3 StdDev - 标准差

**语法**：`$(timeframe).StdDev(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：20）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：标准差值
- `.normalized`：标准化值

**说明**：
标准差衡量价格波动性的统计指标，值越大表示波动性越高。

## 4. 使用示例

### 4.1 趋势强度判断

```javascript
// 使用凯夫纳效率比率判断趋势强度
ALL {
    $(5m).KaufmanER(10).value > 0.5,  // 效率比率大于0.5表示趋势较强
    $(5m).LinearRegSlope(14).trend = BULLISH  // 线性趋势向上
} = BUY;
```

### 4.2 波动性分析

```javascript
// 使用标准差分析波动性
@std_dev = $(5m).StdDev(20).value;
@price = KLINE(5m).close();

// 波动性较低时寻找突破机会
ALL {
    @std_dev < AVERAGE(5m).StdDev(20).value(20),  // 当前波动性低于平均水平
    CHANGE(5m).close(1).pct > 2.0  // 价格突然大幅上涨
} = BUY;
```

### 4.3 综合运用

```javascript
// 结合多个统计指标
@efficiency = $(5m).KaufmanER(10).value;
@slope = $(5m).LinearRegSlope(14).value;
@volatility = $(5m).StdDev(20).value;

// 高效趋势策略
ALL {
    @efficiency > 0.6,     // 高效率趋势
    @slope > 0,            // 正斜率
    @volatility > 1.0      // 足够的波动性
} = BUY;
```

## 5. 最佳实践

### 5.1 参数设置

- 根据交易周期选择合适的计算周期
- 短周期敏感但噪音多，长周期稳定但滞后

### 5.2 组合使用

- 将统计指标与其他技术指标结合使用
- 用统计指标确认趋势质量和波动性特征

### 5.3 风险管理

- 在高波动性时期谨慎交易
- 使用统计指标识别异常市场状况

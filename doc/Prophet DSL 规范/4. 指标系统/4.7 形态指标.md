## 概述

形态指标用于识别和分析价格结构、摆动点和市场结构破坏，帮助交易者识别趋势、支撑阻力和潜在的反转点。这些指标是技术分析中的核心工具，广泛应用于趋势交易和波段交易策略。

**指标特点：**
- ✅ 识别价格结构（Higher High/Lower Low）
- ✅ 检测市场结构破坏（Market Structure Break）
- ✅ 定位摆动高低点（Swing High/Low）
- ✅ 支持多时间框架分析
- ✅ 提供趋势方向判断

**核心指标：**
1. **HHLL** - 更高高点/更低低点（Higher High/Lower Low）
2. **MSB** - 市场结构破坏（Market Structure Break）
3. **SwingHL** - 摆动高低点（Swing High/Low）

---

## HHLL - 更高高点/更低低点

### 概述

**HHLL（Higher High/Lower Low）** 指标用于识别价格结构的变化，判断市场是否形成更高的高点、更低的低点等关键价格结构，是判断趋势方向和趋势强度的重要工具。

**核心概念：**
- **Higher High (HH)**: 更高高点 - 当前周期的最高价高于前一周期的最高价
- **Lower Low (LL)**: 更低低点 - 当前周期的最低价低于前一周期的最低价
- **Higher Low (HL)**: 更高低点 - 当前周期的最低价高于前一周期的最低价
- **Lower High (LH)**: 更低高点 - 当前周期的最高价低于前一周期的最高价

**趋势判断：**
- **上升趋势**: HH + HL（更高高点 + 更高低点）
- **下降趋势**: LH + LL（更低高点 + 更低低点）
- **扩张**: HH + LL（更高高点 + 更低低点，波动加大）
- **收缩**: LH + HL（更低高点 + 更高低点，波动缩小）
- **中性**: 其他情况

---

### 语法

```dsl
$(timeframe).HHLL().field
$(timeframe).HHLL(PERIOD).field
```

---

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `PERIOD` | 整数 | 10 | 2-100 | 比较周期（K线数量） |

**说明：**
- `PERIOD` 定义了用于比较的周期长度
- 指标会比较当前周期和前一周期的高低点
- 每个周期包含 `PERIOD` 根K线

---

### 字段

#### 只读字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_higher_high` | 布尔值 | 是否形成更高高点 |
| `is_lower_low` | 布尔值 | 是否形成更低低点 |
| `is_higher_low` | 布尔值 | 是否形成更高低点 |
| `is_lower_high` | 布尔值 | 是否形成更低高点 |
| `trend_structure` | 字符串 | 趋势结构类型 |

#### 序列字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `higher_high` | 序列 | 更高高点的差值（0表示无） |
| `lower_low` | 序列 | 更低低点的差值（0表示无） |
| `higher_low` | 序列 | 更高低点的差值（0表示无） |
| `lower_high` | 序列 | 更低高点的差值（0表示无） |

---

### trend_structure 取值

| 值 | 含义 | 价格结构 | 市场状态 |
|----|------|----------|----------|
| `UPTREND` | 上升趋势 | HH + HL | 健康上升 |
| `DOWNTREND` | 下降趋势 | LH + LL | 健康下降 |
| `EXPANDING` | 扩张 | HH + LL | 波动加大 |
| `CONTRACTING` | 收缩 | LH + HL | 波动缩小，可能突破 |
| `NEUTRAL` | 中性 | 其他 | 无明确方向 |

---

### 计算逻辑

1. **数据分组**：将K线数据按 `PERIOD` 分成两个周期
   - 前一周期：索引 `[i, i+PERIOD)`
   - 当前周期：索引 `[i+PERIOD, i+2*PERIOD)`

2. **计算高低点**：
   - `prev_high` = 前一周期的最高价
   - `prev_low` = 前一周期的最低价
   - `curr_high` = 当前周期的最高价
   - `curr_low` = 当前周期的最低价

3. **比较判断**：
   - `higher_high`: `curr_high > prev_high`
   - `lower_low`: `curr_low < prev_low`
   - `higher_low`: `curr_low > prev_low`
   - `lower_high`: `curr_high < prev_high`

4. **趋势结构**：根据上述四个条件组合判断

---

### 示例

#### 基础用法

```dsl
// 使用默认周期（10根K线）
is_hh = $(5m).HHLL().is_higher_high
is_ll = $(5m).HHLL().is_lower_low
trend = $(5m).HHLL().trend_structure

// 使用自定义周期（20根K线）
is_hh_20 = $(5m).HHLL(20).is_higher_high
trend_20 = $(5m).HHLL(20).trend_structure
```

---

#### 上升趋势确认

```dsl
// 标准上升趋势（HH + HL）
ALL{
    $(5m).HHLL().trend_structure = UPTREND,
    $(5m).HHLL().is_higher_high = true,
    $(5m).HHLL().is_higher_low = true,
    $(5m).RSI().value < 70
} = BUY;

// 多时间框架确认
ALL{
    $(5m).HHLL().trend_structure = UPTREND,    // 短期上升
    $(1h).HHLL().trend_structure = UPTREND,    // 长期上升
    $(5m).MACD().signal = BUY
} = BUY;  // 趋势一致性强
```

---

#### 下降趋势确认

```dsl
// 标准下降趋势（LH + LL）
ALL{
    $(5m).HHLL().trend_structure = DOWNTREND,
    $(5m).HHLL().is_lower_high = true,
    $(5m).HHLL().is_lower_low = true,
    $(5m).RSI().value > 30
} = SELL;
```

---

#### 趋势反转检测

```dsl
// 上升趋势破坏（出现 LH 或 LL）
ALL{
    $(5m).HHLL().trend_structure != UPTREND,   // 不再是上升趋势
    $(5m).HHLL(-1).trend_structure = UPTREND,  // 前一个数据点是上升趋势
    $(5m).HHLL().is_lower_low = true           // 形成更低低点
} = SELL;  // 上升趋势破坏

// 下降趋势反转（出现 HH 或 HL）
ALL{
    $(5m).HHLL().trend_structure != DOWNTREND, // 不再是下降趋势
    $(5m).HHLL(-1).trend_structure = DOWNTREND,// 前一个数据点是下降趋势
    $(5m).HHLL().is_higher_high = true         // 形成更高高点
} = BUY;  // 下降趋势反转
```

---

#### 波动分析

```dsl
// 扩张（波动加大，可能趋势加速）
ALL{
    $(5m).HHLL().trend_structure = EXPANDING,
    $(5m).MACD().histogram > 0,
    $(5m).RSI().value BETWEEN(40, 60)
} = HOLD;  // 等待方向明确

// 收缩（波动缩小，可能即将突破）
ALL{
    $(5m).HHLL().trend_structure = CONTRACTING,
    $(5m).BOLL().squeeze = true,               // 布林带收口
    $(5m).RSI().value BETWEEN(45, 55)
} = PREPARE_BREAKOUT;  // 准备突破
```

## MSB - 市场结构破坏

### 概述

**MSB（Market Structure Break）** 指标用于检测市场结构的破坏，识别价格突破前一个关键摆动点的时刻。市场结构破坏通常预示着趋势的延续或反转，是重要的交易信号。

**核心概念：**
- **看涨MSB (Bullish MSB)**: 价格突破前一个摆动高点，表明上升动能增强
- **看跌MSB (Bearish MSB)**: 价格跌破前一个摆动低点，表明下降动能增强
- **Break Level**: 被突破的价格水平（摆动高点或摆动低点）

**应用场景：**
- 识别趋势延续信号
- 检测潜在的趋势反转
- 确定关键的支撑阻力突破
- 设置交易进场点

---

### 语法

```dsl
$(timeframe).MSB().field
$(timeframe).MSB(LOOKBACK).field
```

---

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `LOOKBACK` | 整数 | 20 | 5-100 | 回溯周期（K线数量） |

**说明：**
- `LOOKBACK` 定义了查找前一个摆动点的回溯范围
- 较小的值检测短期结构破坏（更敏感）
- 较大的值检测长期结构破坏（更可靠）

---

### 字段

#### 只读字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `msb_type` | 字符串 | MSB类型（NONE/BULLISH/BEARISH） |
| `is_bullish_msb` | 布尔值 | 是否发生看涨MSB |
| `is_bearish_msb` | 布尔值 | 是否发生看跌MSB |

#### 序列字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `break_level` | 序列 | 被突破的价格水平（0表示无） |

---

### msb_type 取值

| 值 | 含义 | 价格行为 | 市场状态 |
|----|------|----------|----------|
| `BULLISH` | 看涨MSB | 突破摆动高点 | 上升动能增强 |
| `BEARISH` | 看跌MSB | 跌破摆动低点 | 下降动能增强 |
| `NONE` | 无MSB | 无结构破坏 | 结构完整 |

---

### 计算逻辑

1. **查找摆动点**：
   - 在回溯期内找到前一个摆动高点（`prev_swing_high`）
   - 在回溯期内找到前一个摆动低点（`prev_swing_low`）

2. **检测突破**：
   - 看涨MSB：`close > prev_swing_high`
   - 看跌MSB：`close < prev_swing_low`

3. **记录突破价位**：
   - `break_level` 记录被突破的价格水平

---

### 示例

#### 基础用法

```dsl
// 使用默认回溯期（20根K线）
msb_type = $(5m).MSB().msb_type
is_bullish = $(5m).MSB().is_bullish_msb
break_level = $(5m).MSB().break_level

// 使用自定义回溯期（50根K线）
msb_type_50 = $(5m).MSB(50).msb_type
```

---

#### 看涨MSB交易

```dsl
// 看涨MSB + 技术面确认
ALL{
    $(5m).MSB().is_bullish_msb = true,       // 发生看涨MSB
    $(5m).MSB().msb_type = BULLISH,          // 确认类型
    $(5m).MACD().histogram > 0,              // MACD柱状图为正
    $(5m).RSI().value BETWEEN(50, 70),       // RSI适中
    KLINE(5m).volume(0) > AVERAGE(5m).volume(20)  // 放量突破
} = BUY;  // 强势突破

// 多时间框架MSB确认
ALL{
    $(5m).MSB().is_bullish_msb = true,       // 短期MSB
    $(1h).HHLL().trend_structure = UPTREND,  // 长期上升趋势
    $(5m).RSI().value < 70
} = BUY;  // 顺势突破
```

---

#### 看跌MSB交易

```dsl
// 看跌MSB + 技术面确认
ALL{
    $(5m).MSB().is_bearish_msb = true,       // 发生看跌MSB
    $(5m).MSB().msb_type = BEARISH,          // 确认类型
    $(5m).MACD().histogram < 0,              // MACD柱状图为负
    $(5m).RSI().value BETWEEN(30, 50),       // RSI适中
    KLINE(5m).volume(0) > AVERAGE(5m).volume(20)  // 放量突破
} = SELL;  // 强势下破
```

---

#### MSB失效检测

```dsl
// 看涨MSB后价格回落（可能是假突破）
ALL{
    $(5m).MSB(-1).is_bullish_msb = true,     // 前一个数据点有看涨MSB
    $(5m).MSB(-1).break_level > 0,           // 有突破价位
    KLINE(5m).close(0) < $(5m).MSB(-1).break_level,  // 价格回落到突破位下方
    $(5m).MACD().histogram < 0
} = SELL;  // 假突破，反向交易
```

---

#### MSB与趋势结合

```dsl
// MSB确认趋势延续
ALL{
    $(5m).MSB().is_bullish_msb = true,       // 看涨MSB
    $(1h).HHLL().trend_structure = UPTREND,  // 上升趋势
    $(5m).HHLL().is_higher_high = true,      // 形成更高高点
    $(5m).RSI().value < 80
} = BUY;  // 趋势延续信号

// MSB确认趋势反转
ALL{
    $(5m).MSB().is_bullish_msb = true,       // 看涨MSB
    $(1h).HHLL().trend_structure = DOWNTREND,// 但长期是下降趋势
    $(5m).RSI().value < 50                   // RSI适中
} = BUY;  // 可能的趋势反转
```

## SwingHL - 摆动高低点

### 概述

**SwingHL（Swing High/Low）** 指标用于识别价格的摆动高点和摆动低点，这些点位通常是重要的支撑阻力位，也是趋势分析和交易决策的关键参考。

**核心概念：**
- **摆动高点 (Swing High)**: 中间K线的高点高于其左右两侧所有K线的高点
- **摆动低点 (Swing Low)**: 中间K线的低点低于其左右两侧所有K线的低点
- **对称性**: 左右两侧的K线数量相同（由 `PERIOD` 参数决定）

**应用场景：**
- 识别关键的支撑阻力位
- 确定趋势的波峰波谷
- 设置止损和目标位
- 绘制趋势线和通道

---

### 语法

```dsl
$(timeframe).SwingHL().field
$(timeframe).SwingHL(PERIOD).field
```

---

### 参数

| 参数 | 类型 | 默认值 | 范围 | 说明 |
|------|------|--------|------|------|
| `PERIOD` | 整数 | 5 | 1-50 | 左右两侧K线数量 |

**说明：**
- `PERIOD` 定义了摆动点左右两侧需要比较的K线数量
- 较小的值检测短期摆动点（更频繁，更敏感）
- 较大的值检测长期摆动点（更稳定，更可靠）
- 总共需要 `2 * PERIOD + 1` 根K线才能计算

---

### 字段

#### 只读字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `is_swing_high` | 布尔值 | 当前是否为摆动高点 |
| `is_swing_low` | 布尔值 | 当前是否为摆动低点 |

#### 序列字段

| 字段 | 类型 | 说明 |
|------|------|------|
| `swing_high` | 序列 | 摆动高点价格（0表示非摆动高点） |
| `swing_low` | 序列 | 摆动低点价格（0表示非摆动低点） |

---

### 计算逻辑

1. **滑动窗口**: 使用大小为 `2 * PERIOD + 1` 的滑动窗口

2. **摆动高点判断**:
   - 中间K线的高点必须高于左侧所有K线的高点
   - 中间K线的高点必须高于右侧所有K线的高点
   - 如果满足，`swing_high` = 高点价格，否则 = 0

3. **摆动低点判断**:
   - 中间K线的低点必须低于左侧所有K线的低点
   - 中间K线的低点必须低于右侧所有K线的低点
   - 如果满足，`swing_low` = 低点价格，否则 = 0

---

### 示例

#### 基础用法

```dsl
// 使用默认周期（左右各5根K线）
is_swing_high = $(5m).SwingHL().is_swing_high
is_swing_low = $(5m).SwingHL().is_swing_low
swing_high_price = $(5m).SwingHL().swing_high
swing_low_price = $(5m).SwingHL().swing_low

// 使用自定义周期（左右各10根K线，更稳定）
is_swing_high_10 = $(5m).SwingHL(10).is_swing_high
```

---

#### 摆动高点交易

```dsl
// 在摆动低点买入
ALL{
    $(5m).SwingHL().is_swing_low = true,     // 形成摆动低点
    $(5m).RSI().value < 40,                  // RSI超卖
    $(5m).MACD().histogram > 0,              // MACD转正
    $(1h).HHLL().trend_structure = UPTREND   // 长期上升趋势
} = BUY;  // 回调买入

// 在摆动高点卖出
ALL{
    $(5m).SwingHL().is_swing_high = true,    // 形成摆动高点
    $(5m).RSI().value > 60,                  // RSI超买
    $(5m).MACD().histogram < 0,              // MACD转负
    $(1h).HHLL().trend_structure = DOWNTREND // 长期下降趋势
} = SELL;  // 反弹卖出
```

---

#### 支撑阻力位应用

```dsl
// 摆动低点作为支撑位
ALL{
    $(5m).SwingHL(-5).is_swing_low = true,   // 5个数据点前有摆动低点
    $(5m).SwingHL(-5).swing_low > 0,         // 获取摆动低点价格
    KLINE(5m).close(0) > $(5m).SwingHL(-5).swing_low,  // 价格在支撑位上方
    KLINE(5m).low(0) <= $(5m).SwingHL(-5).swing_low * 1.01,  // 触及支撑（1%容差）
    $(5m).RSI().value < 45
} = BUY;  // 支撑位买入

// 摆动高点作为阻力位
ALL{
    $(5m).SwingHL(-5).is_swing_high = true,  // 5个数据点前有摆动高点
    $(5m).SwingHL(-5).swing_high > 0,        // 获取摆动高点价格
    KLINE(5m).close(0) < $(5m).SwingHL(-5).swing_high,  // 价格在阻力位下方
    KLINE(5m).high(0) >= $(5m).SwingHL(-5).swing_high * 0.99,  // 触及阻力（1%容差）
    $(5m).RSI().value > 55
} = SELL;  // 阻力位卖出
```

---

#### 趋势线绘制辅助

```dsl
// 连续摆动低点上升（上升趋势）
ALL{
    $(5m).SwingHL().is_swing_low = true,             // 当前摆动低点
    $(5m).SwingHL(-10).is_swing_low = true,          // 前一个摆动低点
    $(5m).SwingHL().swing_low > $(5m).SwingHL(-10).swing_low,  // 更高低点
    $(5m).MACD().signal = BUY
} = BUY;  // 上升趋势确认

// 连续摆动高点下降（下降趋势）
ALL{
    $(5m).SwingHL().is_swing_high = true,            // 当前摆动高点
    $(5m).SwingHL(-10).is_swing_high = true,         // 前一个摆动高点
    $(5m).SwingHL().swing_high < $(5m).SwingHL(-10).swing_high,  // 更低高点
    $(5m).MACD().signal = SELL
} = SELL;  // 下降趋势确认
```

---

#### 多周期摆动点确认

```dsl
// 多时间框架摆动低点重合
ALL{
    $(5m).SwingHL().is_swing_low = true,     // 5分钟摆动低点
    $(15m).SwingHL().is_swing_low = true,    // 15分钟摆动低点
    $(1h).SwingHL().is_swing_low = true,     // 1小时摆动低点
    $(5m).RSI().value < 35
} = STRONG_BUY;  // 多周期支撑位重合，强支撑

// 多时间框架摆动高点重合
ALL{
    $(5m).SwingHL().is_swing_high = true,    // 5分钟摆动高点
    $(15m).SwingHL().is_swing_high = true,   // 15分钟摆动高点
    $(1h).SwingHL().is_swing_high = true,    // 1小时摆动高点
    $(5m).RSI().value > 65
} = STRONG_SELL;  // 多周期阻力位重合，强阻力
```

## 最佳实践

### 1. 多指标组合使用

**✅ 推荐做法：**
```dsl
// 结合HHLL、MSB、SwingHL三个指标
ALL{
    $(5m).HHLL().trend_structure = UPTREND,  // 趋势确认
    $(5m).MSB().is_bullish_msb = true,       // 结构破坏
    $(5m).SwingHL().is_swing_low = true,     // 摆动低点
    $(5m).RSI().value < 50
} = BUY;
```

**❌ 避免做法：**
```dsl
// 只依赖单一指标
ALL{
    $(5m).HHLL().trend_structure = UPTREND
} = BUY;  // 过于简单
```

### 2. 多时间框架确认

**✅ 推荐做法：**
```dsl
// 长期趋势 + 短期信号
ALL{
    $(1h).HHLL().trend_structure = UPTREND,  // 长期趋势
    $(5m).MSB().is_bullish_msb = true,       // 短期信号
    $(5m).SwingHL().is_swing_low = true
} = BUY;
```

### 3. 结合成交量确认

**✅ 推荐做法：**
```dsl
// MSB + 放量突破
ALL{
    $(5m).MSB().is_bullish_msb = true,
    KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5,  // 放量
    $(5m).MACD().histogram > 0
} = BUY;  // 有效突破
```

### 4. 参数优化

**HHLL周期选择：**
- 短期交易：5-10根K线
- 中期交易：10-20根K线
- 长期交易：20-50根K线

**MSB回溯期选择：**
- 敏感（更多信号）：10-20根K线
- 平衡（推荐）：20-30根K线
- 保守（更可靠）：30-50根K线

**SwingHL周期选择：**
- 短期摆动：3-5根K线
- 中期摆动：5-10根K线（推荐）
- 长期摆动：10-20根K线

---

### 5. 假突破过滤

**✅ 推荐做法：**
```dsl
// MSB + 持续性确认
ALL{
    $(5m).MSB(-1).is_bullish_msb = true,     // 前一个数据点有MSB
    $(5m).MSB(-1).break_level > 0,           // 有突破价位
    KLINE(5m).close(0) > $(5m).MSB(-1).break_level,  // 价格仍在突破位上方
    $(5m).MACD().histogram > 0
} = BUY;  // 确认有效突破
```

## 注意事项

### ⚠️ 数据要求

1. **HHLL**: 需要至少 `2 * PERIOD` 根K线
2. **MSB**: 需要至少 `LOOKBACK + 5` 根K线
3. **SwingHL**: 需要至少 `2 * PERIOD + 1` 根K线

---

### ⚠️ 滞后性

**理解：**
- 形态指标基于历史数据计算，有一定滞后性
- SwingHL 需要等待右侧K线确认，滞后 `PERIOD` 根K线
- HHLL 需要完整周期，滞后 `PERIOD` 根K线

**建议：**
```dsl
// 结合实时指标确认
ALL{
    $(5m).SwingHL().is_swing_low = true,     // 形态确认（滞后）
    $(5m).MACD().histogram > 0,              // 实时指标（快速）
    $(5m).RSI().value < 45
} = BUY;
```

---

### ⚠️ 假信号过滤

**问题：**
- 价格噪音可能产生假的摆动点
- 小幅突破可能是假突破
- 波动市场中形态指标可能频繁变化

**建议：**
```dsl
// 1. 使用成交量确认
KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5

// 2. 结合其他技术指标
$(5m).MACD().histogram > 0
$(5m).RSI().value < 70

// 3. 多时间框架确认
$(1h).HHLL().trend_structure = UPTREND

// 4. 等待确认K线
$(5m).MSB(-1).is_bullish_msb = true  // 使用前一个数据点
```

---

### ⚠️ 参数敏感性

**问题：**
- 不同参数设置会产生完全不同的结果
- 过小的参数产生过多噪音
- 过大的参数反应过慢

**建议：**
```dsl
// 使用多参数组合
ALL{
    $(5m).SwingHL(5).is_swing_low = true,    // 短期摆动
    $(5m).SwingHL(10).is_swing_low = true,   // 中期摆动
    $(5m).HHLL(10).trend_structure = UPTREND
} = STRONG_BUY;  // 多周期确认
```

---

### ⚠️ 市场状态适应

**不同市场状态的策略：**

```dsl
// 趋势市场：使用MSB和HHLL
ALL{
    $(5m).HHLL().trend_structure = UPTREND,
    $(5m).MSB().is_bullish_msb = true
} = BUY;

// 波动市场：使用SwingHL
ALL{
    $(5m).SwingHL().is_swing_low = true,
    $(5m).BOLL().percent_b < 0.2
} = BUY;

// 盘整市场：避免使用形态指标
ALL{
    $(5m).HHLL().trend_structure = CONTRACTING
} = HOLD;  // 等待突破
```

## 总结

Prophet DSL 的形态指标为策略提供了强大的价格结构分析能力：

**核心优势：**
- ✅ 识别趋势方向和强度（HHLL）
- ✅ 检测市场结构破坏（MSB）
- ✅ 定位关键支撑阻力（SwingHL）
- ✅ 支持多时间框架分析
- ✅ 与其他技术指标完美集成

**指标选择：**
1. **HHLL** - 判断趋势方向和价格结构
   - 适用场景：趋势确认、趋势反转检测
   - 关键字段：`trend_structure`, `is_higher_high`, `is_lower_low`

2. **MSB** - 检测结构破坏和突破
   - 适用场景：趋势延续、关键突破
   - 关键字段：`msb_type`, `is_bullish_msb`, `is_bearish_msb`

3. **SwingHL** - 识别摆动点和支撑阻力
   - 适用场景：回调买入、反弹卖出、支撑阻力位
   - 关键字段：`is_swing_high`, `is_swing_low`

**使用原则：**
1. 多指标组合使用，提高可靠性
2. 多时间框架确认，避免假信号
3. 结合成交量和其他技术指标
4. 根据市场状态选择合适的指标
5. 注意参数设置，平衡敏感性和稳定性
6. 理解滞后性，结合实时指标
7. 设置合理的过滤条件

**典型应用场景：**
- 趋势交易：HHLL + MSB
- 波段交易：SwingHL + MACD
- 突破交易：MSB + 成交量
- 支撑阻力交易：SwingHL + RSI

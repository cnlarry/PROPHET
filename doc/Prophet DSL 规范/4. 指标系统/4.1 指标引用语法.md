## 1. 概述

### 1.1 什么是指标

指标（Indicator）是预先配置并计算的技术分析工具，其结果被缓存供DSL策略引用。指标需要在策略配置中预先声明参数，然后在DSL中通过特定语法引用。

### 1.2 指标 vs 数据函数

| 特性 | 指标（Indicator） | 数据函数（Function） |
|------|------------------|---------------------|
| **语法** | `$(5m).MACD(12,26,9).trend` | `HIGHEST(5m).high(20)` |
| **配置** | 需要预先配置参数 | 无需配置，参数在DSL中指定 |
| **计算时机** | 预先计算并缓存 | 使用时动态计算 |
| **灵活性** | 一个时间框架一套参数 | 同一策略可使用多个不同参数 |
| **示例** | `indicators: {"RSI": {"5m": {"PERIOD": 14}}}` | `HIGHEST(5m).high(20)` 与 `HIGHEST(5m).high(50)` 共存 |

## 2. 指标引用语法

### 2.1 标准格式

Prophet DSL 采用统一的指标引用语法：

```javascript
$(TIMEFRAME).INDICATOR(PARAMS).FIELD(offset)
```

### 2.2 语法组成

| 组成部分 | 说明 | 示例 | 必需 |
|----------|------|------|------|
| `$(TIMEFRAME)` | 时间框架，包裹在 `$()` 中 | `$(5m)`, `$(1h)`, `$(1d)` | 是 |
| `INDICATOR` | 指标名称（大写） | `MACD`, `RSI`, `EMA` | 是 |
| `(PARAMS)` | 指标参数（可选） | `(12,26,9)`, `(14)` | 否 |
| `.FIELD` | 计算结果字段 | `.value`, `.trend`, `.histogram` | 是 |
| `(offset)` | 历史值偏移量（可选） | `(-1)`, `(-5)`, `(0)` | 否 |

### 2.3 参数传递方式

指标支持三种参数传递方式：
- **位置参数**：指标默认参数，无需指定。
- **参数表**：按指标参数定义顺序传递。
- **命名参数**：使用参数名称=值的形式传递。

1. **位置参数**（DSL中直接指定）：
   ```javascript
   $(5m).MACD(12,26,9).trend  // 快速周期=12, 慢速周期=26, 信号周期=9
   ```

2. **JSON配置参数**（策略配置中声明）：
   ```
   可在策略启用前统一配置指标参数表，也可在DSL中直接指定参数。
   优先级：
   - DSL参数优先
   - 其次是JSON配置参数
   - 最后是指标默认参数
   ```
   ```javascript
   $(5m).RSI().value  // 使用JSON配置的参数
   ```

3. **混合方式**（DSL参数优先）：
   ```javascript
   $(5m).RSI(21).value  // 覆盖JSON配置，使用PERIOD=21
   ```

### 2.4 字段偏移量（历史值访问）

**偏移量语法**：
```javascript
$(TIMEFRAME).INDICATOR(PARAMS).FIELD(OFFSET)
```

**偏移量说明**：
- `OFFSET`：整数，范围 `[-100, 0]`
  - `0`：最新K线的计算结果（默认值）
  - `-1`：上一根K线的计算结果
  - `-2`：上上根K线的计算结果
  - `-100`：最多可回溯100根K线

**向后兼容性**：
以下三种写法完全等价，都返回最新K线的结果：
```javascript
$(5m).MACD().histogram          // 无偏移量（默认返回最新值）
$(5m).MACD().histogram()        // 空括号（等同于OFFSET=0）
$(5m).MACD().histogram(0)       // 显式指定OFFSET=0
```

**使用示例**：
```javascript
// 访问历史MACD柱状图值
$(5m).MACD().histogram(-1)      // 上一根K线的MACD柱状图
$(5m).MACD().histogram(-2)      // 上上根K线的MACD柱状图

// 比较当前值与历史值
$(5m).MACD().histogram > $(5m).MACD().histogram(-1)  // 当前值大于上一根
$(5m).RSI().value < $(5m).RSI().value(-1)            // RSI值下降

// 检测趋势反转
$(5m).MACD().histogram < $(5m).MACD().histogram(-1) AND \
$(5m).MACD().histogram(-1) > $(5m).MACD().histogram(-2)

// 计算变化率
($(5m).RSI().value - $(5m).RSI().value(-5)) / $(5m).RSI().value(-5) * 100  // RSI变化百分比
```

**偏移量限制与边界处理**：
- **有效范围**：`[-100, 0]`
- **超出范围**：如果偏移量超出有效范围或访问的数据不存在，将返回 `NaN`
- **建议**：在使用前检查有效性
  ```javascript
  $(5m).MACD().histogram(-1) != NaN AND $(5m).MACD().histogram(-1) > 0
  ```

### 2.5 布尔字段简写

对于布尔类型的字段，支持简写形式：

```javascript
// 简写形式
$(5m).RSI(14).overbought

// 完整形式（等价）
$(5m).RSI(14).overbought = true

// 否定形式
$(5m).RSI(14).overbought = false
NOT($(5m).RSI(14).overbought)
```

---

### 2.6 语法糖

Prophet Core Engine允许如下简写形式：

```javascript
// 省略参数
$(5m).RSI().overbought

// 如下写法作用相同：
$(5m).RSI().overbought    //当前K线是否超买
$(5m).RSI().overbought()  //等同于$(5m).RSI().overbought
$(5m).RSI().overbought(0) //等同于$(5m).RSI().overbought

// 下列写法作用相同：
$(5m).MACD().histogram > 0  //使用默认参数：12、26、9  
$(5m).MACD.histogram > 0    //使用默认参数：12、26、9  
```

## 4. 完整指标清单

### 4.1 动量指标

#### 1. APO - 绝对价格振荡器

**语法**：`$(timeframe).APO(fast, slow).field(offset)`

**参数**：
- `fast`：快速EMA周期（默认：12）
- `slow`：慢速EMA周期（默认：26）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：APO值
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**示例**：
```javascript
$(5m).APO().value > 0                           // 动量为正
$(5m).APO(10, 20).trend = BULLISH             // 上升趋势
$(5m).APO().value(-1) < $(5m).APO().value       // 当前值大于上一根
```

#### 2. CCI - 商品通道指标

**语法**：`$(timeframe).CCI(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：14）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：CCI值
- `.overbought`：是否超买（boolean）
- `.oversold`：是否超卖（boolean）
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**示例**：
```javascript
$(5m).CCI().value > 100                         // CCI超买
$(5m).CCI(20).oversold                       // CCI超卖
$(5m).CCI().trend = BEARISH                   // 下跌趋势
```

#### 3. CMO - Chande动量摆动指标

**语法**：`$(timeframe).CMO(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：14）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：CMO值（-100到100）
- `.overbought`：是否超买（boolean）
- `.oversold`：是否超卖（boolean）
- `.zero_cross`：零轴穿越（boolean）
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**示例**：
```javascript
$(5m).CMO().value > 50                          // CMO超买
$(5m).CMO().zero_cross                          // 零轴穿越
$(5m).CMO().trend = BULLISH                   // 上升趋势
```

#### 4. ElderRay - 艾尔德射线

**语法**：`$(timeframe).ElderRay(PERIOD).field(offset)`

**参数**：
- `PERIOD`：EMA周期（默认：13）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.bull_power`：多头力量
- `.bear_power`：空头力量

**示例**：
```javascript
$(5m).ElderRay().bull_power > 0                 // 多头力量为正
$(5m).ElderRay().bear_power < $(5m).ElderRay().bear_power(-1)  // 空头力量减弱
```

#### 5. FisherTransform - 费舍尔变换

**语法**：`$(timeframe).FisherTransform(PERIOD).field(offset)`

**参数**：
- `PERIOD`：计算周期（默认：10）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.value`：变换值
- `.signal`：信号值，包含"OVERBOUGHT"/"OVERSOLD"等信号
- `.crossover_type`：交叉类型（GOLDEN_CROSS/DEATH_CROSS/NONE）

**示例**：
```javascript
$(5m).FisherTransform().value > 1.0            // 超买区域
$(5m).FisherTransform().crossover_type = GOLDEN_CROSS  // 金叉
$(5m).FisherTransform().signal = "OVERBOUGHT"   // 超买信号
```

#### 6. KDJ - 随机指标

**语法**：`$(timeframe).KDJ(n, m1, m2).field(offset)`

**参数**：
- `n`：KD周期（默认：9）
- `m1`：K线平滑周期（默认：3）
- `m2`：D线平滑周期（默认：3）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.k`：K值（0-100）
- `.d`：D值（0-100）
- `.j`：J值
- `.crossover_type`：交叉类型（GOLDEN_CROSS/DEATH_CROSS/NONE）
- `.overbought`：是否超买
- `.oversold`：是否超卖

**示例**：
```javascript
$(5m).KDJ().j > 100                            // J值超买
$(5m).KDJ().crossover_type = GOLDEN_CROSS    // K线金叉D线
$(5m).KDJ().k < 20 AND $(5m).KDJ().d < 20      // 超卖区域
```

#### 7. MACD - 移动平均收敛发散指标

**语法**：`$(timeframe).MACD(fast, slow, signal).field(offset)`

**参数**：
- `fast`：快速EMA周期（默认：12）
- `slow`：慢速EMA周期（默认：26）
- `signal`：信号EMA周期（默认：9）
- `offset`：历史值偏移量（默认：0）

**字段**：
- `.macd`：MACD线值
- `.signal`：信号线值
- `.histogram`：柱状图值
- `.crossover_type`：交叉类型（GOLDEN_CROSS/DEATH_CROSS/NONE）
- `.zero_cross`：零轴穿越（boolean）
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）
- `.momentum`：动量强度（0.0-1.0）

**示例**：
```javascript
$(5m).MACD(12,26,9).crossover_type = GOLDEN_CROSS  // MACD金叉
$(5m).MACD().histogram > 0                           // 柱状图为正
$(5m).MACD().histogram > $(5m).MACD().histogram(-1)  // 柱状图增长
```

**字段**：
- `.value`：TSI值（-100到100）
- `.signal`：信号线
- `.crossover_type`：交叉类型（GOLDEN_CROSS/DEATH_CROSS/NONE）
- `.trend`：趋势方向（BULLISH/BEARISH/NEUTRAL）

**示例**：
```javascript
$(5m).TSI().value > 50                            // TSI超买
$(5m).TSI().crossover_type = GOLDEN_CROSS        // 金叉
```

## 5. 参数引用系统

在DSL中，您可以直接引用指标的参数值：

```javascript
// 引用参数
$(5m).MACD().FAST_PERIOD                    // 获取MACD的快速周期参数
$(1h).RSI().PERIOD                          // 获取RSI的周期参数

// 参数赋值
$(5m).MACD().FAST_PERIOD = 12;              // 设置MACD的快速周期
$(1h).RSI().PERIOD = 14;                    // 设置RSI的周期

// 动态阈值
$(5m).RSI(14).value < $(5m).RSI().PERIOD * 2  // RSI值小于周期的2倍
```

**命名约定**：
- 参数名必须全大写，包含下划线（如 `FAST_PERIOD`）
- 无指标前缀

## 6. 最佳实践

### 6.1 时间框架选择

- 短期交易（日内）：5m, 15m, 30m
- 中期交易：1h, 4h
- 长期交易：1d, 1w

### 6.2 多时间框架分析

```javascript
// 5分钟MACD金叉且1小时趋势看涨
$(5m).MACD().crossover_type = GOLDEN_CROSS AND $(1h).MACD().trend = BULLISH

// 5分钟RSI超卖且1小时RSI趋势向上
$(5m).RSI().oversold AND $(1h).RSI().slope > 0
```

### 6.3 偏移量最佳实践

- 避免使用过大的偏移量（建议不超过50）
- 总是检查偏移量返回值是否为NaN
- 结合多个偏移量使用以确认趋势

```javascript
// 确认MACD柱状图持续上升
$(5m).MACD().histogram > $(5m).MACD().histogram(-1) AND \
$(5m).MACD().histogram(-1) > $(5m).MACD().histogram(-2) AND \
$(5m).MACD().histogram(-2) > $(5m).MACD().histogram(-3)
```

### 6.4 指标组合

- 动量指标 + 趋势指标：确认趋势强度
- 波动率指标 + 价格指标：确定入场时机
- 成交量指标 + 价格指标：确认量价配合

## 7. 迁移指南

### 7.1 从旧语法迁移

**旧语法**：
```javascript
$.MACD(5m).trend
$.RSI(1h).value
```

**新语法**：
```javascript
$(5m).MACD().trend
$(1h).RSI().value
```

### 7.2 常见错误

1. **错误**：使用旧的指标前缀
   ```javascript
   // 错误
   $.MACD(5m).histogram
   
   // 正确
   $(5m).MACD().histogram
   ```

2. **错误**：参数位置不正确
   ```javascript
   // 错误
   $(5m).RSI(overbought=70, oversold=30)
   
   // 正确
   $(5m).RSI(14)
   ```

3. **错误**：偏移量使用不当
   ```javascript
   // 错误
   $(5m).MACD().histogram(-101)  // 超出范围
   
   // 正确
   $(5m).MACD().histogram(-100)
   ```

## 概述

动量指标用于衡量价格变化的速度和强度，帮助识别市场的超买超卖状态和潜在的趋势反转点。

**指标特点：**
- ✅ 基于价格变化速度计算
- ✅ 识别超买超卖区域
- ✅ 检测背离信号
- ✅ 可用于趋势确认

## RSI - 相对强弱指数

相对强弱指数衡量价格变动的相对强度，是最常用的动量指标之一。

### 语法
```javascript
$(timeframe).RSI([PERIOD]).value
$(timeframe).RSI([PERIOD]).level
```

### 参数
- `timeframe`: 时间周期（如 "5m", "1h"）
- `PERIOD`: 计算周期（可选，默认14）

### 返回值
- `.value`: RSI数值（0-100）
- `.level`: RSI级别（OVERBOUGHT/OVERSOLD/NEUTRAL）

### 示例
```javascript
// 计算14周期RSI
rsi = $(5m).RSI().value

// 获取RSI超买超卖状态
rsi_overbought = $(5m).RSI().overbought
rsi_oversold = $(5m).RSI().oversold

// 超买超卖判断
ALL{
  $(5m).RSI().value > 70;
} = OVERBOUGHT;
ALL{
  $(5m).RSI().value < 30;
} = OVERSOLD;
ALL{
  $(5m).RSI().value >= 30;
  $(5m).RSI().value <= 70;
} = NEUTRAL;

// RSI背离检测
current_rsi = $(5m).RSI().value
current_price = KLINE(5m).close()
previous_rsi = $(5m).RSI().value(5)
previous_price = KLINE(5m).close(5)

ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  $(5m).RSI().value < $(5m).RSI().value(5);
} = SELL;
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(5);
  $(5m).RSI().value > $(5m).RSI().value(5);
} = BUY;
```

## MACD - 指数平滑异同移动平均线

MACD通过比较不同周期的指数移动平均线来识别趋势变化。

### 语法
```javascript
$(timeframe).MACD([FAST_PERIOD], [SLOW_PERIOD], [SIGNAL_PERIOD]).macd
$(timeframe).MACD([FAST_PERIOD], [SLOW_PERIOD], [SIGNAL_PERIOD]).signal
$(timeframe).MACD([FAST_PERIOD], [SLOW_PERIOD], [SIGNAL_PERIOD]).histogram
$(timeframe).MACD([FAST_PERIOD], [SLOW_PERIOD], [SIGNAL_PERIOD]).trend
```

### 参数
- `timeframe`: 时间周期
- `FAST_PERIOD`: 快线周期（可选，默认12）
- `SLOW_PERIOD`: 慢线周期（可选，默认26）
- `SIGNAL_PERIOD`: 信号线周期（可选，默认9）

### 返回值
- `.macd`: MACD线值
- `.signal`: 信号线值
- `.histogram`: 柱状图值
- `.trend`: 趋势方向（BULLISH/BEARISH/NEUTRAL）

### 示例
```javascript
// 计算标准MACD
macd_line = $(5m).MACD().macd
signal_line = $(5m).MACD().signal
histogram = $(5m).MACD().histogram
trend = $(5m).MACD().trend

// MACD金叉死叉
ALL{
  $(5m).MACD().macd > $(5m).MACD().signal;
  $(5m).MACD().macd(1) <= $(5m).MACD().signal(1);
} = BUY;
ALL{
  $(5m).MACD().macd < $(5m).MACD().signal;
  $(5m).MACD().macd(1) >= $(5m).MACD().signal(1);
} = SELL;

// 柱状图变化
ALL{
  $(5m).MACD().histogram > 0;
  $(5m).MACD().histogram > $(5m).MACD().histogram(1);
} = BUY;
ALL{
  $(5m).MACD().histogram < 0;
  $(5m).MACD().histogram < $(5m).MACD().histogram(1);
} = SELL;
```

## ROC - 变化率

变化率衡量价格相对于指定周期前的变化百分比。

### 语法
```javascript
$(timeframe).ROC([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认10）

### 返回值
- `.value`: 变化率（百分比）

### 示例
```javascript
// 计算10周期ROC
roc = $(5m).ROC().value

// 趋势强度判断
ALL{
  $(5m).ROC().value > 5;
} = BUY;
ALL{
  $(5m).ROC().value < -5;
} = SELL;
ALL{
  $(5m).ROC().value >= -2;
  $(5m).ROC().value <= 2;
} = HOLD;

// 动量衰减检测
ALL{
  $(5m).ROC().value > 0;
  $(5m).ROC().value < $(5m).ROC().value(1);
} = HOLD;
ALL{
  $(5m).ROC().value < 0;
  $(5m).ROC().value > $(5m).ROC().value(1);
} = HOLD;
```

## Momentum - 动量

动量指标衡量价格相对于指定周期前的绝对变化量。

### 语法
```javascript
$(timeframe).Momentum([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认10）

### 返回值
- `.value`: 动量值

### 示例
```javascript
// 计算10周期动量
momentum = $(5m).Momentum().value

// 趋势判断
ALL{
  $(5m).Momentum().value > 0;
} = BUY;
ALL{
  $(5m).Momentum().value < 0;
} = SELL;

// 零线交叉
ALL{
  $(5m).Momentum().value > 0;
  $(5m).Momentum().value(1) <= 0;
} = BUY;
ALL{
  $(5m).Momentum().value < 0;
  $(5m).Momentum().value(1) >= 0;
} = SELL;
```

## CCI - 商品通道指数

商品通道指数衡量价格偏离其统计平均值的程度。

### 语法
```javascript
$(timeframe).CCI([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: CCI值

### 示例
```javascript
// 计算20周期CCI
cci = $(5m).CCI().value

// 超买超卖判断
ALL{
  $(5m).CCI().value > 100;
} = SELL;
ALL{
  $(5m).CCI().value < -100;
} = BUY;
ALL{
  $(5m).CCI().value >= -100;
  $(5m).CCI().value <= 100;
} = HOLD;

// CCI背离
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  $(5m).CCI().value < $(5m).CCI().value(5);
} = SELL;
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(5);
  $(5m).CCI().value > $(5m).CCI().value(5);
} = BUY;
```

## 威廉指标

威廉指标衡量当前收盘价在指定周期内的相对位置。

### 语法
```javascript
$(timeframe).WILLR([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认14）

### 返回值
- `.value`: 威廉指标值（0到-100）

### 示例
```javascript
// 计算14周期威廉指标
willr = $(5m).WILLR().value

// 超买超卖判断
ALL{
  $(5m).WILLR().value > -20;
} = SELL;
ALL{
  $(5m).WILLR().value < -80;
} = BUY;
ALL{
  $(5m).WILLR().value >= -80;
  $(5m).WILLR().value <= -20;
} = HOLD;
```

## 随机指标

随机指标比较收盘价与指定周期内的价格范围。

### 语法
```javascript
$(timeframe).STOCH([K_PERIOD], [D_PERIOD]).k
$(timeframe).STOCH([K_PERIOD], [D_PERIOD]).d
```

### 参数
- `timeframe`: 时间周期
- `K_PERIOD`: %K线周期（可选，默认14）
- `D_PERIOD`: %D线周期（可选，默认3）

### 返回值
- `.k`: %K值（0-100）
- `.d`: %D值（0-100）

### 示例
```javascript
// 计算随机指标
stoch_k = $(5m).STOCH().k
stoch_d = $(5m).STOCH().d

// 超买超卖判断
ALL{
  $(5m).STOCH().k > 80;
  $(5m).STOCH().d > 80;
} = SELL;
ALL{
  $(5m).STOCH().k < 20;
  $(5m).STOCH().d < 20;
} = BUY;

// 金叉死叉
ALL{
  $(5m).STOCH().k > $(5m).STOCH().d;
  $(5m).STOCH().k(1) <= $(5m).STOCH().d(1);
} = BUY;
ALL{
  $(5m).STOCH().k < $(5m).STOCH().d;
  $(5m).STOCH().k(1) >= $(5m).STOCH().d(1);
} = SELL;
```

## 使用示例

### 示例1：多动量指标确认策略

```javascript
// RSI指标
rsi = $(5m).RSI().value

// MACD指标
macd_histogram = $(5m).MACD().histogram

// ROC指标
roc = $(5m).ROC().value

// 多指标买入信号
ALL{
  $(5m).RSI().value < 30;
  $(5m).MACD().histogram > 0;
  $(5m).ROC().value > 0;
} = BUY;

// 多指标卖出信号
ALL{
  $(5m).RSI().value > 70;
  $(5m).MACD().histogram < 0;
  $(5m).ROC().value < 0;
} = SELL;
```

---

### 示例2：背离交易策略

```javascript
// 价格和RSI背离检测
current_price = KLINE(5m).close()
current_rsi = $(5m).RSI().value
previous_price = KLINE(5m).close(10)
previous_rsi = $(5m).RSI().value(10)

// 牛市背离
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(5);
  $(5m).RSI().value > $(5m).RSI().value(5);
} = BUY;

// 熊市背离
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  $(5m).RSI().value < $(5m).RSI().value(5);
} = SELL;
```

---

### 示例3：动量突破策略

```javascript
// MACD柱状图突破
histogram = $(5m).MACD().histogram
histogram_ma = AVERAGE(5m).MACD.histogram(9)

// 突破信号
ALL{
  $(5m).MACD().histogram > AVERAGE(5m).MACD().histogram(20);
  $(5m).MACD().histogram > 0;
} = BUY;
ALL{
  $(5m).MACD().histogram < AVERAGE(5m).MACD().histogram(20);
  $(5m).MACD().histogram < 0;
} = SELL;
```

## 最佳实践

### 1. 指标组合使用

```javascript
// 不要单独依赖单一指标
rsi = $(5m).RSI().value
macd = $(5m).MACD().histogram

// 组合信号更可靠
ALL{
  $(5m).RSI().value < 30;
  $(5m).MACD().histogram > 0;
} = BUY;
```

---

### 2. 参数优化

```javascript
// 不同市场使用不同参数（使用自定义函数）
getRsiValue(isCrypto: Boolean): Double {
  if (isCrypto) {
    return $(5m).RSI(9).value;  // 加密货币波动大，使用短周期
  } else {
    return $(5m).RSI(14).value;  // 传统市场使用标准周期
  }
}

// 使用参数
@rsi_value: Double = getRsiValue(IS_CRYPTO());
ALL{
  @rsi_value < 30;
} = BUY;
```

---

### 3. 背离确认

```javascript
// 背离需要多重确认
price_divergence = DETECT_PRICE_RSI_DIVERGENCE()
volume_confirmation = KLINE(5m).volume() > AVERAGE(5m).volume(20)
time_confirmation = CONSECUTIVE(5m).close(3).stable()

ALL{
  DETECT_PRICE_RSI_DIVERGENCE();
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20);
  CONSECUTIVE(5m).close(3).stable();
} = BUY;
```

---

### 4. 趋势过滤

```javascript
// 在趋势市场中使用动量指标
// 只在趋势市场发出信号
ALL{
  HT(5m).trendmode == 1;
  $(5m).RSI().value < 30;
} = BUY;
```

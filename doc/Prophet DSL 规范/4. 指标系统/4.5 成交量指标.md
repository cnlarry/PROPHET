## 概述

成交量指标用于分析市场参与度、资金流动和交易活跃度，是确认价格趋势的重要工具。

**指标特点：**
- ✅ 衡量市场参与度
- ✅ 确认价格趋势
- ✅ 识别资金流向
- ✅ 预测价格走势

---

## OBV - 能量潮

OBV通过累积成交量来衡量资金流入流出情况。

### 语法
```javascript
$(timeframe).OBV().value
$(timeframe).OBV().trend
```

### 参数
- `timeframe`: 时间周期

### 返回值
- `.value`: OBV值
- `.trend`: OBV趋势（BULLISH/BEARISH/NEUTRAL）

### 示例
```javascript
// 计算OBV
obv = $(5m).OBV().value

// OBV趋势
obv_trend = $(5m).OBV().trend

// 价格与OBV背离
current_price = KLINE(5m).close()
current_obv = $(5m).OBV().value
previous_price = KLINE(5m).close(10)
previous_obv = $(5m).OBV().value(10)

// 牛市背离：价格创新低但OBV创新高
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(5);
  $(5m).OBV().value > $(5m).OBV().value(5);
} = BUY;

// 熊市背离：价格创新高但OBV创新低
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(5);
  $(5m).OBV().value < $(5m).OBV().value(5);
} = SELL;

// OBV信号确认
ALL{
  $(5m).OBV().trend == BULLISH;
  KLINE(5m).close(0) > AVERAGE(5m).close(20);
} = BUY;
```

## 成交量比率

成交量比率衡量当前成交量相对于历史平均水平的关系。

### 语法
```javascript
$(timeframe).VOL_RATIO([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: 成交量比率

### 示例
```javascript
// 计算成交量比率
vol_ratio = $(5m).VOL_RATIO(20).value

// 成交量状态判断
ALL{
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) > 1.5;
} = HOLD;
ALL{
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) < 0.5;
} = HOLD;
ALL{
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) >= 0.5;
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) <= 1.5;
} = HOLD;

// 放量突破
ALL{
  KLINE(5m).close(0) > HIGHEST(5m).high(20);
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) > 2;
} = BUY;

// 缩量整理
ALL{
  KLINE(5m).volume(0) / AVERAGE(5m).volume(20) < 0.3;
} = HOLD;
```

## 资金流量指标

资金流量指标结合价格和成交量来衡量资金流入流出。

### 语法
```javascript
$(timeframe).MFI([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认14）

### 返回值
- `.value`: MFI值（0-100）

### 示例
```javascript
// 计算MFI
mfi = $(5m).MFI(14).value

// 超买超卖判断
ALL{
  $(5m).MFI().value > 80;
} = SELL;
ALL{
  $(5m).MFI().value < 20;
} = BUY;

// MFI背离
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(10);
  $(5m).MFI().value < $(5m).MFI().value(10);
} = SELL;
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(10);
  $(5m).MFI().value > $(5m).MFI().value(10);
} = BUY;

// 资金流量确认
ALL{
  $(5m).MFI().value > 50;
} = BUY;
ALL{
  $(5m).MFI().value < 50;
} = SELL;
```

## 成交量移动平均

成交量移动平均平滑成交量数据，识别成交量趋势。

### 语法
```javascript
$(timeframe).VOL_MA([PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

### 返回值
- `.value`: 成交量移动平均值

### 示例
```javascript
// 计算成交量移动平均
vol_ma = $(5m).VOL_MA(20).value

// 成交量相对于移动平均
ALL{
  KLINE(5m).volume(0) > $(5m).VOL_MA(20).value * 1.5;
} = HOLD;
ALL{
  KLINE(5m).volume(0) < $(5m).VOL_MA(20).value * 0.5;
} = HOLD;

// 成交量趋势
ALL{
  $(5m).VOL_MA(20).value > $(5m).VOL_MA(20).value(1);
} = BUY;
ALL{
  $(5m).VOL_MA(20).value < $(5m).VOL_MA(20).value(1);
} = SELL;
```

## 成交量震荡指标

成交量震荡指标衡量成交量的动量变化。

### 语法
```javascript
$(timeframe).VOL_OSC([FAST_PERIOD], [SLOW_PERIOD]).value
```

### 参数
- `timeframe`: 时间周期
- `FAST_PERIOD`: 快线周期（可选，默认12）
- `SLOW_PERIOD`: 慢线周期（可选，默认26）

### 返回值
- `.value`: 成交量震荡值

### 示例
```javascript
// 计算成交量震荡指标
vol_osc = $(5m).VOL_OSC(12, 26).value

// 震荡指标信号
ALL{
  $(5m).VOL_OSC(12, 26).value > 0;
  $(5m).VOL_OSC(12, 26).value(1) <= 0;
} = BUY;
ALL{
  $(5m).VOL_OSC(12, 26).value < 0;
  $(5m).VOL_OSC(12, 26).value(1) >= 0;
} = SELL;

// 零线交叉
ALL{
  $(5m).VOL_OSC(12, 26).value > 0;
} = BUY;
ALL{
  $(5m).VOL_OSC(12, 26).value < 0;
} = SELL;
```

## 使用示例

### 示例1：量价确认策略

```javascript
// 价格突破确认
current_price = KLINE(5m).close()
previous_high = HIGHEST(5m).high(20)
price_breakout = current_price > previous_high

// 成交量确认
vol_ratio = $(5m).VOL_RATIO(20).value
volume_confirmation = vol_ratio > 1.5

// 综合信号
ALL{
  KLINE(5m).close(0) > HIGHEST(5m).high(20);
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5;
} = BUY;
```

---

### 示例2：资金流量趋势策略

```javascript
// MFI趋势判断
mfi = $(5m).MFI(14).value
mfi_ma = AVERAGE(5m).MFI.value(10)

// 资金流入流出
ALL{
  $(5m).MFI(14).value > AVERAGE(5m).MFI.value(10);
  $(5m).MFI(14).value > 50;
} = BUY;
ALL{
  $(5m).MFI(14).value < AVERAGE(5m).MFI.value(10);
  $(5m).MFI(14).value < 50;
} = SELL;

// 结合价格趋势
ALL{
  $(5m).MFI(14).value > AVERAGE(5m).MFI.value(10);
  $(5m).MFI(14).value > 50;
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
} = BUY;
ALL{
  $(5m).MFI(14).value < AVERAGE(5m).MFI.value(10);
  $(5m).MFI(14).value < 50;
  AVERAGE(5m).close(20) <= AVERAGE(5m).close(50);
} = SELL;
```

### 示例3：成交量背离交易

```javascript
// OBV背离检测
current_price = KLINE(5m).close()
current_obv = $(5m).OBV().value
previous_price = KLINE(5m).close(15)
previous_obv = $(5m).OBV().value(15)

// 牛市背离
bullish_divergence = current_price < previous_price AND current_obv > previous_obv

// 熊市背离
bearish_divergence = current_price > previous_price AND current_obv < previous_obv

// 背离确认
volume_trend = $(5m).VOL_MA(20).value > $(5m).VOL_MA(20).value(5)

ALL{
  DETECT_PRICE_VOLUME_DIVERGENCE();
  $(5m).VOL_MA(20).value > $(5m).VOL_MA(20).value(5);
} = BUY;
ALL{
  DETECT_PRICE_VOLUME_DIVERGENCE();
  $(5m).VOL_MA(20).value < $(5m).VOL_MA(20).value(5);
} = SELL;
```

## 最佳实践

### 1. 量价结合分析

```javascript
// 价格上涨+成交量放大=健康上涨
price_up = KLINE(5m).close() > KLINE(5m).close(1)
volume_up = KLINE(5m).volume() > AVERAGE(5m).volume(20)

ALL{
  KLINE(5m).close(0) > KLINE(5m).close(1);
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20);
} = BUY;

// 价格上涨+成交量萎缩=上涨乏力
ALL{
  KLINE(5m).close(0) > KLINE(5m).close(1);
  NOT(KLINE(5m).volume(0) > AVERAGE(5m).volume(20));
} = HOLD;

// 价格下跌+成交量放大=恐慌性抛售
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(1);
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20);
} = SELL;

// 价格下跌+成交量萎缩=抛售衰竭
ALL{
  KLINE(5m).close(0) < KLINE(5m).close(1);
  NOT(KLINE(5m).volume(0) > AVERAGE(5m).volume(20));
} = HOLD;
```

---

### 2. 成交量趋势过滤

```javascript
// 只在成交量上升趋势中交易（高成交量市场策略）
ALL{
  AVERAGE(5m).volume(10) > AVERAGE(5m).volume(50);
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
} = BUY;

// 低成交量市场策略
ALL{
  AVERAGE(5m).volume(10) <= AVERAGE(5m).volume(50);
  $(5m).RSI().value < 30;
} = BUY;
```

---

### 3. 成交量异常检测

```javascript
// 检测异常成交量
current_volume = KLINE(5m).volume()
avg_volume = AVERAGE(5m).volume(50)
volume_std = STD(5m).volume(50)

// 极端成交量
ALL{
  KLINE(5m).volume(0) > AVERAGE(5m).volume(100) + 3 * STD(5m).volume(100);
} = HOLD;
ALL{
  KLINE(5m).volume(0) < AVERAGE(5m).volume(100) - 2 * STD(5m).volume(100);
} = HOLD;
```

---

### 4. 多时间框架成交量分析

```javascript
// 长期成交量趋势
long_term_volume = AVERAGE(1h).volume(50) > AVERAGE(1h).volume(200)

// 短期成交量信号
short_term_volume = KLINE(5m).volume() > AVERAGE(5m).volume(20) * 2

// 多时间框架确认
ALL{
  AVERAGE(1h).volume(50) > AVERAGE(1h).volume(200);
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 2;
} = BUY;
```

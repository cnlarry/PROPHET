## 概述

趋势指标用于识别市场的趋势方向和强度，帮助交易者跟随趋势进行交易。

**指标特点：**
- ✅ 识别趋势方向
- ✅ 衡量趋势强度
- ✅ 提供趋势跟随信号
- ✅ 可用于支撑阻力识别

---

## 移动平均线

移动平均线是最基础的趋势指标，通过平滑价格数据来识别趋势方向。

### SMA - 简单移动平均线

简单移动平均线对所有价格赋予相等权重。

#### 语法
```javascript
$(timeframe).SMA([PERIOD]).value
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

#### 返回值
- `.value`: SMA值

#### 示例
```javascript
// 计算20周期SMA
sma_20 = $(5m).SMA(20).value

// 价格相对于SMA位置
ALL{
  KLINE(5m).close(0) > $(5m).SMA(20).value;
} = BUY;
ALL{
  KLINE(5m).close(0) < $(5m).SMA(20).value;
} = SELL;

// 多均线系统
ALL{
  $(5m).SMA(10).value > $(5m).SMA(20).value;
  $(5m).SMA(20).value > $(5m).SMA(50).value;
} = BUY;
ALL{
  $(5m).SMA(10).value < $(5m).SMA(20).value;
  $(5m).SMA(20).value < $(5m).SMA(50).value;
} = SELL;
```

---

### EMA - 指数移动平均线

指数移动平均线对近期价格赋予更高权重。

#### 语法
```javascript
$(timeframe).EMA([PERIOD]).value
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认12）

#### 返回值
- `.value`: EMA值

#### 示例
```javascript
// 计算12周期EMA
ema_12 = $(5m).EMA(12).value

// EMA交叉策略
ALL{
  $(5m).EMA(12).value > $(5m).EMA(26).value;
  $(5m).EMA(12).value(1) <= $(5m).EMA(26).value(1);
} = BUY;
ALL{
  $(5m).EMA(12).value < $(5m).EMA(26).value;
  $(5m).EMA(12).value(1) >= $(5m).EMA(26).value(1);
} = SELL;
```

---

### WMA - 加权移动平均线

加权移动平均线对近期价格赋予递增权重。

#### 语法
```javascript
$(timeframe).WMA([PERIOD]).value
```

#### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）

#### 返回值
- `.value`: WMA值

#### 示例
```javascript
// 计算20周期WMA
wma_20 = $(5m).WMA(20).value

// 比较不同平均线
sma_20 = $(5m).SMA(20).value
ema_20 = $(5m).EMA(20).value
wma_20 = $(5m).WMA(20).value

// WMA最敏感
ALL{
  $(5m).WMA(20).value > $(5m).EMA(20).value;
  $(5m).EMA(20).value > $(5m).SMA(20).value;
} = BUY;
```

## 布林带

布林带通过移动平均线和标准差构建价格通道。

### 语法
```javascript
$(timeframe).BOLL([PERIOD], [std_multiplier]).upper
$(timeframe).BOLL([PERIOD], [std_multiplier]).middle
$(timeframe).BOLL([PERIOD], [std_multiplier]).lower
$(timeframe).BOLL([PERIOD], [std_multiplier]).bandwidth
$(timeframe).BOLL([PERIOD], [std_multiplier]).percent_b
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认20）
- `std_multiplier`: 标准差倍数（可选，默认2.0）

### 返回值
- `.upper`: 上轨
- `.middle`: 中轨（SMA）
- `.lower`: 下轨
- `.bandwidth`: 带宽
- `.percent_b`: %B值

### 示例
```javascript
// 计算标准布林带
upper_band = $(5m).BOLL().upper
middle_band = $(5m).BOLL().middle
lower_band = $(5m).BOLL().lower

// 价格位置判断
ALL{
  KLINE(5m).close(0) > $(5m).BOLL().upper;
} = SELL;
ALL{
  KLINE(5m).close(0) < $(5m).BOLL().lower;
} = BUY;
ALL{
  KLINE(5m).close(0) > $(5m).BOLL().lower;
  KLINE(5m).close(0) < $(5m).BOLL().upper;
} = HOLD;

// 布林带收缩扩张
ALL{
  $(5m).BOLL().bandwidth < AVERAGE(5m).BOLL.bandwidth(50) * 0.5;
} = HOLD;
ALL{
  $(5m).BOLL().bandwidth > AVERAGE(5m).BOLL.bandwidth(50) * 1.5;
} = BUY;
```

## MACD

MACD虽然是动量指标，但也广泛用于趋势识别。

### 语法
```javascript
$(timeframe).MACD([FAST_PERIOD], [SLOW_PERIOD], [SIGNAL_PERIOD]).trend
```

### 参数
- `timeframe`: 时间周期
- `FAST_PERIOD`: 快线周期（可选，默认12）
- `SLOW_PERIOD`: 慢线周期（可选，默认26）
- `SIGNAL_PERIOD`: 信号线周期（可选，默认9）

### 返回值
- `.trend`: 趋势方向（BULLISH/BEARISH/NEUTRAL）

### 示例
```javascript
// MACD趋势判断
macd_trend = $(5m).MACD().trend

ALL{
  $(5m).MACD().trend == BULLISH;
} = BUY;
ALL{
  $(5m).MACD().trend == BEARISH;
} = SELL;
ALL{
  $(5m).MACD().trend == NEUTRAL;
} = HOLD;
```

## ADX - 平均趋向指数

ADX衡量趋势的强度，而不指示方向。

### 语法
```javascript
$(timeframe).ADX([PERIOD]).value
$(timeframe).ADX([PERIOD]).di_plus
$(timeframe).ADX([PERIOD]).di_minus
$(timeframe).ADX([PERIOD]).trend
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: 计算周期（可选，默认14）

### 返回值
- `.value`: ADX值（趋势强度）
- `.di_plus`: +DI值（上升动力）
- `.di_minus`: -DI值（下降动力）
- `.trend`: 趋势方向（BULLISH/BEARISH/NEUTRAL）

### 示例
```javascript
// ADX趋势强度
adx = $(5m).ADX().value
di_plus = $(5m).ADX().di_plus
di_minus = $(5m).ADX().di_minus
trend = $(5m).ADX().trend

// 趋势强度判断
ALL{
  $(5m).ADX().value > 25;
} = BUY;
ALL{
  $(5m).ADX().value < 20;
} = HOLD;

// 趋势方向
ALL{
  $(5m).ADX().di_plus > $(5m).ADX().di_minus;
} = BUY;
ALL{
  $(5m).ADX().di_minus > $(5m).ADX().di_plus;
} = SELL;

// 综合趋势信号
ALL{
  $(5m).ADX().value > 25;
  $(5m).ADX().trend == BULLISH;
} = BUY;
ALL{
  $(5m).ADX().value > 25;
  $(5m).ADX().trend == BEARISH;
} = SELL;
```

## 抛物线转向

抛物线转向用于识别趋势反转点。

### 语法
```javascript
$(timeframe).SAR([acceleration], [maximum]).value
$(timeframe).SAR([acceleration], [maximum]).position
```

### 参数
- `timeframe`: 时间周期
- `acceleration`: 加速因子（可选，默认0.02）
- `maximum`: 最大加速因子（可选，默认0.2）

### 返回值
- `.value`: SAR值
- `.position`: 位置（ABOVE/BELOW）

### 示例
```javascript
// SAR趋势判断
sar_value = $(5m).SAR().value
sar_position = $(5m).SAR().position
current_price = KLINE(5m).close()

// 趋势方向
ALL{
  $(5m).SAR().position == BELOW;
  KLINE(5m).close(0) > $(5m).SAR().value;
} = BUY;
ALL{
  $(5m).SAR().position == ABOVE;
  KLINE(5m).close(0) < $(5m).SAR().value;
} = SELL;

// SAR反转信号
ALL{
  $(5m).SAR().position != $(5m).SAR().position(1);
} = HOLD;
```

## Ichimoku - 一目均衡表

一目均衡表提供多维度的趋势分析。

### 语法
```javascript
$(timeframe).ICHIMOKU([tenkan_period], [kijun_period], [senkou_b_period]).tenkan
$(timeframe).ICHIMOKU([tenkan_period], [kijun_period], [senkou_b_period]).kijun
$(timeframe).ICHIMOKU([tenkan_period], [kijun_period], [senkou_b_period]).span_a
$(timeframe).ICHIMOKU([tenkan_period], [kijun_period], [senkou_b_period]).span_b
$(timeframe).ICHIMOKU([tenkan_period], [kijun_period], [senkou_b_period]).cloud_status
```

### 参数
- `timeframe`: 时间周期
- `tenkan_period`: 转换线周期（可选，默认9）
- `kijun_period`: 基准线周期（可选，默认26）
- `senkou_b_period`: 先行.span_b周期（可选，默认52）

### 返回值
- `.tenkan`: 转换线
- `.kijun`: 基准线
- `.span_a`: 先行.span_a
- `.span_b`: 先行.span_b
- `.cloud_status`: 云层状态（ABOVE_CLOUD/BELOW_CLOUD/IN_CLOUD）

### 示例
```javascript
// 一目均衡表组件
tenkan = $(5m).ICHIMOKU().tenkan
kijun = $(5m).ICHIMOKU().kijun
span_a = $(5m).ICHIMOKU().span_a
span_b = $(5m).ICHIMOKU().span_b
cloud_status = $(5m).ICHIMOKU().cloud_status

// 转换线与基准线交叉
ALL{
  $(5m).ICHIMOKU().tenkan > $(5m).ICHIMOKU().kijun;
  $(5m).ICHIMOKU().tenkan(1) <= $(5m).ICHIMOKU().kijun(1);
} = BUY;

// 云层状态
ALL{
  $(5m).ICHIMOKU().cloud_status == ABOVE_CLOUD;
} = BUY;
ALL{
  $(5m).ICHIMOKU().cloud_status == BELOW_CLOUD;
} = SELL;
ALL{
  $(5m).ICHIMOKU().cloud_status == IN_CLOUD;
} = HOLD;
```

## SuperTrend - 超级趋势

超级趋势是一种趋势跟踪指标，结合了ATR和价格动作。

### 语法
```javascript
$(timeframe).SUPERTREND([PERIOD], [multiplier]).value
$(timeframe).SUPERTREND([PERIOD], [multiplier]).trend
```

### 参数
- `timeframe`: 时间周期
- `PERIOD`: ATR周期（可选，默认10）
- `multiplier`: ATR乘数（可选，默认3.0）

### 返回值
- `.value`: SuperTrend值
- `.trend`: 趋势方向（1/-1）

### 示例
```javascript
// 超级趋势
supertrend_value = $(5m).SUPERTREND().value
supertrend_trend = $(5m).SUPERTREND().trend
current_price = KLINE(5m).close()

// 趋势方向
ALL{
  $(5m).SUPERTREND().trend == 1;
  KLINE(5m).close(0) > $(5m).SUPERTREND().value;
} = BUY;
ALL{
  $(5m).SUPERTREND().trend == -1;
  KLINE(5m).close(0) < $(5m).SUPERTREND().value;
} = SELL;

// SuperTrend信号
ALL{
  $(5m).SUPERTREND().trend != $(5m).SUPERTREND().trend(1);
} = HOLD;
```

## 使用示例

### 示例1：多趋势指标确认

```javascript
// 移动平均线趋势
sma_trend = AVERAGE(5m).close(20) > AVERAGE(5m).close(50)

// MACD趋势
macd_trend = $(5m).MACD().trend == BULLISH

// ADX趋势强度
adx_strength = $(5m).ADX().value > 25

// 综合趋势确认
ALL{
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
  $(5m).MACD().trend == BULLISH;
  $(5m).ADX().value > 25;
} = BUY;
```

---

### 示例2：趋势反转检测

```javascript
// SAR反转
sar_reversal = $(5m).SAR().position != $(5m).SAR().position(1)

// SuperTrend反转
supertrend_reversal = $(5m).SUPERTREND().trend != $(5m).SUPERTREND().trend(1)

// 综合反转信号
ALL{
  $(5m).SAR().position != $(5m).SAR().position(1);
  $(5m).SUPERTREND().trend != $(5m).SUPERTREND().trend(1);
} = BUY;
```

---

### 示例3：趋势强度分级

```javascript
// ADX强度分级（使用自定义函数）
calcTrendStrength(adx: Double): String {
  if (adx < 20) {
    return "NO_TREND";
  } else if (adx < 25) {
    return "WEAK_TREND";
  } else if (adx < 30) {
    return "MODERATE_TREND";
  } else {
    return "STRONG_TREND";
  }
}

// 或者使用信号函数判断
ALL{
  $(5m).ADX().value < 20;
} = HOLD;
ALL{
  $(5m).ADX().value >= 20;
  $(5m).ADX().value < 25;
} = HOLD;
ALL{
  $(5m).ADX().value >= 25;
  $(5m).ADX().value < 30;
} = HOLD;
ALL{
  $(5m).ADX().value >= 30;
} = HOLD;
```

## 最佳实践

### 1. 多时间框架分析

```javascript
// 长期趋势
long_term_trend = AVERAGE(1h).close(50) > AVERAGE(1h).close(200)

// 短期趋势
short_term_trend = AVERAGE(5m).close(20) > AVERAGE(5m).close(50)

// 趋势一致性
ALL{
  AVERAGE(1h).close(50) > AVERAGE(1h).close(200);
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
} = BUY;
```

---

### 2. 趋势过滤

```javascript
// 只在强趋势中交易（使用自定义函数）
shouldTradeInTrend(adx: Double): Boolean {
  return adx > 25;
}

// 趋势市场策略
ALL{
  $(5m).ADX().value > 25;
  KLINE(5m).close(0) > $(5m).EMA(20).value;
} = BUY;

// 震荡市场策略（弱趋势时）
ALL{
  $(5m).ADX().value <= 25;
  $(5m).RSI().value < 30;
} = BUY;
```

---

### 3. 动态参数调整

```javascript
// 根据波动率调整参数（使用自定义函数）
calcTrendIndicator(atr: Double): Double {
  if (atr > 10) {
    // 高波动率：使用长周期
    return AVERAGE(5m).close(50);
  } else {
    // 低波动率：使用短周期
    return AVERAGE(5m).close(20);
  }
}

// 使用动态参数
@trend_indicator: Double = calcTrendIndicator($(5m).ATR().value);
ALL{
  KLINE(5m).close(0) > @trend_indicator;
} = BUY;
```

---

### 4. 趋势确认组合

```javascript
// 价格趋势
price_trend = KLINE(5m).close() > KLINE(5m).open()

// 均线趋势
ma_trend = AVERAGE(5m).close(20) > AVERAGE(5m).close(50)

// 指标趋势
indicator_trend = $(5m).MACD().trend == BULLISH

// 三重确认
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
  AVERAGE(5m).close(20) > AVERAGE(5m).close(50);
  $(5m).MACD().trend == BULLISH;
} = BUY;
```

# Prophet DSL 类型转换

本文档介绍了 Prophet DSL 中的数据类型转换机制和相关函数。

## 自动类型转换

Prophet DSL 在大多数情况下会自动进行类型转换，以确保表达式的正确计算。

### 数值运算中的自动转换

```javascript
// 整数与浮点数运算
@result = 10 + 3.14  // 结果为 13.14 (浮点数)

// 布尔值参与数值运算
@flag = true
@value = @flag + 5    // 结果为 6 (true 被转换为 1)
```

### 布尔运算中的自动转换

```javascript
// 数值参与布尔运算
ALL{10 > 5;} = BUY;     // 10 > 5 为 true，条件成立

// 零值被视为 false
ALL{0;} = SELL;         // 0 被视为 false，条件不成立
```

## 显式类型转换函数

### TO_NUMBER 函数

将其他类型转换为数值：

```javascript
// 布尔值转数值
@bool_value = true
@num_value = TO_NUMBER(@bool_value)  // 结果为 1

// 字符串转数值（如果可能）
@str_value = "3.14"
@num_value = TO_NUMBER(@str_value)   // 结果为 3.14
```

### TO_BOOLEAN 函数

将其他类型转换为布尔值：

```javascript
// 数值转布尔值
@num_value = 10
@bool_value = TO_BOOLEAN(@num_value)  // 结果为 true

// 零值转布尔值
@zero_value = 0
@bool_value = TO_BOOLEAN(@zero_value) // 结果为 false
```

### TO_STRING 函数

将其他类型转换为字符串：

```javascript
// 数值转字符串
@num_value = 3.14
@str_value = TO_STRING(@num_value)    // 结果为 "3.14"

// 布尔值转字符串
@bool_value = true
@str_value = TO_STRING(@bool_value)   // 结果为 "true"
```

## 类型检查函数

### IS_NUMBER 函数

检查值是否为数值类型：

```javascript
@value1 = 3.14
@value2 = "hello"

ALL{IS_NUMBER(@value1);} = BUY;   // 条件成立
ALL{IS_NUMBER(@value2);} = SELL;  // 条件不成立
```

### IS_BOOLEAN 函数

检查值是否为布尔类型：

```javascript
@value1 = true
@value2 = 1

ALL{IS_BOOLEAN(@value1);} = BUY;   // 条件成立
ALL{IS_BOOLEAN(@value2);} = SELL;  // 条件不成立
```

### IS_STRING 函数

检查值是否为字符串类型：

```javascript
@value1 = "hello"
@value2 = 3.14

ALL{IS_STRING(@value1);} = BUY;    // 条件成立
ALL{IS_STRING(@value2);} = SELL;   // 条件不成立
```

## 转换规则

### 数值到布尔值

- 非零数值转换为 `true`
- 零值转换为 `false`

### 布尔值到数值

- `true` 转换为 `1`
- `false` 转换为 `0`

### 字符串到数值

- 有效的数字字符串可以转换为对应数值
- 无效的字符串转换结果为 `NaN`（Not a Number）

## 错误处理

当类型转换失败时，Prophet DSL 会采取以下措施：

### 无效转换

```javascript
// 尝试将非数字字符串转换为数值
@invalid_str = "hello"
@result = TO_NUMBER(@invalid_str)  // 结果为 NaN

// 在条件判断中使用 NaN
ALL{@result > 0;} = BUY;              // 条件不成立（NaN 与任何值比较都为 false）
```

### 安全转换模式

建议在进行类型转换时使用安全检查：

```javascript
@input_value = "3.14"

// 安全的类型转换（使用自定义函数）
safeConvertAndCheck(input_value: Any): Boolean {
  if (IS_NUMBER(input_value)) {
    @numeric_value: Double = TO_NUMBER(input_value);
    return @numeric_value > 3.0;
  } else {
    // 处理转换失败的情况
    return false;
  }
}

ALL{
  safeConvertAndCheck(@input_value);
} = BUY;
```

## 最佳实践

1. **尽量避免显式类型转换**：利用自动转换机制
2. **进行安全检查**：在关键转换前使用类型检查函数
3. **处理转换失败**：为可能的转换失败准备备用逻辑
4. **保持一致性**：在同一策略中保持类型使用的一致性

## 示例：动态参数处理

```javascript
// 处理可能来自外部配置的参数
@external_param = GET_PARAM("threshold")  // 可能返回字符串或数值

// 安全地处理参数（使用自定义函数）
safeGetThreshold(external_param: Any): Double {
  if (IS_NUMBER(external_param)) {
    return TO_NUMBER(external_param);
  } else {
    return TO_NUMBER(external_param);
  }
}

@threshold: Double = safeGetThreshold(GET_PARAM("threshold"));

// 使用转换后的参数
@current_rsi = $(5m).RSI().value
ALL{@current_rsi < @threshold;} = BUY;
```

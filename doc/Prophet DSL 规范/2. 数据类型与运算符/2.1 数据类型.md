## 1. 基础类型

### 1.1 类型概览

Prophet DSL 支持 5 种基础数据类型：

| 类型 | 说明 | 字面量示例 | C++ 映射类型 |
|------|------|-----------|------------|
| `Integer` | 整数 | `10`, `-5`, `0` | `int` |
| `Double` | 浮点数 | `10.5`, `3.14`, `-2.7`, `1e-4` | `double` |
| `Boolean` | 布尔值 | `true`, `false` | `bool` |
| `String` | 字符串 | `"5m"`, `"BTCUSDT"`, `'1h'` | `std::string` |
| `Enum` | 枚举值 | `BULLISH`, `GOLDEN_CROSS` | `std::string` |

---

### 1.2 Integer（整数）

**定义**: 32位有符号整数

**范围**: -2,147,483,648 ~ 2,147,483,647

**字面量**:
```javascript
@count: Integer = 10;        // 正整数
@negative: Integer = -5;      // 负整数
@zero: Integer = 0;           // 零
```

**常见用途**:
- 计数器
- 周期参数（如 RSI 周期：14）
- 索引值
- 整数阈值

**示例**:
```javascript
@PERIOD: Integer = 14;
@signal_count: Integer = 0;

ALL{
    $(5m).RSI(@PERIOD).value < 30;
} = BUY;
```

---

### 1.3 Double（浮点数）

**定义**: 64位双精度浮点数

**精度**: 约 15-17 位有效数字

**字面量**:
```javascript
@price: Double = 3000.5;      // 标准表示
@threshold: Double = 0.05;    // 小数
@sci: Double = 1.23e-4;       // 科学计数法 (0.000123)
@negative: Double = -99.9;    // 负数
```

**常见用途**:
- 价格数据
- 指标值（如 RSI、MACD）
- 百分比（如 0.05 表示 5%）
- 数学计算结果

**示例**:
```javascript
@current_price: Double = KLINE(5m).close(0);
@stop_loss: Double = @current_price * 0.98;  // 止损：-2%

ALL{
    @current_price > @stop_loss;
} = HOLD;
```

**注意事项**:
- ⚠️ 浮点数比较应避免使用 `=`，推荐使用范围比较
- ✅ 推荐：`ABS(@value - @target) < 0.0001`
- ❌ 避免：`@value = @target`

---

### 1.4 Boolean（布尔值）

**定义**: 逻辑真假值

**字面量**:
```javascript
@flag: Boolean = true;
@is_active: Boolean = false;
```

**常见用途**:
- 条件标志
- 逻辑判断结果
- 开关控制

**示例**:
```javascript
@use_stop_loss: Boolean = true;

isBullish(): Boolean {
    return $(5m).EMA(12).value > $(5m).EMA(26).value;
}

ALL{
    isBullish();
    @use_stop_loss AND $(5m).ATR(14).value > 10;
} = BUY;
```

**逻辑运算符**:
```javascript
@a: Boolean = true;
@b: Boolean = false;

@result1: Boolean = @a AND @b;   // false
@result2: Boolean = @a OR @b;    // true
@result3: Boolean = NOT @a;      // false
```

---

### 1.5 String（字符串）

**定义**: 文本字符序列

**字面量**:
```javascript
@symbol: String = "BTCUSDT";
@timeframe: String = "5m";
@msg: String = '1h';  // 单引号也可以
```

**常见用途**:
- 交易对名称
- 时间框架标识
- 消息文本
- 枚举值比较

**示例**:
```javascript
@tf: String = "5m";

calcScore(timeframe: String): Double {
    return $(timeframe).RSI().value;
}

ALL{
    calcScore(@tf) < 30;
} = BUY;
```

**字符串比较**:
```javascript
@trend: String = $(5m).MACD().trend;

ALL{
    @trend = "BULLISH";  // 字符串相等比较
} = BUY;
```

---

### 1.6 Enum（枚举值）

**定义**: 预定义的常量值集合

**内置枚举**:

#### 趋势枚举
```javascript
BULLISH      // 看涨
BEARISH      // 看跌
NEUTRAL      // 中性
```

#### 交叉类型枚举
```javascript
GOLDEN_CROSS     // 金叉
DEAD_CROSS       // 死叉
NO_CROSS         // 无交叉
```

#### 资金费率趋势枚举
```javascript
RISING       // 上升
FALLING      // 下降
STABLE       // 稳定
```

**使用示例**:
```javascript
ALL{
    $(5m).MACD().trend = BULLISH;
    $(5m).EMA().cross_type = GOLDEN_CROSS;
} = BUY;
```

**注意**:
- 枚举值**不需要引号**
- 枚举值是**大小写敏感**的
- 枚举值在运行时以字符串形式存储

## 2. 类型推断

### 2.1 自动类型推断

Prophet DSL 支持根据字面量自动推断类型：

```javascript
// 自动推断为 Integer
@count = 10;

// 自动推断为 Double
@price = 3000.5;

// 自动推断为 Boolean
@flag = true;

// 自动推断为 String
@symbol = "BTCUSDT";

// 自动推断为 Enum (实际为 String)
@trend = BULLISH;
```

### 2.2 显式类型声明（推荐）

虽然支持自动推断，但推荐显式声明类型：

```javascript
// ✅ 推荐：类型明确
@count: Integer = 10;
@price: Double = 3000.5;
@flag: Boolean = true;

// ⚠️ 可以，但不推荐
@count = 10;
@price = 3000.5;
@flag = true;
```

**原因**:
- ✅ 提高代码可读性
- ✅ 便于编译器类型检查
- ✅ 避免意外的类型推断错误

### 2.3 表达式类型推断

变量类型由初始化表达式决定：

```javascript
@price: Double = KLINE(5m).close(0);  // KLINE().close() 返回 Double
@rsi: Double = $(5m).RSI().value;     // 指标值返回 Double
@is_bullish: Boolean = $(5m).MACD().trend = BULLISH;  // 比较返回 Boolean
```

## 3. 类型转换

### 3.1 隐式转换

#### Integer → Double（自动）
```javascript
@int_val: Integer = 10;
@double_val: Double = @int_val;  // ✅ 自动转换为 10.0
```

#### 其他隐式转换规则
| 从类型 | 到类型 | 是否允许 |
|--------|--------|---------|
| Integer | Double | ✅ 自动 |
| Double | Integer | ❌ 禁止 |
| Boolean | Integer | ❌ 禁止 |
| String | Integer | ❌ 禁止 |

### 3.2 显式转换（使用数学函数）

#### Double → Integer
```javascript
@double_val: Double = 10.7;

// 四舍五入
@int1: Integer = ROUND(@double_val);  // 11

// 向下取整
@int2: Integer = FLOOR(@double_val);  // 10

// 向上取整
@int3: Integer = CEIL(@double_val);   // 11
```

#### 示例：动态阈值
```javascript
@rsi_value: Double = $(5m).RSI().value;
@rsi_int: Integer = ROUND(@rsi_value);  // 转为整数

ALL{
    @rsi_int < 30;  // 使用整数比较
} = BUY;
```

## 4. 特殊类型

### 4.1 可选类型（Optional）

某些函数可能返回空值（暂不支持）：

```javascript
// 未来支持
@value: Optional<Double> = tryGetValue();

if (@value.hasValue()) {
    return @value.get();
} else {
    return 0.0;
}
```

### 4.2 数组类型（Array）

**当前不支持**数组类型。

如需处理多个值，使用多个变量：

```javascript
// ❌ 不支持
@prices: Array<Double> = [100, 200, 300];

// ✅ 使用多个变量
@price1: Double = 100;
@price2: Double = 200;
@price3: Double = 300;
```

## 5. 类型检查

### 5.1 编译时类型检查

#### 类型不匹配错误
```javascript
// ❌ 错误：类型不匹配
@count: Integer = 3.14;
```

**错误信息**:
```
Type mismatch: expected Integer, got Double
  Line: 1, Column: 19
```

#### 返回类型不匹配
```javascript
// ❌ 错误：返回类型不匹配
calcScore(): Integer {
    return 3.14;  // 返回 Double，但声明返回 Integer
}
```

**错误信息**:
```
Return type mismatch: expected Integer, got Double
  Line: 2, Column: 12
```

### 5.2 运行时类型检查

#### 除零错误
```javascript
@divisor: Double = 0.0;
@result: Double = 100.0 / @divisor;  // 运行时错误或返回 NaN
```

**处理方式**:
- 浮点数除零：返回 `Infinity` 或 `NaN`
- 整数除零：抛出运行时错误

#### 安全除法示例
```javascript
calcRatio(a: Double, b: Double): Double {
    if (ABS(b) < 0.0001) {
        return 0.0;  // 避免除零
    }
    return a / b;
}
```

## 6. 最佳实践

### 6.1 始终使用类型声明

```javascript
// ✅ 推荐
@price: Double = KLINE(5m).close(0);
@count: Integer = 10;

// ❌ 不推荐
@price = KLINE(5m).close(0);
@count = 10;
```

### 6.2 避免隐式类型转换陷阱

```javascript
// ⚠️ 注意：整数除法会截断
@int_result: Integer = 7 / 2;  // 结果是 3，不是 3.5

// ✅ 正确：使用浮点数
@double_result: Double = 7.0 / 2.0;  // 结果是 3.5
```

### 6.3 浮点数比较使用容差

```javascript
// ❌ 不推荐：直接相等比较
@value: Double = 0.1 + 0.2;  // 实际可能是 0.30000000000000004
if (@value = 0.3) {  // 可能失败
    // ...
}

// ✅ 推荐：使用容差
@epsilon: Double = 0.0001;
if (ABS(@value - 0.3) < @epsilon) {
    // ...
}
```

### 6.4 使用合适的类型

```javascript
// ✅ 价格、指标值 → Double
@price: Double = KLINE(5m).close(0);
@rsi: Double = $(5m).RSI().value;

// ✅ 周期、计数 → Integer
@PERIOD: Integer = 14;
@count: Integer = 0;

// ✅ 开关、标志 → Boolean
@use_stop_loss: Boolean = true;

// ✅ 时间框架、交易对 → String
@timeframe: String = "5m";
@symbol: String = "BTCUSDT";

// ✅ 趋势、交叉类型 → Enum
@trend: Enum = BULLISH;
```

### 6.5 类型一致性

```javascript
// ❌ 类型混乱
@value1: Double = 10;
@value2: Integer = 10;
@result = @value1 + @value2;  // 混合类型

// ✅ 类型统一
@value1: Double = 10.0;
@value2: Double = 10.0;
@result: Double = @value1 + @value2;
```

## 7. 类型速查表

### 7.1 字面量类型映射

| 字面量 | 推断类型 |
|--------|---------|
| `10` | Integer |
| `10.0` | Double |
| `10.5` | Double |
| `1e-4` | Double |
| `true`, `false` | Boolean |
| `"text"`, `'text'` | String |
| `BULLISH`, `BEARISH` | Enum (String) |

### 7.2 表达式类型规则

| 表达式 | 结果类型 |
|--------|---------|
| `Integer + Integer` | Integer |
| `Integer + Double` | Double |
| `Double + Double` | Double |
| `Integer / Integer` | Integer（截断） |
| `Double / Double` | Double |
| `value > value` | Boolean |
| `Boolean AND Boolean` | Boolean |

### 7.3 函数返回类型

| 函数调用 | 返回类型 |
|---------|---------|
| `KLINE(tf).close(0)` | Double |
| `$(tf).RSI().value` | Double |
| `$(tf).MACD().trend` | Enum (String) |
| `ROUND(value)` | Integer |
| `ABS(value)` | Double |
| `MAX(a, b)` | Double |

## 8. 常见错误

### 错误 1: 整数除法截断

```javascript
// ❌ 错误
@ratio: Double = 7 / 2;  // 期望 3.5，实际 3.0

// ✅ 正确
@ratio: Double = 7.0 / 2.0;  // 3.5
```

### 错误 2: 类型声明与实际不符

```javascript
// ❌ 错误
@price: Integer = KLINE(5m).close(0);  // close() 返回 Double

// ✅ 正确
@price: Double = KLINE(5m).close(0);
```

### 错误 3: 浮点数精度问题

```javascript
// ❌ 问题
@result: Double = 0.1 + 0.2;  // 可能是 0.30000000000000004
if (@result = 0.3) {  // 可能失败
    // ...
}

// ✅ 解决
@epsilon: Double = 1e-9;
if (ABS(@result - 0.3) < @epsilon) {
    // ...
}
```

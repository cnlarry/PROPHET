## 1. 比较运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `=` | 等于 | `trend = BULLISH` |
| `!=` | 不等于 | `trend != BEARISH` |
| `>` | 大于 | `value > 70` |
| `>=` | 大于等于 | `value >= 50` |
| `<` | 小于 | `value < 30` |
| `<=` | 小于等于 | `value <= 70` |

**示例：**
```javascript
// 等于判断
$(5m).MACD().trend = BULLISH
$(5m).RSI().overbought = true

// 数值比较
$(5m).RSI().value > 70
$(5m).MACD().histogram < 0

// 不等于判断
$(5m).MACD().trend != BEARISH
$(5m).RSI().value != 50
```

## 2. 范围运算符

### 2.1 区间运算

**BETWEEN - 在区间内（闭区间 [a, b]）**
```javascript
$(5m).RSI().value BETWEEN(40, 60)        // 40 <= value <= 60
```

**NOT BETWEEN - 不在区间内**
```javascript
$(5m).RSI().value NOT BETWEEN(30, 70)    // value < 30 OR value > 70
```

**NEAR - 接近某值（在容差范围内）**
```javascript
$(5m).RSI().value NEAR(50, 5)            // 45 <= value <= 55
                                      // 等价于 BETWEEN(45, 55)
```

### 2.2 集合运算

**IN - 在枚举集合中**
```javascript
$(5m).MACD().trend IN(BULLISH, NEUTRAL)  // trend = BULLISH OR trend = NEUTRAL
$(5m).RSI().value IN(30, 50, 70)         // 离散值匹配
```

**NOT IN - 不在枚举集合中**
```javascript
$(5m).MACD().trend NOT IN(BEARISH)       // trend != BEARISH
$(5m).RSI().value NOT IN(0, 100)         // value != 0 AND value != 100
```

### 2.3 范围运算符总结

| 运算符 | 语法 | 说明 | 适用类型 | 示例 |
|--------|------|------|---------|------|
| `BETWEEN` | `value BETWEEN(a, b)` | 在闭区间 [a, b] 内 | Number | $(5m).RSI()..value BETWEEN(30, 70)` |
| `NOT BETWEEN` | `value NOT BETWEEN(a, b)` | 不在区间内 | Number | $(5m).RSI()..value NOT BETWEEN(40, 60)` |
| `IN` | `value IN(v1, v2, ...)` | 在离散集合中 | Number, Enum | `$(5m).MACD().trend IN(BULLISH, NEUTRAL)` |
| `NOT IN` | `value NOT IN(v1, v2, ...)` | 不在集合内 | Number, Enum | $(5m).RSI()..value NOT IN(0, 100)` |
| `NEAR` | `value NEAR(target, tolerance)` | 接近目标值 ± 容差 | Number | `$(5m).MACD().histogram NEAR(0, 0.01)` |

**注意：**
- `NEAR(target, tolerance)` 等价于 `BETWEEN(target - tolerance, target + tolerance)`
- `IN` 和 `NOT IN` 支持任意数量的参数
- 所有范围运算符基于当前值，不需要历史数据

### 2.4 使用示例

```javascript
// 区间运算示例
$(5m).RSI().value BETWEEN(30, 70)                    // RSI在正常区间
$(5m).RSI().value NOT BETWEEN(40, 60)                // RSI不在中性区间
$(5m).MACD().histogram NEAR(0, 0.01)                 // 柱状图接近0（±0.01）

// 集合运算示例
$(5m).MACD().trend IN(BULLISH, NEUTRAL)              // 趋势是看涨或中性
$(5m).MACD().trend NOT IN(BEARISH)                   // 趋势不是看跌
$(5m).RSI().value IN(30, 50, 70)                     // RSI等于特定值之一

// 穿越检测（使用指标内置字段）
$(5m).MACD().crossover_type = GOLDEN_CROSS           // MACD金叉（指标已计算）
$(5m).MACD().crossover_type = DEATH_CROSS             // MACD死叉
$(5m).MACD().zero_cross = true                       // 零轴穿越
$(5m).EMA().golden_cross = true                      // 均线金叉

// 组合使用
ALL{
  $(5m).RSI().value NOT BETWEEN(40, 60),             // 不在中性区间
  $(5m).MACD().trend IN(BULLISH, NEUTRAL),           // 趋势不是看跌
  $(5m).MACD().crossover_type = GOLDEN_CROSS         // 刚发生金叉
} = BUY;
```

## 3. 逻辑运算符

| 运算符 | 说明 | 优先级 |
|--------|------|--------|
| `NOT` | 逻辑非 | 1 (最高) |
| `AND` | 逻辑与 | 2 |
| `OR`  | 逻辑或 | 3 (最低) |

**优先级规则：**
1. `NOT` 最高
2. `AND` 中等
3. `OR` 最低

**示例：**
```javascript
// 简单逻辑运算
$(5m).MACD().trend = BULLISH AND $(5m).RSI().value < 70
$(5m).RSI().overbought = true OR $(5m).RSI().value > 80
NOT($(5m).MACD().trend = BEARISH)

// 复杂逻辑（使用括号改变优先级）
($(5m).MACD().trend = BULLISH OR $(1h).MACD().trend = BULLISH) AND $(5m).RSI().value < 70

// 多重条件
$(5m).MACD().trend = BULLISH AND 
$(1h).MACD().trend = BULLISH AND 
$(5m).RSI().value BETWEEN(30, 70)
```

## 4. 算术运算符

### 4.1 基本算术运算符

| 运算符 | 说明 | 优先级 | 示例 |
|--------|------|--------|------|
| `+` | 加法 | 3 | `a + b` |
| `-` | 减法 | 3 | `a - b` |
| `*` | 乘法 | 2 | `a * b` |
| `/` | 除法 | 2 | `a / b` |
| `%` | 取模 | 2 | `a % b` |
| `()` | 括号 | 1 (最高) | `(a + b) * c` |

**优先级规则：**
1. 括号 `()` 最高
2. `*`, `/`, `%`
3. `+`, `-` 最低

### 4.2 算术表达式示例

```javascript
// 百分比变化
($(5m).MACD().histogram - $(1h).MACD().histogram) / $(1h).MACD().histogram > 0.1

// 平均值计算
($(5m).RSI().value + $(1h).RSI().value) / 2 > 50

// 差值比较
ABS($(5m).RSI().value - $(1h).RSI().value) > 10

// 放大比较（更容易设置阈值）
$(5m).MACD().histogram * 100 > 5

// 加权平均
($(5m).RSI().value * 0.7 + $(1h).RSI().value * 0.3) > 60

// 比率计算
$(5m).MACD().macd / $(5m).MACD().signal > 1.05

// 复杂嵌套
(($(5m).RSI().value - 30) / (70 - 30)) > 0.5
```

### 4.3 算术表达式中的操作数

算术表达式中可以使用：

```javascript
// 1. 指标字段
$(5m).MACD().histogram + $(1h).MACD().histogram

// 2. 数值常量
$(5m).MACD().histogram * 100

// 3. 数学函数
MAX($(5m).RSI().value, $(1h).RSI().value) + 10

// 4. 环境变量
@CURRENT_PRICE * 0.99

// 5. 数据函数
KLINE(5m).close(0) - KLINE(5m).open(0)

// 6. 嵌套表达式
($(5m).RSI().value + 10) * 2 - ($(1h).RSI().value / 2)
```

### 4.4 实用场景

**百分比计算：**
```javascript
// 价格变化百分比
($(5m).EMA().value - $(1h).EMA().value) / $(1h).EMA().value * 100 > 2

// RSI 位置百分比
($(5m).RSI().value - 30) / (70 - 30) BETWEEN(0.3, 0.7)

// K线涨幅百分比
(KLINE(5m).close(0) - KLINE(5m).open(0)) / KLINE(5m).open(0) * 100 > 2
```

**多指标组合：**
```javascript
// RSI + StochRSI 综合得分
($(5m).RSI().value * 0.6 + $(5m).STOCHRSI().k * 0.4) < 35
```

**比率与背离：**
```javascript
// MACD 与信号线比率
$(5m).MACD().macd / $(5m).MACD().signal > 1.1

// 跨时间框架背离度
ABS($(5m).RSI().value - $(1h).RSI().value) / $(1h).RSI().value > 0.15
```

### 4.5 注意事项

**除零保护：**
```javascript
// ❌ 危险：可能除以零
$(5m).MACD().histogram / $(1h).MACD().histogram > 2

// ✅ 安全：添加保护条件
$(1h).MACD().histogram != 0 AND
$(5m).MACD().histogram / $(1h).MACD().histogram > 2

// ✅ 更好：使用ABS和阈值
ABS($(1h).MACD().histogram) > 0.001 AND
$(5m).MACD().histogram / $(1h).MACD().histogram > 2
```

**精度问题：**
```javascript
// ✅ 推荐：使用ROUND避免浮点误差
ROUND(($(5m).RSI().value + $(1h).RSI().value) / 2, 2) > 50.00

// ✅ 或使用足够的容差
ABS(($(5m).RSI().value + $(1h).RSI().value) / 2 - 50) > 0.01
```

# Prophet DSL 基础语法

本文档介绍了 Prophet DSL 的基础语法规则，帮助用户快速上手语言的基本使用。

## 语句结构

Prophet DSL 的基本语句结构如下：
```
<信号函数>{<条件列表>} = <信号类型>[(<止盈表达式>[, <止损表达式>])]
```

例如：
```javascript
// 基础形式：只定义交易信号
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
} = BUY;

// 完整形式：定义交易信号并指定止盈止损
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
} = BUY(
  KLINE(5m).close() + $(5m).ATR().value * 2.0,  // 止盈价格
  KLINE(5m).close() - $(5m).ATR().value * 1.5   // 止损价格
);
```

## 信号类型

Prophet DSL 支持以下信号类型：

| 信号类型 | 说明 | 止盈止损语法 |
|---------|------|------------|
| BUY | 买入信号 | `BUY`, `BUY(tp)`, `BUY(tp, sl)` |
| SELL | 卖出信号 | `SELL`, `SELL(tp)`, `SELL(tp, sl)` |
| HOLD | 持有信号 | `HOLD`（不支持止盈止损） |

### 止盈止损语法

每个交易信号（BUY/SELL）都可以附带止盈止损价格：

```javascript
// 形式1：无止盈止损（默认值0，由Python层计算）
ALL{...} = BUY;

// 形式2：只设置止盈
ALL{...} = BUY(KLINE(5m).close() + $(5m).ATR().value * 2.0);

// 形式3：设置止盈和止损
ALL{...} = BUY(
  KLINE(5m).close() + $(5m).ATR().value * 2.0,  // 止盈价格
  KLINE(5m).close() - $(5m).ATR().value * 1.5   // 止损价格
);
```

**止盈止损表达式**：
- 可以是任意算术表达式
- 可以使用函数调用、变量引用、指标值等
- 支持使用自定义函数计算复杂的止盈止损逻辑

## 条件表达式

条件表达式由以下元素组成：

### 1. 函数调用
```javascript
KLINE(5m).close(0)      // 当前K线收盘价（显式指定偏移量）
KLINE(5m).close()       // 当前K线收盘价（简写形式）
$(5m).RSI().value       // RSI指标值
```

### 2. 运算符
```javascript
KLINE(5m).close(0) > KLINE(5m).open(0)
$(5m).RSI().value >= 70
```

### 3. 逻辑组合
```javascript
// 使用信号函数组合条件
ALL{
  condition1;
  condition2;
} = BUY;

ANY{
  condition1;
  condition2;
} = SELL;
```

## 变量定义

变量可以在策略顶层定义和使用（必须以 `@` 开头）：
```javascript
@ma20: Double = $(5m).MA(20).value;
@rsi: Double = $(5m).RSI().value;

ALL{
  KLINE(5m).close(0) > @ma20;
  @rsi < 30;
} = BUY;
```

## 注释

Prophet DSL 支持单行和多行注释：
```javascript
// 这是一个单行注释
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);  // 价格上涨时买入
} = BUY;

/*
 * 这是一个多行注释
 * 可以跨越多行
 */
```

## 逻辑运算

Prophet DSL 支持标准的逻辑运算：

### 内置逻辑运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `AND` | 逻辑与 | `condition1 AND condition2` |
| `OR` | 逻辑或 | `condition1 OR condition2` |

**注意**：在信号函数（ALL/ANY等）的条件块内，条件之间使用分号 `;` 分隔，不是逗号。

### 比较运算符

| 运算符 | 说明 | 示例 |
|--------|------|------|
| `>` | 大于 | `price > 100` |
| `<` | 小于 | `price < 100` |
| `>=` | 大于等于 | `rsi >= 70` |
| `<=` | 小于等于 | `rsi <= 30` |
| `==` | 等于 | `trend == 1` |
| `!=` | 不等于 | `signal != 0` |

### NOT - 逻辑非

对布尔表达式取反。

**语法**：
```
NOT(condition)
```

**参数**：
- `condition`: 布尔表达式（条件判断）

**返回值**：
- 如果 `condition` 为 `true`，返回 `false`
- 如果 `condition` 为 `false`，返回 `true`

**示例**：
```
// RSI不在超买区
NOT($(5m).RSI().value > 70)

// MACD不为正
NOT($(1h).MACD().macd > 0)

// 价格不高于均线
NOT(KLINE(5m).close(0) > $(5m).MA(20).value)
```

### 逻辑表达式组合

```
// AND 组合（都必须为真）
$(5m).RSI().value > 50 AND $(5m).MACD().macd > 0

// OR 组合（任一为真）
$(5m).RSI().value < 30 OR $(5m).RSI().value > 70

// 混合组合（使用括号明确优先级）
($(5m).RSI().value > 50 AND $(5m).MACD().macd > 0) OR $(5m).ADX().value > 25
```

### 德摩根定律应用

逻辑等价变换：

```
// 德摩根第一定律：NOT(A AND B) = NOT(A) OR NOT(B)
NOT($(5m).RSI().value > 70 AND $(5m).MACD().macd > 0)
// 等价于
NOT($(5m).RSI().value > 70) OR NOT($(5m).MACD().macd > 0)

// 德摩根第二定律：NOT(A OR B) = NOT(A) AND NOT(B)
NOT($(5m).RSI().value < 30 OR $(5m).RSI().value > 70)
// 等价于
NOT($(5m).RSI().value < 30) AND NOT($(5m).RSI().value > 70)
```

## 数据类型

Prophet DSL 支持以下数据类型：

### 数值类型
- 整数：`10`, `20`, `-5`
- 浮点数：`3.14`, `2.5`, `-1.0`

### 布尔类型
- `true`
- `false`

## 函数语法

函数调用的基本语法：
```
FUNCTION_NAME(parameter1, parameter2, ...)
```

例如：
```javascript
KLINE(5m).close(0)      // 获取当前K线收盘价
$(5m).MA(20).value      // 获取20周期移动平均线值
```

## 时间周期格式

支持的时间周期格式：

| 格式 | 说明 |
|------|------|
| 1m | 1分钟 |
| 5m | 5分钟 |
| 15m | 15分钟 |
| 30m | 30分钟 |
| 1h | 1小时 |
| 4h | 4小时 |
| 1d | 1天 |
| 1w | 1周 |

## 最佳实践

1. 使用有意义的变量名
2. 适当添加注释解释复杂逻辑
3. 保持条件表达式的简洁性
4. 合理使用括号明确优先级

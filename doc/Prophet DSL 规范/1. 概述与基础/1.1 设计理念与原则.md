## 1. 设计理念

### 1.1 核心原则

- **简洁性**：语法清晰，易读易写
- **表达力**：能表达复杂的交易逻辑
- **可验证**：支持语法检查和类型验证
- **数据驱动**：所有关键词来自数据库预设
- **模块化**：文档按功能模块组织，便于查找和维护

### 1.2 设计目标

```
✓ 单行表达式足够简洁
✓ 支持复杂嵌套逻辑
✓ 原生支持加权机制
✓ 类型安全
✓ 自定义扩展：支持用户自定义函数与变量
✓ 文档结构清晰，易于查找
```

## 2. 核心概念

### 2.1 DSL 组成要素

Prophet DSL 由以下核心要素组成：

| 要素 | 前缀 | 说明 | 详细文档 |
|------|------|------|---------|
| **信号函数** | 无 | 决定条件逻辑关系（ALL/ANY/WEIGHTED等） | [Prophet DSL 信号函数.md](Prophet%20DSL%20信号函数.md) |
| **指标引用** | `$.` | 引用预计算的指标字段和参数（统一语法） | [Prophet DSL 指标.md](Prophet%20DSL%20指标.md) |
| **数据函数** | 无 | 动态计算K线统计值（HIGHEST/KLINE等） | [Prophet DSL 函数.md](Prophet%20DSL%20函数.md) |
| **环境变量** | `@` | 运行时上下文（价格、时间等） | [Prophet DSL 环境变量.md](Prophet%20DSL%20环境变量.md) |
| **运算符** | 无 | 比较、逻辑、算术运算符 | [Prophet DSL 运算符和数据类型文档.md](Prophet%20DSL%20运算符和数据类型文档.md) |

### 2.2 函数层级

**信号函数（8个）**
- 决定条件之间的逻辑关系
- 返回值为信号类型：`BUY`、`SELL`、`HOLD`
- 包括：`ALL{}`、`ANY{}`、`NONE{}`、`MIN(n){}`、`COUNT(n){}`、`MAX(n){}`、`WEIGHTED(threshold){}`、`VOTE(threshold){}`
- 详见：[Prophet DSL 信号函数.md](Prophet%20DSL%20信号函数.md)

**权重函数（1个）**
- 用于为条件赋值权重
- 仅在 `WEIGHTED{}` 信号函数内使用
- 语法：`WEIGHT(condition) = weight_value`
- 详见：[Prophet DSL 信号函数.md](Prophet%20DSL%20信号函数.md)

**数据函数（17个）**
- 动态计算K线历史数据的统计值
- 无需预先配置，参数在DSL中指定
- **数据访问**：`KLINE`, `PRICE`
- **统计分析**：`HIGHEST`, `LOWEST`, `AVERAGE`, `SUM`, `MEDIAN`, `STD`, `VARIANCE`, `CHANGE`, `RANK`, `SLOPE`
- **高级分析**：`HT`（希尔伯特变换）, `POWER`（力量平衡）, `PATTERN`（形态识别）
- 详见：[Prophet DSL 函数.md](Prophet%20DSL%20函数.md)

**序列条件函数（3个）**
- 检查连续周期的条件满足情况
- 包括：`CONSECUTIVE`/`CONSEC`（连续条件检测）, `COUNT_DATA`（条件计数）
- 支持9种条件类型：rising, falling, increasing, decreasing, above, below, between, crosses_above, crosses_below
- 详见：[Prophet DSL 函数.md](Prophet%20DSL%20函数.md)

**数学函数（18个）**
- 基础运算：`ABS`, `ROUND`, `CEIL`, `FLOOR`, `SQRT`, `POW`
- 三角函数：`SIN`, `COS`, `TAN`, `ASIN`, `ACOS`, `ATAN`
- 双曲函数：`SINH`, `COSH`, `TANH`
- 指数对数：`EXP`, `LN`, `LOG10`
- 详见：[Prophet DSL 函数.md](Prophet%20DSL%20函数.md)

**逻辑函数（1个）**
- `NOT()`：逻辑非
- 详见：[Prophet DSL 函数.md](Prophet%20DSL%20函数.md)

### 2.3 扩展模型（4.0）

除内置函数与指标外，4.0 引入自定义扩展：

| 类型 | 前缀/形式 | 说明 | 文档 |
|------|-----------|------|------|
| 指标引用 | `$(tf).INDICATOR.field` | 预计算指标，字段/参数统一语法 | 见"指标引用文档" |
| 数据函数 | `FUNCTION(tf).field(args)` | 即时计算（KLINE/HIGHEST/STD/PRICE/...） | 见“函数系统文档” |
| 自定义函数 | `FUNC_NAME(args)` | 在注册表中声明，类型签名校验 | 自定义函数用户/设计文档 |
| 自定义变量 | 标识符（无前缀） | 在策略文件顶层声明并赋值，强类型 | 自定义函数用户/设计文档 |

约束：
- 自定义函数默认无副作用（无 I/O、无网络），运行于沙箱上下文；
- 自定义变量为不可变（单赋值）或块级局部（按实现配置），推荐不可变；
- 与内置命名空间不冲突（优先级：内置 > 自定义）。

### 2.4 规则分隔符

多条规则使用分号 `;` 分隔：

```javascript
ALL{...} = BUY; ANY{...} = SELL; WEIGHTED{...} = BUY;
```

## 3. 基础语法

### 3.1 信号表达式格式

```
<信号函数>{<条件列表>} = <信号类型>
```

**示例：**
```javascript
ALL{condition1; condition2;} = BUY;
ANY{condition1; condition2;} = SELL;
MIN(2){condition1; condition2; condition3;} = HOLD;
WEIGHTED(0.6){WEIGHT(condition1)=0.3; WEIGHT(condition2)=0.4;} = BUY;
```

### 3.2 条件表达式格式

#### 完整格式：
```
<Left> <Operator> <Right>
```

#### 布尔字段简写（语法糖）：
```javascript
// 对于布尔类型的字段，支持简写
$(5m).RSI().overbought;             // ✅ 简写
$(5m).RSI().overbought = true;      // ✅ 完整写法（等价）

// 否定形式仍需显式写出
$(5m).RSI().overbought = false;     // ✅ 显式否定
NOT($(5m).RSI().overbought);        // ✅ 使用 NOT 函数
```

### 3.3 指标引用格式（统一语法）

> **⚠️ v3.0.0 重要变更**：统一使用 `$.` 访问指标字段和参数！

#### 单时间框架语法

```javascript
$(TIMEFRAME).INDICATOR.FIELD_OR_PARAM
```

**字段引用（全小写）：**
```javascript
$(5m).MACD().trend;         // MACD 5分钟趋势
$(1h).RSI().value;          // RSI 1小时数值
$(15m).EMA().distance;       // EMA 15分钟距离百分比
$(5m).BBANDS.upper;        // 布林带上轨
```

**参数引用（全大写+下划线）：**
```javascript
$(5m).RSI().PERIOD;            // RSI 周期参数
$(5m).MACD().FAST_PERIOD;     // MACD 快线周期
$(5m).BOLL().STD_DEV;         // 布林带标准差倍数
```

**混合使用示例：**
```javascript
// 动态阈值：RSI 值小于其周期参数的 2 倍
$(5m).RSI().value < $(5m).RSI().PERIOD * 2;

// 柱状图超过快线周期的 10%
$(5m).MACD().histogram > $(5m).MACD().FAST_PERIOD * 0.1;
```

#### 多时间框架语法（v4.1.0 新增）

> **🔥 v4.1.0 新特性**：支持一次性判断多个时间框架的指标条件！

```javascript
$.INDICATOR[TIMEFRAME1, TIMEFRAME2, ...].FIELD
```

**基础用法：**
```javascript
// 所有时间框架的RSI都大于70（隐式ALL语义）
$.RSI[5m, 15m, 1h].value > 70

// 等价于（自动展开）：
ALL{
  $(5m).RSI().value > 70;
  $(15m).RSI().value > 70;
  $(1h).RSI().value > 70;
}
```

**多时间框架共振示例：**
```javascript
// 多周期趋势共振
$[5m, 15m, 1h, 4h].MACD.trend = "BULLISH"

// 多周期RSI确认
$.RSI[5m, 15m, 1h].value BETWEEN(50, 70)

// 多周期成交量趋势
$.OBV[5m, 15m, 1h].trend == BULLISH
```

**语法规则：**
- **单时间框架**：使用圆括号 `$(5m).RSI().value`
- **多时间框架**：使用方括号 `$.RSI[5m, 15m, 1h].value`
- **自动展开**：多时间框架语法在解析时自动展开为 `ALL{}` 结构
- **仅限条件表达式**：多时间框架语法只能用于条件判断，不能获取返回值
- **参数引用限制**：参数引用不支持多时间框架语法

**完整策略示例：**
```javascript
// 多时间框架共振买入策略
ALL{
  // 多时间框架趋势共振
  $[5m, 15m, 1h].MACD.trend = "BULLISH";
  
  // 多时间框架RSI未超买
  $.RSI[5m, 15m, 1h].value < 70;
  
  // 单时间框架强度确认
  $(1h).ADX().value > 25;
  
  // 当前价格突破
  @CURRENT_PRICE > $(5m).EMA().value;
} = BUY;
```

### 3.4 参数赋值（v3.0.2 新增）

> **🔥 v3.0.2 新特性**：支持动态修改指标参数！

DSL 允许在规则中给指标参数赋值，实现动态参数调整：

```javascript
$(TIMEFRAME).INDICATOR.PARAM_NAME = value
```

**✅ 允许的操作（参数赋值）：**
```javascript
// 修改RSI周期参数
$(5m).RSI().PERIOD = 16

// 修改MACD参数
$(5m).MACD().FAST_PERIOD = 10
$(5m).MACD().SLOW_PERIOD = 26
$(5m).MACD().SIGNAL_PERIOD = 9

// 修改布林带标准差倍数
$(5m).BOLL().BOLL_STD_DEV = 2.5
```

**❌ 禁止的操作（只读字段）：**
```javascript
// ❌ 错误：value 是计算结果，属于只读字段
$(5m).RSI().value = 70

// ❌ 错误：trend 是计算结果，属于只读字段
$(5m).MACD().trend = BULLISH

// ❌ 错误：upper 是计算结果，属于只读字段
$(5m).BOLL().upper = 100
```

**参数赋值规则：**

1. **只能给参数赋值**：参数名必须符合命名约定（全大写，可选下划线）
2. **字段只读**：计算结果字段（全小写）不允许修改
3. **类型检查**：参数值必须是有效的数值表达式
4. **作用域**：参数赋值在整个策略执行过程中生效
5. **命名简洁**：参数名无需包含指标名前缀（如 `PERIOD` 而非 `RSI_PERIOD`）
6. **⚠️ 只能在顶层赋值**：参数赋值语句只能出现在规则外部，不能在条件块（`ALL{}`、`ANY{}` 等）内部使用

**完整示例：**
```javascript
// 示例1：先设置参数，再使用
$(5m).RSI().PERIOD = 16;
ALL{
  $(5m).RSI().value < 30;
  $(5m).MACD().crossover_type = GOLDEN_CROSS;
} = BUY;

// 示例2：动态调整布林带参数
$(5m).BOLL().STD_DEV = 2.5;
$(5m).BOLL().PERIOD = 30;
ALL{
  @CURRENT_PRICE < $(5m).BOLL().lower;
  $(5m).RSI().value < 30;
} = BUY;

// 示例3：多个时间框架使用不同参数
$(5m).RSI().PERIOD = 14;
$(1h).RSI().PERIOD = 21;
ANY{
  $(5m).RSI().value < 30;
  $(1h).RSI().value < 40;
} = BUY;
```

**错误处理：**

如果尝试给只读字段赋值，将抛出异常：
```
ParserException: Cannot assign to read-only field 'value'. Only parameters (e.g., PERIOD) can be modified.
```

如果在条件块内尝试参数赋值，将抛出异常：
```
ParserException: Parameter assignment is not allowed inside condition blocks. 
Move '$(5m).RSI().PERIOD = ...' to the top level before the rule.
```

**示例：**
```javascript
// ❌ 错误：在条件块内赋值
ALL{
  $(5m).RSI().PERIOD = 14;     // 错误！
  $(5m).RSI().value < 30;
} = BUY;

// ✅ 正确：在顶层赋值
$(5m).RSI().PERIOD = 14;
ALL{
  $(5m).RSI().value < 30;      // 使用已赋值的参数
} = BUY;
```

**语法对比：**
```javascript
// 指标引用（字段和参数统一使用 $.）
$(5m).MACD().trend                 // ✅ 字段引用（全小写）
$(5m).MACD().FAST_PERIOD           // ✅ 参数引用（全大写）

// 数据函数（实时计算，不需要 $）
KLINE(5m).close(0)               // ✅ K线数据
HIGHEST(5m).close(10)            // ✅ 最高值

// 环境变量（使用 @）
@CURRENT_PRICE                   // ✅ 当前价格
@CURRENT_HOUR                    // ✅ 当前小时
```

**命名约定自动区分：**
- 全大写+下划线 → 参数（如 `PERIOD`、`FAST_PERIOD`）
- 全小写或混合大小写 → 字段（如 `value`、`crossover_type`）

详见：[Prophet DSL 指标.md §2](Prophet%20DSL%20指标.md#2-指标引用语法)

### 3.5 注释

Prophet DSL 支持两种注释类型，完全支持中文、Emoji及Unicode字符。注释在词法分析阶段被自动识别和跳过，不影响程序逻辑。

#### 3.5.1 单行注释

**语法**: `//`

单行注释从 `//` 开始，到行尾结束。

**示例**:
```javascript
// 这是一个完整的单行注释

ALL{
  $(5m).MACD().trend = BULLISH;  // 行尾注释：5分钟趋势看涨
  $(5m).RSI().value < 70;        // 行尾注释：RSI未超买
} = BUY;
```

#### 3.5.2 多行注释

**语法**: `/* ... */`

多行注释从 `/*` 开始，到 `*/` 结束，可以跨越多行。

**示例**:
```javascript
/*
 * 这是一个多行注释
 * 可以跨越多行
 * 用于详细说明策略逻辑
 */
WEIGHTED(0.6){
  WEIGHT($(5m).MACD().crossover_type = GOLDEN_CROSS) = 0.4;
  /* 行内多行注释 */ WEIGHT($(5m).RSI().value < 70) = 0.3;
} = BUY;
```

#### 3.5.3 注释规则

1. **完全忽略**: 注释在词法分析阶段被跳过，不产生任何Token
2. **嵌套限制**: 多行注释不支持嵌套（`/* /* ... */ */` 会导致错误）
3. **未结束检测**: 如果多行注释没有正确结束，会抛出 `LexerException`
4. **Unicode支持**: 注释内容支持任何Unicode字符（中文、Emoji等）
5. **与除法区分**: `/` 只有后面紧跟 `/` 或 `*` 时才被识别为注释，否则是除法运算符

**错误示例**:
```javascript
/* 这是一个未结束的注释
ALL{...} = BUY;
// ❌ 错误：会抛出 "Unterminated multi-line comment" 异常
```

#### 3.5.4 中文与国际化支持

注释系统完全支持Unicode，可以使用中文、Emoji等进行注释。

**示例**:
```javascript
// ==========================================================
// 策略名称：MACD + RSI 多时间框架策略
// 作者：王炼
// 创建日期：2025-10-05
// ==========================================================

/* 
 * 规则1：强买入信号
 * 
 * 触发条件：
 *   - 5分钟MACD金叉
 *   - 1小时趋势看涨  
 *   - RSI未超买（小于70）
 * 
 * 【重要】此规则要求所有条件同时满足！
 */
ALL{
  $(5m).MACD().crossover_type = GOLDEN_CROSS;
  $(1h).MACD().trend = BULLISH;
  $(5m).RSI().value < 70;
} = BUY;  // 💰 强买入信号
```

#### 3.5.5 注释处理流程（技术细节）

**词法分析器（Lexer）处理逻辑**:

1. **空白和注释跳过**: 在 `tokenize()` 主循环中，每次读取Token前调用 `skipWhitespaceAndComments()`
2. **单行注释识别**: 检测到 `//`，调用 `skipSingleLineComment()`，读取直到行尾
3. **多行注释识别**: 检测到 `/*`，调用 `skipMultiLineComment()`，读取直到 `*/`
4. **除法运算符区分**: 如果 `/` 后面不是 `/` 或 `*`，则识别为除法运算符

**实现位置**:
- 文件：`Prophet.Core/src/dsl/lexer.cpp`
- 函数：`skipWhitespaceAndComments()`, `skipSingleLineComment()`, `skipMultiLineComment()`
- 行号：76-161

### 3.6 语法糖

为了提升用户的用户体验，提升核心引擎的鲁棒性和Prophet DSL的宽容性，Prophet Core Engine允许Prophet DSL的多种简写形式；

#### 3.6.1 数据函数
- methods/submethods：需要括号 ()，即使无参数
- fields/subfields：不需要括号，直接访问

**数据函数的访问语法**：
`DataFunction(timeframe).method(parameters)`
`DataFunction(timeframe).method(parameters).subfield`
`DataFunction(timeframe).method(parameters).submethod()`
`DataFunction(timeframe).field`
`DataFunction(timeframe).field.subfield`

**示例**
```javascript
FVG(5m).bullish == true;
FVG(5m).bullish;
FVG(5m).bullish() == true;
FVG(5m).bullish();
FVG(5m).bullish = true;
FVG(5m).bullish() = true;
```


### 3.7 自定义函数与变量（v4.0 新增）

4.0 支持用户在 DSL 中声明变量、调用注册的自定义函数。

1) 顶层变量（不可变）：
```javascript
// 顶层一次性赋值，类型推断或显式类型
threshold = 0.6;
len_fast = 12;
len_slow = 26;

WEIGHTED(threshold){
  WEIGHT($(5m).MACD().crossover_type = GOLDEN_CROSS) = 0.4;
  WEIGHT($(5m).RSI().value < 50) = 0.2;
} = BUY;
```

2) 自定义函数（通过注册表提供）：
```javascript
// 假设已注册: MY_SCORE(x:number, y:number): number
score = MY_SCORE($(5m).RSI().value, STD(5m).close(20));
score > 0.8;
```

规则：
- 变量名使用小写/下划线风格；
- 变量不可在条件块内二次赋值；
- 自定义函数必须返回确定类型；
- 不允许副作用（I/O、网络、线程）；
- 建议在帮助系统中登记签名，便于补全与校验。

更多细节见：`Prophet DSL 自定义函数用户指南.md` 与 `Prophet DSL 自定义函数设计文档.md`。

## 5. 数据类型概览

Prophet DSL 是强类型语言，明确定义了5种基础数据类型：

| 类型 | 说明 | DSL语法示例 | C++类型 | 主要用途 |
|------|------|------------|---------|---------|
| `Integer` | 整数类型 | `14`, `100`, `-5` | `int` | 周期参数、计数、时间 |
| `Double` | 双精度浮点数 | `0.5`, `2.5`, `3.14` | `double` | 价格、指标值、比率、浮点参数 |
| `Boolean` | 布尔类型 | `true`, `false` | `bool` | 条件判断、开关状态 |
| `String` | 字符串类型 | `"BTCUSDT"` | `std::string` | 交易对名称（较少使用） |
| `Enum` | 枚举类型 | `BULLISH`, `GOLDEN_CROSS` | `std::string` | 趋势、信号、状态常量 |

### 类型转换规则

**Integer ↔ Double 转换：**
- **Integer → Double**（自动，向上转换，无损）
  ```javascript
  $(5m).RSI().PERIOD + 0.5;  // 14 + 0.5 = 14.5（14 → 14.0）
  10 / 3;                  // 3.333...（Integer / Integer → Double浮点除法）
  ```
  
- **Double → Integer**（截断，向下转换，有损）⚠️
  ```javascript
  // ⚠️ 不推荐：隐式截断（小数部分丢失）
  // $(5m).RSI().PERIOD = 14.7;  // 14.7 → 14
  
  // ✅ 推荐：使用显式转换函数
  // $(5m).RSI().PERIOD = ROUND(14.7);  // 15（四舍五入）
  ```

**混合运算规则：**
- `Integer + Double` → `Double`
- `Integer * Double` → `Double`
- `Integer / Integer` → `Double`（浮点除法，不是整除）

详见：[Prophet DSL 运算符和数据类型文档.md §1](Prophet%20DSL%20运算符和数据类型文档.md#1-数据类型)

  - **统计满足条件的期数**：`COUNT_DATA(5m).close(20).rising()` - 统计过去20期中有多少期上涨
  - **支持9种条件**：与CONSECUTIVE相同的条件类型
  - **返回整数值**：0 到 PERIOD 之间，可用于数值比较
  - **每期独立判断**：与CONSECUTIVE的连续判断不同
  - **语法智能区分**：
    - `COUNT(n){...}` → 信号函数（精确匹配条件数量）
    - `COUNT_DATA(tf).field(period).condition()` → 数据函数（统计满足条件的期数）
  - **典型应用**：趋势强度评估、波动率分析、成交量活跃度统计
  - **详细文档**：参见 [Prophet DSL 函数.md](Prophet%20DSL%20函数.md) 序列条件函数章节

### v3.1.0 (2025-10-07)
- **🔥 重大变更**：条件分隔符从逗号改为分号
  - **所有条件必须以分号结尾**：包括最后一个条件
  - **一致性增强**：规则用 `;` 分隔，条件也用 `;` 分隔
  - **可读性提升**：分号明确表示"语句结束"
  - **示例**：
    - `ALL{cond1; cond2; cond3;} = BUY;` → ✅ 正确
    - `ALL{cond1, cond2, cond3} = BUY;` → ❌ 错误（旧语法）
  - **WEIGHTED语法**：`WEIGHT(...) = 0.4;` 也用分号
  - **⚠️ 破坏性变更**：不兼容旧版DSL代码

- **🔒 重要澄清**：参数赋值的作用域限制
  - **禁止在条件块内赋值**：参数赋值只能出现在顶层（规则外部）
  - **语义纯净性**：条件块（`ALL{}`、`ANY{}` 等）内只能包含纯条件表达式
  - **设计理念**：配置参数 → 执行策略，职责清晰分离
  - **示例**：
    - `$(5m).RSI().PERIOD = 14; ALL{...} = BUY;` → ✅ 正确
    - `ALL{ $(5m).RSI().PERIOD = 14; ... } = BUY;` → ❌ 错误（Parser报错）

### v3.0.2 (2025-10-06)
- **🔥 新特性**：支持参数赋值
  - **允许动态修改指标参数**：`$(5m).RSI().PERIOD = 16`
  - **只读字段保护**：计算结果字段（全小写）不允许修改
  - **类型安全**：参数赋值进行类型检查
  - **作用域隔离**：参数赋值在整个策略执行过程中生效
  - **命名简化**：参数名无需包含指标名前缀
  - **示例**：
    - `$(5m).RSI().PERIOD = 16` → ✅ 允许（参数修改）
    - `$(5m).RSI().value = 70` → ❌ 禁止（只读字段）

### v3.0.1 (2025-10-06)
- **🔥 重大更新**：统一指标访问语法
  - **废除 `#.` 参数引用语法**，统一使用 `$.` 访问指标字段和参数
  - **命名约定自动区分**：全大写+下划线 = 参数，全小写 = 字段
  - **简化语法**：只需记住 `$.`，无需区分 `$` 和 `#`
  - **零性能开销**：编译期判断，无运行时查表
  - **示例**：
    - `$(5m).RSI().value` → 字段引用
    - `$(5m).RSI().PERIOD` → 参数引用
    - `$(5m).RSI().value < $(5m).RSI().PERIOD * 2` → 混合使用

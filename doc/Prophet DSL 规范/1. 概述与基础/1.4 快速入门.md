# Prophet DSL 快速入门

本文档将引导您快速上手 Prophet DSL，通过实际示例帮助您理解语言的基本用法。

## 第一个策略

让我们从一个简单的策略开始：

```javascript
// 当价格上涨且 RSI 超卖时买入（带止盈止损）
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
  $(5m).RSI().value < 30;
} = BUY(
  KLINE(5m).close() + $(5m).ATR().value * 2.0,  // 止盈：当前价 + 2倍ATR
  KLINE(5m).close() - $(5m).ATR().value * 1.5   // 止损：当前价 - 1.5倍ATR
);

// 当价格下跌且 RSI 超买时卖出（带止盈止损）
ALL{
  KLINE(5m).close(0) < KLINE(5m).open(0);
  $(5m).RSI().value > 70;
} = SELL(
  KLINE(5m).close() - $(5m).ATR().value * 2.0,  // 止盈：当前价 - 2倍ATR
  KLINE(5m).close() + $(5m).ATR().value * 1.5   // 止损：当前价 + 1.5倍ATR
);
```

**说明**：
- 止盈止损价格使用 ATR（平均真实波幅）动态计算，适应市场波动
- 买入时：止盈在上方，止损在下方
- 卖出时：止盈在下方，止损在上方

## 理解策略结构

这个简单策略包含两个部分：

1. **买入条件**：价格上涨且 RSI 超卖
2. **卖出条件**：价格下跌且 RSI 超买

## 使用变量优化策略

为了提高可读性，我们可以使用变量：

```javascript
// 定义变量（必须在顶层，使用 @ 前缀）
@current_close: Double = KLINE(5m).close(0);
@current_open: Double = KLINE(5m).open(0);
@rsi_value: Double = $(5m).RSI().value;

// 买入条件
ALL{
  @current_close > @current_open;
  @rsi_value < 30;
} = BUY;

// 卖出条件
ALL{
  @current_close < @current_open;
  @rsi_value > 70;
} = SELL;
```

## 添加移动平均线

让我们创建一个更复杂的策略，使用移动平均线：

```javascript
// 计算20周期移动平均线
@ma20: Double = $(5m).MA(20).value;

// 当价格上穿移动平均线且成交量放大时买入
ALL{
  CROSS(5m).close(@ma20).above;
  KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.5;
} = BUY;

// 当价格下穿移动平均线时卖出
ALL{
  CROSS(5m).close(@ma20).below;
} = SELL;
```

## 使用逻辑组合

Prophet DSL 支持复杂的逻辑组合：

```javascript
// 多条件买入策略
ALL {
    KLINE(5m).close(0) > $(5m).MA(20).value;           // 价格在均线之上
    $(5m).RSI().value < 60;                          // RSI 不超买
    KLINE(5m).volume(0) > AVERAGE(5m).volume(20);      // 成交量放大
    CONSECUTIVE(5m).close(3).rising();                 // 连续3期上涨
} = BUY;

// 多条件卖出策略
ANY {
    $(5m).RSI().value > 80;                          // RSI 超买
    KLINE(5m).close(0) < $(5m).MA(20).value;          // 价格跌破均线
    CONSECUTIVE(5m).close(3).falling();                // 连续3期下跌
} = SELL;
```

## 完整策略示例

以下是一个完整的交易策略示例，包含完整的止盈止损管理：

```javascript
// ==================== 变量定义 ====================
@ma20: Double = $(5m).MA(20).value;
@ma50: Double = $(5m).MA(50).value;
@rsi: Double = $(5m).RSI().value;
@macd_histogram: Double = $(5m).MACD().histogram;
@atr: Double = $(5m).ATR().value;
@current_price: Double = KLINE(5m).close();

// ==================== 买入条件 ====================
// 金叉策略：短期均线上穿长期均线（带止盈止损）
ALL{
    CROSS(5m).close(@ma20).above;
    @ma20 > @ma50;
    @rsi < 60;
} = BUY(
    @current_price + @atr * 2.5,  // 止盈：当前价 + 2.5倍ATR
    @current_price - @atr * 1.5   // 止损：当前价 - 1.5倍ATR
);

// 多因子确认策略（带止盈止损）
ALL {
    KLINE(5m).close(0) > @ma20;                         // 价格在均线上方
    @macd_histogram > 0;                               // MACD 柱状图正值
    @rsi < 70;                                         // RSI 未超买
    KLINE(5m).volume(0) > AVERAGE(5m).volume(20) * 1.2; // 成交量放大
} = BUY(
    @current_price + @atr * 3.0,  // 强信号，更激进的止盈
    @current_price - @atr * 1.0   // 紧密止损
);

// ==================== 卖出条件 ====================
// 死叉策略：短期均线下穿长期均线（带止盈止损）
ALL{
    CROSS(5m).close(@ma20).below;
    @ma20 < @ma50;
    @rsi > 40;
} = SELL(
    @current_price - @atr * 2.5,  // 止盈：当前价 - 2.5倍ATR
    @current_price + @atr * 1.5   // 止损：当前价 + 1.5倍ATR
);

// 止损策略
ALL {
    KLINE(5m).close(0) < @ma20;                         // 价格跌破均线
    @rsi > 50;                                          // RSI 下降到中性区域
} = SELL(
    @current_price - @atr * 1.0,  // 快速止盈
    @current_price + @atr * 0.5  // 紧密止损
);
```

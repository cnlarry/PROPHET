# Prophet DSL 核心概念

本文档介绍了 Prophet DSL 的核心概念，帮助用户理解语言的基本原理和设计思想。

## 什么是 Prophet DSL

Prophet DSL（Domain Specific Language）是一种专门为量化交易策略开发设计的领域特定语言。它旨在让交易策略的编写变得更加直观和高效。

## 核心设计理念

### 1. 简洁性
Prophet DSL 致力于提供简洁明了的语法，让策略开发者能够专注于策略逻辑而非语言细节。

### 2. 表达力
通过丰富的内置函数和灵活的语法结构，Prophet DSL 能够表达复杂的交易策略。

### 3. 可读性
代码即文档，策略逻辑清晰易懂，便于团队协作和后期维护。

## 基本构成元素

### 信号函数
信号函数是 Prophet DSL 的核心，用于定义交易信号。每个交易信号都可以附带止盈止损价格，实现完整的风险管理：
```javascript
// 基础信号：只定义买入条件
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
  $(5m).RSI().value < 30;
} = BUY;

// 带止盈止损的信号：定义买入条件的同时指定止盈止损价格
ALL{
  KLINE(5m).close(0) > KLINE(5m).open(0);
  $(5m).RSI().value < 30;
} = BUY(
  KLINE(5m).close() + $(5m).ATR().value * 2.0,  // 止盈价格
  KLINE(5m).close() - $(5m).ATR().value * 1.5   // 止损价格
);
```

### 数据访问函数
用于获取市场数据：
```javascript
@current_price: Double = KLINE(5m).close(0);
@volume: Double = KLINE(5m).volume(0);
```

### 变量系统
支持变量定义和使用：
```javascript
@ma20: Double = $(5m).MA(20).value;
ALL{
  KLINE(5m).close(0) > @ma20;
} = BUY;
```

## 风险管理

Prophet DSL 内置了止盈止损机制，允许在生成交易信号的同时指定止盈和止损价格。这使策略开发者能够在策略层面就完成风险管理的设计，而不需要依赖外部系统。

**止盈止损的特点**：
- ✅ **与信号一体**：止盈止损是信号的一部分，逻辑清晰
- ✅ **动态计算**：可以使用任意表达式计算止盈止损价格
- ✅ **灵活配置**：支持只设置止盈、只设置止损，或两者都设置

## 执行模型

Prophet DSL 采用事件驱动的执行模型，每当有新的 K 线数据到达时，策略会被重新评估并产生相应的交易信号。每个信号都包含完整的交易信息：交易方向、止盈价格和止损价格。

## 最佳实践

1. 保持策略简洁
2. 充分利用内置函数
3. 合理使用变量提高可读性
4. 添加适当的注释

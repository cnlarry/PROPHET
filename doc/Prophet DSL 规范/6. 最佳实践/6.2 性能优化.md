## 1. 概述

本文档介绍如何优化 Prophet DSL 策略的性能，提高执行效率，减少资源消耗。

## 2. 计算优化

### 2.1 避免重复计算

使用变量存储重复使用的计算结果。

```javascript
// 不推荐：重复计算
ALL {
    $(5m).RSI().value > 70,
    $(5m).RSI().value < 80
} = SELL;

// 推荐：使用变量
@rsi_value = $(5m).RSI().value;
ALL {
    @rsi_value > 70,
    @rsi_value < 80
} = SELL;
```

### 2.2 简化数学运算

避免不必要的复杂计算。

## 3. 数据访问优化

### 3.1 合理使用指标

预配置常用指标参数，避免在DSL中重复指定。

### 3.2 减少历史数据访问

避免过多访问历史数据，特别是深度历史数据。

## 4. 条件判断优化

### 4.1 条件顺序优化

将最可能为假的条件放在前面，利用短路求值。

### 4.2 合理使用信号函数

选择合适的信号函数，避免过度复杂的逻辑组合。

## 5. 最佳实践

- 使用变量缓存计算结果
- 避免深层嵌套
- 合理设置指标参数
- 定期审查策略性能

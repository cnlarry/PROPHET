## 3. 日志输出

### 3.1 变量输出

使用 PRINT 函数输出变量值：

```javascript
@price = KLINE(5m).close();
PRINT("当前价格: ", @price);
```

### 3.2 条件输出

输出条件判断结果：

```javascript
@rsi_value = $(5m).RSI().value;
PRINT("RSI值: ", @rsi_value);
PRINT("RSI > 70: ", @rsi_value > 70);
```

### 5.2 性能问题

### 5.3 语法错误

- 检查括号匹配

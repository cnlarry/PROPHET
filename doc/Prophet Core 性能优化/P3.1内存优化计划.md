## 🎯 优化目标

### 当前问题

```cpp
// 当前实现（低效）
MACDResult calculate_MACD(...) {
    MACDResult result;
    result.macd.resize(length);      // 堆分配 #1
    result.signal.resize(length);    // 堆分配 #2
    result.histogram.resize(length); // 堆分配 #3
    
    // SIMD计算...
    
    return result;  // 3个vector拷贝（移动构造）
}

// 在Calculator中使用
auto simd_result = simd::calculate_MACD(...);  // 拷贝 #1
macd_line = simd_result.macd;       // vector拷贝 #2
signal_line = simd_result.signal;   // vector拷贝 #3
histogram = simd_result.histogram;  // vector拷贝 #4
```

**开销估算**（500根K线）：
- 内存分配：3次 × 500 × 8字节 = 12KB
- 内存拷贝：4次 × 500 × 8字节 = 16KB
- 总开销：28KB + 分配/释放时间

### 优化后（零拷贝）

```cpp
// 优化实现（高效）
void calculate_MACD(
    const double* prices,
    size_t length,
    int FAST_PERIOD,
    int SLOW_PERIOD,
    int SIGNAL_PERIOD,
    double* out_macd,      // 预分配缓冲区
    double* out_signal,    // 预分配缓冲区
    double* out_histogram  // 预分配缓冲区
) {
    // 直接写入out_*，零拷贝，零分配
}

// 在Calculator中使用
std::vector<double> macd_line(length);
std::vector<double> signal_line(length);
std::vector<double> histogram(length);

simd::calculate_MACD(
    close.data(), length,
    fast, slow, signal,
    macd_line.data(),    // 直接写入
    signal_line.data(),  // 直接写入
    histogram.data()     // 直接写入
);
```

**优化效果**：
- 内存分配：0次（预分配）
- 内存拷贝：0次（直接写入）
- 总开销：0KB

## 🔧 技术细节

### 零拷贝设计原则

1. **预分配缓冲区**
   ```cpp
   std::vector<double> buffer(length);  // 调用者负责分配
   calculate_XXX(..., buffer.data());   // 直接写入
   ```

2. **避免返回大对象**
   ```cpp
   void calculate_XXX(..., double* out);  // 返回void
   ```

3. **允许NULL输出**
   ```cpp
   void calculate_RSI(
       ...,
       double* out_rsi,      // 必需
       double* out_avg_gain, // 可选，传nullptr跳过
       double* out_avg_loss  // 可选，传nullptr跳过
   );
   ```

### 向后兼容

```cpp
// 新接口：零拷贝
void calculate_MACD(..., double* out1, double* out2, double* out3);

// 旧接口：便捷（内部调用新接口）
inline MACDResult calculate_MACD(...) {
    MACDResult result;
    result.macd.resize(length);
    result.signal.resize(length);
    result.histogram.resize(length);
    calculate_MACD(..., result.macd.data(), ...);
    return result;
}
```

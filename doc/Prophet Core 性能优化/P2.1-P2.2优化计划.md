### **优化1: VM栈复用** (预期 +3-5%)

**当前问题**:
- 每次`execute()`都清空栈 (`stack_.clear()`)
- 频繁的vector resize/realloc

**优化方案**:
```cpp
class BytecodeVM {
private:
    std::vector<Value> stack_;
    size_t stack_top_;  // 栈顶指针
    
public:
    void reset() {
        stack_top_ = 0;  // 不清空，只重置指针
    }
    
    void push(const Value& v) {
        if (stack_top_ >= stack_.size()) {
            stack_.push_back(v);
        } else {
            stack_[stack_top_] = v;
        }
        stack_top_++;
    }
    
    Value pop() {
        return stack_[--stack_top_];
    }
};
```

**收益**:
- 消除vector清空/重分配
- 减少内存分配次数
- 提升缓存命中率

**常见模式**:
```
Pattern 1: LOAD + LOAD + CMP
  LOAD_INDICATOR x
  LOAD_CONST y

Pattern 2: LOAD + LOAD + ADD
  LOAD_INDICATOR x
  LOAD_INDICATOR y
  ADD
  
  → ADD_INDICATORS x, y  (融合指令)
```

**实现**:
1. 编译器识别常见模式
2. 生成融合指令
3. VM实现融合指令执行

**收益**:
- 减少指令数量
- 减少栈操作
- 提升指令缓存效率

### **简化方案**: 不使用完整JIT，而是"伪JIT"

**思路**: 将热点指令序列预编译为C++函数指针

```cpp
// 传统JIT: 字节码 → 机器码
// 简化方案: 字节码 → C++模板函数

template<typename T>
using JITFunc = std::function<Value(Context&)>;

// 预编译常见模式
JITFunc<void> compile_rsi_lt_30 = [](Context& ctx) {
    Value rsi = ctx.getOrCalculateIndicator("5m", "RSI").get("value");
    return Value::fromBoolean(rsi.toNumber() < 30.0);
};
```

### **优化1: 热点检测** (基础设施)

**实现**:
```cpp
class BytecodeVM {
private:
    std::unordered_map<size_t, size_t> hotspot_counter_;  // 规则ID → 执行次数
    size_t jit_threshold_ = 100;  // JIT触发阈值
    
public:
    Value execute(const std::vector<Instruction>& code, Context& ctx) {
        size_t rule_id = get_rule_id(code);
        hotspot_counter_[rule_id]++;
        
        if (hotspot_counter_[rule_id] >= jit_threshold_) {
            // 触发JIT编译
            auto jit_func = jit_compile(code);
            if (jit_func) {
                return jit_func(ctx);  // 使用JIT版本
            }
        }
        
        // 正常字节码执行
        return execute_bytecode(code, ctx);
    }
};
```

### **优化2: 模式匹配JIT** (核心)

**识别可JIT的模式**:
```cpp
enum class JITPattern {
    INDICATOR_CMP_CONST,    // $(5m).RSI().value < 30
    INDICATOR_CMP_INDICATOR, // $(5m).MACD().histogram > $(5m).MACD().signal
    SIMPLE_ALL,              // ALL{cond1, cond2}
    SIMPLE_ANY,              // ANY{cond1, cond2}
};

class JITCompiler {
    JITFunc<void> compile(const std::vector<Instruction>& code) {
        auto pattern = detect_pattern(code);
        
        switch (pattern) {
            case JITPattern::INDICATOR_CMP_CONST:
                return compile_indicator_cmp_const(code);
            case JITPattern::SIMPLE_ALL:
                return compile_simple_all(code);
            // ... 更多模式
        }
        
        return nullptr;  // 不支持JIT
    }
    
private:
    JITFunc<void> compile_indicator_cmp_const(const std::vector<Instruction>& code) {
        // 解析参数
        std::string tf = extract_timeframe(code[0]);
        std::string indicator = extract_indicator(code[0]);
        std::string field = extract_field(code[0]);
        double threshold = extract_const(code[1]);
        Opcode cmp_op = code[2].opcode;
        
        // 返回优化后的lambda
        return [=](Context& ctx) {
            auto result = ctx.getOrCalculateIndicator(tf, indicator);
            double value = result.get(field).toNumber();
            
            switch (cmp_op) {
                case Opcode::LT: return Value::fromBoolean(value < threshold);
                case Opcode::GT: return Value::fromBoolean(value > threshold);
                // ... 更多比较
            }
        };
    }
};
```

## 🔬 **P3.1零拷贝设计**

### **优化原理**

当前SIMD指标函数返回包含多个`std::vector`的结构体，虽然有RVO（返回值优化），但仍有以下开销：

1. **多次内存分配**: 每次调用都需要resize 3个vector
2. **结构体复制**: RVO并非总是生效
3. **缓存不友好**: 分散的内存分配

**零拷贝方案**: 调用者预分配缓冲区，SIMD函数直接写入

```cpp
// P3.1零拷贝版本
void calculate_RSI_zerocopy(
    const double* prices,
    size_t length,
    int PERIOD,
    double* out_rsi,        // 预分配缓冲区
    double* out_avg_gain,   // 可选
    double* out_avg_loss    // 可选
) {
    // 直接写入out_*，零拷贝，零分配
}
```

### **预期收益**

**假设**:
- 当前SIMD调用开销: ~2-3μs（内存分配+RVO）
- 零拷贝后: ~0.5μs
- 节省: ~2μs

**影响**:
- 当前单策略评估时间: 13.66μs
- 零拷贝后: 11.66μs
- **提升**: 73,236 → 85,000+ ops/s (+16%!)

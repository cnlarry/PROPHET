## 💡 SIMD向量化原理

### 什么是SIMD？

**SIMD** = Single Instruction, Multiple Data（单指令多数据）

传统计算（标量）:
```cpp
// 计算4个数的和：需要4次加法
result[0] = a[0] + b[0];  // 1次加法
result[1] = a[1] + b[1];  // 1次加法
result[2] = a[2] + b[2];  // 1次加法
result[3] = a[3] + b[3];  // 1次加法
// 总计：4条指令
```

SIMD计算（向量）:
```cpp
// 计算4个数的和：只需1次向量加法
__m256d va = _mm256_load_pd(a);      // 加载4个double
__m256d vb = _mm256_load_pd(b);      // 加载4个double
__m256d vr = _mm256_add_pd(va, vb);  // 1次向量加法 = 4次标量加法
_mm256_store_pd(result, vr);         // 存储4个double
// 总计：1条指令（4倍加速）
```

### AVX2指令集

Intel AVX2（Advanced Vector Extensions 2）:
- 256位寄存器（可存储4个double或8个float）
- 一条指令处理4-8个数据
- 理论加速比：4-8倍

## 📋 优化范围

### 优先级P0：核心指标（Week 1-2）

#### 1. 简单移动平均（SMA）
```cpp
// 当前实现（标量）
for (int i = 0; i < length; i++) {
    double sum = 0;
    for (int j = 0; j < PERIOD; j++) {
        sum += prices[i + j];
    }
    sma[i] = sum / PERIOD;
}

// SIMD实现（向量化）
__m256d vsum = _mm256_setzero_pd();
__m256d vperiod = _mm256_set1_pd(PERIOD);
for (int i = 0; i < length; i += 4) {
    // 向量化累加
    for (int j = 0; j < PERIOD; j++) {
        __m256d vprices = _mm256_loadu_pd(&prices[i + j]);
        vsum = _mm256_add_pd(vsum, vprices);
    }
    // 向量化除法
    __m256d vsma = _mm256_div_pd(vsum, vperiod);
    _mm256_storeu_pd(&sma[i], vsma);
    vsum = _mm256_setzero_pd();
}
```

        const std::vector<double>& prices,
        int PERIOD
    ) {
        if (simd::Config::instance().isEnabled() &&
            simd::Config::instance().features().has_avx2) {
            // SIMD路径
            return calculateSMA_SIMD(prices, PERIOD);
        } else {
            // 标量回退路径
            return calculateSMA_Scalar(prices, PERIOD);
        }
    }

        const std::vector<double>& prices,
        int PERIOD
    );

        const std::vector<double>& prices,
        int PERIOD
    );
};

## ⚠️ 技术挑战与解决方案

### 挑战1: 串行依赖（EMA）

**问题**: EMA依赖前一个值
```cpp
EMA[i] = price[i] * α + EMA[i-1] * (1-α)
```

**解决方案**:
1. **分块处理**: 每4个数据一组，块内串行，块间可优化
2. **预计算**: 批量计算 α 的幂次
3. **混合方案**: 串行计算+向量化乘法

### 挑战2: 数据对齐

**问题**: SIMD要求内存对齐（16字节或32字节）

**解决方案**:
```cpp
// 使用对齐分配
alignas(32) double data[1000];

// 或使用非对齐加载/存储
__m256d v = _mm256_loadu_pd(data);  // 非对齐加载
```

### 挑战3: 边界处理

**问题**: 数据长度不是4的倍数

**解决方案**:
```cpp
// 向量化主循环
for (size_t i = 0; i < length - 3; i += 4) {
    // SIMD处理
}

// 标量处理剩余元素
for (size_t i = length - (length % 4); i < length; i++) {
    // 标量处理
}
```

### 挑战4: CPU兼容性

**解决方案**:
- 运行时检测CPU特性
- 提供标量回退路径
- 编译时条件编译

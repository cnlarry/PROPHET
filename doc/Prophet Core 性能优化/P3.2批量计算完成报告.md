## 📊 **技术架构**

### **核心类：BatchEngine**

```cpp
class BatchEngine {
public:
    BatchEngine(size_t num_threads = 0);  // 0=自动
    
    // 批量评估（多策略，共享K线）
    std::vector<Signal> evaluateBatch(
        std::vector<std::unique_ptr<Engine>>& engines,
        const KlineDataView& klines,
        bool parallel = true
    );
    
    // 获取线程数
    size_t getNumThreads() const;
};
```

### **零拷贝K线视图**

```cpp
struct KlineDataView {
    const double* open;
    const double* high;
    const double* low;
    const double* close;
    const double* volume;
    const int64_t* open_time;
    const int64_t* close_time;
    size_t count;
};
```

**优势**:
- 避免大量K线数据复制
- 多线程共享只读数据
- 内存占用最小化

### **并行评估机制**

```cpp
// std::async异步执行
for (size_t i = 0; i < total_tasks; ++i) {
    futures.push_back(std::async(std::launch::async,

            engines[i]->SetKlines(...);
            return engines[i]->getSignal(current_price, current_time);
        }
    ));
}

// 收集结果
for (auto& future : futures) {
    results.push_back(future.get());
}
```

## ⚠️ **技术挑战与解决方案**

### **挑战1: Python GIL (Global Interpreter Lock)**

**问题**: Python的GIL限制多线程并行

**解决方案**:
- C++层面释放GIL：`py::gil_scoped_release release;`
- 确保所有计算在C++层完成
- Python仅负责调度和结果收集

### **挑战2: Engine实例共享**

**问题**: 每个线程需要独立的Engine实例

**当前方案**:
- 要求Python端预先创建多个Engine
- 每个Engine独立加载相同的规则

**优化方案** (TODO):
- 实现Engine::clone()方法
- 共享规则AST/字节码
- 仅复制Context状态

### **挑战3: 内存开销**

**问题**: 多个Engine实例占用大量内存

**解决方案**:
- 规则共享（AST/字节码只编译一次）
- K线数据零拷贝（KlineDataView）
- 缓存按需分配

### **挑战4: 负载均衡**

**问题**: 不同策略计算时间不同

**当前方案**:
- `std::async`自动调度
- 操作系统线程池管理

**未来优化** (TODO):
- 工作窃取算法
- 动态任务分配

```python
strategies = [strategy1, strategy2, ..., strategy10]

for i, (engine, dsl) in enumerate(zip(engines, strategies)):
    engine.load_rules(dsl)

# 并行评估
batch_engine = Core.BatchEngine(8)
signals = batch_engine.evaluate_batch(engines, klines_data, parallel=True)

# 性能对比

# 并行: 16 μs (8核)
# 加速: 8.5x
```

### **场景2: 实盘多币种监控**

```python
# 100个币种，同一策略
symbols = ['BTCUSDT', 'ETHUSDT', ..., 'SOLUSDT']  # 100个
engines = [create_engine(strategy_dsl) for _ in range(100)]

# 分批并行评估 (每批8个)
for i in range(0, 100, 8):
    batch_engines = engines[i:i+8]
    batch_klines = [get_klines(sym) for sym in symbols[i:i+8]]
    signals = batch_engine.evaluate_batch_multi_klines(
        batch_engines, batch_klines, parallel=True
    )

# 总耗时: 100/8 × 16 μs = 200 μs
# vs 串行: 100 × 13.66 μs = 1,366 μs
# 加速: 6.8x
```

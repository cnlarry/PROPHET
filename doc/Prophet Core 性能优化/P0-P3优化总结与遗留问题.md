### 遗留问题

#### 问题1：Session Cache性能损失 ⚠️

**现象**：
```
P1基准: 27,041 ops/s
P2实际: 20,764 ops/s (-23%)
```

**原因**：
- 简单策略下，session cache的初始化/清理开销 > 缓存收益
- 即使智能启用/禁用后，仍有轻微性能损失

**解决方案**（待实施）：
1. 更精细的启用条件判断
2. 延迟初始化session cache
3. 或完全移除session cache（待评估）

#### 问题2：字节码编译未实现 ⚠️

**影响**：
- 无法获得字节码编译的性能收益（预期+30-50%）
- P2优化未完全达成目标

**推迟原因**：
- 字节码编译工作量大（2-3周）
- P3 SIMD优化优先级更高
- 字节码收益需要实现后才能验证

**待办任务**（记录在`doc/字节码编译待办任务.md`）：
```
1. BytecodeCompiler实现
   - compile_node()
   - compile_expression()
   - compile_statement()
   
2. BytecodeVM实现
   - 栈式虚拟机
   - 指令执行
   - 函数调用
   
3. Context集成
   - evaluateBytecode()
   - 字节码缓存
   
4. 性能测试
   - 对比AST解释执行
   - 验证30-50%提升
```

**建议**：
- 等P3完全完成后（包括P3.1-P3.4）
- 或等明确需要字节码优化时再实施

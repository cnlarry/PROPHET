// Prophet.Core/src/bytecode/compiler.cpp
std::vector<Instruction> BytecodeCompiler::compile(const dsl::ASTNodePtr& condition) {
    code_.clear();
    compile_node(condition);
    emit(Opcode::RETURN);
    return code_;
}
```

// Prophet.Core/src/bytecode/vm.cpp
Value BytecodeVM::execute(const std::vector<Instruction>& code, dsl::Context& context) {
    while (ip_ < code.size()) {
        const auto& inst = code[ip_];
        switch (inst.opcode) {
            case Opcode::ADD: exec_add(); break;
            case Opcode::LOAD_INDICATOR: exec_load_indicator(inst, context); break;
            // ... 更多指令
        }
        ip_++;
    }
    return pop();
}
```

**性能优化**:

- 内联栈操作 (push/pop)
- 最小化分支预测失败

## 🎯 **优化效果分析**

### **为什么字节码更快？**

#### **1. 消除AST遍历开销**
- **AST评估**: 每次都要递归遍历树形结构
- **字节码评估**: 线性指令序列，CPU缓存友好

#### **2. 减少函数调用**
- **AST评估**: 每个节点一次虚函数调用
- **字节码评估**: switch-case分发，内联优化

#### **3. 编译时优化**
- **AST评估**: 运行时解释执行
- **字节码评估**: 编译时做类型检查和常量折叠

#### **4. 数据局部性**
- **AST评估**: 指针跳转，缓存不友好
- **字节码评估**: 顺序执行，缓存命中率高

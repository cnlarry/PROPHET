```
├─ parameters_              ├─ ParameterStore (独立)
└─ klines_                  └─ KlineManager (独立)
```

**关键成果**:
- 模块化设计
- 线程安全保证
- 可维护性提升

### **P3: SIMD向量化** (30,644 ops/s, +104%)
**实施内容**:
- CPU特征检测 (SSE2/AVX/AVX2/AVX-512)
- SIMD数学库 (add/mul/mean/stddev)
- SIMD指标 (SMA/EMA/RSI/MACD/BBANDS)
- Calculator自动集成

**性能对比** (MACD计算，1000根K线):
| 实现 | 耗时 | 加速比 |
|------|------|--------|
| TA-Lib | ~150 μs | 1x |
| SIMD | ~45 μs | 3.3x |

**关键代码**:
```cpp
// AVX2: 8个double并行计算
__m256d sum_vec = _mm256_setzero_pd();
for (size_t i = 0; i < count; i += 4) {
    __m256d data = _mm256_loadu_pd(prices + i);
    sum_vec = _mm256_add_pd(sum_vec, data);
}
```

---

### **P2: 字节码编译** (38,314 ops/s, +155%)
**实施内容**:
- BytecodeCompiler (23种指令)
- BytecodeVM (栈式架构)
- 自动编译DSL→字节码
- 编译失败自动回退AST

**字节码示例**:
```
DSL:     $(5m).RSI().value < 30
Bytecode:
  0: LOAD_INDICATOR 5m|RSI|value
  1: LOAD_CONST 30.0
  2: LT
  3: RETURN
```

**优势**:
- 消除AST递归遍历
- 减少虚函数调用
- 提升CPU缓存命中率

---

### **P2.1.1: VM栈复用** (43,478 ops/s, +190%, 不稳定环境)
**实施内容**:
- 使用`stack_top_`指针，避免`vector::clear()`
- 预分配栈空间 32→64元素
- 复用内存，减少分配

**关键代码**:
```cpp
// 之前：每次清空栈
stack_.clear();  // 调用析构，释放内存

// 之后：只重置指针
stack_top_ = 0;  // 保留已分配内存
```

**为什么效果好？**:
1. 消除Value析构（包含std::string）
2. 消除vector realloc
3. 提升内存局部性

### **P2.2: 简化JIT** (73,236 ops/s, +388%, 固定环境)
**实施内容**:
- 模式识别引擎
- Lambda函数生成器
- 三级评估：JIT → 字节码 → AST

**关键发现**:

| 测试环境 | P2.1.1 | P2.2 | 提升 |
|----------|--------|------|------|
| **不稳定** | 43,478 ops/s | 35,971 ops/s | -17% ❌ 误判 |
| **固定** | ~38,300 ops/s | **73,236 ops/s** | **+91%** ✅ 真实 |

**教训**: **测试环境的稳定性至关重要！**

**JIT模式示例**:
```cpp
// 模式：$(5m).RSI().value < 30
auto jit_func = [](Context& ctx) -> bool {
    // 直接访问，跳过字节码VM
    auto result = ctx.getOrCalculateIndicator("5m", "RSI");
    double value = result.get("value").toNumber();
    return value < 30.0;
};
```

**优势**:
- 跳过字节码VM循环
- 编译器内联优化
- 直接内存访问

## 🔬 **关键技术突破**

### **1. 测试环境的决定性影响** ⭐⭐⭐⭐⭐

**发现**: P2.2从"失败"到"成功"，完全因为测试环境

**不稳定环境问题**:
- CPU频率动态调整（省电→高性能）
- 缓存冷启动
- 后台进程干扰
- 性能波动高达200%+

**固定环境方案**:
```powershell
# setup_test_environment.ps1
powercfg /setactive 8c5e7fda-e8bf-4a96-9a85-a6e23a8c635c  # 高性能
powercfg /setacvalueindex ... /001 100  # CPU最小100%
powercfg /setacvalueindex ... /002 100  # CPU最大100%
```

**结果**:
- 性能稳定可重复
- CV从42.7%降至5.7%
- 避免了P2.2和P3.1的误判

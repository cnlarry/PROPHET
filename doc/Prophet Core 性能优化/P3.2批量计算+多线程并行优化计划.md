## 🏗️ **设计方案**

### **核心思想**

1. **批量API**: 一次提交多个评估任务
2. **线程池**: 利用多核CPU并行计算
3. **零拷贝共享**: K线数据在线程间共享
4. **结果收集**: 线程安全的结果队列

### **Phase 2: 线程池实现** (1.5小时)

```cpp
// Prophet.Core/src/strategy/batch_engine.cpp

#include "prophet/strategy/batch_engine.hpp"
#include <algorithm>

namespace prophet::strategy {

BatchEngine::BatchEngine(size_t num_threads) {
    if (num_threads == 0) {
        num_threads_ = std::thread::hardware_concurrency();
    } else {
        num_threads_ = num_threads;
    }
}

BatchEngine::~BatchEngine() {
    // 清理资源
}

std::vector<Signal> BatchEngine::evaluateBatch(
    const std::vector<std::unique_ptr<Engine>>& engines,
    const std::vector<KlineDataView>& klines_batch,
    bool parallel
) {
    if (!parallel || engines.size() <= 1) {
        return evaluate_serial(engines, klines_batch);
    }
    
    return evaluate_parallel(engines, klines_batch);
}

std::vector<Signal> BatchEngine::evaluate_serial(
    const std::vector<std::unique_ptr<Engine>>& engines,
    const std::vector<KlineDataView>& klines_batch
) {
    std::vector<Signal> results;
    results.reserve(engines.size());
    
    for (size_t i = 0; i < engines.size(); ++i) {
        const auto& klines = klines_batch[i % klines_batch.size()];
        
        // 设置K线
        engines[i]->SetKlines(
            klines.open, klines.high, klines.low, klines.close,
            klines.volume, klines.open_time, klines.close_time, klines.count
        );
        
        // 评估
        double current_price = klines.close[klines.count - 1];
        int64_t current_time = klines.close_time[klines.count - 1];
        
        results.push_back(engines[i]->get_signal(current_price, current_time));
    }
    
    return results;
}

std::vector<Signal> BatchEngine::evaluate_parallel(
    const std::vector<std::unique_ptr<Engine>>& engines,
    const std::vector<KlineDataView>& klines_batch
) {
    size_t total_tasks = engines.size();
    std::vector<std::future<Signal>> futures;
    futures.reserve(total_tasks);
    
    // 分发任务到线程池
    for (size_t i = 0; i < total_tasks; ++i) {
        futures.push_back(std::async(std::launch::async, [&, i]() {
            const auto& klines = klines_batch[i % klines_batch.size()];
            
            // 设置K线
            engines[i]->SetKlines(
                klines.open, klines.high, klines.low, klines.close,
                klines.volume, klines.open_time, klines.close_time, klines.count
            );
            
            // 评估
            double current_price = klines.close[klines.count - 1];
            int64_t current_time = klines.close_time[klines.count - 1];
            
            return engines[i]->get_signal(current_price, current_time);
        }));
    }
    
    // 收集结果
    std::vector<Signal> results;
    results.reserve(total_tasks);
    
    for (auto& future : futures) {
        results.push_back(future.get());
    }
    
    return results;
}

} // namespace prophet::strategy
```

## ⚠️ **技术挑战**

### **1. 线程安全**

**问题**: Engine内部状态共享
**方案**: 
- 每个线程独立Engine实例
- Context不共享（已实现thread_local）

### **2. 内存开销**

**问题**: 多个Engine实例占用大量内存
**方案**:
- 规则DSL共享（只编译一次）
- K线数据视图（零拷贝）
- 缓存按需分配

### **3. 负载均衡**

**问题**: 某些策略计算慢，导致线程空闲
**方案**:
- 动态任务分配
- 工作窃取算法

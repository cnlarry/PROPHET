## 🎯 核心功能对比

### Panda QuantFlow 核心功能

1. **可视化工作流系统**
   - 节点式编程（类似Node-RED）
   - 工作流JSON导入导出
   - 自定义插件系统（@work_node装饰器）
   - 超级图表可视化

2. **因子分析与研究**
   - 兼容PandaFactor分析框架
   - 因子挖掘和验证
   - 因子回测

3. **机器学习集成**
   - XGBoost、LightGBM、RandomForest、SVM
   - 神经网络支持
   - 多任务学习(MTL)
   - 自动化模型训练和验证

4. **回测系统**
   - 事件驱动架构
   - 支持股票、期货
   - 高性能回测引擎
   - 精确模拟真实交易环境

5. **企业级服务**
   - FastAPI REST API
   - 多用户工作流管理
   - 权限控制
   - 分布式任务执行
   - 实时监控和日志系统

6. **数据支持**
   - MongoDB数据库（含行情数据）
   - 需要PandaFactor服务支持

### Prophet 核心功能

1. **DSL策略开发**
   - 自定义DSL语言（Prophet DSL）
   - Monaco代码编辑器（VS Code核心）
   - 语法高亮和智能提示
   - 62个技术指标支持
   - 48个系统函数
   - 61种K线形态识别

2. **策略回测与优化**
   - C++高性能回测引擎（比Python快40-60倍）
   - 参数优化（网格搜索、贝叶斯优化、遗传算法等）
   - 性能指标分析（收益率、夏普比率、最大回撤等）
   - TradingView专业K线图表

3. **实盘交易**
   - 交易所API集成（Binance、OKX、Bybit等）
   - 订单管理
   - 实时监控
   - 风险控制（仓位限制、止损止盈）

4. **策略市场**
   - 策略分享和订阅
   - 策略创作者收益分成
   - 策略评价系统

5. **区块链集成**
   - BEP20钱包登录（MetaMask、Trust Wallet等）
   - PEC代币支付
   - 智能合约自动分成
   - 策略NFT化（可选）

## 🏗️ 技术架构对比

### Panda QuantFlow 技术栈

#### 前端
- **技术**: JavaScript 90% + Python 10%
- **UI**: Web界面（超级图表、工作流编辑器）
- **访问方式**: 浏览器访问（http://127.0.0.1:8000/）

#### 后端
- **框架**: FastAPI（Python）
- **数据库**: MongoDB（含行情数据）
- **架构**: 微服务架构、插件化设计
- **部署**: Docker + Docker Compose

#### 依赖服务
- **PandaFactor**: 因子分析服务（需要单独启动）
- **MongoDB**: 数据库服务（需要单独启动）

#### 核心特性
- **插件系统**: 通过`@work_node`装饰器开发自定义节点
- **工作流**: JSON格式导入导出
- **机器学习**: 集成主流ML算法

### Prophet 技术栈

#### 前端（Prophet.Client）
- **UI框架**: Avalonia UI 11.x（跨平台.NET UI框架）
- **编程语言**: C# 12 (.NET 8)
- **架构模式**: MVVM (Prism)
- **代码编辑器**: Monaco Editor（VS Code核心）
- **图表库**: TradingView Lightweight Charts
- **数据库**: SQLite + EF Core
- **产品形态**: 桌面应用（Windows/macOS/Linux）

#### 后端（Prophet.Core）
- **核心引擎**: C++（高性能策略执行引擎）
- **性能**: 比Python版本快40-60倍
- **指标库**: TA-Lib（业界标准技术分析库）
- **指标计算**: 5-25微秒/次
- **Python绑定**: PyBind11（用于优化算法）

#### API服务（Prophet.API）
- **框架**: ASP.NET Core
- **语言**: C#
- **数据库**: MySQL

#### 其他组件
- **优化算法**: Python.NET + Optuna/scikit-optimize
- **区块链**: Nethereum + WalletConnect.NET
- **文档系统**: HTML帮助系统（Prophet.Help）

## 📝 总结

### 核心区别

1. **策略开发方式**
   - **Panda QuantFlow**: 可视化工作流（节点式），适合非编程用户
   - **Prophet**: DSL代码式，适合开发者

2. **目标市场**
   - **Panda QuantFlow**: 股票、期货（传统金融市场）
   - **Prophet**: 加密货币（数字货币市场）

3. **技术重点**
   - **Panda QuantFlow**: 可视化工作流、机器学习集成、因子分析
   - **Prophet**: C++高性能引擎、DSL语言、区块链集成

4. **产品形态**
   - **Panda QuantFlow**: Web应用（浏览器访问）
   - **Prophet**: 桌面应用（安装包）

5. **开源程度**
   - **Panda QuantFlow**: 完全开源（AGPL-3.0）
   - **Prophet**: 私有项目

### 相似之处

- 两者都是量化交易平台
- 都支持策略回测
- 都提供可视化界面
- 都支持自定义扩展（Panda QuantFlow通过插件，Prophet通过DSL函数）
- 都规划了实盘交易功能

### 适用场景

**选择 Panda QuantFlow 如果：**
- 需要可视化工作流开发策略
- 专注于因子研究和机器学习
- 交易股票、期货等传统资产
- 需要企业级多用户管理
- 偏好开源解决方案

**选择 Prophet 如果：**
- 偏好代码式策略开发（DSL）
- 专注于加密货币交易
- 需要极致性能（C++引擎）
- 需要区块链集成（钱包、代币）
- 需要策略市场功能

### 结论

**Panda QuantFlow 和 Prophet 都是量化交易平台，但定位不同**：

- **Panda QuantFlow**: 面向传统金融市场的可视化工作流平台，强调因子研究和机器学习
- **Prophet**: 面向加密货币市场的代码式策略平台，强调高性能和区块链集成

两者在开发方式、目标市场、技术重点等方面有显著差异，适合不同的用户群体和使用场景。

# Prophet DSL 代码生成检查清单

## ⚠️ 生成代码前的自检清单（必须遵守！）

在生成DSL代码前，请务必检查以下几点：

### 1. 自定义函数参数类型检查
- [ ] 所有参数类型是否使用基础类型（Integer、Double、Boolean、String）？
- [ ] 是否避免使用枚举类型名称（如TrendType、CrossoverType）作为参数类型？

### 2. trend字段枚举值检查
- [ ] 所有指标的trend字段是否使用BULLISH/BEARISH/NEUTRAL？
- [ ] 是否避免对指标使用RISING/FALLING值？
- [ ] 只有FEARGREED()和FUNDINGRATE()的trend()方法才使用RISING/FALLING/STABLE

### 3. 信号函数内容检查
- [ ] 信号函数内是否只包含条件表达式，没有变量定义？
- [ ] 是否所有变量定义都在自定义函数内部或策略顶层？

### 4. 变量声明检查
- [ ] 所有用户变量是否使用@前缀？
- [ ] 是否避免使用var、let等JavaScript关键字？

### 5. 信号类型检查
- [ ] 是否只使用BUY、SELL、HOLD三种信号类型？
- [ ] 是否避免使用ENTRY_LONG、EXIT_SHORT等不存在的信号？

### 6. 条件分隔符检查
- [ ] 所有条件是否使用分号`;`分隔，而不是逗号？
- [ ] 每个条件是否都以分号结尾（包括最后一个）？

### 7. 逻辑运算符检查
- [ ] 是否使用 OR/AND/NOT 关键字，而不是 ||/&&/! 符号？
- [ ] 所有逻辑运算是否使用关键字形式？

### 8. 枚举值检查
- [ ] 枚举值是否不加双引号？
- [ ] volatility、trend、crossover_type等字段是否直接使用枚举常量？

### 9. 数据函数访问检查
- [ ] 指标访问是否使用 $(tf) 前缀？
- [ ] 数据函数访问是否直接使用函数名，不带 $ 前缀？

### 10. 止盈止损检查
- [ ] 止盈止损是否设置在信号函数的返回值内？
- [ ] 格式是否正确：`ALL{} = BUY(tp, sl)`？

## 检查通过标准

所有检查项都必须通过（✓），才能生成代码。如果有任何一项不符合，请修正后再生成。

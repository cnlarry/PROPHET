# AI提示词配置说明

## 📋 概述

Prophet Client 的 AI 提示词系统现在支持从 Markdown 文档中加载提示词内容，无需重新编译即可修改AI的行为。

## 🗂️ 文件结构

```
Prophet.Client/Resources/AIPrompts/
├── AI策略生成提示词.md       # 策略生成的核心提示词（语法规则、示例等）
├── AI常见错误避免.md         # AI需要避免的常见错误列表
├── AI代码检查清单.md          # 生成代码前的检查清单
└── README.md                  # 本说明文档
```

## ✨ 主要特性

### 1. 灵活的配置管理
- **无需重新编译**：修改 MD 文档后，重启应用即可生效
- **版本控制友好**：MD 文档可以轻松进行版本管理和对比
- **易于维护**：使用熟悉的 Markdown 格式编写和修改提示词

### 2. 混合模式
- **静态内容**：从 MD 文档加载（语法规则、最佳实践、错误示例等）
- **动态内容**：从 DSLRules.yaml 自动生成（指标列表、函数签名、参数范围等）


## 📝 如何修改提示词

### 修改策略生成提示词

编辑 `AI策略生成提示词.md`，您可以修改：

- 系统角色定义
- 核心任务说明
- 语法规则和示例
- 止盈止损设置说明
- 自定义函数使用说明
- 运算符规则
- 最佳实践建议

**示例**：添加新的语法规则

```markdown
### 新增的语法规则

**自定义运算符：**
- ✅ 正确：使用标准运算符
- ❌ 错误：使用自定义符号
```

### 修改常见错误避免

编辑 `AI常见错误避免.md`，添加新的错误类型：

```markdown
### 错误12：使用不支持的功能

- ❌ 错误：`someUnsupportedFunction()`
- ✅ 正确：使用支持的替代方案
- **原因**：说明为什么不支持
```

### 修改检查清单

编辑 `AI代码检查清单.md`，添加新的检查项：

```markdown
### 11. 新功能检查
- [ ] 是否使用了最新的语法特性？
- [ ] 是否符合新的规范要求？
```

## 🔄 应用修改

### 方法1：重启应用
1. 修改 MD 文档
2. 保存文件
3. 重启 Prophet Client
4. 新的提示词立即生效

### 方法2：清除缓存（推荐）
如果应用支持清除提示词缓存，可以不重启直接应用新配置。

## 🎯 最佳实践

### 1. 保持结构清晰
- 使用 Markdown 标题层级组织内容
- 使用代码块展示示例
- 使用列表列举规则

### 2. 提供充足的示例
```markdown
✅ 正确示例：
\`\`\`dsl
// 展示正确的用法
\`\`\`

❌ 错误示例：
\`\`\`dsl
// 展示错误的用法
\`\`\`
```

### 3. 使用醒目的标记
- ✅ 表示正确
- ❌ 表示错误
- ⚠️ 表示警告
- 📌 表示重点

### 4. 保持简洁明了
- 避免冗长的描述
- 重点突出关键规则
- 使用简短的代码示例

## 🔍 调试技巧

### 查看加载日志
应用启动时会在控制台输出加载信息：

```
[PromptTemplates] 成功加载提示词文件: AI策略生成提示词.md (路径: ...)
[PromptTemplates] 成功加载提示词文件: AI常见错误避免.md (路径: ...)
[PromptTemplates] 成功加载提示词文件: AI代码检查清单.md (路径: ...)
```

如果文件缺失，应用会抛出 `FileNotFoundException` 异常并显示详细的错误信息，包括搜索的所有路径。这确保您能够及时发现配置问题。

### 查看完整提示词
在开发者模式下，可以输出完整的提示词内容进行检查。

## ⚠️ 注意事项

### 1. 文件编码
- 必须使用 **UTF-8** 编码
- 确保文件中的中文字符正确显示

### 2. Markdown 格式
- 遵循标准 Markdown 语法
- 代码块必须指定语言（如 `dsl`）
- 避免使用特殊的 Markdown 扩展

### 3. 与 DSLRules.yaml 的关系
- MD 文档：描述性的规则说明、示例、最佳实践
- DSLRules.yaml：结构化的规则定义，用于自动生成指标、函数列表

### 4. 不要修改动态生成的部分
以下内容由系统自动生成，**无法**通过修改 MD 文档改变：
- 指标列表和签名
- 函数列表和签名
- 环境变量列表
- 枚举值列表

这些内容来自 `DSLRules.yaml`，修改它们需要编辑 YAML 文件并可能需要代码配合。

## 📚 示例场景

### 场景1：添加新的逻辑运算符说明
用户反馈AI生成了使用 `||` 的代码，您可以在 `AI常见错误避免.md` 中添加：

```markdown
### 错误X：使用符号形式的逻辑运算符
- ❌ 错误：`condition1 || condition2`
- ✅ 正确：`condition1 OR condition2`
```

### 场景2：更新止盈止损设置方式
如果止盈止损的设置方式发生变化，编辑 `AI策略生成提示词.md`：

```markdown
### 止盈止损设置（v5.0新语法）
新版本支持更灵活的止盈止损设置...
```

### 场景3：添加新的检查项
在 `AI代码检查清单.md` 中添加新的验证步骤。
